KS / AUC / PSI / O/E Bad Ratio 完整指标学习卡

今日主题：不要把“排序能力”“客群漂移”“概率校准”混成一个问题。四个指标必须在同一监控框架里使用。

KS｜Kolmogorov-Smirnov Statistic｜KS值

1）指标是什么

一句大白话：在所有可能阈值里，模型把Bad与Good累计分布拉开得最远的那一点有多远。

2）为什么重要

KS衡量模型排序区分度，属于模型开发、验证和贷中持续监控指标。它帮助判断Score是否仍能把风险较高和较低的人区分开，但不直接说明PD是否预测准确，也不直接等于策略利润。

3）精确定义与公式

KS = max_t |CDF_Bad(t) − CDF_Good(t)|

Bad/Good定义、模型分数方向、样本成熟期和用户/订单口径必须固定。拒绝样本没有自然表现标签时，还需警惕Selection/Reject Bias。

4）如何看高低

通常更高表示排序区分度更强，但KS高不代表Calibration好，也不代表线上策略更赚钱。阈值变化、样本结构变化和Bad定义变化都会影响横向比较。

5）墨西哥现金贷案例七步法（模拟）

背景：首贷模型V5运行三个月，渠道C快速扩量。
数据：成熟样本18,000；KS 0.42→0.41；AUC 0.76→0.75；Approval 32%→33%；FPD7 15%→18%；渠道C占比18%→36%；渠道C PSI=0.28。
现象：KS几乎稳定，但业务风险明显恶化。
拆解：Channel×Score×Limit后，新增风险集中在渠道C低Score与高Limit组合。
根因：当前证据更支持“客群结构/额度映射变化”，而不是模型整体失去排序能力。是否需要重训仍需看Calibration和变量漂移。
决策：先限制渠道C边缘Score高额度，并对渠道C做独立Challenger；不因KS轻微下降就立即全量重训。
观察结果：未来两个成熟Vintage看KS/AUC、O/E、FPD7、EL与Contribution Margin。

6）诊断逻辑

①确认Bad定义/成熟度 → ②看全量KS → ③按Channel/Product/Vintage拆KS → ④看PSI/变量Missing → ⑤看O/E、Approval和EL。

7）策略动作

KS下降且PSI高：优先查客群/数据漂移；KS下降但PSI稳定：查变量、标签或模型老化；KS稳定而风险恶化：查Calibration、Cutoff、Limit和渠道结构。

8）常见误区

误区1：KS越高就一定利润越高。误区2：不同Bad定义直接比较。误区3：用未成熟样本计算。误区4：只报全量KS、不拆渠道。

9）推荐拆分维度

Channel、Campaign、Product、New/Repeat、Vintage、Score Band、Model Version、Strategy Version。

10）预警方式

使用同模型、同Bad定义、同成熟窗口的稳定历史做基线；黄/红灯阈值应来自内部波动和样本量，不使用所谓行业统一KS阈值。

11）与其他指标关系

Data/Population → PSI → KS/AUC → Lift/Bad Capture → Cutoff → Approval → FPD/EL → Profit。

12）小练习

KS从0.43降到0.41，但AUC稳定、PSI大幅上升、渠道结构变化明显。首先做什么？

答案：先做渠道/客群漂移和变量分布诊断，而不是直接宣布模型失效。

AUC｜Area Under ROC Curve｜ROC曲线下面积

1）指标是什么

大白话：随机拿一个Bad和一个Good，模型把Bad排得更高的概率有多大。

2）为什么重要

AUC是模型排序能力的整体指标，比单一Cutoff更全面，适合开发、OOT验证和持续监控。但它并不告诉你预测PD是否准确。

3）精确定义与公式

AUC = P(score_Bad > score_Good)（假设分数越高风险越高）

ROC由不同阈值下TPR与FPR组成。样本Bad定义、成熟窗口和Score方向必须固定。

4）如何看高低

通常越高排序越好，但高AUC可能只来自极端高/低风险段，而实际Cutoff附近改善很小；因此线上利润可能几乎不变。

5）墨西哥现金贷案例七步法（模拟）

背景：模型V6替换V5。
数据：V5 AUC=0.75，V6=0.79；同Approval=32%；FPD7 15.2%→14.9%；EL/Loan 165→162；Contribution Margin 88→89；Top10% Lift 3.0→3.6。
现象：AUC提升明显，但线上利润改善极小。
拆解：V6改善主要集中在Score最极端两端，实际审批Cutoff附近排序变化有限。
根因：模型统计性能改善并没有被策略Cutoff/Limit充分转化成业务价值。
决策：保留V6，但重新优化Cutoff和额度映射，而不是因为AUC提高就直接宣传“风险显著改善”。
观察结果：看Cutoff附近Bad Capture、Approval、EL和Contribution Margin。

6）诊断逻辑

①标签/成熟度 → ②AUC全量与分群 → ③Cutoff附近排序 → ④Calibration/OE → ⑤利润与风险成本。

7）策略动作

AUC下降：查数据/渠道/变量；AUC上升但业务不改善：优化策略映射；AUC稳定但实际Bad偏高：做Calibration分析。

8）常见误区

误区1：AUC就是PD准确度。误区2：AUC更高就一定可直接替换模型。误区3：不同Bad定义横比。误区4：只看开发集。

9）推荐拆分维度

OOT、Vintage、Channel、Product、New/Repeat、Score Range、Model Version。

10）预警方式

使用滚动成熟窗口比较OOT AUC，同时设置最小样本量；任何数值阈值都应基于内部基准与不确定性。

11）与其他指标关系

PSI/Data Drift → AUC/KS → Lift → Strategy Cutoff → Approval/Bad Capture → EL/Profit。

12）小练习

AUC从0.74升到0.78，但O/E从1.0恶化到1.4。模型是否更好？

答案：排序更好，但概率校准更差；不能只用AUC下结论。

PSI｜Population Stability Index｜群体稳定性指数

1）指标是什么

大白话：现在的Score/变量/客群分布和基准期相比变了多少。

2）为什么重要

PSI是客群/变量漂移的领先监控指标，可在Bad标签尚未成熟时提前发现渠道、设备、产品或数据供应商变化。

3）精确定义与公式

PSI = Σ (Actual_i − Expected_i) × ln(Actual_i / Expected_i)

分箱方式、Expected基准期、样本范围和缺失值处理必须固定；Score PSI、变量PSI和渠道结构变化应分开解释。

4）如何看高低

高只说明“分布变化大”，不说明风险一定变坏；如果高分用户增加，PSI也可能升高但风险改善。低PSI也不保证模型没问题，因为标签定义、数据语义或Calibration可能变化。

5）墨西哥现金贷案例七步法（模拟）

背景：渠道C换投放素材并引入新Android设备流量。
数据：全量Score PSI=0.11；渠道C PSI=0.31；Device Age变量PSI=0.38；渠道C FPD7 16%→24%；AUC渠道C 0.74→0.70。
现象：全量PSI看起来不严重，但单渠道发生显著漂移并伴随风险恶化。
拆解：Channel×Device×Score×Limit，发现低端Android、新设备、低Score占比明显增加。
根因：渠道/设备结构变化是强候选原因；仍需确认设备指纹算法和SDK版本没有同步变化。
决策：渠道C单独限量并做Challenger，排查设备变量；不全局重训。
观察结果：看渠道C PSI回落、AUC/KS、FPD7和EL。

6）诊断逻辑

①确认分箱/基准 → ②全量PSI → ③渠道/产品PSI → ④变量PSI和Missing → ⑤AUC/KS/Bad/OE。

7）策略动作

渠道漂移：降量/独立策略；数据漂移：修Vendor/字段；真实客群漂移：Recalibration/Challenger；仅PSI高但风险稳定：继续观察而非机械收紧。

8）常见误区

误区1：PSI高=坏账升。误区2：机械套0.1/0.25。误区3：不同分箱方式横比。误区4：只看Score PSI不看变量。

9）推荐拆分维度

Channel、Campaign、Device、Region、Product、Score、Core Variable、Vendor Version。

10）预警方式

内部建立稳定期分位基线，并加样本量门槛；黄/红灯与业务风险指标联动，不能单指标触发全量策略。

11）与其他指标关系

Population/Data Shift → PSI → AUC/KS/Calibration → Approval/Bad → EL。

12）小练习

PSI明显升高，但实际Bad下降。是否说明PSI“错了”？

答案：不是。PSI只描述分布变化，不描述方向；需要看客群到底往好还是往坏移动。

O/E Bad Ratio｜Observed / Expected Bad Ratio｜实际/预测坏账比

1）指标是什么

大白话：模型预计会坏多少，最后实际坏了多少，两者差多远。

2）为什么重要

O/E直接监控PD Calibration，是额度、EL、定价和利润预算的重要桥梁。排序模型可以AUC很高，但如果PD持续低估，经营预算仍会失真。

3）精确定义与公式

O/E = Observed Mature Bad Rate ÷ Average Predicted PD

Observed Bad与Predicted PD必须对应同一Default定义、预测窗口、观察窗口和样本。建议同时看全量O/E和Score Band O/E。

4）如何看高低

在口径一致前提下，O/E>1表示实际风险高于预测（模型低估风险），O/E<1表示实际风险低于预测（模型高估风险）。但过度高估也会导致额度和Approval保守。

5）墨西哥现金贷案例七步法（模拟）

背景：模型V5用于首贷PD和EL预算。
数据：平均Pred PD=13%；Observed Bad=17%；O/E=1.31；AUC=0.75稳定；渠道C O/E=1.62；低Score高Limit组O/E=1.78；EL/Loan预算145、实际信用损失178。
现象：模型仍能排序，但PD系统性低估，特别是渠道C。
拆解：Channel×Score×Limit×Vintage后，发现低Score高Limit段偏差最大。
根因：客群漂移与Calibration偏低并存；需要确认Bad标签和模型输入供应商没有变化。
决策：对渠道C/低Score做PD Overlay或Recalibration并降额度，保留模型重训Challenger。
观察结果：两个成熟Vintage后看O/E、EL Budget vs Actual、Approval和Margin。

6）诊断逻辑

①PD与Bad窗口一致性 → ②全量O/E → ③Score Band O/E → ④Channel/Vintage → ⑤PSI/AUC/KS/EL偏差。

7）策略动作

O/E高但AUC稳定：Recalibration/Overlay；O/E高且AUC下降：评估重训；O/E低很多：检查是否过度保守并评估Approval/利润空间。

8）常见误区

误区1：未成熟样本算O/E。误区2：PD预测90天Bad却拿FPD7比较。误区3：全量O/E正常就认为所有Score段都准。误区4：把O/E当AUC。

9）推荐拆分维度

Score Decile、Channel、Vintage、Product、Limit、New/Repeat、Model Version。

10）预警方式

设置Score Band最小成熟样本量；O/E应结合置信区间/历史波动，连续多个成熟Cohort偏离再升级，不用单日数值。

11）与其他指标关系

Predicted PD → O/E / Calibration → EL Budget → Actual Credit Loss → Contribution Margin。

12）小练习

Predicted PD=10%，Observed Bad=15%，O/E是多少？意味着什么？

答案：1.5；在口径完全一致前提下，实际风险比模型预测高50%，说明PD存在明显低估。

四指标一起怎么用

PSI高 + AUC/KS下降：优先客群/数据漂移与模型老化。

PSI高 + AUC/KS稳定 + O/E恶化：排序还行，重点做Calibration和策略映射。

PSI低 + AUC/KS下降：检查标签、变量语义、模型本身。

AUC/KS稳定 + O/E正常 + EL仍恶化：重点查EAD/Limit、LGD/Recovery、Funding和策略变化。
