海外投放指标词典｜现金贷 APP

从曝光、点击、安装、申请，一路看到放款、风险、数据连接与利润｜2026-08-22 更新：新增 Event Match Quality、Event Coverage Rate、Deduplication Success Rate

一张图先记住

曝光 → 点击 → 安装 → 注册/KYC → 申请 → 授信 → 放款 → 首期还款 → 复借 → 生命周期价值
CPM/Frequency → CTR/CPC → CPI → CVR/CPA → Approve/Disburse Rate → CAC → FPD/Vintage → LTV → Payback → ROI
数据健康：Event Coverage → EMQ/Diagnostics → Deduplication → Conversion Lag

原则：前端指标解释流量价格和素材反应，中间指标解释漏斗损失，后端指标回答“用户值不值得买”，数据连接指标回答“这些数字本身是否可信”。

CPM

Cost Per Mille｜千次展示成本

CPM = 花费 ÷ 展示 × 1000

看库存价格与竞价强度。

CTR

Click-through Rate｜点击率

CTR = 点击 ÷ 展示

看素材吸引力；高 CTR 不等于高质量用户。

CPC

Cost Per Click｜点击成本

CPC = 花费 ÷ 点击

CVR

Conversion Rate｜转化率

CVR = 下一步完成数 ÷ 上一步人数

必须注明区间：Click→Install、Register→Apply、Apply→Disburse 都不同。

CPI

Cost Per Install｜安装成本

CPI = 花费 ÷ 安装人数

CPA

Cost Per Action/Acquisition｜目标行动成本

CPA = 花费 ÷ 目标行动人数

必须说明是注册、申请还是其他事件 CPA。

tCPA

Target CPA｜目标 CPA

自动出价希望平均实现的转化成本，不是每次转化封顶价。

CAC

Customer Acquisition Cost｜客户获取成本

CAC = 获取有效客户总成本 ÷ 新增有效客户数

现金贷最常看首贷 CAC。

ROAS / tROAS

广告支出回报 / 目标广告支出回报

ROAS = 广告带来的收入 ÷ 广告花费

现金贷不要把放款金额直接当利润型 value。

ROI

Return on Investment｜投资回报率

ROI = (收益 − 总成本) ÷ 总成本

总成本应含获客、坏账、资金和运营等。

LTV

Lifetime Value｜生命周期价值

风险调整 LTV ≈ 生命周期收入 − 信用损失 − 资金成本 − 服务/催收等变动成本

LTV/CAC

价值/获客成本比

LTV/CAC = 风险调整 LTV ÷ 首贷 CAC

Payback

Payback Period｜回收周期

累计风险调整贡献首次 ≥ CAC 时，对应天数 = Payback

FPD

First Payment Default｜首期逾期/违约

必须写清 FPD1/FPD7 等窗口、件数/金额口径和成熟分母。

Vintage

批次/账龄表现

同账龄比较不同放款 Cohort 的风险，避免新资产稀释总体逾期。

Uplift

提升幅度 / 增量提升

相对 Uplift = (实验指标 − 基线指标) ÷ 基线指标

CVR uplift 不等于利润 uplift。

Conversion Lag

转化延迟

从广告点击/曝光到目标转化被记录之间的时间差。

Frequency

频次 / 平均曝光频次

Frequency ≈ Impressions ÷ Reach

与 CTR/CVR/CPA、受众规模结合判断 Creative Fatigue。

Engagement Rate

互动率

常见口径 = 互动 ÷ Impressions 或 Reach

不同平台分母不同；不能直接当申请/还款质量。

Event Match Quality / EMQ

事件匹配质量

平台用于诊断事件是否有足够、有效的匹配信息，从而与广告触达/用户建立关联。不同平台的算法和评分不可横向比较。

看法：EMQ 高说明数据连接/匹配更健康，不代表 Approve Rate、FPD 或 LTV 更好。

官方参考：Meta CAPI ｜ TikTok Events Manager

Event Coverage Rate

事件覆盖率｜内部建议指标

Event Coverage = 平台收到的去重有效事件数 ÷ 内部 eligible 事件数

用途：检查 Pixel/SDK/API 是否漏传。必须用相同事件定义、时区、成熟窗口对账。

例：内部当天 10,000 个 SubmitApplication，平台去重后收到 9,200 个，则覆盖率约 92%。

Deduplication Success Rate

去重成功率｜内部建议指标

Dedup Success = 被正确合并的预期重复事件对 ÷ 应去重的重叠事件对

用途：验证 Browser + Server 双链路是否把同一转化正确合并，而不是重复计数。

核心字段：event_id、event_name、event_time、source。

2026-08-22 学习：先确认“数据是真的”，再讨论“成本好不好”

如果 Pixel 与 Server API 同时上报同一 Apply，却没有正确 dedup，平台会虚增转化，Apply CPA 看起来突然下降；如果 Server 漏传 20%，平台又可能低估深层转化。任何出价/AI 优化前，先看数据连接健康。

第一层：Event Coverage / EMQ / Dedup / Lag
第二层：CPM / CTR / CPC / CPI / CPA
第三层：Approve / Disburse / CAC / FPD / LTV / ROI

现金贷常见指标联动

现象优先检查不要急着下结论
平台转化突然暴涨event_id、去重、事件定义、重复回传素材/算法突然变好
平台转化突然下降Event Coverage、API/SDK错误、延迟、版本用户需求突然消失
EMQ 上升匹配覆盖、归因稳定性、CPA变化风险质量变好
Frequency 上升Reach、CTR、CVR、CPA、受众规模一定素材疲劳
CTR 上升、CPC 下降Click→Apply、Approve/Disburse、FPD素材一定更好
CPI 下降Install→Register→Apply→Disburse渠道更便宜
申请 CPA 达标授信率、放款率、首贷 CAC业务目标已完成
首贷 CAC 下降件均、FPD、Vintage、复借利润更高
LTV/CAC 上升预测成熟度、Payback、现金流可以无限扩量

成熟度与口径红线

  1. Event Coverage 对账必须使用同一事件定义、时区和去重口径。
  2. FPD/Vintage 必须等观察窗口成熟。
  3. 实验类指标要考虑 Conversion Lag，不用短期未成熟数据过早决策。
  4. 平台归因与自有数仓口径并行保留，件数率、金额率、渠道 Cohort 分开观察。

每天看数据的推荐顺序

  1. 数据健康：Event Coverage、EMQ/Diagnostics、Deduplication、Lag。
  2. 量：Spend、Impression、Reach、Click、Install。
  3. 素材健康：Frequency、Engagement Rate、CTR。
  4. 价格：CPM、CPC、CPI、CPA。
  5. 业务：Approve Rate、Disburse Rate、首贷 CAC、件均。
  6. 风险：FPD、Vintage、欺诈/拒绝原因。
  7. 价值：LTV、Payback、ROAS、ROI。

正式经营看板应标注事件定义、分母、时间窗口、成熟期、件数/金额口径、归因来源和数据连接方式。
