海外投放指标词典｜现金贷 APP

从曝光、点击、安装、申请，一路看到放款、风险、数据健康、归因、增量与价值｜2026-08-25 更新：新增 Risk-adjusted Value、Risk-adjusted Value/Cost、Value Coverage Rate

一张图先记住

曝光 → 点击 → 安装 → 注册/KYC → 申请 → 授信 → 放款 → 首期还款 → 复借 → 生命周期价值
CPM/Frequency → CTR/CPC → CPI → CVR/CPA → Approve/Disburse Rate → CAC → FPD/Vintage → LTV → Payback → ROI
数据健康：Event Coverage → EMQ → Deduplication → Conversion Lag → Maturity
归因：Referred / Assisted → Holdout/Lift → Incremental CAC
价值：Conversion Value → Risk-adjusted Value → Value/Cost → LTV/ROI

CPM

Cost Per Mille｜千次展示成本

CPM = 花费 ÷ 展示 × 1000

CTR

Click-through Rate｜点击率

CTR = 点击 ÷ 展示

高 CTR 不等于高质量用户。

CPC

Cost Per Click｜点击成本

CPC = 花费 ÷ 点击

CVR

Conversion Rate｜转化率

CVR = 下一步完成数 ÷ 上一步人数

必须注明 Click→Apply、Apply→Disburse 等区间。

CPI

Cost Per Install｜安装成本

CPI = 花费 ÷ 安装人数

CPA

Cost Per Action｜目标行动成本

CPA = 花费 ÷ 目标行动人数

tCPA

Target CPA｜目标 CPA

自动出价希望平均实现的转化成本，不是单次转化封顶价。

Approve Rate

授信/审批通过率

Approve Rate = 通过人数 ÷ 有效申请人数

Disburse Rate

放款率

常见口径 = 放款人数 ÷ 审批通过人数

CAC

Customer Acquisition Cost｜客户获取成本

CAC = 获取有效客户总成本 ÷ 新增有效客户数

现金贷常看首贷 CAC。

ROAS / tROAS

广告支出回报 / 目标广告支出回报

ROAS = Conversion Value ÷ Ad Spend

现金贷不要直接把放款本金当利润型 value。

ROI

Return on Investment｜投资回报率

ROI = (收益 − 总成本) ÷ 总成本

LTV

Lifetime Value｜生命周期价值

风险调整 LTV ≈ 生命周期收入 − 信用损失 − 资金成本 − 服务/催收等变动成本

LTV/CAC

LTV/CAC = 风险调整 LTV ÷ 首贷 CAC

Payback

回收周期

累计风险调整贡献首次 ≥ CAC 时，对应天数 = Payback

FPD

First Payment Default｜首期逾期/违约

必须写清 FPD1/FPD7、件数/金额口径和成熟期。

Vintage

批次/账龄表现

同账龄比较不同放款 Cohort 风险。

Frequency

Frequency ≈ Impressions ÷ Reach

结合 CTR/CVR/CPA 判断 Creative Fatigue。

Conversion Lag

广告互动到转化发生/被记录之间的时间差。

P50 / P90 Conversion Lag

P50 = 50% 转化完成所需延迟
P90 = 90% 转化完成所需延迟

Conversion Maturity Rate

Maturity Rate(Dn) = Dn 已观察转化 ÷ 最终成熟转化

Provisional CPA

当前累计花费 ÷ 当前已观察转化

Mature CPA

Cohort 成熟后花费 ÷ 最终成熟转化

Event Match Quality / EMQ

说明平台数据匹配/连接健康度，不代表 Approve Rate、FPD 或 LTV 更好。

Event Coverage Rate

平台收到的去重有效事件 ÷ 内部 eligible 事件

Deduplication Success Rate

正确合并的重复事件对 ÷ 应去重的重叠事件对

Assisted Share

Assisted ÷ (Assisted + Referred)

说明渠道参与路径上游的程度，不代表增量。

Assist-to-Referred Ratio

Assisted ÷ Referred

Incremental CAC

实验新增花费 ÷ 实验带来的增量首贷人数

需要 Holdout/Lift/Geo Experiment 等因果设计。

Risk-adjusted Value

风险调整价值｜2026-08-25 新增

≈ 预期收入 − 预期信用损失 − 资金成本 − 服务/催收等变动成本

用途：从“放了多少款”升级到“这些客户真正创造多少价值”。

注意：首先是内部经营口径；发送给广告平台的 value 需满足平台数据政策与隐私要求。

Risk-adjusted Value / Cost

风险调整价值/广告花费

Risk-adjusted Value / Cost = 风险调整总价值 ÷ 广告花费

用途：比只看 CAC 更适合比较“量少但高价值”和“量多但低价值”的 Campaign。

现金贷例：A CAC 更低但 Value/Cost=1.30；B CAC 更高但 Value/Cost=1.51，B 可能更值得扩量。

Value Coverage Rate

价值覆盖率｜内部建议指标

带有效 value 的 eligible 转化数 ÷ eligible 转化总数

用途：上线 VBO/tROAS 前检查 value 是否漏传。Coverage 太低时，平台价值优化会建立在不完整样本上。

2026-08-25 学习：从 CAC 优化升级到风险调整价值优化

媒体层：CPA / CAC
风险层：FPD / Vintage
价值层：Risk-adjusted Value / Cost → LTV / Payback / ROI

当一个 Campaign 的 CAC 更高但风险调整价值/成本更好时，不应仅因为 CAC 高就砍量。反过来，平台 ROAS 变好也必须验证 FPD/Vintage 与成熟 LTV 是否同步改善。

每天看数据的推荐顺序

  1. 数据健康：Event Coverage、EMQ、Deduplication、Value Coverage。
  2. 成熟度：P50/P90 Lag、Maturity、Provisional/Mature。
  3. 媒体流量：Spend、CPM、CTR、CPC、CPI。
  4. 转化：Register、Apply、Approve、Disburse、CPA/CAC。
  5. 风险：FPD、Vintage。
  6. 归因/增量：Referred、Assisted、Holdout/Lift、Incremental CAC。
  7. 价值：Risk-adjusted Value/Cost、LTV、Payback、ROI。

正式经营看板应标注事件定义、分母、时间窗口、成熟期、件数/金额口径、归因来源、value 版本、数据连接方式与是否为增量估计。
