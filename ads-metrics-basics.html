一、媒体与漏斗指标

CPM

CPM = Spend ÷ Impressions × 1000

千次展示成本。

Frequency

Frequency ≈ Impressions ÷ Reach

用于辅助判断素材疲劳，不能单独作为质量结论。

CTR

CTR = Clicks ÷ Impressions

衡量吸引力，不等于借款人质量。

CPC

CPC = Spend ÷ Clicks

CPI

CPI = Spend ÷ Installs

现金贷必须继续接 Register、Apply、Approve、Disburse、Fraud。

CVR

CVR = 下一步完成数 ÷ 上一步人数

必须写清区间，例如 Click→Apply、Apply→Disburse。

CPA

CPA = Spend ÷ Target Actions

必须注明事件：Register CPA、Apply CPA、Qualified Lead CPA、Disburse CPA 完全不同。

tCPA

Target CPA。平台希望长期平均接近的目标成本，不是单笔硬上限。

Approve Rate

Approved ÷ Valid Applications

Disburse Rate

常见口径 = Disbursed ÷ Approved

也可使用 Disbursed ÷ Applications，必须标分母。

First-loan CAC

首贷 CAC = 获客广告花费 ÷ 首次成功放款人数

比 CPI/Apply CPA 更接近经营结果。长期模型建议使用 Gross Spend。

二、线索质量指标

Qualified Lead Rate

Qualified Leads ÷ Raw Leads

Qualified Lead CPA

Ad Spend ÷ Qualified Leads

Lead-to-Disburse Rate

First Disbursed Borrowers ÷ Raw Leads

也可定义 Qualified Lead→Disburse，但必须固定口径。

Converted Lead Rate

Converted Leads ÷ Qualified Leads

三、风险与价值指标

FPD

First Payment Default。必须写清 FPD1/3/7/30、件数/金额口径和成熟期。

Vintage

按放款 Cohort、MOB/账龄比较风险表现，不同渠道必须同成熟度比较。

Risk-adjusted LTV

≈ 生命周期收入 − 信用损失 − 资金成本 − 服务/催收等变动成本

LTV/CAC

Risk-adjusted LTV ÷ First-loan CAC

Payback

累计风险调整贡献首次 ≥ CAC 时，对应天数 = Payback

ROAS / tROAS

ROAS = Conversion Value ÷ Ad Spend

现金贷不应把放款本金直接当利润型 Value。

ROI

ROI = (收益 − 总成本) ÷ 总成本

Risk-adjusted Value / Cost

风险调整总价值 ÷ 广告花费

四、TikTok Smart+ 与平台激励

Billing Ratio

Actual Spend ÷ (Cost Cap × Conversions) ≈ Actual CPA ÷ Cost Cap

衡量实际成本相对 Cost Cap 的偏离。

Budget Utilization Rate

Spend ÷ Available Budget

低利用率可能来自 Bid、事件量、受众、素材或竞价机会。

Ad Credit Offset Rate

Confirmed Usable Ad Credit ÷ Gross Ad Spend

Credit-adjusted First-loan CAC

(Gross Spend − Confirmed Usable Ad Credit) ÷ First Disbursed Borrowers

只做辅助；正式扩量仍应看 Gross CAC。

Incentive Dependency Ratio

Ad Credit ÷ Spend

越高说明经济性越依赖临时平台激励。

Protected Day Rate

Protection Active / Eligible Days ÷ Campaign Active Days

五、数据健康、成熟度与归因

Event Coverage Rate

平台收到的去重有效事件 ÷ 内部 Eligible 事件

EMQ / Event Match Quality

平台衡量事件与广告/用户匹配的质量；高 EMQ 不等于高信用质量。

Deduplication Success Rate

正确合并的重复事件对 ÷ 应去重的重叠事件对

P50 / P90 Conversion Lag

P50/P90 分别表示 50%/90% 转化完成所需延迟。

Conversion Maturity Rate

Dn 已观察转化 ÷ 最终成熟转化

Provisional CPA

当前累计花费 ÷ 当前已观察转化

Mature CPA

成熟 Cohort Spend ÷ Mature Conversions

Assisted Share

Assisted ÷ (Assisted + Referred)

说明渠道参与度，不代表增量。

Incremental CAC

实验新增 Spend ÷ Incremental First Loans

需要 Holdout/Lift/Geo Experiment 等因果设计。

六、移动归因反作弊指标

MMP-to-Backend Install Gap

(MMP Attributed Installs − Backend Verified First Launches) ÷ MMP Attributed Installs

识别 SDK Spoofing、归因异常、埋点丢失或版本/网络问题。

Backend Verified Conversion Rate

Backend Confirmed Target Events ÷ MMP/Platform Reported Target Events

Valid Install Rate

Valid Installs ÷ MMP Installs

Fraud Block Rate

Real-time Blocked Fraud ÷ Eligible Attempts

Post-attribution Fraud Rate

后续确认 Fraud 的已归因 Install/Event ÷ 已归因 Install/Event

Publisher Fraud Index

内部综合评分，可融合 Fraud、MMP-Backend Gap、设备/网络异常与 Backend Quality。

Attribution Trust Score

综合 MMP fraud flags、Backend Verification、Event Timing、设备/IP/ASN 与 Publisher 历史。

七、页面、合规与运营

Landing Page Apply CVR

Applications ÷ Landing Page Sessions（或 Ad Clicks，必须标分母）

Landing Page First-loan CAC

归属于该 URL 的广告花费 ÷ 该 URL 带来的首贷数

Landing Page Risk-adjusted Value / Cost

该 URL Cohort 风险调整总价值 ÷ 归属于该 URL 的广告花费

Ad Approval Rate

Approved Ads ÷ Submitted Ads

Policy Rejection Rate

Policy-Rejected Ads ÷ Submitted Ads

Permission Coverage Rate

已有有效 Platform Permission 的需要许可组合 ÷ 所有需要 Permission 的组合

P90 Approval Time

90% 广告/许可流程完成所需时间

八、AI Max 迁移与 Search Query Routing

AI Max Migration Coverage Rate

已完成 AI Max 升级的 Eligible Legacy Search Campaigns ÷ 全部 Eligible Legacy Campaigns

用于区分“尚未迁移”和“迁移后表现变化”。

Intended Query Routing Rate

进入 Intended Campaign/Ad Group 的 Governed Query Clicks ÷ 全部 Governed Query Clicks

可按 Click/Spend/First-loan 另做版本，但必须标口径。

Exact Query Capture Rate

由 Intended Exact Campaign 承接的 Critical Identical-query Clicks ÷ 全部 Critical Identical-query Clicks

Search Term Match Mix

按 Search Terms Match Type 统计 Clicks / Spend / Conversions / First-loan 占比

Query Routing Shift

Post-migration Intended Routing Share − Pre-migration Baseline Routing Share

用百分点 pct 表达更适合运营诊断。

九、iOS Postback 与隐私可见性｜2026-09-02

Verified Postback Rate

中文：Apple Postback 验签通过率｜数据健康指标。

Apple JWS Signature Verified Unique Postbacks ÷ Unique Received Postbacks

口径：先按 `postback-identifier` 去重，再计算签名验证通过率；重试消息不应重复进入分母。

用途：识别伪造、损坏、错误 endpoint/密钥/验证逻辑等数据完整性问题。

常见误区：只要 HTTP 收到就计 Conversion。Apple 要求验证其签名；签名无效的数据不应计入正式归因。

Apple 官方：Verifying a postback

Fine Conversion Value Availability Rate

中文：细粒度转化值可见率｜隐私可见性指标。

Valid Postbacks containing Fine Conversion Value ÷ Valid Postbacks

用途：观察 iOS 归因能看到多少细粒度漏斗/价值信号。

解释：下降可能来自 Postback Data Tier / crowd anonymity / 流量规模结构，而不一定是产品、SDK 或用户质量恶化。

现金贷：必须与 Backend Register/Apply/Disburse 同期对照。

Apple 官方：Postback parameters

Coarse Conversion Value Availability Rate

中文：粗粒度转化值可见率。

Valid Postbacks containing Coarse Conversion Value ÷ Valid Postbacks

Coarse Value 取值为 low / medium / high。它代表开发者定义的相对信号，不等于高/中/低信用质量。

误区：把 Fine + Coarse 可见率机械相加当总 Conversion；应按 Postback 类型/版本/窗口分析。

Apple 官方：Postback

iOS Postback-to-Backend Coverage Rate

中文：iOS Postback 对 Backend Cohort 覆盖率｜内部诊断指标。

Comparable Valid Winning Postbacks ÷ Backend Eligible iOS Cohort Count

前提：必须对齐 conversion_type、时间窗口、国家、App Version 和 Cohort；这是聚合诊断指标，不追求用户级一一对应。

用途：判断 Apple/MMP 可见性变化与真实业务变化是否一致。

常见误区：分母用首贷、分子用安装 Postback，造成事件层级错配。

Invalid Postback Signature Rate

Invalid Signature Unique Postbacks ÷ Unique Received Postbacks

与 Verified Postback Rate 互补。突然升高应排查来源、解析/验签实现、环境与 endpoint。

现金贷推荐的数据阅读顺序

  1. 先查平台/迁移状态：AI Max Migration Coverage、Change Log。
  2. 再查 iOS / 数据可见性：Verified Postback、Fine/Coarse Availability、MMP-Backend Gap、Event Coverage。
  3. 再查 Search Routing：Intended Routing、Exact Capture、Match Mix、Final URL。
  4. 再看媒体：Spend、CPM、CTR、CPC、CPI、CPA。
  5. 然后看后端：Approve、Disburse、First-loan CAC。
  6. 再看风险：FPD、Vintage。
  7. 最后看价值：Risk-adjusted LTV、Payback、ROI / Incremental CAC。
  8. 平台 Credit / Bid Protection 只作为辅助层。

所有指标进入经营看板时，应标注事件定义、分母、时间窗口、成熟度、归因来源、Fraud 处理口径、件数/金额口径、privacy/data tier 及 metric_version。
