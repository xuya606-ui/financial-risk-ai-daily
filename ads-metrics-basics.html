一、媒体与漏斗指标

CPM

CPM = Spend ÷ Impressions × 1000

千次展示成本。

Frequency

Frequency ≈ Impressions ÷ Reach

辅助判断素材疲劳，不能单独判断用户质量。

CTR

CTR = Clicks ÷ Impressions

衡量吸引力，不等于借款人质量。

CPC

CPC = Spend ÷ Clicks

CPI

CPI = Spend ÷ Installs

现金贷必须继续接 Register、Apply、Approve、Disburse 与 Fraud。

CVR

CVR = 下一步完成数 ÷ 上一步人数

必须注明区间，如 Click→Apply、Apply→Disburse。

CPA

CPA = Spend ÷ Target Actions

必须写事件：Install CPA、Apply CPA、Disburse CPA 不可混用。

tCPA

Target CPA。平台希望长期平均接近的目标成本，不是单笔硬上限。

Approve Rate

Approved Applications ÷ Valid Applications

Disburse Rate

常见口径 = Disbursed ÷ Approved

也可用 Disbursed ÷ Applications，但必须固定分母。

First-loan CAC

获客广告花费 ÷ 首次成功放款人数

现金贷最重要的获客经营指标之一。

二、Google Search 合规资产指标

Compliance Asset Coverage Rate

已绑定且 Approved 的必需 Compliance Asset Campaigns ÷ 全部需要该资产的 Active Campaigns

Disclaimer Disapproval Rate

Disapproved Disclaimer Assets ÷ Submitted Disclaimer Assets

Disclaimer Pending Rate

Pending Disclaimer Assets ÷ Active Required Disclaimer Assets

FUE Disclosure Pass Rate

通过贷款披露审计的 FUE-selected URLs ÷ 全部被审计的 FUE-selected URLs

Compliance Drift Rate

使用过期 disclosure_version / 错误产品参数的 Active Ad-URL Combinations ÷ 全部 Active Regulated Combinations

Disclosure Version Coverage Rate

带有效 disclosure_version 的 Active Regulated URLs / Assets ÷ 全部 Active Regulated URLs / Assets
Google 官方背景：Text Disclaimer ｜ Personal Loans

三、线索质量指标

Qualified Lead Rate

Qualified Leads ÷ Raw Leads

Qualified Lead CPA

Ad Spend ÷ Qualified Leads

Lead-to-Disburse Rate

First Disbursed Borrowers ÷ Raw Leads

Converted Lead Rate

Converted Leads ÷ Qualified Leads

四、风险与价值指标

FPD

First Payment Default。必须写清 FPD1/3/7/30、件数/金额口径和成熟期。

Vintage

按放款 Cohort、MOB/账龄比较风险表现，不同渠道必须同成熟度比较。

Risk-adjusted LTV

≈ 生命周期收入 − 预期信用损失 − 资金成本 − 服务/催收等变动成本

LTV/CAC

Risk-adjusted LTV ÷ First-loan CAC

Payback

累计风险调整贡献首次 ≥ CAC 时对应天数

ROAS / tROAS

ROAS = Conversion Value ÷ Ad Spend

现金贷不应把放款本金直接当利润型 Value。

ROI

ROI = (收益 − 总成本) ÷ 总成本

Risk-adjusted Value / Cost

风险调整总价值 ÷ 广告花费

五、Publisher / Network 质量

TikTok Ad Network Spend Share

TikTok Ad Network Spend ÷ Total TikTok Spend

Publisher ID Coverage Rate

带有效 Publisher/Sub-publisher ID 的 Events ÷ 全部 Eligible Ad Network Events

Publisher Backend Verified Install Rate

Backend Verified First Launches ÷ MMP Attributed Installs（按 Publisher）

Publisher First-loan CAC

Publisher Attributed Spend ÷ Publisher First Disbursed Borrowers

Publisher FPD7 Delta

Publisher Mature FPD7 − Comparable Baseline FPD7

Publisher Risk-adjusted Value / Cost

Publisher Cohort Risk-adjusted Value ÷ Publisher Spend

六、Smart+、预算与扩量

Billing Ratio

Actual Spend ÷ (Cost Cap × Conversions) ≈ Actual CPA ÷ Cost Cap

Budget Utilization Rate

Spend ÷ Available Budget

Ad Credit Offset Rate

Confirmed Usable Ad Credit ÷ Gross Ad Spend

Credit-adjusted First-loan CAC

(Gross Spend − Confirmed Usable Ad Credit) ÷ First Disbursed Borrowers

辅助口径；正式扩量仍看 Gross CAC。

七、数据健康、成熟度与归因

Event Coverage Rate

平台收到的去重有效事件 ÷ 内部 Eligible 事件

Deduplication Success Rate

正确合并的重复事件对 ÷ 应去重的重叠事件对

P50 / P90 Conversion Lag

P50/P90 分别表示 50%/90% 转化完成所需延迟。

Conversion Maturity Rate

Dn 已观察转化 ÷ 最终成熟转化

Provisional CPA

当前累计花费 ÷ 当前已观察转化

Mature CPA

成熟 Cohort Spend ÷ Mature Conversions

Assisted Share

Assisted ÷ (Assisted + Referred)

说明渠道参与度，不等于业务增量。

Incremental CAC

实验新增 Spend ÷ Incremental First Loans

八、移动归因反作弊

MMP-to-Backend Install Gap

(MMP Installs − Backend Verified First Launches) ÷ MMP Installs

Backend Verified Conversion Rate

Backend Confirmed Target Events ÷ MMP/Platform Reported Target Events

Valid Install Rate

Valid Installs ÷ MMP Installs

Fraud Block Rate

Real-time Blocked Fraud ÷ Eligible Attempts

Post-attribution Fraud Rate

后续确认 Fraud 的已归因 Install/Event ÷ 已归因 Install/Event

九、Search / AI Max 治理

AI Max Migration Coverage Rate

已完成升级 Eligible Campaigns ÷ 全部 Eligible Legacy Campaigns

Intended Query Routing Rate

进入 Intended Campaign/Ad Group 的 Governed Query Clicks ÷ 全部 Governed Query Clicks

Exact Query Capture Rate

由 Intended Exact Campaign 承接的 Critical Identical-query Clicks ÷ 全部 Critical Identical-query Clicks

Search Term Match Mix

按 Match Type 统计 Clicks / Spend / Conversion / First-loan 占比

十、iOS Postback 与隐私可见性

Verified Postback Rate

Apple Signature Verified Unique Postbacks ÷ Unique Received Postbacks

Fine CV Availability Rate

Valid Postbacks containing Fine Conversion Value ÷ Valid Postbacks

Coarse CV Availability Rate

Valid Postbacks containing Coarse Conversion Value ÷ Valid Postbacks

Invalid Postback Signature Rate

Invalid Signature Unique Postbacks ÷ Unique Received Postbacks

十一、广告审核与运营

Ad Approval Rate

Approved Ads ÷ Submitted Ads

Policy Rejection Rate

Policy-Rejected Ads ÷ Submitted Ads

P90 Approval Time

90% 广告/许可流程完成所需时间

十二、AI Agent 治理指标

Agent Recommendation Acceptance Rate

Approved Agent Recommendations ÷ Eligible Agent Recommendations

Auto-change Rate

Auto-executed Changes ÷ All Executed Changes

Rollback Rate

Rolled-back Agent Changes ÷ Executed Agent Changes

Business Guardrail Breach Rate

Agent Changes triggering CAC/FPD/LTV Guardrail ÷ Executed Agent Changes

Time to Rollback

Rollback Timestamp − Guardrail Breach/Detection Timestamp

十三、iOS Dedicated Campaign Capacity｜2026-09-06 新增

iOS Dedicated Campaign Quota Utilization Rate

Occupied Dedicated Campaign Slots ÷ 15

口径：TikTok Placement 与 TikTok Ad Network 分别计算。Automatic Placement Dedicated Campaign 在两个 Pool 各占 1 个 Slot。

iOS Quota Headroom Rate

Remaining Available Slots ÷ 15

用途：衡量还剩多少结构容量可用于新实验、事件切换或应急重建。

内部起点：可先保留 20%–30% Headroom；这不是 TikTok 官方阈值。

Automatic Placement Dual-Quota Consumption Rate

由 Automatic Placement 占用的 TikTok + Ad Network Slots ÷ 全部 Occupied Dedicated Slots

用于识别有多少 Quota 被双池同时占用。

Postback Density per Active Dedicated Campaign

Valid Postbacks ÷ Active iOS Dedicated Campaigns

内部信号密度指标；不能单独决定扩量，但可辅助识别过度碎片化。

First-loan Density per Active Dedicated Campaign

Mature First Disbursed Borrowers ÷ Active iOS Dedicated Campaigns

衡量每个 Campaign 能沉淀多少可用于 CAC/FPD/Vintage 判断的业务样本。

Quota-to-First-loan Efficiency

Mature First Disbursed Borrowers ÷ Occupied Dedicated Quota Slots

内部经营指标：用于比较结构简化前后，每个稀缺 Slot 产生的成熟首贷样本。

TikTok 官方背景：iOS 14.5+ Dedicated Campaign Quota ｜ Create dedicated campaign

现金贷推荐阅读顺序

  1. 先看 Compliance / Data Health：Disclaimer Coverage、FUE Disclosure Pass、Event Coverage、MMP-Backend Gap。
  2. iOS 再看 Capacity：Quota Utilization、Headroom、Postback Density。
  3. 看媒体：Spend、CTR、CPC、CPA、Budget Utilization。
  4. 看后端：Approve、Disburse、First-loan CAC。
  5. 第三方 Network 再拆 Publisher。
  6. 看风险：FPD、Vintage。
  7. 最后看价值：Risk-adjusted LTV、Payback、ROI、Incremental CAC。

所有指标进入经营看板时，应标注事件定义、分母、时间窗口、成熟度、归因来源、Placement/Publisher、Fraud 处理、件数/金额口径、disclosure_version、quota_pool 和 metric_version。
