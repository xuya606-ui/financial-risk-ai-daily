一、媒体与漏斗指标

CPM

Cost Per Mille｜千次展示成本

CPM = Spend ÷ Impressions × 1000

Frequency

Frequency ≈ Impressions ÷ Reach

和 CTR/CVR/CPA 一起看素材疲劳，不能单独作为好坏结论。

CTR

CTR = Clicks ÷ Impressions

衡量吸引力，不等于用户质量。

CPC

CPC = Spend ÷ Clicks

CPI

CPI = Spend ÷ Installs

现金贷必须继续接 Register、Apply、Approve、Disburse 和 Fraud。

CVR

CVR = 下一步完成数 ÷ 上一步人数

必须写清区间，例如 Click→Apply、Apply→Disburse。

CPA

CPA = Spend ÷ Target Actions

必须注明事件：Register CPA、Apply CPA、Disburse CPA 不同。

tCPA

Target CPA。平台希望长期平均接近的目标成本，不是单笔硬上限。

Approve Rate

Approve Rate = Approved ÷ Valid Applications

Disburse Rate

常见口径 = Disbursed ÷ Approved

也可用 Disbursed ÷ Applications，必须写分母。

First-loan CAC

首贷 CAC = 获客广告花费 ÷ 首次成功放款人数

现金贷比 CPI/Apply CPA 更接近经营结果。

二、风险与价值指标

FPD

First Payment Default｜首期逾期/违约

必须写清 FPD1/3/7/30、件数/金额口径和成熟期。

Vintage

按放款 Cohort、MOB/账龄比较风险表现。不同获客渠道必须同成熟度比较。

Risk-adjusted LTV

≈ 生命周期收入 − 信用损失 − 资金成本 − 服务/催收等变动成本

LTV/CAC

LTV/CAC = Risk-adjusted LTV ÷ First-loan CAC

Payback

累计风险调整贡献首次 ≥ CAC 时，对应天数 = Payback

ROAS / tROAS

ROAS = Conversion Value ÷ Ad Spend

现金贷不应把放款本金直接当利润型 value。

ROI

ROI = (收益 − 总成本) ÷ 总成本

Risk-adjusted Value / Cost

风险调整总价值 ÷ 广告花费

三、数据健康、成熟度与归因

Event Coverage Rate

平台收到的去重有效事件 ÷ 内部 eligible 事件

下降时先查埋点、API、SDK、版本和网络，不要直接归因于用户行为。

EMQ / Event Match Quality

平台衡量事件能否与广告/用户匹配的质量；高 EMQ 不等于高信用质量。

Deduplication Success Rate

正确合并的重复事件对 ÷ 应去重的重叠事件对

P50 / P90 Conversion Lag

P50=50% 转化完成所需延迟；P90=90% 转化完成所需延迟。

Conversion Maturity Rate

Dn 已观察转化 ÷ 最终成熟转化

Provisional CPA

当前累计花费 ÷ 当前已观察转化

Mature CPA

成熟 Cohort Spend ÷ Mature Conversions

Assisted Share

Assisted ÷ (Assisted + Referred)

说明渠道参与度，不代表增量。

Incremental CAC

实验新增 Spend ÷ Incremental First Loans

需要 Holdout/Lift/Geo Experiment 等因果设计。

四、移动归因反作弊指标｜2026-08-29 新增

MMP-to-Backend Install Gap

MMP 与后端安装/首启差异率｜内部数据健康指标

Gap = (MMP Attributed Installs − Backend Verified First Launches) ÷ MMP Attributed Installs

用途：识别 SDK Spoofing、归因异常、埋点丢失或版本/网络问题。必须先排除正常技术损耗。

内部起点：>5% 预警、>10% 专项排查可作为首版规则，但不是 AppsFlyer/Adjust 官方阈值。

Backend Verified Conversion Rate

后端验证转化率

Backend Verified Conversion Rate = Backend Confirmed Target Events ÷ MMP/Platform Reported Target Events

例如平台/MMP 有 2,000 Apply，但 backend 只有 1,200 个真实 application_id，则为 60%。

Valid Install Rate

Valid Installs = MMP Installs − Real-time Fraud Blocks − Confirmed Post-attribution Fraud
Valid Install Rate = Valid Installs ÷ MMP Installs

用于估算“真正可用于业务分析的安装基线”。注意不同 MMP 对 fraud 分类口径不同。

Fraud Block Rate

Fraud Block Rate = Real-time Blocked Fraud Installs/Events ÷ Eligible Attempts

需要按 Media Source / Publisher / Geo / App Version 拆分。高 Block Rate 可能是流量差，也可能是规则变更，不能脱离原因判断。

AppsFlyer Protect360 Guide

Post-attribution Fraud Rate

Post-attribution Fraud Rate = 后续确认 Fraud 的已归因 Install/Event ÷ 已归因 Install/Event

用于修正历史渠道质量、供应商结算和成熟 CAC。归因后 Fraud 不能只在 Fraud Dashboard 看，必须回写业务报表。

Publisher Fraud Index

内部评分指标

示例 = 0.3×Fraud Rate Z-score + 0.25×MMP-Backend Gap Z-score + 0.2×Device/Network Anomaly + 0.25×Backend Quality Penalty

用于 Publisher 白名单/观察名单/Blocked 分层。权重需按业务校准，不是行业标准公式。

Attribution Trust Score

内部可信度分

综合 MMP fraud flags、backend verification、event timing、设备/IP/ASN、Publisher 历史、App Version 质量等，输出 Trusted / Review / Blocked。

反作弊指标最容易犯的三个错误

  1. Fraud Rate 低就认为没有问题：规则没识别到 ≠ 没有欺诈。
  2. 只看 Install Fraud，不看 In-app Event Fraud：现金贷深度事件更容易直接影响 CPA 和自动出价学习。
  3. MMP Fraud Dashboard 与业务数据分开：最终必须把 Fraud 标签接到 Approve、Disburse、FPD、Vintage、LTV。

五、预算与扩量健康

Budget Utilization Rate

Spend ÷ Available Budget

低利用率不等于 Campaign 差，可能受 Bid、事件量、受众、素材或竞价机会约束。

Billing Ratio

Actual Spend ÷ (Cost Cap × Conversions) ≈ Actual CPA ÷ Cost Cap

和 Budget Utilization 联动判断规模瓶颈。

六、页面与 Search 质量

Landing Page Apply CVR

Applications ÷ Landing Page Sessions（或 Ad Clicks，必须标分母）

Landing Page First-loan CAC

归属于该 URL 的广告花费 ÷ 该 URL 带来的首贷数

Landing Page Risk-adjusted Value / Cost

该 URL Cohort 风险调整总价值 ÷ 归属于该 URL 的广告花费

七、金融广告审核运营指标

Ad Approval Rate

Approved Ads ÷ Submitted Ads

Policy Rejection Rate

Policy-Rejected Ads ÷ Submitted Ads

Permission Coverage Rate

已有有效 Platform Permission 的“确实需要额外 Permission”的账户/产品组合 ÷ 所有需要 Permission 的组合

2026-08-29 纠偏：这个指标只能用于平台明确要求额外 permission 的受限类别，不能把 TikTok Mexico 普通贷款全部纳入。当前 Mexico 普通贷款核心要求是当地/区域许可、必要披露、18+；Crypto/NFT 等特定类别才有 Sales Representative application permission。

TikTok 官方

P90 Approval Time

90% 广告/许可流程完成所需时间

需区分 Ad Review 与 Platform Permission。

现金贷推荐的数据阅读顺序

  1. 先查数据可信：MMP-Backend Gap、Fraud Block、Post-attribution Fraud、Event Coverage。
  2. 再看媒体：Spend、CPM、CTR、CPC、CPI、CPA。
  3. 然后看后端：Backend Verified Apply、Approve、Disburse、首贷 CAC。
  4. 再看风险：FPD、Vintage。
  5. 最后看价值：Risk-adjusted LTV、Payback、ROI / Incremental CAC。

所有指标正式进入经营看板时，应标注事件定义、分母、时间窗口、成熟度、归因来源、Fraud 处理口径、件数/金额口径及版本号。
