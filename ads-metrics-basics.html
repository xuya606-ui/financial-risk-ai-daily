海外投放指标入门：CPC、CPI、CPA、CAC、ROAS、ROI

适用于现金贷 APP｜从广告平台指标一路看到放款、风险与利润

先记住一件事

现金贷投放不能只追求“便宜流量”。CPC、CPI、CPA 是前端效率指标，CAC 更接近真实获客成本，ROAS/ROI 才开始回答“这批用户有没有创造价值”。对现金贷来说，还必须继续叠加授信率、放款率、FPD、Vintage、LTV 等后端指标。

CPC

Cost Per Click｜单次点击成本

CPC = 广告花费 ÷ 点击次数

回答：买一个点击要多少钱？适合判断素材吸引力、媒体流量价格。

CPI

Cost Per Install｜单次安装成本

CPI = 广告花费 ÷ 安装人数

回答：带来一个 APP 安装要多少钱？适合 App 买量前端效率判断。

CPA

Cost Per Action / Acquisition｜单次目标行动成本

CPA = 广告花费 ÷ 目标行动人数

行动可以是注册、KYC、申请、授信或放款，所以谈 CPA 时必须说明“是什么 CPA”。

CAC

Customer Acquisition Cost｜客户获取成本

CAC = 获取客户的总成本 ÷ 新增有效客户数

现金贷更建议看首贷 CAC：获得一个首次成功放款客户花了多少钱。

ROAS

Return on Ad Spend｜广告支出回报

ROAS = 广告带来的收入 ÷ 广告花费

回答：1 元广告费带来了多少收入。主要聚焦广告投入本身。

ROI

Return on Investment｜投资回报率

ROI = （收益 - 总成本）÷ 总成本

比 ROAS 更接近经营结果，因为总成本还可能包括资金成本、坏账、渠道费、运营成本等。

六个指标到底有什么区别？

指标看什么现金贷典型用途最大风险
CPC点击价格判断素材/关键词/媒体流量成本点击便宜不代表用户质量好
CPI安装价格App 获客前端效率便宜安装可能不注册、不申请
CPA某个行为价格注册 CPA、申请 CPA、放款 CPA事件定义越浅，越容易“虚假优化”
CAC获得真实客户成本首贷 CAC、有效借款人 CAC如果不考虑坏账，仍可能高估渠道价值
ROAS广告收入回报比较渠道的广告变现效率收入不是利润，可能忽略坏账和资金成本
ROI整体投入利润回报最终经营判断需要完整成本和收益口径，计算更复杂

现金贷案例：为什么 CPI 很低，业务却可能更差？

假设墨西哥市场投放 100,000 MXN：

渠道 A渠道 B
广告花费100,000100,000
安装5,0003,500
CPI20 MXN28.6 MXN
申请人数1,0001,050
申请 CPA100 MXN95.2 MXN
成功放款180300
首贷 CAC556 MXN333 MXN

只看 CPI，会认为 A 完胜；但真正看到放款后，B 的首贷 CAC 明显更好。原因可能是 B 的用户意图更强、授信质量更好或额度/定价匹配度更高。

因此现金贷投放的判断链路应该是：

曝光 → 点击(CPC) → 安装(CPI) → 注册/申请(CPA) → 授信 → 放款(首贷 CAC) → FPD/Vintage → LTV → ROAS/ROI

CPA 和 CAC 最容易混淆

CPA 是广告平台视角：你让平台优化什么 Action，它就可以产生什么 CPA，例如“申请 CPA”。

CAC 是企业经营视角：公司真正获得一个有效客户付出了多少钱。现金贷通常更值得管理的是“首次成功放款 CAC”，甚至进一步管理“风险调整 CAC”。

首贷 CAC = 广告花费 ÷ 首次放款人数

申请 CPA = 广告花费 ÷ 申请人数

首贷 CAC ≈ 申请 CPA ÷（授信率 × 授信后放款率）

ROAS 与 ROI 的区别

假设投放花费 100,000 MXN，带来的贷款业务收入为 160,000 MXN：

ROAS = 160,000 ÷ 100,000 = 1.6 = 160%

看起来不错。但如果同时产生 30,000 MXN 坏账损失、15,000 MXN 资金成本、10,000 MXN 运营/渠道成本，则总成本为 155,000 MXN：

ROI = (160,000 - 155,000) ÷ 155,000 ≈ 3.2%

所以 ROAS 很高不等于业务利润高。对现金贷尤其要把信用风险成本算进去。

不同岗位应该关注什么？

角色核心指标
素材/投放优化CTR、CPC、CPI、浅层 CPA

产品经理点击→安装→注册→KYC→申请→授信→放款各环节转化率
风控渠道/素材/用户群的通过率、FPD、Vintage、坏账率

判断顺序：每天看数据时怎么用？

  1. 先看量：Spend、曝光、点击、安装有没有异常。
  2. 看前端效率：CPC、CPI、注册 CPA、申请 CPA。
  3. 看业务质量：授信率、放款率、首贷 CAC、件均。
  4. 看风险：FPD、Vintage、渠道风险分层。
  5. 最后看价值：LTV、回收周期、ROAS、ROI。

原则：前端指标决定“流量是否便宜”，后端指标决定“用户是否值得买”。
