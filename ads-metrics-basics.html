海外投放指标词典｜现金贷 APP

从曝光、点击、安装、申请，一路看到放款、风险与利润｜2026-08-19 更新：新增 Uplift、Conversion Lag

一张图先记住

曝光 → 点击 → 安装 → 注册/KYC → 申请 → 授信 → 放款 → 首期还款 → 复借 → 生命周期价值
CPM → CTR/CPC → CPI → CVR/CPA → Approve/Disburse Rate → CAC → FPD/Vintage → LTV → Payback → ROI

原则：前端指标解释流量价格，中间指标解释漏斗损失，后端指标回答“这批用户到底值不值得买”。

CPM

Cost Per Mille｜千次展示成本

CPM = 花费 ÷ 展示 × 1000

看库存价格与竞价强度。

CTR

Click-through Rate｜点击率

CTR = 点击 ÷ 展示

看素材吸引力；高 CTR 不等于高质量用户。

CPC

Cost Per Click｜点击成本

CPC = 花费 ÷ 点击

通常受 CPM 与 CTR 同时影响。

CVR

Conversion Rate｜转化率

CVR = 下一步完成数 ÷ 上一步人数

必须注明区间：Click→Install、Register→Apply、Apply→Disburse 都不是同一个 CVR。

CPI

Cost Per Install｜安装成本

CPI = 花费 ÷ 安装人数

适合 App 买量前端效率判断。

CPA

Cost Per Action/Acquisition｜目标行动成本

CPA = 花费 ÷ 目标行动人数

必须说明是注册、申请还是其他事件 CPA。

tCPA

Target CPA｜目标 CPA

自动出价希望平均实现的转化成本，不是每次转化的封顶价。

CAC

Customer Acquisition Cost｜客户获取成本

CAC = 获取有效客户的总成本 ÷ 新增有效客户数

现金贷最常看首贷 CAC。

ROAS / tROAS

广告支出回报 / 目标广告支出回报

ROAS = 广告带来的收入 ÷ 广告花费

现金贷不要把放款金额直接当利润型 value。

ROI

Return on Investment｜投资回报率

ROI = (收益 − 总成本) ÷ 总成本

总成本应含获客、坏账、资金和运营等。

LTV

Lifetime Value｜生命周期价值

风险调整 LTV ≈ 生命周期收入 − 信用损失 − 资金成本 − 服务/催收等变动成本

LTV/CAC

价值/获客成本比

LTV/CAC = 风险调整 LTV ÷ 首贷 CAC

Payback

Payback Period｜回收周期

累计风险调整贡献首次 ≥ CAC 时，对应天数 = Payback

FPD

First Payment Default｜首期逾期/违约

必须写清 FPD1/FPD7 等窗口、件数/金额口径和成熟分母。

Vintage

批次/账龄表现

同账龄比较不同放款 Cohort 的风险，避免新资产稀释总体逾期。

Uplift

提升幅度 / 增量提升

相对 Uplift = (实验方案指标 − 基线方案指标) ÷ 基线方案指标

例：Web CVR 8%，Deep Link CVR 12%，相对 uplift = 50%。

误区：CVR uplift 不等于利润 uplift；还要继续看首贷 CAC、FPD 和 LTV。

Google 场景：App Connect A/B test 提供 Deep-link uplift 与 UHA uplift。

官方原文：Google App Connect A/B test reporting

Conversion Lag

转化延迟

从广告点击/曝光到目标转化被记录之间的时间差。

现金贷：Click→Apply 可能当天发生，而 Apply→Disburse、FPD/Vintage 要更久成熟。

误区：实验刚跑 1–3 天，就用“未成熟转化”判断最终 CAC/ROI。

2026-08-19 学习：Uplift 必须穿透到经营结果

假设 CPC 都是 20 MXN。Web Apply CVR = 8%、Approve = 35%、Approve→Disburse = 70%，理论首贷 CAC 约 1,020 MXN；Deep Link Apply CVR 提升到 12%，但如果 Approve 只有 25%、Approve→Disburse 只有 60%，理论首贷 CAC 反而约 1,111 MXN。

结论：体验层 uplift 与经营层 uplift 要分开评价。

体验：CVR / UHA uplift
经营：首贷 CAC / FPD / D30 Contribution / LTV / Payback

现金贷最常见的指标联动

现象优先检查不要急着下结论
CTR 上升、CPC 下降Click→Apply、Approve/Disburse、FPD素材一定更好
CPI 下降Install→Register→Apply→Disburse渠道更便宜
申请 CPA 达标授信率、放款率、首贷 CAC业务目标已完成
Deep-link CVR upliftUHA uplift、Approve、Disburse、CAC、风险App 承接一定更赚钱
首贷 CAC 下降件均、FPD、Vintage、复借利润更高
LTV/CAC 上升预测成熟度、Payback、现金流可以无限扩量

成熟度红线

  1. FPD/Vintage 必须等观察窗口成熟。
  2. 实验类指标要考虑 Conversion Lag，不用短期未成熟数据过早决策。
  3. 平台归因与自有数仓口径并行保留，尤其是 App/Web 双路径实验。
  4. 件数率、金额率、渠道 Cohort 分开观察。

每天看数据的推荐顺序

  1. 量：Spend、Impression、Click、Install。
  2. 价格：CPM、CTR、CPC。
  3. 前端：CPI、CVR、CPA、Uplift。
  4. 业务：Approve Rate、Disburse Rate、首贷 CAC、件均。
  5. 风险：FPD、Vintage、欺诈/拒绝原因。
  6. 价值：LTV、Payback、ROAS、ROI。

正式经营看板应标注事件定义、分母、时间窗口、成熟期、件数/金额口径和归因来源。
