一、媒体与漏斗

CPM

CPM = Spend ÷ Impressions × 1000

千次展示成本。只能说明买曝光的成本。

Frequency

Frequency ≈ Impressions ÷ Reach

辅助判断素材疲劳，不能单独判断借款人质量。

CTR

CTR = Clicks ÷ Impressions

衡量广告吸引点击能力，不等于授信/放款质量。

CPC

CPC = Spend ÷ Clicks

CPI

CPI = Spend ÷ Installs

现金贷必须继续接 Backend Valid Install、Apply、Approve、Disburse、Fraud。

CVR

CVR = 下一步完成数 ÷ 上一步人数

必须注明区间，如 Click→Apply、Apply→Disburse。

CPA

CPA = Spend ÷ Target Actions

必须写明事件：Install CPA、Apply CPA、Disburse CPA 不可混用。

tCPA

Target CPA = 平台出价目标

不是每笔转化的硬上限。

Approve Rate

Approved Applications ÷ Valid Applications

Disburse Rate

常用 = Disbursed ÷ Approved

也可用 Disbursed ÷ Applications，但必须固定分母。

First-loan CAC

Acquisition Ad Spend ÷ First Disbursed Borrowers

现金贷最核心的获客经营指标之一。

二、2026-09-07 新增：Attribution Governance

Attribution Window Expansion Lift

Conversions under Longer Window ÷ Conversions under Shorter Window − 1

用途：量化仅因归因窗口变长，平台报告多识别了多少转化。

现金贷判断：Lift 很高不等于真实首贷新增；必须继续与 Backend 成熟首贷对账。

Window-normalized CPA

Spend ÷ Conversions under a Standardized Attribution Window

用途：跨 Campaign/时期比较时固定相同归因窗口，减少口径变化造成的假优化。

注意：必须把 window label（如 CTA7/EVTA1/VTA1）保存进报表。

TTAM-to-MMP Reporting Gap

(TikTok Ads Manager Attributed Events − MMP Attributed Events) ÷ MMP Attributed Events

用途：监控 TikTok SAN/Ads Manager 与 MMP 在同一事件上的报告差异。

误区：Gap 不自动等于 Fraud；先排 Attribution Window、Event Mapping、Dedup、Conversion Lag。

Measurement Consistency Rate

Window/Event/Source-of-Truth 均已登记且符合内部标准的 Active Ad Groups ÷ 全部 Eligible Active Ad Groups

用途：衡量多少投放单元具备可比较的测量配置。

内部目标建议：受监管现金贷可把关键 Active Ad Groups 目标设为 100%；这是内部治理目标，不是 TikTok 官方 KPI。

Referred Share

Referred Conversions ÷ (Referred + Assisted Conversions)

用途：观察 TikTok 更偏最后触点还是上游触点。主要用于 Attribution Analytics 支持的场景。

注意：不是“新增转化占比”。

Assisted Share

Assisted Conversions ÷ (Referred + Assisted Conversions)

用途：衡量 TikTok 在非最后触点路径中的参与程度。

注意：高 Assisted Share ≠ 高 Incrementality；当前多项 Attribution Analytics/3P 比较能力以 Web 场景为核心。

Backend Outcome Independence Check

比较窗口变化前后：Mature First Loans / FPD / LTV 是否实际变化

如果平台 CPA 因窗口变化大幅改善，而 Backend 首贷/风险完全稳定，应优先判断为“归因可见性变化”。

TikTok 官方背景：Attribution Analytics Overview（Sep 2026） ｜ App/SAN Attribution Window ｜ Assisted Conversions

三、Placement / Publisher / PineDrama

TikTok Ad Network Spend Share

TikTok Ad Network Spend ÷ Total TikTok Spend

Publisher ID Coverage Rate

Events with Valid Publisher/Sub-publisher ID ÷ Eligible Ad Network Events

Publisher Backend Verified Install Rate

Backend Verified First Launches ÷ MMP Attributed Installs（by Publisher）

Publisher First-loan CAC

Publisher Attributed Spend ÷ Publisher First Disbursed Borrowers

Publisher FPD7 Delta

Publisher Mature FPD7 − Comparable Baseline FPD7

PineDrama Spend Share

PineDrama Spend ÷ Eligible TikTok Placement Spend

用途：Smart+/Automatic Placement 中识别有多少预算实际进入 PineDrama。

前提：账户报表能按 placement/ad type 拆出 PineDrama。

PineDrama First-loan CAC

PineDrama-attributed/mapped Spend ÷ Mature First Disbursed Borrowers from PineDrama Cohort

用途：判断短剧版位是否只是便宜流量，还是能产生合格首贷。

注意：必须保持 Attribution Window/产品/时间成熟度可比。

TikTok 官方背景：TikTok Placement（Sep 2026，列 Mexico/PineDrama） ｜ PineDrama Performance Auction

四、线索质量与业务

Qualified Lead Rate

Qualified Leads ÷ Raw Leads

Qualified Lead CPA

Ad Spend ÷ Qualified Leads

Lead-to-Disburse Rate

First Disbursed Borrowers ÷ Raw Leads

Converted Lead Rate

Converted Leads ÷ Qualified Leads

Register Rate

Registered Users ÷ Valid Visits/First Launches

Application Rate

Valid Applications ÷ Registered/Eligible Users

五、风险与价值

FPD

First Payment Default。必须写清 FPD1/3/7/30、件数/金额口径和成熟期。

Vintage

按放款 Cohort、MOB/账龄比较风险表现；跨渠道必须同成熟度。

Risk-adjusted LTV

≈ 生命周期收入 − 预期信用损失 − 资金成本 − 服务/催收等变动成本

LTV/CAC

Risk-adjusted LTV ÷ First-loan CAC

Payback

累计风险调整贡献首次 ≥ CAC 时对应天数

ROAS / tROAS

ROAS = Conversion Value ÷ Ad Spend

现金贷不应把放款本金直接当利润型 Value。

ROI

ROI = (收益 − 总成本) ÷ 总成本

Risk-adjusted Value / Cost

Risk-adjusted Total Value ÷ Ad Spend

六、数据健康、归因成熟度与反作弊

Event Coverage Rate

平台收到的去重有效事件 ÷ 内部 Eligible 事件

Deduplication Success Rate

正确合并的重复事件对 ÷ 应去重的重叠事件对

P50 / P90 Conversion Lag

P50/P90 分别表示 50%/90% 转化完成所需延迟，是选择窗口和判断数据成熟的重要依据。

Conversion Maturity Rate

Dn 已观察转化 ÷ 最终成熟转化

Provisional CPA

Current Spend ÷ Current Observed Conversions

Mature CPA

Mature Cohort Spend ÷ Mature Conversions

MMP-to-Backend Install Gap

(MMP Installs − Backend Verified First Launches) ÷ MMP Installs

Backend Verified Conversion Rate

Backend Confirmed Target Events ÷ MMP/Platform Reported Target Events

Fraud Block Rate

Real-time Blocked Fraud ÷ Eligible Attempts

Post-attribution Fraud Rate

Later-confirmed Fraud among Attributed Events ÷ Attributed Events

七、iOS Postback 与 Capacity

Verified Postback Rate

Apple Signature Verified Unique Postbacks ÷ Unique Received Postbacks

Fine CV Availability Rate

Valid Postbacks with Fine Conversion Value ÷ Valid Postbacks

Coarse CV Availability Rate

Valid Postbacks with Coarse Conversion Value ÷ Valid Postbacks

Invalid Postback Signature Rate

Invalid Signature Unique Postbacks ÷ Unique Received Postbacks

iOS Dedicated Campaign Quota Utilization

Occupied Dedicated Campaign Slots ÷ 15

TikTok Placement 与 TikTok Ad Network 分池计算。

iOS Quota Headroom

Remaining Available Slots ÷ 15

Automatic Placement Dual-Quota Consumption Rate

Automatic Placement Occupied Slots across both pools ÷ Total Occupied Dedicated Slots

Postback Density per Active Dedicated Campaign

Valid Postbacks ÷ Active iOS Dedicated Campaigns

First-loan Density per Active Dedicated Campaign

Mature First Disbursed Borrowers ÷ Active iOS Dedicated Campaigns

八、Google Search 合规资产

Compliance Asset Coverage Rate

Active Campaigns with required Approved Compliance Assets ÷ All Active Campaigns requiring them

Disclaimer Disapproval Rate

Disapproved Disclaimer Assets ÷ Submitted Disclaimer Assets

Disclaimer Pending Rate

Pending Disclaimer Assets ÷ Active Required Disclaimer Assets

FUE Disclosure Pass Rate

Audited FUE-selected URLs passing Loan Disclosure Check ÷ Audited FUE-selected URLs

Compliance Drift Rate

Active Regulated Ad-URL combinations using stale/incorrect disclosure_version ÷ All Active Regulated Combinations

Disclosure Version Coverage Rate

Active Regulated URLs/Assets with valid disclosure_version ÷ All Active Regulated URLs/Assets
Google 官方背景：Text Disclaimer ｜ Personal Loans

九、Smart+ / 预算 / AI Agent

Billing Ratio

Actual Spend ÷ (Cost Cap × Conversions) ≈ Actual CPA ÷ Cost Cap

Budget Utilization Rate

Spend ÷ Available Budget

Credit-adjusted First-loan CAC

(Gross Spend − Confirmed Usable Ad Credit) ÷ First Disbursed Borrowers

辅助口径；正式扩量仍优先 Gross CAC。

Agent Recommendation Acceptance Rate

Approved Agent Recommendations ÷ Eligible Agent Recommendations

Auto-change Rate

Auto-executed Changes ÷ All Executed Changes

Rollback Rate

Rolled-back Agent Changes ÷ Executed Agent Changes

Business Guardrail Breach Rate

Agent Changes triggering CAC/FPD/LTV Guardrail ÷ Executed Agent Changes

现金贷推荐阅读顺序

  1. 先检查 Policy / Compliance / Data Health：金融广告准入、Disclosure、Event Coverage、Dedup、MMP-Backend Gap。
  2. 再统一 Attribution Window 与 Source of Truth：TTAM/MMP/Backend 是否可比较。
  3. 看媒体：Spend、CTR、CPC、CPI/CPA、Placement/Publisher。
  4. 看业务：Apply、Approve、Disburse、Mature First-loan CAC。
  5. 看风险：FPD、Vintage。
  6. 看价值：Risk-adjusted LTV、Payback、ROI。
  7. 如果要证明“广告真正新增了业务”，再做 Incrementality，而不是用 Assisted/长窗口替代因果实验。

所有指标进入经营看板时，应标注事件定义、分母、时间窗口、成熟度、归因来源、Attribution Window、Placement/Publisher、Fraud 处理、件数/金额口径、disclosure_version 和 metric_version。
