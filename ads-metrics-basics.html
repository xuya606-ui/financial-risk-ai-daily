海外投放指标词典｜现金贷 APP

从曝光、点击、安装、申请，一路看到放款、风险与利润｜2026-08-18 更新：新增 LTV、Payback、FPD、Vintage

一张图先记住

曝光 → 点击 → 安装 → 注册/KYC → 申请 → 授信 → 放款 → 首期还款 → 复借 → 生命周期价值
CPM → CTR/CPC → CPI → CVR/CPA → Approve/Disburse Rate → CAC → FPD/Vintage → LTV → Payback → ROI

原则：前端指标解释“流量为什么变贵/变便宜”，中间指标解释“漏斗哪里损失”，后端指标回答“这批用户到底值不值得买”。

CPM

Cost Per Mille｜千次展示成本

CPM = 花费 ÷ 展示 × 1000

看库存价格和竞价强度。

CTR

Click-through Rate｜点击率

CTR = 点击 ÷ 展示

看素材吸引力；高 CTR 不等于高质量用户。

CPC

Cost Per Click｜点击成本

CPC = 花费 ÷ 点击

受 CPM 与 CTR 同时影响。

CVR

Conversion Rate｜转化率

CVR = 下一步完成数 ÷ 上一步人数

必须注明区间：Click→Install、Register→Apply、Apply→Disburse 都是不同 CVR。

CPI

Cost Per Install｜安装成本

CPI = 花费 ÷ 安装人数

适合 App 买量前端效率判断。

CPA

Cost Per Action/Acquisition｜目标行动成本

CPA = 花费 ÷ 目标行动人数

必须说明是注册 CPA、申请 CPA 还是放款 CPA。

tCPA

Target CPA｜目标 CPA

tCPA = 希望自动出价系统平均实现的转化成本

不是单次转化的封顶价。

CAC

Customer Acquisition Cost｜客户获取成本

CAC = 获取有效客户的总成本 ÷ 新增有效客户数

现金贷最常用的是首贷 CAC：获得一个首次成功放款客户要花多少钱。

ROAS

Return on Ad Spend｜广告支出回报

ROAS = 广告带来的收入 ÷ 广告花费

只聚焦广告投入本身，不等于利润。

tROAS

Target ROAS｜目标广告回报

tROAS = 希望平台平均实现的转化价值 ÷ 广告花费

现金贷需要先定义正确的 conversion value，不能把放款金额直接当利润。

ROI

Return on Investment｜投资回报率

ROI = (收益 − 总成本) ÷ 总成本

总成本应包含获客、坏账、资金和运营等。

LTV

Lifetime Value｜生命周期价值

风险调整 LTV ≈ 生命周期收入 − 信用损失 − 资金成本 − 服务/催收等变动成本

回答一个客户在整个生命周期内能贡献多少价值。

LTV/CAC

价值/获客成本比

LTV/CAC = 风险调整 LTV ÷ 首贷 CAC

适合比较“贵但高质量”和“便宜但低质量”的渠道。

Payback

Payback Period｜回收周期

累计风险调整贡献首次 ≥ CAC 时，对应天数 = Payback

回答投放出去的钱多久能赚回来；和 LTV/CAC 一起看。

FPD

First Payment Default｜首期逾期/首期违约

常见件数口径：首期达到定义逾期条件的贷款数 ÷ 到期且已成熟的首期贷款数

必须写清 FPD1/FPD7 等窗口、件数还是金额口径，以及成熟分母。

Vintage

账龄/批次表现

例如 DPD30+@MOB2 = 某放款 Cohort 在 MOB2 的 DPD30+ 余额 ÷ 该 Cohort 原始放款本金

用于同账龄比较不同放款批次的风险，避免新资产稀释总体逾期。

2026-08-18 新增学习：LTV 与 Payback 必须一起看

假设墨西哥某渠道首贷 CAC = 800 MXN。首期风险调整贡献 260 MXN，第二次借款后累计 560 MXN，第三次借款后累计 880 MXN；若第三次借款通常发生在获客后第 95 天，则该 cohort 的 Payback 约为 95 天。

如果后续生命周期总风险调整贡献预计为 1,200 MXN：

LTV/CAC = 1,200 ÷ 800 = 1.5

但注意：1.5 并不自动等于“优秀”。还要看预测是否成熟、资金占用能否承受 95 天回收、以及不同渠道的 FPD/Vintage 是否稳定。

现金贷最常见的指标联动

看到的现象优先检查不要急着下的结论
CTR 上升，CPC 下降Click→Apply CVR、Approve/Disburse、FPD“素材一定变好了”
CPI 下降Install→Register→Apply→Disburse“渠道更便宜了”
申请 CPA 达标授信率、放款率、首贷 CAC“投放目标完成”
首贷 CAC 下降件均、FPD、Vintage、复借“利润更高了”
LTV/CAC 上升预测成熟度、Payback、现金流“可以无限扩量”
FPD 恶化渠道/素材/Publisher/小时/风险等级“一定是风控模型坏了”

FPD 与 Vintage 的口径红线

  1. 先定义到期与成熟：未到首期还款观察窗口的订单不能塞进 FPD 分母。
  2. 件数/金额分开：FPD 件数率和金额率可能方向不同，高额度坏客户会显著拉高金额风险。
  3. 按 Cohort 比：渠道扩量后，应按获客/放款 Cohort 看 Vintage，不要只看当日全量逾期率。
  4. 风险指标有滞后：今天的投放变化可能要数天到数周才能在 FPD/Vintage 成熟，因此前端扩量要给风险观察窗口。

每天看数据的推荐顺序

  1. 量：Spend、Impression、Click、Install。
  2. 流量价格：CPM、CTR、CPC。
  3. 前端转化：CPI、Register/Apply CVR、CPA。
  4. 业务转化：Approve Rate、Disburse Rate、首贷 CAC、件均。
  5. 风险：FPD、Vintage、欺诈/拒绝原因。
  6. 价值：LTV、LTV/CAC、Payback、ROAS、ROI。
