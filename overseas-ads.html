2026-08-20｜TikTok Search Ads 8 月工作流升级：支持多 Ad Group / 多 Ad，并在创建流程中列出 App Promotion

TikTok 2026 年 8 月更新的 Search Ads Campaign 设置文档明确：升级后的 Search 工作流支持一个 Campaign 下创建多个 Ad Group 和多个 Ad，关键词仍由 Ad Group 管理；支持目标列表中包含 Traffic、Sales、Lead Generation 和 App Promotion。TikTok 同时建议 Search Ads 的预算约为 Bid 的 20 倍，以保证充分的预算与竞价空间。

今日知识

Keyword ≠ Search Term：先把搜索投放的四个词分清楚

Keyword 是广告主设置的词；Search Term / Query 是用户真实输入；Match Type 决定两者允许差多远；Negative Keyword 用于明确排除不想买的搜索意图。

Keyword → Match Type → Search Term → Ad → Apply → Approve → Disburse → FPD/LTV

现金贷必须把搜索词一路穿透到后端风险和价值，不要只看 CTR/CPC。

今日实操

墨西哥现金贷 Search Keyword 首轮测试

用 Mexico Keyword Planner 建 40–80 个候选词；按通用个人贷款、在线/数字信贷、品牌/产品意图拆 Ad Group；每组保持足够关键词样本，建立房贷、车贷、企业贷款等无关意图的 Negative Keywords；次日先看 Spend/CTR/CPC/Search Term relevance/Apply CVR，后续再看 Approve、Disburse、FPD。

业务分析

Search CPC 高，不代表首贷 CAC 高

高意图 Search 流量可能 CPC 更贵，但如果 Click→Apply、Approve 和 Disburse 更高，最终首贷 CAC 反而更低。今天完整日报给出了 Feed CPC 8 MXN 对比 Search CPC 14 MXN 的漏斗算例：Search 在后端率更好时，理论首贷 CAC 可从约 1,026 MXN 降到约 569 MXN。

产品协同

把 Search Intent 写进 LP、Deep Link 与数据链路

产品不应把所有关键词都送到同一首页；应按用户搜索意图映射到资格说明、费用披露、申请入口等页面。数据侧保留 keyword、search_term、match_type、campaign_id、adgroup_id，并与 user_id/application_id/loan_id 串起来，最终形成关键词级首贷 CAC、FPD 和 LTV。
