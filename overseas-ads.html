Agentic Ads Operations：MCP / Agent / Skill / Tool

Goal → AI Agent → AI Skill / Workflow → MCP Tools → Ads Platform Action → Measurement → Next Decision

AI Agent 负责理解目标并调用工具；MCP 是标准连接协议；MCP Tool 是具体动作；AI Skill 是多个动作和规则组成的高层工作流。现金贷建议权限按 Read → Recommend → Approve-to-Write → Auto-Write 逐级开放。

3）实操训练

只读 Agent + 扩量审批闸门

  1. Agent 首先只读取 Spend、CPA、Budget、Bid、Learning/Status。
  2. 接入内部聚合 Approve、Disburse、First-loan CAC、FPD7 成熟度和 D30 Contribution。
  3. 只有 Mature CAC、FPD、样本量均满足内部门槛时才输出扩量建议。
  4. Budget/Bid 变更生成 `change_id / old_value / proposed_value / reason / rollback_rule`，人工批准后执行。
  5. 次日对比 Agent 建议组与人工对照组，检查是否出现“媒体指标改善、业务质量恶化”。
4）业务分析

Apply CPA -25%，First-loan CAC 可以 +29%

迁移前：Apply CPA 160；Approve 40%；Approved→Disburse 70% → First-loan CAC ≈ 571 MXN
迁移后：Apply CPA 120；Approve 25%；Approved→Disburse 65% → First-loan CAC ≈ 738 MXN

因此 Agent 的目标不能只是“最小化 CPA”，必须同时满足媒体效率、首贷 CAC、FPD/Vintage、LTV/Payback 与合规 Guardrail。
