2026-09-08｜Google Target-based Bidding 已全面生效：Loose Target 会更接近被“严格执行”

Google 已确认，新的 target-based bidding 行为已经在 2026-08-27 完成全球部署。核心变化是：处于 Limited by budget 且使用 Target CPA / Target ROAS（以及 Demand Gen Target CPC）的受影响 Campaign，会更一致地朝你设置的 target 优化，即使你调整 Budget。

如果某个 Campaign 的 tCPA=400 MXN，但历史实际 CPA 只有 240 MXN，过去可能长期“超额完成”；新行为下，如果 target 继续保持 400，实际表现可能逐步更接近 400。因此今天真正需要审计的是 Target 是否仍等于真实业务目标，而不是先看 Budget 要不要加。

2）海外投放知识学习

Target Gap：平台目标必须从真实首贷 CAC 反推

tCPA = 平台目标事件成本
Actual CPA = Spend ÷ 实际目标事件
First-loan CAC = Spend ÷ 首次放款用户

Business-derived Apply tCPA ≈ Allowable First-loan CAC × Mature Apply→Disburse Rate

例如业务允许 First-loan CAC=800 MXN，成熟 Apply→Disburse=25%，则合理的 Apply tCPA 上限约 200 MXN。若平台仍设 350–400，即使系统“达成 target”，真实首贷 CAC 也可能超标。

Target Gap Ratio = (Platform Target − Mature Actual CPA) ÷ Mature Actual CPA。Gap 大且为正的 Limited-by-budget Campaign，是今天优先审计对象。

3）实操训练

Mexico Google Bid Target Alignment Audit

  1. 导出 Mexico Search / PMax / Demand Gen，筛 Limited by budget + Target CPA / Target ROAS / Target CPC；Google App Campaign 单独排除。
  2. 固定最近 28 天成熟口径：Target、Mature Actual CPA/ROAS、Optimization Event、Apply、Approve、Disburse、First-loan CAC、FPD/Vintage、Conversion Lag。
  3. 计算 Target Gap Ratio，并反推 Business-derived Target。
  4. 对偏差最大的 Campaign 用 Bid Target Adjustment Tool 或手动调整；为便于归因，一次只改一个主要变量。
  5. 至少等待 1–2 conversion cycles，再评价真实结果。

内部预警起点：Target Gap Ratio ≥ +30%，或 Platform Target 与 Business-derived Target 偏差 ≥20%，进入 Review/P0；这些是内部治理阈值，不是 Google 官方 KPI。

4）业务分析

平台达成 tCPA，首贷 CAC 反而恶化 67%

Spend = 120,000 MXN
旧 Actual Apply CPA = 240 → 500 Apply
Apply→Disburse = 30% → 150 首贷
First-loan CAC = 800 MXN

若实际 CPA 向旧 tCPA=400 靠拢 → 300 Apply
同样 30% 放款率 → 90 首贷
First-loan CAC ≈ 1,333 MXN（+67%）

所以目标出价不能只由投手沿用历史数字，必须从业务允许 CAC、漏斗转化率和风险调整 LTV 反推。
