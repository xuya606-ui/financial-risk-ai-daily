1）今日最新资讯

2026-09-22｜iOS 27 进入真实流量期：投放效果必须做 Version-aware 分析

Apple 9 月 14 日正式发布 iOS 27、iPadOS 27 等系统。Apple 官方测试显示 iPhone/iPad App 启动速度最高可提升约 30%，同时强调实际表现取决于设备、配置和使用条件。现金贷 APP 的 First Open、注册与 KYC 基线可能因此变化。

Apple 官方原文：Major updates for Apple’s software platforms are now available

App Store Connect 自 9/14 接受 Xcode 27 / iOS 27 SDK 正式提交，9/18 又支持 Xcode 27.1 beta / iOS 27.1 beta TestFlight。因此 App 发版、SDK、Deep Link、权限、KYC 相机/证件上传和事件回传都应进入投放变更日历。

Apple 官方原文：App Store Connect Release Notes

Apple 的 AdAttributionKit 点击后 30 天、曝光后 24 小时可形成安装归因；Postback 应验证 JWS 签名并按 postback-identifier 去重。Apple Ads 还提醒 MMP 常以 First Open 定义 Install，而 Apple Ads 使用 App Store verified download，因此差异不应自动判定为作弊。

Apple 官方原文：AdAttributionKit ｜ Postback verification ｜ Apple Ads × MMP

身份治理继续关注 TikTok 和 Meta：TikTok 已推进 Custom Identity 退出并鼓励 Verified Business Account；Meta 正扩大 Advertiser Verification。信贷类广告应保证广告主体、域名、App Store 开发者和贷款主体一致。

官方原文：TikTok F.I.R.S.T. ｜ Meta Advertiser Verification

【墨西哥重点】系统升级不能改变贷款产品事实与平台准入

TikTok 当前 Mexico 金融广告仍要求当地/区域许可、disclosure/disclaimer 和 18+；禁止示例仍包括 APR ≥50% High APR Loan、Payday Loan、还款期 ≤90 天 Short-term Loan。Google Personal Loans 仍只允许需要 61 天或以上才能完全偿清的个人贷款，并要求 LP/App 显著披露期限、最高 APR/当地等效年化口径和代表性总成本。

2）海外投放知识学习

Release Confounding：版本变化会“污染”渠道效果

Release Confounding 指 OS、App Build、MMP/Analytics SDK、Deep Link、KYC SDK 或产品/风控版本同时变化，导致总报表无法区分媒体变化与产品/技术变化。

真实媒体效果 + OS/App版本影响 + SDK/埋点影响 + 产品/风控变化 = 总报表里的“效果变化”

每个付费 Cohort 建议附带 os_version / app_version / build_version / mmp_sdk_version / analytics_schema_version / deep_link_version / product_version / risk_strategy_version。先做同版本对比，再做跨版本归一化。

3）实操训练

Mexico iOS 27 Acquisition QA

  1. 拉 9/7 至今 Mexico iOS 付费 Cohort，按 platform/campaign/os/app/build 拆分。
  2. 串联 click → download → first_open → deep_link → register → kyc → apply → approve → disburse。
  3. iOS 27 真机回归 Deep Link、Deferred Deep Link、相机/证件上传、权限、WebView、OTP、MMP 初始化和 S2S。
  4. AdAttributionKit/MMP/Backend 对账：JWS 签名、postback-identifier 去重、did-win、Redownload、时间窗与 S2S 延迟。
  5. 所有版本变化生成 release_id，保存上线时间、灰度比例、SDK 和 Owner。

内部起点（非官方 Benchmark）：First Open→Register 或 KYC Completion 版本差异 ≥10pct 触发 P1；Deep Link Success 下降 ≥5pct 暂停对应版本扩量；Attribution Match Gap 相比自身 28 天基线恶化 ≥10pct，先查技术链路。

4）业务分析

CPI 不变，First-loan CAC 也可能变化 20%+

示例：两期 Spend 都是 100,000 MXN、Install 都是 4,000，CPI 均 25 MXN。旧版本约 216 个首贷，CAC≈463 MXN；若新版本 Register/KYC 改善，约 257 个首贷，CAC≈389 MXN；若 KYC SDK 兼容问题使 KYC 掉到42%，则约197个首贷，CAC≈508 MXN。

Media CAC Change = Traffic Mix Effect + Product/Version Effect + Risk/Approval Effect + Measurement Effect

预算评审必须同时看 Blended CAC 与 OS/App-version CAC；只有版本内 CAC、Approve、FPD/Vintage 同时恶化，才更有证据指向媒体人群质量。
