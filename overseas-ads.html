2026-09-18｜TikTok Upgraded Smart+：自动化从“开关”升级成“控制面”

截至今天官方核查，过去 24 小时没有发现会立即改变 Mexico 现金贷核心准入边界的新禁投规则。今天最值得落地的是 TikTok 当前重点展示的 Upgraded Smart+：Manual 与 Smart+ 统一到一个创建流程，广告主可以按模块选择 full automation、partial automation 或 fully manual。升级版支持 Traffic、Sales、Lead Generation、App Promotion；并提供更灵活的 Audience/Placement、多个 Ad Group、Automatic Campaign Budget 或 Custom Ad Group Budgets、Creative Combination Control、Multi-URL、最多 50 个 Creative Assets/Asset Group，以及 Creative-level Reporting。该能力可能尚未对所有账户开放。

对现金贷的核心影响：以后不能只记录“Smart+ 开/关”，而要记录 Audience、Budget、Placement、Bid/Optimization、Creative、Destination 六个自动化控制面；合规边界固定，算法探索空间动态开放。

2）海外投放知识学习

Automation Surface：自动化不是一个开关

把 Campaign 自动化拆成六层：Audience、Budget、Placement、Bid/Optimization、Creative、Destination。一个 Campaign 完全可以是“受众自动 + 预算自动 + 版位手动 + 素材自动 + Destination 锁定”。

Policy Guardrail → Automation Surface → Delivery → Apply/Approve/Disburse → FPD/Vintage → Risk-adjusted LTV

现金贷的年龄、地域、产品、URL、贷款期限/APR/费用、Disclosure 属于 Guardrail；这些不能为了追求算法自由而取消。正确比较对象不是“Smart+ vs Manual”，而是 automation_version vs automation_version。

3）实操训练

Mexico Smart+ Automation Control Ladder Test

  1. 选一个最近 28 天稳定的 App Promotion 或 Lead Generation 流量单元，固定 Product Version、Optimization Event、Creative Pool、Destination 与 Disclosure Version。
  2. Control 保留当前较多手动约束；Treatment 只开放 1–2 个自动化面，例如 Audience Automatic + Automatic Placement。
  3. 记录 automation_version / audience_mode / budget_mode / placement_mode / creative_mode / destination_lock / bid_strategy。
  4. D1–D3 看 Delivery、CPA、Placement Mix、Creative Combination；D7+ 看 Valid Apply、Approve、Disburse、First-loan CAC；风险成熟后看 FPD/Vintage、LTV。
  5. 如果平台 CPA 改善但首贷 CAC/FPD 恶化，直接回退对应 automation_version。

内部起点（非官方 Benchmark）：若 Treatment 的 First-loan CAC 改善 ≥10%、Approve Rate 不恶化超过 3pct、成熟 FPD7 不恶化超过 1.5pct，再考虑开放下一层自动化。

4）业务分析

Apply CPA 便宜约 21%，首贷 CAC 仍可能更贵

示例：Partial Control 花 120,000 MXN，1,500 Apply，Apply CPA=80；Approve=38%，约 428 个首贷，First-loan CAC≈280 MXN，FPD7=18%。Full Automation 同样花 120,000 MXN，1,900 Apply，Apply CPA≈63（便宜约 21%），但 Approve=29%、约 397 个首贷，First-loan CAC≈302 MXN（反而贵约 8%），FPD7 升到 23%。

Platform CPA → Valid Apply → Approve → Disburse → First-loan CAC → FPD/Vintage → Risk-adjusted LTV → Payback/ROI

因此自动化成功不等于经营成功；最终目标是新增健康首贷，而不是最便宜的浅层事件。

5）产品相关

Automation Control Registry + Destination Guardrail

产品
定义 Product/Offer/Amount/Tenor/Fee、允许 URL/App Destination、Disclosure Version。
投放
维护 Audience/Budget/Placement/Bid/Creative 自动化模式与 automation_version。
数据
按 automation_version 输出 CAC、Approve、FPD/Vintage、LTV，并拆 Placement/Creative。
风控
比较自动化版本的 Fraud/Approve/FPD/Vintage，不把用户级风险标签直接用于广告定向。
研发
保证 campaign/adgroup/creative/destination/automation_version→user→application→loan 可追踪并可回滚。

Registry：platform / market / campaign_id / automation_version / audience_mode / budget_mode / placement_mode / bid_mode / creative_mode / destination_lock / product_version / disclosure_version / enabled_at / owner
