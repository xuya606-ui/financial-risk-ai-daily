1）今日最新资讯

2026-09-05｜Google Search Text Disclaimer：AI Max / FUE 自动化下的合规“强制展示位”

Google 当前已经向全球广告主提供 Text Disclaimer。批准后的 Disclaimer Asset 会在 RSA 描述区域展示，并与 AI Max、Final URL Expansion 兼容；单条上限 90 个字符，且必须在 Campaign/RSA 创建后再添加。

Google 官方原文：About text disclaimers for Search ads

重要风险：如果 Disclaimer Asset 审核不通过，RSA 仍可能继续投放；此外，极少数语言/无障碍大字号场景可能出现截断。因此“有 Disclaimer”不等于无需监控。

更重要的是，Disclaimer 不能替代贷款 LP/App 的政策披露。Google Personal Loans 仍要求只允许 61 天或以上才能完全偿还的个人贷款，并要求最短/最长期限、最高 APR/当地等效口径和代表性总成本在 LP/App 显著展示。

Google 官方原文：Google Personal Loans

【墨西哥重点】今天没有发现贷款准入规则的 24 小时级重大变化

TikTok Mexico 与 Google Personal Loans 的核心边界维持不变。Mexico 团队今天最值得做的不是追新规，而是把“广告层 Disclaimer + AI Max FUE URL + LP Disclosure Version”做成可审计链路。

2）知识学习

Compliance Asset Stack：RSA、Text Disclaimer、Text Customization、FUE、LP Disclosure

Search Term → RSA
├─ Advertiser Assets
├─ Text Customization / Google AI Assets
└─ Text Disclaimer（批准后进入描述区）
→ Final URL / FUE URL
→ Landing Page / App Disclosure
→ Apply → Approve → Disburse

Text Disclaimer 管“广告必须展示什么”；Text Customization 管“AI 还能自动生成什么”；FUE 管“用户最终去哪一个 URL”；LP/App Disclosure 管“贷款产品必须披露什么”。这四层不能互相替代。

Google 官方原文：Text Disclaimer ｜ AI Max / FUE
3）实操训练

Mexico Search：Disclaimer × FUE × LP 合规体检

  1. 导出 Mexico Personal Loan Search Campaign，标记 AI Max / Text Customization / FUE / RSA / Final URL。
  2. 需要广告层强制披露的 Campaign，添加合规团队批准过、≤90 字符的 Text Disclaimer。
  3. 每日监控 Disclaimer Approved / Disapproved / Pending；Disapproved 时不要误以为广告必然停投。
  4. 导出 AI Max 实际选择的 Final URL，检查每个 URL 的贷款披露和 disclosure_version。
  5. 业务复盘接 CTR/CPC → Apply → Approve → Disburse → 首贷 CAC → FPD/Vintage。

内部建议把 Compliance Asset Coverage 和 FUE Disclosure Pass 设为 100% 才允许新增预算；这是公司治理阈值，不是 Google 官方 KPI。

4）业务分析

CTR 少一点，不代表经营更差

示例 A：100,000 Spend → 200 Apply → 80 Approve → 56 首贷 → CAC ≈ 1,786 MXN
示例 B：更透明文案 → 190 Apply → 90 Approve → 68 首贷 → CAC ≈ 1,471 MXN

Disclaimer 可能占用描述空间并改变 CTR，但如果减少误解型用户、提高 Approve/Disburse，最终首贷 CAC 可能反而更好。最终仍以成熟 CAC、FPD/Vintage、LTV 判断。
