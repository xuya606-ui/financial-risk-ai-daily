【墨西哥重点】价值优化不能绕过 Credit Policy

TikTok 对 Mexico 当前仍要求当地/区域许可、必要披露和 18+，并禁止 APR ≥50%、Payday Loan 及期限 ≤90 天的短期贷款。Google Conversion Value Rules 还提示，Credit 相关广告的部分 value rule 条件可能不可用。

建议：价值优化优先使用事件层级和允许回传的商业价值；信用评分、逾期、收入、审批额度等敏感属性默认留在内部数仓，是否外发需经过合规/隐私审查。

官方原文：TikTok Financial Services Policy ｜ Google Conversion Value Rules

今日知识

VBO：Conversion Count → Conversion Value

Value-Based Optimization / VBO 不再只把每次 Apply/Disburse 当成同样价值，而是尝试把预算给到更高价值转化。

Conversion-based：最大化转化数量 / 控制 CPA
Value-based：最大化转化价值 / 控制 ROAS
内部经营：Risk-adjusted Value ≈ 收入 − 信用损失 − 资金成本 − 变动成本

官方原文：Google Value-based Smart Bidding

今日实操

先做 Value Mapping，再做 tROAS Challenger

列 Register → KYC → Apply → Approve → Disburse → Good First Payment；用成熟 Cohort 估计每个事件的 expected contribution；内部 Risk-adjusted Value 与平台允许回传的 value 分开管理。选一个稳定 Campaign 小流量做 tCPA Champion vs VBO/tROAS Challenger。

业务分析

CAC 更低，不等于 Value/Cost 更高

同样花费 100,000 MXN：A 有 500 笔首贷、CAC 200，但每笔风险调整价值 260，Value/Cost=1.30；B 只有 350 笔、CAC≈286，但每笔风险调整价值 430，Value/Cost≈1.51。预算从“最低 CAC”升级到“风险调整价值最大化”后，B 可能更值得扩量。

产品协同

Value Event Contract

产品定义事件/value 口径；投放选择 tCPA 或 VBO/tROAS；数据维护成熟 Cohort 与 value_version；风控提供内部风险调整结果；研发保证 event_id、event_time、currency、value、版本、重试与去重。所有 value 修改必须可追溯。
