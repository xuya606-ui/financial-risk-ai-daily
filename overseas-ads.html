2026-08-22｜Meta AI 接入 Meta Ads + Google Workspace：投放分析进入“账户级 AI 助手”阶段

TikTok 对墨西哥现行金融广告限制仍未改变：APR ≥50% 的高 APR Loan、Payday Loan 和还款周期 ≤90 天的短期贷款仍不允许投放。今天更值得执行的是事件数据治理：TikTok 支持 SubmitApplication 标准事件，但明确提醒不要发送敏感访客数据；Meta Business Tools Terms 也禁止向 Meta 分享金融信息等敏感类别。

今日知识

Pixel + Events API / Conversions API + Event Deduplication

Pixel 从浏览器收事件，Events API/Conversions API 从服务器发送事件。两条链路联合使用时，要靠同一 event_id 做 Event Deduplication，避免同一申请被算两次。

Browser Event + Server Event + same event_id → Deduplication → 1 unique conversion

官方原文：TikTok：Pixel + Events API ｜ TikTok：Event Deduplication ｜ Meta：Conversions API

今日实操

建立“营销事件白名单 + 数据防火墙”

把所有事件按“允许外发 / 需审批 / 仅内部”分级；外发参数采用白名单；Browser + Server 重叠事件统一 event_id；建立 Event Coverage、EMQ/Diagnostics 与去重对账；研发预留 Kill Switch，发现敏感字段误传或事件暴涨时可立即关闭。

业务分析

Apply CPA -20%，首贷 CAC 仍可能 +17.6%

示例：Apply CPA 从 160 MXN 降到 128 MXN，但 Approve Rate 由 40% 降至 28%、Approved→Disburse 由 70% 降至 68%，理论首贷 CAC 从约 571 MXN 升至约 672 MXN。媒体 AI 优化的是你给它的目标，不一定是公司利润函数。

产品协同

把 Marketing Event Contract 做成正式产品能力

产品维护事件字典和字段白名单；投放只申请必要信号；数据维护 event_id 与数仓映射；风控敏感数据优先留内部；研发负责 Pixel/SDK + Server API、重试、去重、字段过滤和 Kill Switch。
