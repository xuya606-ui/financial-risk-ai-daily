2）海外投放知识学习

Impression Share ≠ Search Quality ≠ Business Value

Impression Share描述“在有资格参与的 Search Results 展示中，你拿到了多少”；Top 1 Impression Share描述“在有资格参与的第一广告位展示中，你拿到了多少”。两者主要衡量可见度，不直接代表借款人质量。

Eligible Search Demand → Impression Share → Top 1 Share → Click/LPV → Apply → Approve → Disburse → Search First-loan CAC → FPD/Vintage → Risk-adjusted LTV

某关键词 Share 低可能是预算不足、Bid 不够、Keyword Coverage 小或 Creative Relevance 差；即使 Share 拉高，如果新增流量 Approve Rate 下滑或 FPD 上升，业务上仍然可能是负优化。

Search Impression Share
Captured Eligible Search Impressions ÷ Eligible Search Impressions
Top 1 Impression Share
Captured Eligible Top-1 Impressions ÷ Eligible Top-1 Impressions
Search→Disburse Rate
Search First Disbursed Borrowers ÷ Matched Search Clicks/Visits
Search First-loan CAC
Search Spend ÷ First Disbursed Borrowers
Search FPD Delta
Search Mature FPD − Comparable Non-search Baseline

常见误区：Share 低就直接加预算；Top 1 越高越好；Search CPC 高就判断搜索流量贵；把 TopSearch 当直接转化产品。TopSearch 当前官方定位是 Reach/上中层漏斗的第一 Sponsored Position。

3）实操训练

Mexico TikTok Search Intent Audit

  1. 先确认账户是否开放 Search Ads Campaign、Impression Share、Top 1 Impression Share、TopSearch；Financial Services 是受限制垂类。
  2. 导出最近 28 天：campaign_id / adgroup_id / keyword / search_query / match_type / impression_share / top1_impression_share / impressions / clicks / spend / creative_id / landing_url。
  3. 按意图分组：Brand / Category / Need-state / Competitor / Seasonal；金融高风险词单独进入 Compliance Review。
  4. 接 Backend：search_query → session/user_id → application_id → loan_id，计算 Apply、Approve、Disburse、Search CAC、FPD/Vintage、LTV。
  5. 满预算且业务质量健康 → 小步加 Budget；未花满 → 查 Bid；Query 少 → 查 Keyword Coverage；Share 低且相关性差 → 改 Keyword-Creative-Landing Match。
  6. TopSearch 只在账户/市场支持且金融类别允许时，对品牌/高意图品类词小范围测试。

内部判断逻辑（非 TikTok 官方阈值）：某意图组 Impression Share <40%，同时 Search First-loan CAC ≤ 非搜索成熟 CAC 的 90%、FPD Delta ≤ +1pct，可测试 10%–15% 的 Budget/Bid 提升；Share >70% 但首贷量仍低，优先扩 Keyword/Creative/LP Coverage；Search FPD Delta >+2pct 或 Approve 明显低于基线时暂停扩量。

4）业务分析

Search CPC 更贵，不代表首贷更贵

示例：Search Spend 100,000 MXN，2,000 Clicks，CPC=50；800 Apply，Approve=40%，Disburse=75%，得到 240 首贷，First-loan CAC≈417 MXN，FPD7=17%。Feed 同样花 100,000 MXN，4,000 Clicks，CPC=25；900 Apply，Approve=30%，Disburse≈67%，得到约 181 首贷，CAC≈552 MXN，FPD7=20%。

Search 的 CPC 是 Feed 的 2 倍，但首贷 CAC 反而低约 24%。因此要问的不是“Search CPC 贵不贵”，而是：

新增 Search Share 带来的边际首贷，是否仍满足 Allowable CAC + FPD/Vintage + LTV/Payback Guardrail？

如果 Share 从 35% 拉到 70% 后新增 Query 更泛，Approve 从 40% 降到 28%、FPD7 升到 23%，那 Search Share 翻倍并不代表业务变好。

5）产品相关

Search Intent Registry + Query-to-Landing Contract

产品
定义 query_intent、product_version、额度/期限/费用、landing_version、disclosure_version、Deep Link/Fallback。
投放
维护 keyword/query、match_type、negative keywords、Bid/Budget、Search/TopSearch、Creative 与 Landing 映射。
数据
打通 query→session→application→loan，按 Intent Cohort 输出 CAC、Approve、FPD/Vintage、LTV。
风控
比较 Brand/Category/Need-state 等搜索意图组的风险质量，识别泛词扩量后的边际恶化。
研发
保证 UTM/Click ID、Deep Link、landing_version、event_id、application_id、loan_id 可追溯并支持回滚。

Search Intent Registry：market / platform / campaign_id / keyword / query_cluster / intent_type / match_type / compliance_status / owner

Query-to-Landing Contract：query_cluster / eligible_url / app_destination / product_version / disclosure_version / approved_copy_hash / fallback / effective_from
