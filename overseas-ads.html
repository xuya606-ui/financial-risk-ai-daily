【墨西哥重点】先做 es-MX Canonical Copy，再考虑自动翻译

Mexico 贷款广告不建议直接把全球英语素材交给自动翻译后扩量。先固定 es-MX 的 Amount、Tenor、APR/Fees、Approval Condition、Disbursement Time、Eligibility、Legal Entity、Privacy/Permissions、CTA、Disclaimer；自动生成音频/字幕只要触碰这些关键字段，就必须重新人工 QA。

2）海外投放知识学习

Localization ≠ Translation

Translation解决语言转换；Localization还要保证目标市场的语言习惯、产品事实、用户理解和监管披露一致。建议把素材拆成可灵活优化的 Creative Layer 和不可任意改写的 Compliance Lock。

Source Creative → Translation / Dubbing → Language QA → Compliance Lock → Locale Routing → LP/App Locale → Apply → Approve → Disburse → FPD/Vintage

Device Language 是交付信号，不等于国籍、居住地、贷款资格或产品 Locale。不同西语市场也不能默认完全共用同一金融文案。

3）实操训练

Mexico Multilingual Guardrail Test

  1. 保留现有人工审核 es-MX 素材作为 Baseline。
  2. 在 Ads generation 检查账户是否真的开放 Multilingual Tool，并读取真实支持语言方向。
  3. 抽取 Amount / Tenor / APR&Fees / Approval / Disbursement / Eligibility / Entity / Privacy / CTA / Disclaimer 10 类关键语义。
  4. 逐语言核对自动音频和字幕，登记 variant_id、product_version、disclosure_version、qa_status。
  5. 比较 CTR/CPI/CPA → KYC → Apply → Approve → Disburse → First-loan CAC；风险等 Cohort 成熟后再看。
  6. D1先复盘语言路由、投诉/语义事故和浅层媒体指标。

内部 Guardrail：Localized Asset Compliance Pass Rate = 100% 才进入自动扩量；关键金融语义出现重大 Translation Incident 直接停用 Variant。不是 TikTok 官方 KPI。

4）业务分析

CPI 便宜 20%，First-loan CAC 仍可能贵约 50%

人工 es-MX：100,000 MXN → 4,000 Install → CPI 25 → 294 首贷 → CAC≈340

自动多语言：100,000 MXN → 5,000 Install → CPI 20 → 196 首贷 → CAC≈510

低 CPI 可能来自更大的语言覆盖，但如果 KYC、Apply、Approve 或 LP/App Locale 承接变差，首贷 CAC 仍可能恶化。最终按 Language Variant → KYC → Apply → Approve → Disburse → CAC → FPD/Vintage → Risk-adjusted LTV 判断。
