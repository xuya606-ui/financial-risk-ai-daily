2026-09-01｜Google AI Max 自动升级进入 9 月执行窗口：重点监控 Keyword Prioritization

Google 已明确，从 2026 年 9 月开始，仍使用 Campaign-level Broad Match Setting 或 Automatically Created Assets / Text Customization 的符合条件 Search Campaign 会开始自动升级到 AI Max；Google 预计符合条件的升级在 9 月底前完成。DSA 自动升级已延后至 2027 年 2 月，因此本轮 9 月迁移不要和 DSA 混在一起。

配置映射：ACA/Text Customization 用户升级后默认开启 Search Term Matching + Text Customization；Campaign-level Broad Match Setting 用户升级后默认开启 Search Term Matching。不要误以为本次 ACA/Broad 自动升级一定会自动打开 Final URL Expansion。

Google 官方原文：AI Max automatic upgrade & feature mapping ｜ Broad Match Setting / Keyword Prioritization

最关键的结构变化：旧 Campaign-level Broad Setting 下，和 Search Term 完全相同的 Broad Keyword 会被按“Exact + Broad”优先级参与路由；迁移到 AI Max 后，这种 Exact-like priority 不再保留。品牌词、核心产品词、PMax Search Theme 与不同 Search Campaign 之间的流量可能重新分配。

建议：今天先保存 8/18–8/31 Query Routing 基线；对必须稳定承接的 Brand / Core Product / Compliance-sensitive Query 增加 Exact Match Coverage，再观察迁移后的 Spend、Apply、Approve、Disburse 和 FPD，而不是直接按 Campaign CPA 调预算。

【墨西哥重点】自动升级不改变贷款准入

AI Max Migration Query Routing Audit

  1. 导出 Mexico Search Campaign，标记 legacy broad setting / ACA / AI Max / migration notice。
  2. 保存 8/18–8/31 的 Search Term → Campaign → Ad Group → Keyword → Spend/Apply/Disburse 基线。

  5. 新增 AI Max Migration Coverage、Intended Query Routing Rate、Exact Query Capture Rate。
  6. 次日先看路由和 Spend Mix；若关键 Query Intended Routing 比基线下降 >5pct，优先查 priority / Ad Rank / exact coverage。5pct 是内部预警起点。

4）业务分析

Campaign CAC 变差，不代表账户 CAC 变差

示例：迁移前 Brand Broad 与 Brand Exact 合计 Spend=100,000 MXN、500 首贷，账户 CAC=200。迁移后 Query Routing 变化，Broad 变成 30,000/120 首贷，CAC=250；Exact 变成 70,000/380 首贷，CAC≈184；但账户仍为 100,000/500=200。若只看 Campaign，会错误认为 Broad 恶化、Exact 改善；实际上可能只是流量重新路由。

Account CAC = Total Spend ÷ Total First Loans
Campaign CAC Change = Routing Mix Effect + Within-Campaign Performance Effect

因此 9 月 Search 迁移的预算决策顺序应是：Routing Mix → Approve/Disburse → FPD/Vintage → LTV/ROI → Budget。
