1）今日最新资讯

2026-09-04｜TikTok Ad Network（formerly Pangle）进入 9 月新口径，Mexico 现金贷应重点治理 Publisher 质量

TikTok 当前官方文档已经统一使用 TikTok Ad Network（formerly TikTok Pangle）。2026 年 9 月更新的说明称，该网络覆盖接近 40 万个 App / Publisher，并通过 App 流量触达超过 10 亿日活用户；平台强调 Publisher 透明度、实时 anti-fraud，以及 DoubleVerify / IAS 等第三方 post-bid brand safety measurement。

TikTok 官方原文：About TikTok Ad Network｜September 2026

TikTok Ad Network 的流量不是 TikTok Feed 的简单延伸。它在大量第三方 App / Publisher 中交付，支持 CPC、CPM、oCPM；oCPM 下可使用 Cost Cap、Maximum Delivery、Hybrid Bidding、Target ROAS。TikTok 明确说明 Placement 在创建 Ad Group 时选择，创建后不可修改。

TikTok 官方原文：Placement / Bidding / Delivery ｜ Split Testing Variables

平台提供 Block List 管理不希望出现的媒体 App / Publisher，但 TikTok 同时提示 Block List 可能减少 Impression 和 Performance。现金贷应按 Fraud、Backend Verified Install、Approve、Disburse、FPD/Vintage 和 LTV 做 Publisher 级治理，而不是按单日 CTR/CPI 粗暴拉黑。

TikTok 官方原文：TikTok Ad Network Block List

互动素材方面，TikTok Ad Network 可自动应用 Endcard、Recommended Card、Animation Effects；Endcard 可引用 App Store 的 App icon、名称、评分、描述和 CTA，并可能使用内部 AI 生成动画。因此贷款 APP 的商店页描述也应纳入广告合规治理。

TikTok 官方原文：Interactive Customizations｜September 2026

【墨西哥重点】Mexico 可作为 TikTok Ad Network 投放地区，但金融准入规则不变

TikTok 当前 Available locations 文档将 Mexico 列入 TikTok Ad Network managed account 的可投地区；self-serve Mexico account 的可用地区列表也包含 Mexico。具体是否可用仍以 Ads Manager 实际 Placement 选项为准。

TikTok 官方原文：Available locations for TikTok Ad Network Ads

TikTok Mexico 金融广告仍要求当地/区域许可、必要披露和 18+；明确禁止 APR ≥50% High APR Loan、Payday Loan、≤90 天 Short-term Loan。

TikTok 官方原文：Financial Services Policy

Google Personal Loans 当前仍只允许需要 61 天或以上才能完全偿还的个人贷款，并要求 LP/App 显著披露最短/最长期限、最高 APR/当地等效口径和代表性总成本。

2）知识学习

Publisher / Placement Quality：为什么“TikTok 流量”不能只看成一个渠道

TikTok Channel
├─ TikTok placements
└─ TikTok Ad Network
   ├─ Publisher A
   ├─ Publisher B
   └─ Publisher C ...

Placement 是广告展示环境；Publisher 是实际承载广告的网站/App。现金贷判断 Publisher 时至少同时看 Spend、Valid Install、Apply、Approve、Disburse、First-loan CAC、Fraud、FPD/Vintage、Risk-adjusted LTV。

低 CPI + 低 Backend Verified Install + 低 Approve + 高 FPD 的 Publisher，应归类为“便宜但不可扩”，而不是“高效流量”。

3）实操训练

Placement Split Test：TikTok Feed vs Ad Network

  1. 在 Mexico Ads Manager 检查 TikTok Ad Network Placement 是否实际可选。
  2. 优先用 Split Test，把 Placement 作为唯一变量；Objective、Optimization Event、Creative、Bid、Budget、OS、产品版本保持一致。
  3. 媒体层看 Spend、CTR、CPC、CPI/CPA、Budget Utilization。
  4. 业务层接 Backend Verified First Launch、Apply、Approve、Disburse、First-loan CAC。
  5. 风险成熟后再看 FPD/Vintage、D30 Contribution、Risk-adjusted LTV。
  6. Publisher 进入 `New → Observe → Eligible → Limited → Blocked → Re-test`，不要因单日波动永久封禁。

内部第一版可用“Publisher Verified Install Rate 比账户中位数低 >10pct，或 First-loan CAC 高于账户成熟基线 30%”触发 Review；这是内部阈值，不是 TikTok 官方标准。

4）业务分析

Ad Network CPI 便宜 40%，首贷 CAC 仍可能贵 57%

Feed：100,000 Spend → 4,000 installs → 3,800 valid launch → 1,140 Apply → 399 Approve → 279 首贷 → First-loan CAC ≈ 358 MXN

Ad Network：100,000 Spend → 6,667 installs → 5,000 valid launch → 1,200 Apply → 264 Approve → 177 首贷 → First-loan CAC ≈ 565 MXN

前端 CPI 低并不代表最终客户便宜。正确链路应是：`Placement / Publisher → Valid Install → Apply → Approve → Disburse → First-loan CAC → FPD/Vintage → Risk-adjusted LTV → Incremental ROI`。
