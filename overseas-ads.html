【墨西哥重点】先做 es-MX Canonical Copy，再考虑自动翻译

Mexico 贷款广告不建议直接把全球英语素材交给自动翻译后扩量。先固定 es-MX 的 Amount、Tenor、APR/Fees、Approval Condition、Disbursement Time、Eligibility、Legal Entity、Privacy/Permissions、CTA、Disclaimer；自动生成的音频/字幕只要触碰这些关键字段，就必须重新人工 QA。

2）海外投放知识学习

Localization ≠ Translation：机器翻译正确，不代表金融本地化正确

Translation是语言转换；Localization还要考虑目标市场的语言习惯、产品事实、监管披露和用户理解。建议把素材拆成可自动优化的 Creative Layer 和不可随意漂移的 Compliance Lock。

Source Creative → Translation / Dubbing → Language QA → Compliance Lock → Locale Routing → LP/App Locale → Apply → Approve → Disburse → FPD/Vintage

Device Language 只能作为广告交付信号之一，不能代替国籍、居住地、贷款资格或产品 Locale。不同西语市场也不应默认完全共用同一金融文案。

3）实操训练

Mexico Multilingual Guardrail Test

  1. 保留现有人工审核 es-MX 素材作为 Baseline。
  2. 在 Ads generation 检查账户是否真正开放 Multilingual Tool，并查看实际 Source/Output Language。
  3. 抽取 Amount / Tenor / APR&Fees / Approval / Disbursement / Eligibility / Entity / Privacy / CTA / Disclaimer 10 类关键语义。
  4. 逐语言核对自动音频和字幕，登记 variant_id、product_version、disclosure_version、qa_status。
  5. 比较 CTR/CPI/CPA → KYC → Apply → Approve → Disburse → First-loan CAC，风险等 Cohort 成熟后再看。
  6. D1先复盘语言路由、投诉/语义事故和浅层媒体指标；不要用 D0 直接判断风险。

内部 Guardrail：Localized Asset Compliance Pass Rate = 100% 才进入自动扩量；金额、期限、APR/费用、审批保证、到账时效发生重大 Translation Incident 直接停用 Variant。不是 TikTok 官方 KPI。

4）业务分析

CPI 便宜 20%，First-loan CAC 仍可能贵 50%

人工 es-MX：100,000 MXN → 4,000 Install → CPI 25 → 294 首贷 → CAC≈340

自动多语言：100,000 MXN → 5,000 Install → CPI 20 → 196 首贷 → CAC≈510

低 CPI 可能来自更大的语言覆盖，但如果 KYC、Apply、Approve 或语言承接变差，首贷 CAC 仍可能恶化。正确判断链是 Language Variant → CTR/CPI → KYC → Apply → Approve → Disburse → First-loan CAC → FPD/Vintage → Risk-adjusted LTV。
