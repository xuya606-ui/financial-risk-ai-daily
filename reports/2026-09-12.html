第三部分｜海外风控知识学习

今日主题：Expected Loss & Limit Economics｜PD × LGD × EAD 预期损失拆解与额度经济学

概念：Expected Loss把“会不会坏（PD）”“坏了亏多少比例（LGD）”和“坏的时候暴露多少钱（EAD）”放到一个损失框架里。

EL = PD × LGD × EAD

为什么重要：只看PD很容易低估额度策略的风险。同一个客户即使违约概率下降，如果EAD大幅上升，EL仍可能明显恶化。EL是准入、额度、定价、资金、催收和利润之间共同语言。

墨西哥现金贷七步案例

背景：30天首贷，Strategy B放宽部分边缘用户并提高Limit。
数据：A：PD12%、LGD70%、EAD MXN1,500，EL=126；Revenue450、Funding85、CAC80、Variable40，Contribution Margin≈119。B：PD13%、LGD72%、EAD1,900，EL≈178；Revenue510、Funding112、CAC75、Variable45，Margin≈100；Approval 31%→35%。
现象：PD只上升1pp，但EL约上升41%，新增收入没有完全覆盖新增风险和Funding。
拆解：Channel C × Low Score × Limit≥MXN2,000贡献主要EL增量；中Score×中额度仍保持正Margin。
根因：PD、LGD、EAD同时变化，特别是EAD增幅大。不能把EL恶化只归因于PD，也不能因为Approval提高就判断增长更好。
决策：低Score高Limit恢复旧额度，中Score保留Challenger；按PD/LGD/EAD做额度Guardrail，不用高价格掩盖失控风险。
结果：等两个成熟FPD7 Cohort，并继续看MOB1 DPD30+、O/E、Actual Loss vs EL、Margin。

判断方法：先固定Default和预测窗口 → 校准PD → 固定Default EAD与Recovery窗口 → 计算LGD → 拆Limit/Utilization/EAD → 做EL Bridge → 回到Contribution Margin。

常见误区：Score=PD；FPD7=长期PD；Approved Limit=EAD；Recovery Rate与LGD窗口不一致；直接用平均PD×平均LGD×平均EAD替代逐笔加总；把EL当已经发生的Actual Loss。

小练习与答案

A：PD10%、LGD70%、EAD1,500；B：PD8%、LGD70%、EAD3,000。谁的EL更高？

答案：A=MXN105；B=MXN168。B虽然PD更低，但更高EAD导致EL更高。

第四部分｜风控指标集合学习

今天完整复习/升级四个高频指标：PD、LGD、EAD、Expected Loss。以下每个指标均按12段结构；更详细版同步在今日指标页。

1. PD｜Probability of Default

1）是什么：固定预测窗口内发生Default的概率。 2）重要性：贷前/贷中领先风险输入，也是模型校准对象。 3）公式：P(Default within horizon | decision-time information)，固定Default、窗口、观察时点和账户/用户口径。 4）高低：通常低更好，但低PD不代表高利润，也不能无限提额。

5）七步案例：背景Strategy B提额；数据PD12%→13%、EAD1,500→1,900、LGD70%→72%、EL126→178；现象PD小升但EL大升；拆解风险集中Channel C×低Score×高Limit；根因PD与额度结构同时变化；决策低Score高Limit降额；结果看FPD7/MOB1/O-E/EL。 6）诊断：定义/成熟 → PD分布 → O/E → Segment → Vintage/EL。 7）动作：漂移查数据/流量，低估风险做Recalibration，边缘PD高EAD降额。 8）误区：Score=PD、FPD=PD、不同窗口横比。 9）拆分：Channel、Score、Limit、Term、Region、Model/Strategy。 10）预警：同模型同成熟Cohort看O/E与PSI，阈值只用内部基线。 11）关系：Score→PD；PD×LGD×EAD→EL。 12）练习：PD更低但EAD翻倍，EL可能更高，答案见今日指标页。

2. LGD｜Loss Given Default

1）是什么：违约后最终净损失比例。 2）重要性：连接催收/Recovery与EL。 3）公式：(Default EAD − Net Recoveries@N) ÷ Default EAD，固定Recovery MOB和成本。 4）高低：通常低更好，但不同回收窗口不可直接比较。

5）七步案例：两个Vendor各Default EAD 10m；A Gross Recovery2.6m/Cost0.5m，Net21%、LGD79%；B 3.0m/1.1m，Net19%、LGD81%；现象B毛回收高但净LGD差；拆解高成本低增量账户；根因需控制分案差异；决策按Net LGD分案；结果同Default Vintage/Recovery MOB看9-12个月。 6）诊断：EAD→窗口→Gross/Net→Vendor/Balance→Cost→LGD。 7）动作：提升触达/支付、优化Vendor、高余额分层。 8）误区：Gross=Net、不同MOB横比、展期算回收。 9）拆分：Default Vintage、Recovery MOB、Vendor、Balance、Region。 10）预警：同成熟窗口+最小EAD门槛。 11）关系：Collection→Recovery→LGD→EL。 12）练习：Default EAD5m、现金回收1.5m、成本0.3m，Net LGD=76%。

3. EAD｜Exposure at Default

1）是什么：违约时真正暴露在风险中的金额。 2）重要性：额度/金额风险核心变量。 3）公式：固定现金贷可用违约时未偿本金；循环额度可用Drawn + CCF×Undrawn。 4）高低：高不一定坏，要与PD/LGD/Margin联看。

5）七步案例：复借提额Limit 2,000→3,500；PD8.5%→8.0%、Avg EAD1,650→2,450、LGD68%→69%、金额FPD12.5%→16.8%、EL约95→135；现象件数风险没恶化但金额风险升；拆解中档Score×高Utilization；根因提额+利用率；决策分层提额并加Utilization Cap；结果看Amount FPD/MOB1/EL/Margin。 6）诊断：Limit→Utilization→EAD→PD→Amount FPD→EL。 7）动作：高PD高EAD降额，EAD突升查利用率/重复放款。 8）误区：Limit=EAD、只看均值、忽略未提款转换。 9）拆分：Score、Limit、Utilization、Term、Cycle、Strategy。 10）预警：Avg/Median/P90 EAD+金额FPD/EL联动。 11）关系：Limit→EAD→EL。 12）练习：Drawn1,200、Undrawn1,800、内部CCF40%，EAD=1,920。

4. Expected Loss / EL｜预期损失

1）是什么：综合PD、LGD、EAD得到的期望信用损失。 2）重要性：连接风险、额度、定价、资金和利润。 3）公式：EL = PD × LGD × EAD，三者窗口/Default/币种必须一致，组合优先逐笔加总。 4）高低：低通常好，但不能以牺牲全部增长为目标。

5）七步案例：A EL126/Margin119；B EL178/Margin100；现象收入增加但EL与Funding吃掉增量；拆解Channel C×低Score×高Limit；根因PD/LGD/EAD共同驱动；决策低Score恢复旧Limit，中Score做Challenger；结果比较Actual Credit Loss vs EL与Margin。 6）诊断：EL Bridge：PD Effect→LGD Effect→EAD Effect→Segment→Actual/O-E→Margin。 7）动作：PD驱动收准入/校准，LGD驱动催收，EAD驱动降额度。 8）误区：EL=Actual Loss、平均数直接相乘、窗口混用。 9）拆分：Channel、Score、Limit、Term、Vintage、Funding、Strategy。 10）预警：EL/Loan、EL/EAD、Actual/Expected与Margin联合；数值阈值仅内部使用。 11）关系：PD×LGD×EAD→EL→Provision/Pricing→Margin/LTV。 12）练习：PD15%、LGD65%、EAD2,000，EL=195；若Revenue480、Funding100、CAC80、Variable40，Margin=65。

第五部分｜海外风控实操

今日实操：EL Bridge × Limit Stress Test

所需数据：loan_id / user_id / channel / campaign / score_band / predicted_pd / lgd_assumption / approved_limit / utilization / ead / strategy_version / revenue / funding_cost / cac / variable_cost / mature_bad / recovery_cash / default_ead。

操作步骤：统一Default/窗口 → 逐笔算PD×LGD×EAD → Channel×Score×Limit分层 → A/B策略EL Bridge → Actual Bad/Recovery成熟后做O/E与LGD回测 → 计算Contribution Margin → Limit Stress（-20% / Base / +20%） → 输出动作。

SQL思路：

SELECT channel, score_band, limit_band, strategy_version,
       COUNT(*) AS n,
       AVG(predicted_pd) AS avg_pd,
       AVG(ead) AS avg_ead,
       AVG(predicted_pd * lgd_assumption * ead) AS el_per_loan,
       AVG(revenue - funding_cost - cac - variable_cost
           - predicted_pd * lgd_assumption * ead) AS contribution_margin
FROM loan_risk_economics
GROUP BY channel, score_band, limit_band, strategy_version;

Excel：逐笔增加PD、LGD、EAD、EL、Margin五列，再用Pivot拆Channel×Score×Limit；不要用全表平均PD×平均LGD×平均EAD替代逐笔EL。

阈值逻辑：不采用行业统一数值。内部黄灯可设为连续两个成熟Cohort EL/Loan明显高于历史稳定区间且Margin下降；若Actual Loss持续高于EL、Margin转负，则升级红灯并进入模型/策略治理。

异常诊断：先看PD/O-E，再看LGD/Recovery，再看EAD/Limit/Utilization，最后确认Funding与收入是否共同变化。

输出模板：Channel｜Score｜Limit｜N｜PD｜LGD｜EAD｜EL/Loan｜Actual Loss｜O/E｜Funding｜Margin｜Action。

第二天复盘：先检查模型/数据版本、Limit/Utilization和资金成本变化；深度Default/Recovery未成熟前，不因为一天Actual Loss直接改LGD。

第六部分｜业务与产品

风控 × 业务：PD下降，也可能越做越亏

经营链应固定成：Approval → PD → Limit/Utilization → EAD → LGD → EL → Funding → Contribution Margin → LTV。如果PD下降10%，但EAD上升50%，损失金额仍可能上升。增长会议不建议只报Approval、Bad Rate或件数FPD，必须同屏显示Amount FPD、EL/Loan、Average/P90 EAD和Margin。

风控 × 产品：不要默认“最大额度=最佳Offer”

页面/交互：Offer页可展示用户可选额度与期限，但默认推荐应受风险调整Margin约束；边缘Score用户进入高额度档时，可以降低默认额度或增加更明确的还款能力确认，而不是靠提高价格覆盖失控EL。

规则：Score/PD × Limit × Term × Utilization Guardrail；高PD+高EAD组合不开放促销提额；复借提额必须绑定历史还款与成熟Vintage。

职责：产品负责Offer与透明成本展示；风控负责PD/Limit/Term Guardrail；数据负责EL Bridge、O/E、Amount FPD和Margin；研发负责Strategy Version、灰度、回滚；运营只能在批准额度/优惠区间内触达，不得人工绕过高风险额度约束。
