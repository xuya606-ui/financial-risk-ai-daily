第三部分｜海外风控知识学习

今日主题：Affordability Decisioning & Income Stress｜还款能力决策与收入压力

概念：信用评分回答“这个人历史上像不像坏客”，而 Affordability 回答“在当前收入、已有债务和新贷款付款安排下，他是否还有足够现金流偿还”。建议把 DTI、PTI、Residual Income 和 Income Volatility 联合，而不是只看一个 Score。

Verified Income → Existing Debt Service → Proposed Payment → Residual Income → Income Stability → FPD / Vintage → EL / Margin

为什么重要：在高频短期现金贷中，风险可能不是“客户长期信用很差”，而是额度/价格/期限把当期现金流压得太紧。只收 Score Cutoff 会错过“中等信用 + 高支付负担”这一类风险。

背景：墨西哥30天首贷，Strategy B 在 Channel B 放宽额度并扩大流量。
数据：成熟申请40,000；Approval 31%→35%；Avg Ticket MXN1,450→1,950；DTI 30%→38%；PTI 10.8%→15.2%；Median Residual Income MXN3,700→2,500；高收入波动客占比14%→24%；FPD7 13.8%→18.5%。
现象：量和票面额增长，但早期风险恶化明显。
拆解：Channel B × Low/Medium Score × PTI高 × Income Volatility高 的 FPD7 达27%；稳定工资 + 低PTI Segment约11%。
根因：能够确认支付负担、收入波动与风险恶化高度相关，但 Channel、额度和客群结构同时变化，因此不能把高PTI直接写成唯一因果。
决策：高PTI+高波动客降额；稳定工资、中等Score保留Challenger；技术/工资识别异常先修数据，不把Missing当高风险。
结果：观察两个成熟FPD7 Cohort，再看MOB1 DPD30+、EL/Loan、Approval和Contribution Margin；风险下降且利润恢复才认为策略有效。

常见误区：DTI越低越好；把申请人自报收入当 Verified Income；短期贷款 PTI 与月收入周期不对齐；把房租/生活费全部忽略；Income Missing直接判高风险；只看件数Bad不看金额EAD。

判断方法：先统一收入定义与周期 → Existing Debt → Proposed Payment → Residual Income → Income Volatility → Channel×Score×Limit → FPD/Vintage → EL/Margin。

小练习与参考答案

用户月度可验证净收入 MXN10,000，已有月债务付款 MXN3,000，新贷款到期应付 MXN1,400。DTI=30%，PTI=14%。如果必要生活支出估计 MXN4,000，则新贷款后 Residual Income=MXN1,600。仅凭 DTI=30% 能否判断安全？

答案：不能。必须联合看 PTI、Residual Income、收入稳定性、期限匹配和历史表现。

第四部分｜风控指标集合学习

今天完整升级：DTI、PTI、Residual Income Buffer、Income Volatility

完整12段学习卡已同步到 今日指标页 和主 风控指标字典。以下为核心结论。

1. DTI｜Debt-to-Income｜债务收入比

1）是什么：现有周期性债务付款占可验证同期收入的比例。

2）重要性：贷前同步/领先指标，用于判断已有负债对现金流的挤压。

3）公式：DTI = Existing Monthly Debt Service ÷ Verified Monthly Net Income；固定税前/税后、月度化方式、征信债务范围、用户/家庭口径。

4）高低：高通常压力更大，但低DTI也可能因为漏报/征信No-hit；高收入稳定用户可承受能力与低收入用户不同。

5）七步案例：Strategy B DTI30%→38%、PTI10.8%→15.2%、FPD7 13.8%→18.5%；风险集中 Channel B×中低Score×高PTI。相关性明确，但不能单独归因DTI。

6）诊断：Income定义 → Bureau Debt完整性 → DTI Band → PTI/Residual → Score/Limit → FPD/Vintage。

7）动作：高DTI高PTI降额/拒绝；高DTI但稳定高收入可进入Challenger；No-hit不自动当低DTI。

8）误区：自报收入直接做分母；只看信用卡余额不看还款；家庭/个人收入混用；不同周期直接相除。

9）拆分：Channel、Score、Income Band、Employment、Limit、Term、New/Repeat、Region。

10）预警：用内部成熟样本按Income/Score分层建立P50/P75/P90，不采用统一行业阈值。

11）关系：Bureau Debt + Income → DTI → Approval/Limit → FPD/Vintage → EL。

12）练习

月收入12,000、现有月债务3,600，DTI=30%。

2. PTI｜Payment-to-Income｜新贷款还款收入比

1）是什么：拟发放贷款在对应周期的应付款，占同期可验证收入的比例。

2）重要性：直接衡量新贷款给现金流增加多少压力，是额度/期限/定价的前置指标。

3）公式：PTI = Proposed Periodic Payment ÷ Verified Income for Same Period；30天Bullet Loan用到期总应付与同期净收入匹配，不能把周贷付款直接除月收入而不周期转换。

4）高低：通常越高压力越大，但低PTI可能来自过长Term或低首期付款，不能单独等价于低风险。

5）案例：PTI10.8%→15.2%，高波动收入+高PTI组FPD7 27%，稳定收入低PTI约11%。

6）诊断：Payment口径 → Income周期 → Limit/Price/Term → Income Stability → FPD/Amount FPD。

7）动作：高PTI优先降额度/延长合理期限/调整Offer；不能用更高价格“覆盖”明显不可负担风险。

8）误区：只算本金；忽略费用；周期错配；PTI低就无限提额。

9）拆分：Score、Income、Limit、Term、Price、Cycle、Channel、Employment。

10）预警：按产品期限和收入档建立内部历史带；PTI上升且Residual/FPD同步恶化进入黄灯。

11）关系：Limit/Price/Term → PTI → Cash-flow Stress → FPD/Cure → Bad/EL。

12）练习

月净收入10,000，到期总应付1,500且周期约30天，PTI=15%。

3. Residual Income Buffer｜剩余收入缓冲

1）是什么：收入扣除必要生活支出、已有债务和新贷款付款后还剩多少钱。

2）重要性：补充DTI/PTI无法反映的“绝对现金余额”，低收入客群尤其重要。

3）公式：Residual Income = Verified Net Income − Essential Expense Estimate − Existing Debt Service − Proposed Payment；也可报告 Residual Ratio = Residual ÷ Income。必要支出模型必须固定版本。

4）高低：通常越高缓冲越强，但必要支出估计错误会造成假精度。

5）案例：Median Residual 3,700→2,500，低于内部历史P25的客群FPD7明显更高；但需控制收入档和地区生活成本。

6）诊断：Income → Expense Model → Debt → Proposed Payment → Region/Household → FPD/Vintage。

7）动作：低Residual降额/减少优惠驱动的过度借款；支出模型偏差先重估，不直接拒绝。

8）误区：生活支出设为0；地区成本不区分；负Residual直接视为欺诈；把税前收入和税后支出混算。

9）拆分：Income、Region、Household、Employment、Score、Limit、Term、Cycle。

10）预警：按收入/地区历史分位数建立内部基线；Residual下降且Amount FPD/EL同步升高升级。

11）关系：Income − Expense − Existing Debt − New Payment → Residual → FPD/Bad → EL/Margin。

12）练习

收入10,000，生活支出4,000，已有债务3,000，新付款1,400，Residual=1,600。

4. Income Volatility｜收入波动度

1）是什么：观察3-6个月收入/净流入的稳定程度；大白话是“每个月的钱是否稳定进来”。

2）重要性：贷前领先指标，帮助识别平均收入相同但现金流稳定性完全不同的用户。

3）公式：内部示例可用 CV = Std(monthly verified net inflow) ÷ Mean(monthly verified net inflow)，也可用最低月/平均月、工资到账规律等；这不是行业统一公式。

4）高低：高波动通常需要更保守，但佣金制/季节性职业天然波动，必须按职业和行业解释。

5）案例：高波动客占比14%→24%；高波动×高PTI组FPD7 27%，稳定工资低PTI组11%。

6）诊断：数据覆盖月数 → Payroll识别 → Seasonality → Employer/Industry → DTI/PTI → FPD。

7）动作：高波动降额、缩短风险暴露或要求更多收入证据；稳定复借用户可用行为数据缓解。

8）误区：一个月收入代表长期；奖金月拉高均值；现金转入全部当工资；Missing当波动。

9）拆分：Employer、Industry、Region、Channel、Income Band、Score、Cycle、Payroll Method。

10）预警：用职业/收入类型分组历史分位数；高波动占比跳升且FPD同步升高时才进入风险告警。

11）关系：Employer/Payroll → Income Volatility → Affordability → FPD/Cure → Vintage/EL。

12）练习

第五部分｜海外风控实操

今日实操：Affordability Stress Matrix｜DTI × PTI × Income Volatility × Limit

所需字段：application_id、user_id、channel、verified_income、income_source、income_history_monthly、existing_debt_payment、essential_expense_estimate、proposed_payment、approved_limit、disbursed_amount、term、price、score_band、fpd7、dpd30、maturity、strategy_version。

执行步骤：统一收入周期/税前税后 → 计算DTI/PTI/Residual/Income Volatility → 按 Channel×Score×Income×Limit 分层 → 看FPD7/Amount FPD → 等MOB1 DPD30+成熟 → 计算EL/Margin → 形成Limit/Term Challenger。

SELECT
  channel,
  score_band,
  limit_band,
  COUNT(*) AS n,
  AVG(existing_debt_payment / NULLIF(verified_income,0)) AS dti,
  AVG(proposed_payment / NULLIF(verified_income,0)) AS pti,
  AVG(verified_income-essential_expense-existing_debt_payment-proposed_payment) AS residual_income,
  AVG(CASE WHEN fpd7_matured=1 THEN fpd7_flag END) AS fpd7
FROM affordability_sample
GROUP BY channel, score_band, limit_band;

Excel/Python：Excel 用 Pivot 看 DTI/PTI Band × Income Volatility × Limit；Python 用分位数箱、WOE/单调性图或简单二维热力表（内部分析）检查风险梯度。

阈值逻辑：不要套行业统一 DTI/PTI 数字。内部黄灯示例：同Score、同收入档的高PTI组连续两个成熟Cohort FPD7/EL明显高于历史区间；红灯候选：Residual持续为低分位且Amount FPD、MOB1 DPD30+、Margin同步恶化。

异常诊断：先查Income数据/周期 → Bureau债务完整性 → Product Payment口径 → Channel Mix → Limit/Price/Term → FPD/Vintage。

输出模板：Segment｜N｜Income｜DTI｜PTI｜Residual｜Income Volatility｜Approval｜Avg EAD｜FPD7｜DPD30+@MOB1｜EL/Loan｜Margin｜Action。

第六部分｜业务与产品

风控 × 业务：不要只优化“Approval”，要优化可负担的风险调整增长

经营链建议固定成：Verified Income → DTI/PTI → Residual → Approval → Limit/EAD → FPD/Vintage → EL → Contribution Margin。如果 Approval 上升同时 PTI、EAD 和EL明显上升，即使件数Bad暂时没成熟，也要提前看 Amount FPD 和Residual；真正目标是风险调整后的可持续利润，不是最大批准率。

风控 × 产品：额度选择页可以用 Affordability Guardrail，而不是默认推最大额度

用户拖动额度/期限时，产品可以实时计算预计到期应付与收入压力；当高额度导致 PTI/Residual 进入内部高风险区时，默认推荐更低金额或更合适期限，并清楚展示总成本。不要通过隐藏费用或默认最大额度诱导过度借款。

职责：产品负责金额/期限/成本展示与安全推荐；风控定义 DTI/PTI/Residual Guardrail 和Challenger；数据负责收入质量、FPD/Vintage/EL；研发负责实时计算、版本和回滚；运营只能在批准的Offer范围内触达。
