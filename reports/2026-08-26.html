第三部分｜海外风控知识学习

今日知识：额度策略 Limit Strategy——提额不是奖励，而是边际风险资本配置

概念：额度策略决定某个可批准用户最多能拿到多少EAD。它通常由信用风险、收入/负债能力、历史还款、产品期限、资金成本和目标利润共同决定。

为什么重要：同一个用户的PD不变，额度从MXN1,200提升到MXN1,800，也会使EAD提高50%；如果低Score用户更倾向把新增额度全部用满，PD和EAD还可能同时上升。

简化边际EL ≈ PD × LGD × ΔEAD（仅当PD/LGD近似不变时成立）

常见误区：把提额当忠诚度奖励；只看件数Bad不看金额；先提额再等Vintage成熟；不同Score使用同一提额比例；忽略Take-up/Utilization的选择效应。

墨西哥现金贷模拟案例

背景：复借客策略V6把上限从MXN2,000提高到2,800。
数据：样本8,000；件均1,650→2,050；Take-up 58%→66%；FPD7件数9.5%→10.2%；FPD7金额10.1%→13.8%；Contribution Margin/借款人 MXN210→198。
现象：件数风险变化很小，但金额风险和EAD明显增加，利润反而下降。
拆解：Score×Limit后发现，中高Score提额后风险稳定；最低两档Score的Limit≥2,400组金额FPD达到18%。
根因：额度增量集中到边缘Score且Utilization更高。是否完全由提额造成仍需Champion/Challenger验证。
决策：中高Score保留提额；边缘Score设置低上限或更小提额步长；提款前增加多头与账户风险轻量复核。
观察：至少等FPD7成熟，并继续追MOB1/2 Vintage、EL和Contribution Margin。

判断方法：Score → Limit → Utilization → EAD → FPD/Vintage → EL → Contribution Margin。提额策略最终要回答“每增加1 MXN额度，边际收入是否覆盖边际EL和资金成本”。

小练习与参考答案

某组PD约12%、LGD约70%，每人平均新增使用额度MXN500。在假设PD/LGD不变时，边际EL约多少？

参考答案：0.12×0.70×500≈MXN42/人。真实业务还要考虑PD随额度/选择效应变化。

第五部分｜海外风控实操

今日实操：额度策略分层 + 边际EL分析

所需数据：user_id、channel、score_band、approved_limit、disbursed_amount、utilization、term、verified_income、monthly_debt_payment、installment_amount、fpd7、dpd30、bad_flag、revenue、funding_cost、collection_cost、strategy_version。

步骤：①固定成熟样本；②按Score×Limit做矩阵；③同时算Utilization/件均/FPD件数与金额；④估算PD/LGD/EAD与EL；⑤计算每个Limit档Contribution Margin；⑥识别“提额后边际利润转负”的拐点；⑦设计Champion/Challenger。

SELECT score_band, limit_band, COUNT(*) n, AVG(disbursed_amount) avg_ticket, AVG(disbursed_amount/NULLIF(approved_limit,0)) utilization, AVG(fpd7_flag) fpd7_cnt, SUM(CASE WHEN fpd7_flag=1 THEN disbursed_amount ELSE 0 END)/NULLIF(SUM(disbursed_amount),0) fpd7_amt FROM matured_loans GROUP BY score_band,limit_band;

阈值判断：不要用行业统一额度阈值。以同Score历史稳定Limit档作为内部基线；若提额档的风险调整后Contribution Margin连续两个成熟Cohort低于原档，可进入收缩/Challenger复核。该逻辑是内部示例，不是行业标准。

异常诊断：先看Utilization和Take-up → 再看Score/多头/收入 → 再看件数vs金额FPD → 再看PD/LGD/EAD → 最后看资金成本和利润。

输出模板：Score｜Limit｜样本｜件均｜Utilization｜DTI/PTI｜FPD7件数｜FPD7金额｜MOB1 DPD30+｜EL｜Contribution Margin｜建议动作。

第二天复盘：只看流量、Limit分布、Take-up、Utilization、支付失败和FPD1；FPD7/Vintage未成熟前不全量扩大额度。

第六部分｜业务与产品

风控 × 业务：件均提高为什么利润可能下降？

件均上涨会同时提高收入和EAD，但两者并不是线性同速增长。一个常见链路是：Limit↑ → Take-up/Utilization↑ → EAD↑ → 金额FPD/Vintage↑ → EL↑。如果新增利息收入小于新增资金成本+EL+催收成本，件均越高反而利润越差。

业务评审应从“件均提升多少”升级为：每新增MXN100放款本金，新增收入、Funding Cost、EL和Contribution Margin分别是多少。

风控 × 产品：额度展示、提额与风险回退

页面建议：同时区分“当前可借额度”“本次建议借款额”“潜在最高额度”；不要把尚未最终授信的上限显示成确定承诺。用户手动选择借款额时，展示不同金额对应的总成本和还款计划。

规则建议：额度有效期内如果用户发生新设备、手机号/银行卡变化、近期多头显著上升或账户风险事件，提款前执行轻量复核；轻度风险可降额，身份风险高则二次KYC，重大风险则暂停提款。

职责：产品负责额度展示与解释；风控负责Limit/提额/回退规则；数据负责Limit→Utilization→FPD/Vintage→EL看板；研发负责额度版本、有效期和实时回滚；运营只触达当前仍符合资格的用户。
