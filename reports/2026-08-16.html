第三部分｜海外风控知识学习：FPD7 口径

推荐定义：首期应还后第7天仍处于逾期状态的贷款表现。必须明确件数/金额口径、到期日 cohort、技术失败/特殊展期处理，以及是“DPD7时点”还是“7天内曾逾期”。

推荐公式：FPD7件数 = DPD7仍逾期笔数 ÷ 首期已成熟笔数；FPD7金额 = 对应逾期首期应还金额 ÷ 首期成熟应还金额。

墨西哥案例：A渠道件数FPD7为18%、件均MXN1,000；B渠道件数FPD7为14%、件均MXN2,000。只看件数B更好，但高额度坏客可能让B的金额FPD7更差，因此渠道评估必须同时看件数与金额。

常见误区：混用申请日 cohort 和到期日 cohort；把支付技术失败全部算信用风险；只看FPD7不看批准率/件均；不按渠道、额度、评分段拆解。

小练习：对昨天成熟 cohort 同时计算 FPD1/3/7 件数与金额，并按渠道 × 评分段 × 额度档拆解。

第四部分｜海外风控实操：渠道质量 × FPD7

所需字段：channel、campaign、score_band、approved_limit、disbursed_amount、due_date、dpd_at_day7、first_due_amount、fraud_flag、CAC。

SELECT channel,
       COUNT(*) AS matured_loans,
       AVG(CASE WHEN dpd_at_day7 > 0 THEN 1.0 ELSE 0 END) AS fpd7_cnt,
       SUM(CASE WHEN dpd_at_day7 > 0 THEN first_due_amount ELSE 0 END)
         / NULLIF(SUM(first_due_amount),0) AS fpd7_amt,
       AVG(disbursed_amount) AS avg_ticket
FROM first_due_matured
GROUP BY channel;

判断逻辑：以最近8周稳定渠道中位数做内部基线。FPD7金额高于基线20%且样本≥300笔可进入黄色预警；高于35%且连续2个成熟cohort出现可进入红色预警，再结合欺诈率、评分分布、额度和CAC决定降量或收紧。以上阈值是管理示例，不是行业统一标准。

输出模板：渠道｜样本｜通过率｜放款率｜件均｜FPD7件数｜FPD7金额｜欺诈率｜首贷CAC｜预计贡献利润｜建议动作。

第五部分｜业务与产品

风控 × 业务：为什么通过率提高，利润反而下降

通过率是漏斗指标，不是利润指标。常见路径包括：新增通过用户集中在低分层导致FPD/Vintage上升；同时提高额度使坏账金额放大；投放平台继续按“批准/放款”优化后学到更易通过但更差的用户。

建议：用贡献利润≈收入−资金成本−获客成本−预计信用损失−支付/运营/催收成本评估准入放宽，最终看增量利润是否覆盖增量损失。

风控 × 产品：KYC 权限与数据流重构

注册页只收必要信息；KYC按手机号验证→证件/OCR→人脸→银行卡分步展示用途；“营销同意”“风控处理”“第三方共享”避免捆绑。Android今天优先核查 target API 与包名注册状态；READ_CALL_LOG 电话验证迁移虽然2027年1月27日才生效，也应提前排期。第三方AI/OCR/人脸服务需明确处理目的、数据范围、保存和跨境安排。

职责：产品负责流程和文案；风控定义必要字段；数据负责埋点与血缘；研发负责权限/SDK扫描和降级；运营/法务负责 Store metadata、牌照和隐私政策一致性。
