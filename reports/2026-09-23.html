三、海外风控知识学习｜Agentic Commerce Risk & KYA

概念：支付或交易由AI Agent代表用户完成时，风控对象从“用户+设备”扩展到“用户+Agent+Operator+授权意图+支付工具+商户”。

User → Agent Identity → Delegated Intent → Merchant → Payment Instrument → Transaction → Dispute / Revocation

为什么重要：银行已警告Agent可能误用支付数据、引导不安全支付方式和放大诈骗；Agentic Payment也已进入真实交易测试。对现金贷APP，未来账户变更、还款、自动扣款、放款和召回都可能有Agent参与。

墨西哥现金贷七步案例

背景：APP引入AI客服/Agent帮助用户修改还款账户并发起还款。
数据：月度相关申请20,000；正常设备+原账户占82%；新设备+新账户占8%；新设备+新账户组合的Bank Change成功率高、后续非本人投诉率显著高于基线。
现象：Agent显著提高了操作完成率，但也放大了ATO风险。
拆解：New Device×Password Reset×Bank Change×High-value Payment是高风险组合；稳定老客固定设备则可保留低摩擦流程。
根因：组合信号与投诉/欺诈结果高度相关，但需要Holdout或Step-up Challenger验证真实增量风险。
决策：为Agent建立唯一身份、Operator、金额/商户/有效期范围、撤销和二次确认；高风险组合禁止Agent直接写入资金账户。
结果：观察7—14天完成率、Step-up转化、ATO/投诉、支付成功、重复扣款和Net Fraud Loss。

常见误区：“Agent成功完成操作=安全”；用户授权等于无限授权；把Agent当普通客服账号；只看完成率不看争议和欺诈；只做模型测试不做权限测试。

小练习：10,000次Agent交易中，9,200次完成，150次争议，30次确认欺诈。问：完成率、争议率、确认欺诈率分别是多少？答案：92%、1.5%、0.3%。

四、风控指标集合学习

指标统一学习卡摘要
Agent Transaction Completion Rate看Agent是否完成用户委托动作；分子为成功完成并结算的唯一交易，分母为进入Agent流程且资格成熟的交易。高不一定好，必须联合Dispute/ATO/Net Fraud Loss。案例：完成率92%，但高风险组合确认欺诈0.3%。预警组合：Completion↑ + Dispute/ATO↑。
Agent Dispute Rate固定窗口内发生用户争议的交易数÷已结算Agent交易数；需区分未授权、错误金额、重复扣款、服务不符。高通常不利，但可因召回/举证机制变化而变。拆Agent、Operator、Merchant、Amount、Device、Intent。
Agent Authorization Scope Breach RateAgent执行动作超出金额/商户/频率/期限或工具权限范围的比例；分子为审计确认越界动作，分母为Agent执行动作。该指标不是传统业务KPI，而是控制有效性指标；一旦上升应优先停用高权限写操作。
Non-human Identity Coverage已登记、可追溯、可撤销的Agent/Service Identity占全部非人类身份的比例；覆盖率越高越好，但不能掩盖权限过大。关系链：Identity Registry→Permission→Action Log→Incident/Revocation。
