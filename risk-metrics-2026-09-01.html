CAC / LTV / Contribution Margin / Break-even Bad Rate

本页使用墨西哥现金贷模拟数据训练指标分析逻辑。任何数值阈值均为内部分析示例，不代表行业统一标准或监管标准。

CAC｜Customer Acquisition Cost｜获客成本

1）指标是什么：获得一个符合固定定义的新客户/借款人实际花多少钱。大白话：为了多一个真正放款的新客，我们到底花了多少营销钱。

2）为什么重要：CAC是增长与利润的上游指标，主要用于获客/首贷阶段。它本身既不是纯风险指标也不是纯营销指标，必须和Approval、Take-up、FPD、EL、LTV一起看。

首贷CAC = 可归因获客营销成本 ÷ 成功首贷借款人数

3）精确定义与公式：必须固定分母是注册、申请、审批通过还是成功首贷。推荐经营口径至少保留“First-disbursement CAC”。分子是否包含代理费、素材制作、渠道返点、优惠券/补贴、税费要全团队统一；归因窗口和MMP规则不能随意变化。

4）如何看高低：通常越低越好，但极低CAC可能来自低质量流量、作弊或放宽准入；高CAC如果带来高LTV和低EL客群仍可能值得。

5）墨西哥现金贷案例七步法

背景：首贷产品比较渠道A与B，预算规模相近。
数据：A成功首贷4,000人，CAC=MXN260，FPD7=19%，金额FPD=22%，预测12月LTV=MXN410；B成功首贷2,900人，CAC=MXN330，FPD7=10%，金额FPD=11%，预测LTV=MXN720。
现象：A获客明显更便宜，但风险更差、长期价值更低。
拆解：按Campaign×Score×Limit发现，A低Score+高Limit流量占比更高；B虽然竞价贵，但高Score用户和优质复借占比更高。
根因：可以确认流量结构与风险/价值差异高度相关，但还需排除归因窗口、素材与额度策略差异后，才能把差异完全归因给渠道。
决策：A不直接停投，先降低低Score素材/媒体位预算并限制高额度；B优化出价但保留优质流量。
结果：观察至少一个FPD7成熟周期并继续追MOB1 Vintage、LTV/CAC和Contribution Margin。

6）诊断逻辑：先检查归因/分母 → 再看Channel/Campaign/Creative → 再看KYC/Approval/Take-up漏斗 → 再看Score/Limit结构 → 最后看FPD/EL/LTV。

7）策略动作：低CAC高风险渠道降量/换素材/限额；高CAC高LTV渠道优化出价而非直接停投；归因异常先修MMP，不要把数据问题当成本上涨。

8）常见误区：用注册用户作首贷CAC分母；自然量与付费量混用；不同归因窗口直接比较；漏算优惠券/渠道服务费；只看CAC不看风险。

9）推荐拆分维度：Channel、Campaign、Creative、Region、OS、Score、Limit、First/Repeat、Strategy Version。

10）预警方式：用成熟Cohort做CAC+FPD+LTV联合黄/红灯；样本过小不下结论。具体阈值使用内部历史基线。

11）与其他指标关系：CAC → First-loan Contribution Margin → Repeat/Redraw → LTV → ROI。

12）小练习与参考答案

CAC下降20%，但金额FPD上涨6个百分点、预测LTV下降25%，是否应该继续扩量？

答案：不能只因为CAC下降就扩量。应计算EL和LTV变化后的风险调整后利润。

LTV｜Lifetime Value｜客户生命周期价值

1）指标是什么：一个客户在完整生命周期里预计/实际贡献的净经济价值。大白话：这个客户从第一次借款到最后一次离开，最终给公司赚了多少钱。

2）为什么重要：LTV连接首贷亏损、复借、资金成本、风险损失、催收与留存，是确定可承受CAC和增长预算的重要指标；它通常是滞后指标，同时也可做预测。

简化LTV = 生命周期收入 − Funding Cost − Expected/Credit Loss − 支付/运营/催收成本 − 激励成本

3）精确定义与公式：必须固定生命周期窗口（如6/12个月）、是否折现、客户/账户口径、预测LTV与成熟实际LTV、是否把CAC包含在LTV里。跨团队使用前先统一版本。

4）如何看高低：高通常更好，但高复借率不必然高LTV。如果用户进入Debt Cycling、EAD不断扩大、LGD恶化，LTV可能下降。

5）墨西哥现金贷案例七步法

背景：复借产品推出“还款即恢复额度+Push召回”。
数据：30天复借率42%→58%，收入/用户+22%，Average EAD+28%，MOB2 DPD30+ 11%→16%，Funding Cost+6%，12个月预测LTV MXN680→590。
现象：复借更活跃、收入更高，但LTV反而下降。
拆解：按Redraw@1d×Inquiry×Limit发现，24小时内重借且高多头用户贡献了大部分新增EAD和坏账。
根因：高频复借与风险恶化高度相关，但营销强度、额度恢复和客群结构同时变化，需受控实验确认。
决策：优质复借客保持顺滑体验；高Redraw+高多头用户降恢复额度或增加轻量复核。
结果：至少观察两个成熟Vintage，验证实际LTV、EL、投诉和Repeat质量。

6）诊断逻辑：Repeat/Retention → Revenue → EAD/Vintage → Recovery/LGD → Funding/Ops → LTV。

7）策略动作：提高优质复借留存；高频Debt Cycling客群限额；用LTV/CAC而非Repeat Rate驱动营销预算。

8）常见误区：把GMV/收入当LTV；未成熟Vintage过度外推；忽略Funding和Collection；不同窗口的LTV直接比较。

9）推荐拆分维度：Channel、Score、New/Repeat、Cycle、Limit、Term、Region、Pricing、Strategy Version。

10）预警方式：监控预测LTV与成熟实际LTV偏差、LTV/CAC、同MOB Vintage；预测偏差持续扩大时检查模型/客群。

11）与其他指标关系：CAC → First-loan Margin → Repeat/Redraw → Vintage/EL → LTV → ROI。

12）小练习与参考答案

复借率从45%升到60%，但LTV下降，优先检查什么？

答案：检查EAD/Vintage、Funding Cost、Recovery/LGD和营销激励，确认复借是否变成高风险Debt Cycling。

Contribution Margin｜贡献利润

1）指标是什么：每笔贷款或每个客户在扣除与业务直接相关的变动成本和风险损失后，还剩多少利润贡献。

2）为什么重要：它把Approval、Limit、Price、CAC、Funding Cost和EL统一到一个经营结果，是风控与业务最重要的共同语言之一。

Contribution Margin = Revenue − Funding Cost − CAC − EL − Variable Payment/Ops/Collection Cost

3）精确定义与公式：明确按Loan/User/Vintage计算，收入确认时点，EL使用成熟或预测，哪些成本属于Variable，固定成本是否排除。跨产品必须统一币种和期限。

4）如何看高低：通常越高越好，但短期高Margin若靠高投诉、高APR、透支未来LTV获得，并不可持续。

5）墨西哥现金贷案例七步法

背景：策略V8放宽边缘Score并统一提额。
数据：Approval 30%→35%，Average Ticket MXN1,500→1,750，Revenue/Loan +18%，EL/Loan +40%，Funding Cost/Loan +8%，Contribution Margin MXN96→72。
现象：放款量、件均和收入都增长，但单笔贡献利润下降。
拆解：Score×Limit发现新增放款集中在低Score、高Limit，Revenue增加无法覆盖EL和Funding。
根因：主要经济拖累来自EAD扩张与PD略恶化，而不是CAC。
决策：保留中Score低额度新增客群，收回低Score高Limit扩张；重新做边际额度利润曲线。
结果：观察成熟FPD7、MOB1 DPD30+、EL/Loan和Margin是否恢复。

6）诊断逻辑：Revenue → CAC → Funding → PD/LGD/EAD/EL → Payment/Collection → Margin。

7）策略动作：收入不足调产品/定价；CAC高调投放；PD高收准入；EAD高控额度；LGD高优化催收。

8）常见误区：收入增长=利润增长；不计EL；固定/变动成本混淆；未成熟样本直接当最终利润。

9）推荐拆分维度：Channel、Score、Limit、Term、Cycle、Pricing、Funding Source、Strategy Version。

10）预警方式：成熟Cohort Margin、EL/Loan、CAC、Funding Cost联合预警；单项指标改善但Margin恶化必须追因。

11）与其他指标关系：Price/CAC/Funding + PD×LGD×EAD → Contribution Margin → LTV/ROI。

12）小练习与参考答案

收入+20%，EL+45%，Funding Cost+10%，是否一定更赚钱？

答案：不一定，直接计算Contribution Margin并检查增长来自哪些Score/Limit段。

Break-even Bad Rate｜盈亏平衡坏账率

1）指标是什么：在当前收入、资金成本、CAC、额度和回收假设下，坏账最多到多少仍能做到边际不亏。

2）为什么重要：它把“可以承受多少风险”转成业务可解释的内部阈值，适合渠道、准入、定价和额度评审。

Break-even Credit Loss = Revenue − Funding Cost − CAC − Other Variable Cost；再结合EAD与LGD换算可承受PD/Bad Rate

3）精确定义与公式：不是统一行业公式。必须明确Bad定义、LGD/Recovery、平均EAD、期限、收入、税费和运营成本；件数Bad与金额Bad不能混。

4）如何看高低：可承受Bad Rate高不等于产品更健康，可能只是价格更高；还必须看用户保护、平台政策、Take-up和LTV。

5）墨西哥现金贷案例七步法

背景：比较渠道A/B首贷经济性。
数据：A每单在信用损失前剩余MXN180，Average EAD=1,500，LGD=80%，简化Break-even PD≈15%，实际成熟Bad=18%；B Break-even≈14%，实际Bad=9%，虽然CAC高于A。
现象：A获客更便宜、表面收入也不错，但实际Bad超过盈亏平衡点。
拆解：A的问题主要集中在低Score高额度段，且Recovery低于B。
根因：经济性差异来自PD与LGD共同恶化，而不仅是CAC。
决策：A降量并收紧低Score高Limit，同时优化Recovery；B可在LTV/CAC约束下扩大。
结果：观察成熟Bad、EL、Margin和LTV，确认实际风险回到Break-even以下并且利润为正。

6）诊断逻辑：Revenue/Price → Funding → CAC → Ops → LGD/EAD → Actual Mature Bad。

7）策略动作：实际Bad高于Break-even时，先区分PD/EAD/LGD根因，再决定收紧、降额、改渠道、优化催收或在合规范围内调整价格。

8）常见误区：把Break-even当监管阈值；忽略LGD/Recovery；未成熟Bad参与；用高价格掩盖不可持续风险。

9）推荐拆分维度：Channel、Score、Limit、Term、Pricing、Funding Source、Strategy Version。

10）预警方式：监控Actual Mature Bad − Break-even差值、Contribution Margin和LTV；所有阈值均仅作内部管理。

11）与其他指标关系：Revenue/Cost → Break-even Loss → Actual PD/LGD/EAD → Contribution Margin。

12）小练习与参考答案

可承受信用损失MXN180，EAD=1,500，LGD=80%，简化Break-even PD是多少？

答案：180 ÷ (1,500×80%) = 15%。如果实际成熟Bad达到18%，应进入策略复盘。

今日关系链

Price / Offer → Take-up → Customer Mix → EAD → PD/LGD → EL → Contribution Margin → LTV → CAC上限 / ROI

这条链是今天风险定价主题的核心：价格不是孤立的收入变量，它会反过来改变谁愿意借、借多少以及最终风险。
