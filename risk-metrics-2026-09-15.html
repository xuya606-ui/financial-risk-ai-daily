2026-09-15E. 模型与策略

模型监控四张完整指标学习卡

今日高级复习：PSI、AUC、KS、O/E。核心原则是分布漂移、排序能力和概率校准必须联合看。所有阈值数字只可作为内部示例，不代表行业统一标准。

联合判断框架

Population Drift → PSI ｜ Rank Performance → AUC / KS ｜ Calibration → O/E

PSI高而AUC/KS/O-E稳定：优先查流量/渠道/数据结构；AUC/KS下降但PSI稳定：优先查特征-标签关系、数据质量与策略选择效应；AUC/KS稳定但O/E高：更像校准/Base Rate变化；四者与FPD/EL/Margin同时恶化：升级为模型/策略红灯候选。

PSI｜Population Stability Index｜群体稳定性指数

1）指标是什么：衡量当前样本分布和基准样本分布的差异。大白话：今天来的客户/分数/特征，还是不是模型参考期那批人。

2）为什么重要：领先/同步指标，在坏账尚未成熟时就能发现渠道、客群、特征、设备或策略漂移；用于贷前/贷中模型监控。

3）精确定义与公式：PSI = Σ (Actual_i − Expected_i) × ln(Actual_i / Expected_i)Expected 为固定Reference Cohort各箱占比，Actual为当前各箱占比。必须固定Reference、分箱、Missing、样本窗口、用户/订单口径；零占比按内部平滑规则处理。

4）如何看高低：高表示分布变得不同，不代表风险一定更高；促销、渠道扩量、地区变化也可能推高PSI。低也不表示PD校准一定正常。

5）墨西哥七步案例：

背景：30天首贷Model V6，Channel C扩量并提高部分额度。
数据：N=50,000；整体PSI0.06→0.24；Channel C=0.37；AUC0.73→0.72；O/E1.02→1.28；FPD7 14.8%→17.2%；Avg EAD1,500→1,800。
现象：分布和风险显著变动，但总体排序能力只小幅下降。
拆解：C渠道Low Score×High Limit占比明显增加；其他渠道PSI约0.08。
根因：流量/额度结构是强候选，但仍需排除Feature Missing和上游数据管道变化，不能仅凭PSI说模型失效。
决策：C渠道降量；低Score高Limit回滚；保持模型Champion并对C渠道做Challenger/数据检查。
结果：观察两个成熟Vintage的PSI、O/E、FPD7、MOB1 DPD30+、EL和Margin。

6）诊断逻辑：Data/Missing → Channel/Campaign Mix → Feature/Score PSI → Strategy Version → AUC/KS/O-E。

7）策略动作：Missing异常先修数据；单渠道漂移降量/拆分策略；季节性可更新稳定基线；PSI+O/E持续恶化再做Recalibration/重训评估。

8）常见误区：PSI高=模型坏；每次临时重分箱；只看总体不看Segment；忽略样本量、季节性和策略版本。

9）推荐拆分：Channel、Campaign、Score、关键Feature、Region、Device、Product、新老客、Model/Strategy Version。

10）预警方式：用自身历史稳定分布+最小样本。内部示例可用“连续两个周期超历史P90”作为黄灯，再结合O/E/FPD升级；0.1/0.25等经验数值不得冒充行业统一标准。

11）与其他指标关系：Traffic/Data → PSI → Score Distribution → AUC/KS/O-E → FPD/Vintage → EL/Margin。

12）小练习

PSI显著升高，但AUC、KS、O/E稳定。第一动作？

答案：先拆渠道/流量/数据结构并检查Feature Missing，不应直接全量重训。

AUC｜Area Under ROC Curve｜ROC曲线下面积

1）指标是什么：衡量模型整体排序能力。大白话：随机抽一个真实坏客和一个好客，模型有多大概率把坏客排得更风险。

2）为什么重要：滞后模型性能指标，需标签成熟；用于判断Score排序能力是否随时间、渠道或策略变化。

3）精确定义与公式：AUC是ROC曲线面积，也可解释为随机好坏样本正确排序概率。固定Bad Definition、预测窗口、成熟期、Score方向、账户/订单口径和Selection样本。

4）如何看高低：一般越高排序越强，但AUC高≠PD校准好、≠利润高；AUC稳定时O/E仍可能恶化。

5）墨西哥七步案例：

背景：V6模型上线，Channel C快速扩量。
数据：AUC0.73→0.72；C渠道0.69、其他0.73；PSI0.24；O/E1.28；FPD7+2.4pp；Approval+3pp。
现象：整体AUC只小幅下降，但业务风险恶化明显。
拆解：C渠道排名能力弱于其他渠道，且Low Score/High Limit新增最多。
根因：局部排序变弱存在，但总体更明显是Population Shift和Calibration变化，不能直接归因“模型整体失效”。
决策：C渠道做独立数据/特征审计与Challenger；O/E校准单独处理；不急于全量重训。
结果：等两个成熟Cohort后看AUC置信区间、O/E、FPD/Vintage和Margin。

6）诊断逻辑：标签成熟/定义 → Score方向与样本 → Channel/Segment → Feature Missing → PSI/O-E → FPD/EL。

7）策略动作：局部下降做分群模型/特征治理；全局持续下降再重训；AUC稳定但O/E差优先Recalibration。

8）常见误区：AUC高=校准好；未成熟Bad当Good；不同预测窗口横比；只看总体掩盖Segment下降。

9）推荐拆分：Channel、Product、Vintage、MOB、Score、Region、Model Version、Strategy Version、Thin/Thick file。

10）预警方式：同成熟期、同Bad Definition、置信区间和最低坏样本数；使用相对Champion/历史基线的持续变化，而不是统一绝对阈值。

11）与其他指标关系：Feature/Score → AUC ↔ KS → Rank Quality；AUC + O/E → Model Performance → Approval/EL/Margin。

12）小练习

AUC稳定，但O/E从1.0升到1.4，能说模型正常吗？

答案：不能。排序可能稳定，但PD可能系统性低估实际坏账。

KS｜Kolmogorov–Smirnov Statistic｜好坏区分度

1）指标是什么：好客和坏客累计分布之间的最大距离。大白话：某个分数切点能把好坏客户拉开多远。

2）为什么重要：滞后排序/区分指标，直观评估模型分离能力，也可辅助Cutoff和Champion/Challenger分析。

3）精确定义与公式：KS = max_t |CDF_good(t) − CDF_bad(t)|必须固定Bad标签、预测窗口、成熟期、Score方向、账户/订单口径；避免策略筛选后的Selection Bias被误当模型能力。

4）如何看高低：通常高表示好坏分离更强，但KS只取最大差点，不代表全部Score区间都好；高KS也不意味着PD校准准确。

5）墨西哥七步案例：

背景：Channel C扩大低价获客。
数据：总体KS0.38→0.36；C渠道0.30；其他0.37；C渠道PSI0.37、O/E1.55、金额FPD显著升高。
现象：C渠道好坏区分下降且真实风险恶化。
拆解：Low Score×High Limit、新设备、Bureau薄档案组合最差。
根因：客群/特征覆盖变化与KS下降相关，但仍需验证数据质量和策略选择，不能宣布模型全局失效。
决策：C渠道限量、补特征/数据质量审计、建立独立Challenger；其他渠道继续Champion。
结果：成熟Cohort继续看KS/AUC、O/E、EL/Margin。

6）诊断逻辑：标签/Score方向 → KS Cut-point → Channel/Segment → Feature/PSI → AUC/O-E → Bad/EL。

7）策略动作：局部下降做分群阈值/特征治理；全局持续下降考虑重训；KS稳但O/E坏只做校准/价格额度不一定要重训。

8）常见误区：KS越高越赚钱；不同Bad窗口横比；忽略Rejected/Selection Bias；只看一个最大点。

9）推荐拆分：Channel、Score Band、Vintage、Product、Region、Device、Model/Strategy Version。

10）预警方式：同标签/成熟期历史区间+最小坏样本；连续两个成熟Cohort明显低于稳定区间可黄灯，叠加AUC/O-E/EL恶化升级。

11）与其他指标关系：Population/Feature → Score → KS/AUC → Cutoff/Approval → Bad/EL；KS不替代Calibration。

12）小练习

KS下降但PSI稳定，先查什么？

答案：标签/特征-风险关系、数据质量、策略选择和Segment表现，而不是先归因流量变化。

O/E｜Observed / Expected Ratio｜实际/预期坏账比

1）指标是什么：成熟实际Default数量与模型预测Default数量的比值。大白话：模型预测坏100个，实际坏了多少。

2）为什么重要：滞后校准指标，直接连接PD、EL、定价和额度；解决“模型有没有系统性低估/高估风险”。

3）精确定义与公式：O/E = Σ Observed Default_i ÷ Σ Predicted PD_i固定Default Definition、预测窗口、决策时点、成熟样本、账户口径。金额/损失版本应单独命名Loss O/E，以Expected Loss作分母，不与Default O/E混用。

4）如何看高低：接近1表示总体校准较接近；>1通常表示实际坏账高于预测，<1表示模型更保守。小样本、未成熟和策略变化会制造假信号。

5）墨西哥七步案例：

背景：Channel C扩量并提额。
数据：整体O/E1.02→1.28；C渠道1.55；其他1.05；AUC0.72；PSI0.24；Avg EAD+20%；FPD7+2.4pp。
现象：模型明显低估新增客群真实坏账。
拆解：Low Score×High Limit O/E最高，同时金额FPD恶化。
根因：Base Rate/客群和额度结构变化是强候选；排序仍基本可用，暂不支持“排序模型完全失效”结论。
决策：C渠道做Segment Recalibration + Limit回滚Challenger；加强流量门控。
结果：两个成熟Vintage观察O/E回归、EL/Loan和Contribution Margin。

6）诊断逻辑：Default/成熟期 → PD版本 → Segment O/E → PSI → AUC/KS → EAD/LGD/EL。

7）策略动作：排序稳定O/E高优先Recalibrate；单Segment高做Segment PD/价格/额度；O/E与AUC/KS都恶化再升级重训。

8）常见误区：未成熟Bad进Observed；窗口混用；Default O/E和Loss O/E混用；O/E>1就说模型必然失效。

9）推荐拆分：Channel、Score Band、Vintage、MOB、Product、Term、Limit/EAD、Region、Model/Strategy Version。

10）预警方式：成熟Cohort+置信区间/最低Observed事件数。内部示例：连续两个成熟Cohort显著偏离1并超自身历史稳定区间为黄灯；EL/Margin同步恶化升级红灯。

11）与其他指标关系：PD → Expected Defaults → O/E → Recalibration → EL/Price/Limit → Margin；与PSI/AUC/KS组成模型监控三角。

12）小练习

10,000笔成熟贷款，ΣPD=1,200，实际Default=1,500，O/E是多少？

答案：1.25。实际坏账比模型预期高25%，需继续拆Segment、成熟度和策略版本判断校准问题。

模拟数字用于内部学习，不构成行业统一阈值。生产定义应以公司数据字典、模型文档和成熟度规则为准。
