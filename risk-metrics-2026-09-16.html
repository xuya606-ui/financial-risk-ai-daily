2026-09-16｜Affordability 指标学习卡

今日四个指标：DTI、PTI、Residual Income Buffer、Income Volatility。所有阈值均应来自内部成熟样本，不冒充行业统一标准。

DTI｜Debt-to-Income｜债务收入比

1）指标是什么：现有周期性债务付款占可验证同期收入的比例，大白话是“已有债务已经吃掉多少收入”。

2）为什么重要：贷前同步/领先指标，解决现有负债是否已经挤压新贷款偿付能力的问题。

3）精确定义与公式：DTI = Existing Monthly Debt Service ÷ Verified Monthly Net Income固定税前/税后、月度化方式、征信债务范围、用户/家庭口径；征信No-hit不能直接当0债务。

4）如何看高低：高通常代表现金流压力更高；但低DTI也可能来自漏报、征信覆盖不足或收入高估。不同收入档的可承受程度不同。

5）墨西哥七步案例：背景：30天首贷 Strategy B 在Channel B提额；数据：N40k、Approval31%→35%、Ticket1450→1950、DTI30%→38%、PTI10.8%→15.2%、Residual3700→2500、FPD7 13.8%→18.5%；现象：量增但风险恶化；拆解：Channel B×中低Score×高PTI集中；根因：DTI/PTI与风险相关但渠道/额度同时变化；决策：高DTI高PTI降额、稳定工资保留Challenger；结果：两个成熟Cohort看FPD7、MOB1、EL、Margin。

6）诊断逻辑：Income定义 → Bureau Debt完整性 → DTI Band → PTI/Residual → Score/Limit → FPD/Vintage。

7）策略动作：高DTI+高PTI降额/收准入；高DTI但高且稳定收入可灰度；No-hit补充替代债务信号，不自动当低风险。

8）常见误区：自报收入直接做分母；信用卡余额当月供；个人收入和家庭收入混用；周/月周期错配。

9）推荐拆分：Channel、Campaign、Score、Income Band、Employment、Limit、Term、新老客、Region。

10）预警方式：按Income×Score建立历史P50/P75/P90；同成熟Cohort高DTI占比和FPD7/EL同步升高进入黄灯。

11）与其他指标关系：Bureau Debt + Income → DTI → Approval/Limit → PTI/Residual → FPD/Vintage → EL。

12）小练习

月净收入12,000、现有月债务3,600，则DTI=30%。

PTI｜Payment-to-Income｜新贷款还款收入比

1）指标是什么：拟发放贷款在对应周期的应付款占同期收入的比例，回答“这笔新贷款本身要吃掉多少收入”。

2）为什么重要：贷前领先指标，直接用于额度、期限、定价和Offer Guardrail。

3）精确定义与公式：PTI = Proposed Periodic Payment ÷ Verified Income for Same Period30天Bullet Loan可用到期总应付与30天净收入匹配；周贷、双周贷必须先统一周期。

4）如何看高低：高通常压力更大；低PTI不一定风险低，可能只是期限过长、首期低或费用后置。

5）墨西哥七步案例：背景同上；数据PTI10.8%→15.2%，高收入波动×高PTI组FPD7达27%，稳定工资×低PTI约11%；现象是高负担组恶化；拆解按Channel×Score×Limit×Income Stability；根因仍需控制客群与额度；决策高PTI优先降额/调期限；结果看Amount FPD、DPD30+、EL和Margin。

6）诊断逻辑：Payment口径 → Income周期 → Limit/Price/Term → Income Stability → FPD/Amount FPD。

7）策略动作：高PTI降额、调整期限/Offer；不能靠提价覆盖明显不可负担风险；高价值稳定复借可分层放宽。

8）常见误区：只算本金不算费用；周付款直接除月收入；PTI低就无限提额；不同产品期限直接比较。

9）推荐拆分：Score、Income、Limit、Term、Price、Cycle、Channel、Employment。

10）预警方式：同产品/期限/收入档历史带；PTI上升且Residual、FPD7、EL同步变差进入黄灯。

11）与其他指标关系：Limit/Price/Term → PTI → Cash-flow Stress → FPD/Cure → Bad/EL → Margin。

12）小练习

月净收入10,000，到期总应付1,500，周期约30天，则PTI=15%。

Residual Income Buffer｜剩余收入缓冲

1）指标是什么：收入扣除必要支出、已有债务和新贷款付款后剩余的绝对现金。

2）为什么重要：弥补DTI/PTI只看比例、不看绝对生活空间的缺陷，低收入客群尤其重要。

3）精确定义与公式：Residual Income = Verified Net Income − Essential Expense Estimate − Existing Debt Service − Proposed Payment可同时报告Residual Ratio=Residual/Income；必要支出模型、家庭人口和地区口径必须固定。

4）如何看高低：通常越高缓冲越强；但支出估计错误会带来假精度，不能把模型估计当客观事实。

5）墨西哥七步案例：背景Strategy B提额；数据Median Residual 3700→2500、FPD7 13.8%→18.5%、Avg EAD1450→1950；现象为缓冲下降；拆解低Residual×高PTI×Channel B更差；根因需控制收入档/地区；决策低Residual降额、修正支出模型；结果看两个成熟Cohort的Amount FPD、EL、Margin。

6）诊断逻辑：Income → Expense Model → Existing Debt → Proposed Payment → Region/Household → FPD/Vintage。

7）策略动作：低Residual降额或减少过度借款激励；支出模型偏差先修模型；重复低Residual但稳定还款可保留Challenger。

8）常见误区：生活支出设为0；不同地区同一支出假设；负Residual直接当欺诈；税前收入配税后支出。

9）推荐拆分：Income、Region、Household、Employment、Score、Limit、Term、Cycle。

10）预警方式：收入/地区内使用历史分位数；Residual落入低分位且Amount FPD/EL同步升高升级。

11）与其他指标关系：Income − Expense − Debt − New Payment → Residual → FPD/Bad → EL/Margin。

12）小练习

收入10,000、生活支出4,000、已有债务3,000、新付款1,400，则Residual=1,600。

Income Volatility｜收入波动度

1）指标是什么：过去3-6个月收入/净流入稳定程度，大白话是“每个月的钱是否稳定进来”。

2）为什么重要：贷前领先指标，区分平均收入相同但现金流稳定性不同的用户。

3）精确定义与公式：内部常用示例：Income CV = Std(monthly verified net inflow) ÷ Mean(monthly verified net inflow)也可用最低月/平均月、工资到账规律、Employer一致性；不存在行业唯一公式。

4）如何看高低：高波动通常更谨慎，但佣金制、季节性职业天然波动，需要按行业/职业解释。

5）墨西哥七步案例：背景Channel B扩量；数据高波动客占比14%→24%，高波动×高PTI组FPD7 27%，稳定工资低PTI组11%；现象是风险梯度明显；拆解Employer×Industry×Score×PTI；根因收入不稳定是强相关因素但渠道/额度同时变化；决策高波动降额并补收入证据；结果看FPD7、Cure、MOB1、EL。

6）诊断逻辑：数据覆盖月数 → Payroll识别 → Seasonality → Employer/Industry → DTI/PTI → FPD。

7）策略动作：高波动降额/缩短暴露；稳定复借可用历史还款缓解；Payroll识别不准先修数据。

8）常见误区：一个月收入代表长期；奖金月拉高均值；全部转入都算工资；Missing直接当高波动。

9）推荐拆分：Employer、Industry、Region、Channel、Income Band、Score、Cycle、Payroll Method。

10）预警方式：按职业/收入类型的历史分位数；高波动占比突然上升且FPD/EL同步上升才触发风险黄灯。

11）与其他指标关系：Employer/Payroll → Income Volatility → Affordability → FPD/Cure → Vintage/EL。

12）小练习

8k/12k/10k与10k/10k/10k平均收入相同，但前者波动更高，不能只按均值给相同额度。

模拟案例仅用于训练诊断逻辑。
