PD / LGD / EAD / Expected Loss

这四个指标把“会不会坏、坏了损失多少、坏的时候暴露多少钱”统一成可用于额度、定价和利润管理的货币风险框架。案例均为墨西哥现金贷模拟数据。

先记住这条关系

简化业务EL = PD × LGD × EAD

该公式适合业务风控分析和分层比较，但不能替代正式监管资本或IFRS 9会计ECL计量。不同框架对时间窗口、违约定义、折现和概率加权的要求不同。

PD｜Probability of Default｜违约概率

1）指标是什么：在固定预测窗口内，借款人/账户发生既定Default事件的概率。大白话：这个客户未来坏掉的可能性有多大。

2）为什么重要：PD是贷前/贷中最核心的前瞻信用指标之一，连接评分、准入、额度、定价和EL。它通常是领先指标，但只有真实Bad标签成熟后才能验证。

3）精确定义与公式：

PD = P(Default within horizon | decision-time information)

必须固定Default定义、预测窗口、样本成熟期、用户/订单/账户口径。Basel IRB以一年PD作为重要风险参数之一；现金贷内部可使用更短窗口，但要清楚命名，例如PD30、PD90或Lifetime PD。

4）如何看高低：通常越低越好，但低PD不等于高利润。高CAC、高Funding Cost或高EAD都可能使低PD客群仍然亏损。

5）墨西哥现金贷案例七步法

背景：首贷V6按Score分三档定额。
数据：A档PD 8%、Limit 2,400；B档PD 14%、Limit 1,800；C档PD 25%、Limit 800；LGD暂按80%。样本分别为4,000/5,000/3,000。
现象：C档PD最高，但单笔EL不一定最高。
拆解：A/B/C简化EL约154/202/160 MXN。B档虽然PD低于C，但更高EAD使EL最高。
根因：风险排序和金额暴露共同决定损失；单看PD会忽略Limit。
决策：B档先降Limit或做更细Score分层，不一定直接拒绝C档。
观察结果：观察同Score下EL/Loan、FPD、金额Bad和Contribution Margin。

6）诊断逻辑：Default定义 → 成熟度 → Calibration → Channel/Score → Limit/EAD → 实际Bad。

7）策略动作：PD升高可收准入、降额、调定价或二验；最终动作由EL和利润决定。

8）常见误区：把Score直接当PD；不同Default窗口横比；未成熟标签做校准；训练集PD直接当线上PD。

9）推荐拆分：Channel、Campaign、Score、Product、New/Repeat、Term、Strategy Version。

10）预警方式：同模型/同窗口滚动比较Predicted PD与Observed Bad；样本量不足时只做方向提示，不强设红线。

11）与其他指标关系：Data → Score → PD → EL → Pricing/Limit → Contribution Margin。

12）小练习与答案

PD从12%降到10%，EAD从1,200升到1,800，风险一定改善吗？

答案：不一定。若LGD不变，EL反而可能上升。

LGD｜Loss Given Default｜违约损失率

1）指标是什么：已经发生Default后，最终损失掉的暴露比例。大白话：客户真的坏了以后，100块钱最后收不回来多少。

2）为什么重要：它是贷后/催收/资产价值的重要滞后指标，并直接进入EL。两个PD相同的客群，LGD可能因为回收能力、欺诈占比、支付手段而差很多。

3）精确定义与公式：

简化Net LGD = (EAD − Net Recovery) ÷ EAD = 1 − Net Recovery Rate

必须固定Default时点、Recovery观察窗口、是否折现、是否扣催收/诉讼成本。Gross LGD和Net LGD建议分开。

4）如何看高低：通常越低越好；但短观察窗会机械产生高LGD，因此跨团队比较必须统一回收月龄。

5）墨西哥现金贷案例七步法

背景：两个外包催收商处理同类DPD90+账户。
数据：A 违约EAD 10m，Gross Recovery 2.0m，成本0.4m；B EAD 10m，Gross Recovery 2.3m，成本0.9m；观察期6个月。
现象：B的Gross Recovery更高，但净价值可能更差。
拆解：A Net Recovery=1.6m→Net LGD84%；B=1.4m→Net LGD86%。
根因：B的额外回款没有覆盖额外催收成本。
决策：供应商KPI从Gross Recovery改为Net Recovery/LGD + Complaint。
观察结果：同Default Vintage跟踪3/6/12月Net LGD。

6）诊断逻辑：Default Cohort → DPD/Write-off → RPC/PTP → Recovery → Cost → Net LGD。

7）策略动作：优化早催、分案、支付渠道、外包商；欺诈类违约与普通信用违约分开。

8）常见误区：未成熟Recovery计算LGD；Gross/Net混用；展期当Recovery；不同回收月龄横比。

9）推荐拆分：DPD Bucket、Collection Vendor、Balance、Score、Channel、Fraud/Credit Type、Legal Path。

10）预警方式：同Default Vintage、同Recovery MOB比较；Net LGD恶化且投诉/成本同步升高优先排查供应商。

11）与其他指标关系：RPC/PTP → Collection/Recovery → LGD → EL → Profit。

EAD｜Exposure at Default｜违约风险暴露

1）指标是什么：客户真正违约时，公司暴露在风险中的金额。大白话：坏账发生那一刻，到底有多少钱在桌上。

2）为什么重要：EAD连接额度、提款、Utilization和金额风险，是贷中同步/滞后暴露指标。提额不一定提高坏客件数，却可能大幅放大损失。

3）精确定义与公式：

一次性现金贷：EAD ≈ Default时未偿本金 + 按内部风险口径应计入暴露的其他金额；循环额度还需考虑Default前可能继续提款的未使用额度

必须区分Approved Limit、Disbursed Amount、Current Balance和Default-time EAD。

4）如何看高低：EAD高不代表PD高，但会线性放大同一PD/LGD下的EL。

5）墨西哥现金贷案例七步法

背景：复借提额从2,000提高到2,800。
数据：件数FPD7 9.5%→10.2%；Average EAD 1,550→2,050；金额FPD 10.1%→13.8%；Take-up 58%→66%。
现象：件数风险变化小，金额风险显著恶化。
拆解：低Score + Limit≥2,400组EAD利用率>90%，金额FPD最高。
根因：新增额度被边缘风险用户充分使用，是暴露扩张的重要候选原因。
决策：中高Score保留提额；低Score缩小步长，提款前复核近期多头。
观察结果：Average EAD、Amount FPD、MOB1/2 Vintage、EL、Contribution Margin。

6）诊断逻辑：Approved Limit → Take-up → Utilization → Ticket → Default Balance → Amount FPD/EL。

7）策略动作：按PD/Score分层Limit；边缘客小步提额；对复借高利用率结合Inquiry/DTI控制。

8）常见误区：Limit直接当EAD；只看件数Bad；Current Balance与Default EAD混用。

9）推荐拆分：Score、Limit、Utilization、Term、New/Repeat、Channel、Cycle。

10）预警方式：Average/P90/P95 EAD + 高风险段EAD占比 + Amount FPD联合。

11）与其他指标关系：Limit → Take-up/Utilization → EAD → EL → Funding/Capital → Profit。

Expected Loss｜EL｜预期损失

1）指标是什么：在统一风险窗口下预计会损失多少钱。大白话：把坏的概率、坏了损多少、暴露多少钱合成一个货币风险数。

2）为什么重要：EL是贷前、贷中、经营和资产管理共同使用的桥梁指标，可以直接与收入、CAC和资金成本比较。

3）精确定义与公式：

业务简化EL = PD × LGD × EAD

PD/LGD/EAD必须时间窗口兼容。IFRS 9的ECL是概率加权信用损失，并考虑现金短缺的现值；业务简化公式不能替代正式会计计量。

4）如何看高低：通常越低越好，但如果通过大幅拒绝好客压低EL，利润和LTV可能更差。

5）墨西哥现金贷案例七步法

背景：复借V6统一提额。
数据：PD 12%→12.5%；LGD 75%→76%；Average EAD 1,500→2,000；收入/Loan +25%。
现象：EL约从135升到190 MXN，增幅约41%，快于收入增长。
拆解：低Score高Limit组贡献多数新增EL；高Score提额仍有正Contribution Margin。
根因：EAD扩张是主要候选因素，PD/LGD也有小幅恶化。
决策：边缘Score缩小提额步长，不全量撤回提额。
观察结果：两个成熟Vintage的EL/Loan、Revenue、Funding Cost和Contribution Margin。

6）诊断逻辑：PD变化？→ LGD/Recovery变化？→ EAD/Limit变化？→ Revenue/Funding/CAC → Net Value。

7）策略动作：PD问题收准入/二验；LGD问题优化贷后与回收；EAD问题调额度；最终以利润验证。

8）常见误区：用FPD直接代替EL；三个参数窗口不一致；未成熟样本算长期EL；业务EL等同会计ECL。

9）推荐拆分：Channel、Score、Limit、Term、New/Repeat、Strategy、Funding Source。

10）预警方式：EL/Loan、EL/Disbursement、Segment EL与Contribution Margin联合；阈值使用内部稳定历史，不冒充行业标准。

11）与其他指标关系：PD × LGD × EAD → EL → Pricing/Limit → Contribution Margin → LTV/ROI。

12）小练习与答案

PD=10%、LGD=80%、EAD=2,000，简化EL是多少？

答案：160 MXN。

四指标组合诊断

PD↑、LGD/EAD稳定：优先查客群、渠道、准入和模型。

LGD↑、PD/EAD稳定：优先查催收、回收、欺诈类型、支付和供应商。

EAD↑、PD/LGD稳定：优先查额度、Take-up、Utilization和提额策略。

PD/LGD/EAD同时↑：属于高优先级组合恶化，应快速拆Channel × Score × Limit × Strategy Version，并冻结继续扩量直到根因明确。
