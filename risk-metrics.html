今日核心指标速学

Delegated Payment Rate｜代理支付占比

成功Agent支付 ÷ Eligible且已授权可由Agent执行的支付

自动化覆盖率本身不是成功指标。必须同时看Dispute、ATO、Payment Failure、用户撤销和Contribution Margin。

Policy Breach Rate｜授权规则违反率

被规则阻止的Agentic Payment Attempts ÷ 全部Agentic Payment Attempts

总值之外必须保留Reason Code；账户/设备变化类Breach通常比普通金额超限更值得优先处理。

Agentic Payment Dispute Rate｜代理支付争议率

固定成熟期内产生有效争议的Agent支付 ÷ 同期成熟Agent成功支付

需要同时报件数和争议金额；重复扣款、ATO、授权误解和商户/收款方错误要分开。

Delegated Limit Utilization｜代理授权额度使用率

固定周期Agent累计支付金额 ÷ 同周期用户授权金额上限

高Utilization不等于欺诈，但会扩大授权失效或ATO后的金额暴露；应重点看P90/P95。

常用指标字典｜口径提醒

指标核心定义/提醒
Delegated Payment RateAgent成功执行 ÷ Eligible已授权支付；不要把“Agent建议”算执行。
Policy Breach Rate被金额/频率/收款方/账户状态规则阻止的Agent尝试 ÷ Agent尝试；Reason Code必须保留。
Agentic Payment Dispute Rate成熟争议Agent支付 ÷ 成熟Agent成功支付；固定7/30/60天成熟窗口，件数与金额双报。
Delegated Limit Utilization周期Agent支付金额 ÷ 周期授权上限；单笔限额、月度限额不能混用。
CAC可归因获客成本 ÷ 固定口径客户；First-disbursement CAC需统一归因窗口/补贴。
LTV生命周期净价值；收入、Funding、风险损失、支付/运营/催收、激励与观察窗口需统一。
Contribution MarginRevenue − Funding Cost − CAC − EL − Variable Cost；按Loan/User/Vintage固定。
Break-even Bad Rate由收入/成本/Recovery/EAD反推内部可承受Bad；不是行业统一阈值。
PD / LGD / EAD / ELPD是违约概率；LGD是违约后损失比例；EAD是违约时金额暴露；EL=PD×LGD×EAD（业务简化口径）。
Redraw / Time-to-Redraw复借率和还后再借时间必须与Inquiry、多头、Utilization、Vintage联动，识别Debt Cycling。
Bureau Hit / Inquiry / Multi-BorrowingNo-file、技术失败、身份不匹配分开；近期查询比历史账户总数更有实时性。
Approval / KYC / Take-up / Disbursement漏斗每层分母必须固定；技术失败不能混入信用拒绝。
Payment Failure / Auto-debit / Repayment Success支付技术风险和信用风险分开归因；Error Code、Provider、Retry必须可追踪。
FPD1/3/7/30首期对应观察日仍逾期的成熟订单；件数和金额同时看，成熟期必须固定。
DPD30+ / Vintage / MOB总体DPD可能被新资产稀释；风险趋势优先同Vintage同MOB比较。
Roll / Cure / Recovery迁徙、治愈、回收需固定Bucket和观察窗口；Cash Cure与Extension Cure建议分开。
RPC / PTP / PTP Kept触达→承诺→兑现→回款；只考核PTP会诱导低质量承诺。
ATO / Fraud Loss / Step-up账户接管件数和金额损失双看；Step-up要联动Pass、Abandon、Complaint。
KS / AUC / Gini / PSI排序能力、分布漂移和校准是不同问题；模型指标不能直接替代利润指标。
Precision / Recall / FPR / FNR必须将FP/FN的真实业务成本、Approval、Bad Capture和利润一起评估。
Limit Utilization / Average Ticket / DTI / PTI额度、实际EAD和偿付能力要联合；一次性贷款与循环额度口径不同。
APR / CAT / Funding Cost / ROI价格、资金和收益跨期限需统一；高价格不能自动覆盖不良资产。

指标关系树｜当前版

获客经营：Spend → CAC → Application/KYC → Approval → First Disbursement

征信/收入：Bureau Hit → Inquiry/Active Lenders → Income/DTI/PTI → Approval/Limit

报价/授信：Funding Cost → Price/APR/CAT → Take-up → Customer Mix → EAD/PD → EL → Contribution Margin

支付/Agent：Authorization → Delegated Payment → Policy Breach/Step-up → Payment Success → Dispute/ATO/Fraud Loss

复借：Repayment → Redraw/Time-to-Redraw → Frequency/Utilization/Balance Rebound → EAD → Vintage/EL

信用：FPD → DPD → Vintage/MOB → Roll/Cure → Bad → PD×LGD×EAD → EL

催收：RPC → PTP → PTP Kept → Collection → Cure/Recovery → LGD

模型治理：PSI → AUC/KS/Gini → Precision/Recall/FPR/FNR → Bad Capture → Override → Strategy Value

利润：CAC + Funding + Revenue + EL + Variable Cost → Contribution Margin → LTV/ROI/Risk-adjusted Return
