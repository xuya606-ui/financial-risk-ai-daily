Vintage DPD30+@MOBn｜同批次同账龄30+逾期率

1）是什么：同一放款Vintage在相同MOB时，有多少账户/余额已达到DPD≥30；看同一批贷款长到同样年龄后谁更差。

2）为什么重要：滞后信用表现指标，适用于贷中/贷后；剥离增长/收缩导致的资产年龄结构影响，比Current DPD30+更适合评价渠道、额度与策略版本。

3）公式：件数 = Vintage V在MOBn时DPD≥30成熟账户 ÷ Vintage V在MOBn时成熟账户金额 = 同Vintage同MOB的DPD≥30风险余额 ÷ 固定定义的同Vintage风险金额分母金额分母可采用期末Outstanding或Origination Exposure，但必须全公司固定；Vintage/MOB、快照、核销/重组/展期口径也必须统一。

4）高低：通常越低越好；但展期、核销、资产出售与Cure会改变期末余额，所以件数/金额要一起看。Current DPD低不能替代Vintage DPD低。

5）案例：墨西哥30天首贷6月上线额度V5并扩大渠道C。4月N=18k/MXN26m、5月19.5k/29m、6月27k/47m；Current DPD30+ 12.1%→11.7%，但MOB1为9.8%/10.4%/14.6%；6月Avg EAD 1,740 vs前两月约1,440，低Score×Limit≥2,000占比9%→21%。风险集中Channel C×低Score×高Limit，MOB1约21%。可以确认新Vintage恶化但不能认定单一因果；恢复该组合旧Limit、渠道C降量，中Score低额保留Challenger，观察后续两个Vintage的MOB1/2、Bad、EL和Margin。

6）诊断：Vintage/MOB/快照成熟度 → Channel×Score×Limit×Term×Strategy → FPD/Cure/Roll → 件数vs金额/EAD → Bad/EL/Margin。

7）动作：边缘Score高Limit降额/收紧；单一渠道异常降量；支付/催收问题先修流程；用Challenger/回滚验证。

8）误区：不同MOB直接比；Current替代Vintage；件数金额混用；分母变化；核销/出售造成幸存者偏差。

9）拆分：Channel、Campaign、Product、Score、Limit、Term、New/Repeat、Region、Device、Strategy。

10）预警：同MOB连续两个Vintage高于自身历史P75/P90可作内部黄灯示例；金额风险、EL和Margin同步恶化升级红灯；必须设样本门槛。

11）关系：Traffic/Approval → Limit/EAD → FPD → Vintage DPD30+@MOB → Bad → Recovery/LGD → EL → Margin。

12）练习

Current DPD 12%→11%，最新MOB1 10%→14%→16%，放款+60%。风险改善吗？答案：不能；优先相信同Vintage同MOB恶化。

MOB｜Month on Book｜在账月龄

1）是什么：贷款从放款到观察时点的年龄坐标；它不是坏账率。

2）为什么重要：成熟度/时间轴指标，贯穿贷中贷后。没有统一MOB，DPD、Bad、Recovery和Vintage无法公平比较。

3）定义：MOB没有唯一行业公式，可按自然月或日龄映射。示例：MOB≈floor((Observation Date−Origination Date)/30)生产环境更建议统一Calendar Mapping；MOB0/1、放款日、续借/重组是否重置必须写入数据字典。

4）高低：MOB高低本身无好坏；MOB高意味着更成熟、风险暴露时间更长。低MOB不适合下最终Bad结论。

5）案例：单月扩量60%，MOB0资产占比35%→63%，Current DPD30+ 12%→10.9%，但MOB1 10.2%→14.8%，FPD7金额16%→20%、Avg EAD+28%。总体指标被新资产稀释；改为同MOB报告并等待MOB1/2成熟。

6）诊断：MOB起点/日历 → 资产年龄分布 → 提前结清/核销/重组 → 同Vintage同MOB → Strategy Version。

7）动作：统一数据字典；所有DPD/Vintage看板强制同MOB；低MOB仅使用早期指标做可回滚调整。

8）误区：MOB越高越坏；30天与自然月混用；MOB0/MOB1起点不一致；重组/复借后随意重置。

9）拆分：Vintage、Product、Term、Cycle、New/Repeat、Strategy。

10）预警：先监控负MOB、空值、异常跳月等数据质量；业务风险固定同MOB比较，阈值来自自身历史。

11）关系：Origination → Vintage → MOB → DPD/Bad Maturity → Recovery/LGD → EL。

12）练习

90天产品MOB0与MOB3的Bad直接比较合理吗？答案：不合理。

Bad Rate｜坏账率/违约率

1）是什么：满足固定Default/Bad Definition的成熟账户或金额比例。

2）为什么重要：滞后信用结果指标，服务贷后、模型校准、EL预算和经营复盘。

3）公式：件数Bad Rate = 达到Bad Definition成熟账户 ÷ 同成熟期Eligible账户金额Bad Rate = 达到Bad定义风险金额 ÷ 固定成熟风险金额分母必须固定Bad Definition、预测窗口、成熟期、重组/展期、欺诈Bad是否单列、件数/金额和用户/订单口径。

4）高低：通常越低越好，但大量拒绝好客也可降低Bad并损害利润；必须联动Approval、EAD、EL与Margin。

5）案例：90天成熟N=10k，Bad定义=90天内Ever DPD60+；Cutoff和额度放宽后件数Bad 13%→16%、金额Bad14%→20%、Avg EAD1,420→1,860、Approval30%→35%、Margin82→58 MXN/loan。新增Bad主要集中低Score×Limit≥2,000。恢复边缘额度并保留中Score小流量，观察两个成熟Vintage。

6）诊断：Bad定义/成熟度 → Vintage/MOB → Channel×Score×Limit → Fraud/Payment → Recovery/LGD → EL/Margin。

7）动作：PD型恶化收准入；金额恶化控Limit/EAD；欺诈Bad强化KYC；回收差优化催收。

8）误区：FPD=Bad；未成熟样本进分母；Write-off与Ever DPD混用；只看件数。

9）拆分：Vintage、MOB、Channel、Score、Limit、Term、Cycle、Region、Fraud/Credit、Strategy。

10）预警：只用成熟Cohort、同Vintage同MOB、最小样本量；金额Bad/EL一起做内部黄红灯。

11）关系：Score/PD → Approval/Limit → Bad Rate → LGD/EAD → EL → Contribution Margin。

12）练习

件数Bad下降1pp，但金额Bad+6pp、Avg EAD+35%。能说风险改善吗？答案：不能。

Recovery Rate｜回收率

1）是什么：已经Default/Write-off的风险金额中，后续真正收回多少现金。

2）为什么重要：滞后贷后指标，直接影响LGD、EL和催收/债务出售价值。

3）公式：Gross Recovery@N = N月内回收现金 ÷ Default时EADNet Recovery@N = (回收现金−可归因催收/诉讼成本) ÷ Default时EAD固定Default Vintage、Recovery MOB、EAD、收入组件和成本。

4）高低：通常越高越好，但Gross高不代表Net高；不同Recovery窗口不能直接横比。

5）案例：两Vendor各MXN10m Default EAD；A Gross2.1m、成本0.4m→Net17%，B Gross2.5m、成本0.9m→Net16%，投诉A0.9%、B2.1%。B表面回款高但净价值低。按余额/可联系性重新分案，观察3/6/12月Net Recovery、Complaint和LGD。

6）诊断：Default Cohort/成熟期 → Vendor/DPD/Balance → RPC/PTP/Cure → Gross Cash → Cost/Complaint → Net Recovery/LGD。

7）动作：分层分案；优化支付与和解；淘汰Net差Vendor；欺诈/信用违约分开。

8）误区：未成熟窗口横比；Gross/Net混用；Default前还款计Recovery；Extension当回收。

9）拆分：Default Vintage、Recovery MOB、DPD、Vendor、Balance、Score、Channel、Region、Fraud/Credit。

10）预警：同Default Vintage同Recovery MOB；达到最小EAD后结合Net Recovery与Complaint设置内部灯号。

11）关系：RPC/PTP/Collection → Recovery → LGD↓ → EL↓ → Margin/LTV↑。

12）练习

A回收21%成本4%，B回收25%成本9%。哪个Net高？答案：A 17%高于B 16%。

Collection Rate｜催收回款率

1）是什么：固定催收窗口/队列的应收金额中，期间实际收回多少现金；与Default后的Recovery不同。

2）为什么重要：贷后同步/滞后经营指标，连接支付、RPC/PTP、Cure、Roll和催收成本。

3）公式：Cash Collection Rate@N = 固定催收Cohort在N日/月实际收款 ÷ 固定定义的应收金额/期初逾期余额分母可以是到期应收或期初余额，但必须固定；同时报Gross与Net=(Cash−Collection Cost)/同分母。

4）高低：通常越高越好，但高回款若伴随高成本、高投诉或展期，经济价值可能更差。

5）案例：两个DPD1-30策略各MXN8m期初应收。A Cash2.40m、Cost0.45m、Gross30%、Net24.4%、投诉1.8%；B Cash2.25m、Cost0.18m、Gross28.1%、Net25.9%、投诉0.7%，且Cash Cure高2pp。A Gross更高但B净效率更优；低余额Digital First，高余额/高Forward Roll人工，观察2-4周。

6）诊断：分母/账单 → Payment Success → RPC/PTP/Kept → Cash Cure/Roll → Cost/Complaint → Recovery。

7）动作：支付故障修通道；低Contactability改善触达；低Kept调整策略；高成本低增量转Digital；高余额高风险人工。

8）误区：Collection/Recovery混用；展期当Cash；期初余额与当期应还混用；件数与金额混用。

9）拆分：DPD、Score、Limit、Balance、Vendor/Collector、Payment Method、Region、Cycle、Strategy。

10）预警：同DPD/同年龄历史作基线；Gross下降但Net上升不一定坏。红灯叠加Forward Roll、Cost、Complaint，阈值为内部标准。

11）关系：Payment UX/RPC → Collection → Cure/Roll → DPD30+ → Recovery/LGD → EL/Margin。

12）练习

A Gross30%、Net24.4%、投诉1.8%；B Gross28.1%、Net25.9%、投诉0.7%。其他风险相近优先谁？答案：B。
