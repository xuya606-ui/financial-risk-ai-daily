PD｜Probability of Default｜违约概率

1）是什么：固定预测窗口内发生Default的概率，看“未来变坏的可能性”。

2）为什么重要：贷前/贷中领先风险输入，用于准入、额度、定价和EL，也是模型Calibration治理对象。

3）公式：PD = P(Default within fixed horizon | information at decision time)固定Default定义（如90+DPD/Write-off）、预测窗口、观察时点和账户/用户口径。

4）高低：通常低代表信用风险较低，但低PD不保证利润更高，也不意味着可以无限提额。

5）墨西哥七步案例：背景：30天首贷Strategy B提额；数据：PD12%→13%、EAD1500→1900、LGD70%→72%、EL126→178、Approval31%→35%；现象：PD只升1pp但EL约升41%；拆解：Channel C×低Score×Limit≥2000的PD约19%且EAD更高；根因：PD与额度结构共同变化；决策：低Score高Limit降额，中Score保留Challenger；结果：两个成熟FPD7/MOB1 Cohort看O/E和EL。

6）诊断：Default/成熟期 → PD/Score分布 → O/E → Channel/Score/Limit → FPD/Vintage → EL/Margin。

7）动作：PD整体上移+PSI高先查流量/数据；PD稳定但Observed Bad高做Recalibration/Overlay；边缘PD+高EAD优先降额度。

8）误区：Score=PD；FPD7=长期PD；不同预测窗口横比；PD低就无限提额；用未成熟Bad校准。

9）拆分：Channel、Campaign、Score Decile、Limit、Term、新老客、Region、Bureau Hit、Model/Strategy。

10）预警：同模型、同成熟Cohort看平均PD、Score Band O/E与PSI；任何黄红灯阈值都来自内部稳定历史，不是行业标准。

11）关系：Population/Score → PD → Approval/Price/Limit；PD×LGD×EAD → EL → Margin。

12）练习

A：PD10%、LGD70%、EAD1500，EL105；B：PD8%、LGD70%、EAD3000，EL168。B的PD更低但EL更高。

LGD｜Loss Given Default｜违约损失率

1）是什么：发生违约后最终无法净回收的损失比例，看“坏了以后真正亏几成”。

2）为什么重要：贷后成熟指标，连接催收/Recovery、资产处置和EL。

3）公式：LGD@N = (Default EAD − Net Recoveries within N months) ÷ Default EAD固定Default EAD时点、Recovery窗口、催收/诉讼成本、折现与重组口径。

4）高低：通常越低越好，但不同Recovery MOB不能直接比较；Gross Recovery高也不一定Net LGD低。

5）墨西哥七步案例：背景：两个Vendor各处理Default EAD MXN10m；数据：A Gross2.6m/Cost0.5m→Net Recovery21%、LGD79%；B Gross3.0m/Cost1.1m→Net19%、LGD81%，B投诉2.4% vs A1.1%；现象：B毛回收高但净损失更差；拆解：高余额低Contactability案件增量不足；根因：策略与成本相关但要控制分案差异；决策：按Net Recovery/LGD分案；结果：同Default Vintage、同Recovery MOB观察9-12个月。

6）诊断：Default EAD → Recovery Window → Gross/Net → Vendor/DPD/Balance → Cost/Complaint → LGD。

7）动作：LGD高且RPC低则提升触达/支付；高成本拖累则优化Vendor；高余额低LGD潜力账户提高优先级；Fraud/Credit Default分开。

8）误区：Gross Recovery当Net；不同Recovery MOB横比；Default前还款算Recovery；展期算现金回收；Recovery与LGD分母不一致。

9）拆分：Default Vintage、Recovery MOB、DPD、Balance/EAD、Vendor、Region、Payment Method、Fraud/Credit Type。

10）预警：同Default Vintage/Recovery MOB+最小Default EAD门槛；Net LGD、Collection Cost、Complaint联动。

11）关系：RPC/PTP/Collection → Recovery → LGD；PD×LGD×EAD → EL。

12）练习

Default EAD5m，回收1.5m、成本0.3m，Net Recovery=1.2m，LGD=76%。

EAD｜Exposure at Default｜违约风险暴露

1）是什么：发生违约时真正暴露在风险中的金额，看“坏掉时有多少钱在外面”。

2）为什么重要：额度策略和金额风险核心变量；同样PD下，EAD决定损失金额。

3）公式：固定现金贷可用违约时未偿本金/风险余额；循环额度可用EAD = Current Drawn Balance + CCF × Undrawn Committed Limit固定观察时点、利息/费用是否纳入、币种和账户/订单口径。

4）高低：高不一定坏，高质量客户高EAD也可能产生高利润；需要与PD、LGD、Funding、Margin共同判断。

5）墨西哥七步案例：背景：复借提额Limit 2000→3500；数据：PD8.5%→8.0%、Avg EAD1650→2450、LGD68%→69%、金额FPD12.5%→16.8%、EL约95→135；现象：件数风险未恶化但金额风险升；拆解：中档Score×高Utilization贡献主要EAD；根因：提额+利用率；决策：按PD/LTV/还款历史分层提额并加Utilization Cap；结果：看Amount FPD、MOB1、EL/Margin。

6）诊断：Limit → Utilization/Drawdown → Avg/P90 EAD → Score/PD → Amount FPD/Vintage → EL/Margin。

7）动作：高PD高EAD降额/拒绝；低PD高EAD看Margin和资本占用；EAD突升但Limit不变查利用率/重复放款；循环产品加入CCF。

8）误区：Approved Limit=EAD；只看平均值；件数风险下降就忽略金额风险；循环额度忽略未提款转换。

9）拆分：Score、Limit、Utilization、Term、Channel、Cycle、新老客、Income/DTI、Strategy、Funding Source。

10）预警：Avg/Median/P90 EAD与Amount FPD、EL同步；阈值依据内部稳定历史。

11）关系：Approval → Limit → Utilization → EAD → Amount Bad；PD×LGD×EAD → EL。

12）练习

Drawn1200、Undrawn1800、内部CCF40%：EAD=1200+0.4×1800=1920。CCF不是行业固定值。

Expected Loss / EL｜预期损失

1）是什么：综合PD、LGD、EAD得到固定窗口内的期望信用损失，看“平均应该为信用损失预留多少”。

2）为什么重要：连接准入、额度、定价、资金、预算和经营利润，是风险与业务共同语言；不等于已经发生的Actual Loss。

3）公式：EL = PD × LGD × EAD三者必须使用一致的Default定义、时间窗口与币种；组合优先逐笔计算后加总，避免简单平均数相乘。

4）高低：低通常更好，但不能单独追求低EL而牺牲所有增长；与EL/Loan、EL/EAD、Contribution Margin和ROI联合。

5）墨西哥七步案例：背景：A/B边际首贷提额；数据A PD12%、LGD70%、EAD1500、EL126、Revenue450/Funding85/CAC80/Variable40→Margin119；B PD13%、LGD72%、EAD1900、EL178、Revenue510/Funding112/CAC75/Variable45→Margin100；现象B收入高但新增风险/资金吃掉增量；拆解Channel C×Low Score×High Limit；根因PD/LGD/EAD共同驱动；决策低Score旧Limit，中ScoreChallenger；结果看Actual Loss vs EL、O/E、Margin。

6）诊断：EL Bridge：PD Effect → LGD Effect → EAD Effect → Channel/Score/Limit → Actual Loss/O-E → Margin。

7）动作：PD驱动则收准入/校准；LGD驱动优化催收/Recovery；EAD驱动降额/Utilization；Funding和EL双升则减少低ROI资产。

8）误区：EL=Actual Loss；件数Bad替代金额损失；平均PD×平均LGD×平均EAD；窗口混用；未成熟Actual判断模型。

9）拆分：Channel、Campaign、Score、Limit、Term、Vintage、MOB、新老客、Region、Funding Source、Strategy。

10）预警：EL/Loan、EL/EAD、Actual/Expected和Margin联合；连续成熟Cohort Actual显著高于EL且Margin转负可作为内部红灯候选。

11）关系：Score/Bureau/Income→PD；Recovery→LGD；Limit/Utilization→EAD；三者→EL→Provision/Pricing→Margin/LTV。

12）练习

PD15%、LGD65%、EAD2000：EL=195。Revenue480、Funding100、CAC80、Variable40：Contribution Margin=65。
