今日核心指标速学

ATO Rate｜Account Takeover Rate

大白话：真实账户中有多少被别人拿走控制权并执行了关键动作。

ATO Rate = 确认ATO独立账户 ÷ 可观察活跃账户；建议同时报每万账户和ATO金额损失

业务重点：单一新设备不应直接判欺诈；重点看新设备 + 密码重置 + 手机号/银行卡变化 + 短时间提款等多信号组合。

关系：Account Change Risk → Step-up → ATO → Fraud Loss → Recovery → Contribution Margin。

Fraud Loss Rate｜欺诈损失率

大白话：放出去的钱里最终有多少因欺诈真正损失。

Fraud Loss Rate = 确认欺诈净损失金额 ÷ 同期放款本金或EAD

业务重点：件数Fraud Rate下降但高额度欺诈增加时，金额Fraud Loss仍可能恶化；Gross/Net和Recovery口径必须固定。

关系：Fraud Signals → Capture/ATO → Fraud Loss → Recovery → Net Loss → Profit。

Step-up Challenge Rate｜二次验证触发率

大白话：多少关键操作被要求额外验证身份。

Challenge Rate = 触发Step-up的eligible关键操作 ÷ eligible关键操作总数

业务重点：不是越高越好；需要与Pass Rate、Abandonment、Fraud Loss和投诉一起看，目标是高风险高触发、低风险低摩擦。

关系：Risk Signal → Challenge → Pass/Abandon → Fraud Loss → Take-up/Profit。

Override Rate｜人工改写率

大白话：模型/规则原本的决策，有多少被人工最终改掉。

Override Rate = 被人工改变结果的决策 ÷ 可被Override的决策

业务重点：必须拆Approve Override和Decline Override，并保留Original Decision、Final Decision、Reason、Operator、Strategy Version。持续高Override可能是模型失配，也可能是治理/激励问题。

关系：Model/Rule → Override → Final Approval → FPD/Vintage → EL → Governance。

常用指标字典｜口径提醒

指标核心定义/提醒
Approval Rate审批通过有效申请 ÷ 进入审批有效申请；前置硬拒和技术失败是否入分母必须固定。
KYC Pass Rate通过KYC ÷ 完成对应KYC流程；OCR/Face/Liveness/Bank-name应拆开。
Take-up Rate成功提款/放款用户 ÷ 获得有效可用额度用户；需固定额度有效期。
Disbursement Rate成功到账订单 ÷ 进入放款执行的有效订单；支付/CLABE失败不能误当信用拒绝。
FPD1/3/7/30首期到期后对应观察日仍逾期的成熟订单比例；件数和金额必须同时看。
DPD30+观察日DPD≥30的账户/余额比例；Current DPD和Ever DPD不可混用。
Vintage同一放款批次在相同MOB下比较风险；可识别扩量导致的“资产稀释”。
MOBMonths on Book，账龄坐标；自然月/账期月定义必须统一。
Roll Rate从一个DPD Bucket迁移到另一个Bucket的期初账户/余额比例。
Cure Rate期初逾期桶中恢复Current的账户/余额比例；Cash Cure与Extension Cure建议分开。
Recovery Rate违约/核销暴露中实际收回现金比例；Gross与Net Recovery分开。
RPC / PTP / PTP Kept本人有效触达 → 承诺还款 → 承诺兑现，不能只用PTP作为催收KPI。
KS / AUC / Gini模型排序区分度；不代表PD校准准确，也不直接代表利润。
PSI分布漂移指标；只能说明分布变了，不能单独说明风险方向。
Precision / Recall / FPR / FNR必须与FP/FN的真实业务成本、Approval、Bad Capture和利润一起评估。
Bad Capture成熟Bad中被规则/模型捕获的比例；拒绝样本存在Reject Bias。
Limit Utilization实际使用额度 ÷ Approved/Current Limit；一次性贷款与循环额度口径不同。
Average Ticket成功放款总本金 ÷ 成功放款笔数；与Average Limit不是同一指标。
DTI / PTI总债务偿付/收入与本笔还款/同周期收入；收入验证和周期匹配是核心。
CAC获客成本需要按首贷成功放款用户或其他固定口径计算，并与LTV/EL联动。
Funding Cost资金利息+承诺费+管理/对冲等All-in成本，不只看票面利率。
Expected LossEL = PD × LGD × EAD；时间窗口和口径必须兼容。
Contribution Margin收入 − Funding Cost − CAC − EL − 可变支付/运营/催收成本。
Risk-adjusted Return风险调整后收益 ÷ 平均EAD/本金/资本基数；跨期限需校正。

指标关系树｜当前版

漏斗：注册 → 申请 → KYC → Approval → Limit → Take-up → Disbursement

账户安全/欺诈：Device/Identity/Account Change → Step-up → ATO/Fraud → Fraud Loss

信用：FPD → DPD → Vintage/MOB → Roll/Cure → Bad Rate → PD/LGD/EAD → EL

催收：RPC → PTP → PTP Kept → Collection → Cure/Recovery → LGD

模型治理：PSI → AUC/KS/Gini → Precision/Recall/FPR/FNR → Bad Capture → Override → Strategy Value

经营：CAC + Funding Cost + Revenue + EL + Cost → Contribution Margin → LTV/ROI/Risk-adjusted Return
