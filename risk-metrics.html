今日联合判断框架

Verified Income → DTI / PTI → Residual Income → Income Volatility → FPD / Vintage → EL / Margin

DTI回答已有债务压力；PTI回答新贷款新增压力；Residual回答绝对剩余现金；Income Volatility回答收入是否稳定。四者必须与Score、Limit、Channel和成熟风险结果联合使用。

DTI｜Debt-to-Income｜债务收入比

1）是什么：现有周期性债务付款占可验证同期收入比例。

2）重要性：贷前同步/领先指标，判断已有债务是否挤压偿付空间。

3）公式：DTI = Existing Monthly Debt Service ÷ Verified Monthly Net Income固定税前/税后、月度化、征信债务范围、用户/家庭口径。

4）高低：高通常压力更大；低可能来自漏报/No-hit/收入高估。

5）七步案例：背景：Channel B提额；数据：N40k、Approval31→35%、Ticket1450→1950、DTI30→38%、PTI10.8→15.2%、Residual3700→2500、FPD7 13.8→18.5%；现象量增风险坏；拆解中低Score×高PTI集中；根因与DTI相关但额度/渠道共变；决策高DTI高PTI降额；结果看两个成熟Cohort。

6）诊断：Income → Bureau Debt → DTI → PTI/Residual → Score/Limit → FPD/Vintage。

7）动作：高DTI高PTI降额/收准入；No-hit补替代债务信号；稳定高收入可Challenger。

8）误区：自报收入直接用；余额=月供；家庭/个人混用；周期错配。

9）拆分：Channel、Score、Income、Employment、Limit、Term、新老客、Region。

10）预警：收入×Score内历史分位数；高DTI占比与FPD/EL同步升高才升级。

11）关系：Bureau Debt + Income → DTI → Approval/Limit → FPD/Vintage → EL。

12）练习

12,000收入、3,600现有月付款，DTI=30%。

PTI｜Payment-to-Income｜新贷款还款收入比

1）是什么：拟发放贷款对应周期应付款占同期收入。

2）重要性：额度、期限、定价的前置现金流指标。

3）公式：PTI = Proposed Periodic Payment ÷ Verified Income for Same Period短贷必须统一周期并包含适用费用。

4）高低：高通常压力更大；低也可能来自费用后置或期限延长。

5）七步案例：PTI10.8→15.2%，高波动×高PTI FPD7=27%，稳定工资低PTI≈11%；按Channel×Score×Limit拆；决策高PTI优先降额/调Offer。

6）诊断：Payment口径 → Income周期 → Limit/Price/Term → Stability → FPD。

7）动作：降额度、优化期限/Offer；不可用提价掩盖不可负担。

8）误区：只算本金；周期错配；低PTI就无限提额。

9）拆分：Score、Income、Limit、Term、Price、Cycle、Channel。

10）预警：同产品/期限历史带，PTI与Residual/FPD/EL联合。

11）关系：Limit/Price/Term → PTI → FPD/Cure → Bad/EL。

12）练习

月收入10,000，30天到期应付1,500，PTI=15%。

Residual Income Buffer｜剩余收入缓冲

1）是什么：收入扣除必要支出、已有债务、新贷款付款后剩余现金。

2）重要性：补充DTI/PTI只看比例的不足。

3）公式：Residual = Verified Income − Essential Expense − Existing Debt Service − Proposed Payment可同时报告Residual/Income。

4）高低：高通常更稳，但生活支出模型误差会造成假精度。

5）七步案例：Median Residual 3700→2500，低Residual×高PTI×Channel B风险更高；控制收入档/地区后再做策略。

6）诊断：Income → Expense Model → Debt → Payment → Region/Household → FPD。

7）动作：低Residual降额；支出模型偏差先修；减少过度借款激励。

8）误区：生活支出=0；地区不分；负Residual直接当欺诈。

9）拆分：Income、Region、Household、Employment、Score、Limit、Term。

10）预警：分收入/地区历史分位数；Residual低且Amount FPD/EL升高升级。

11）关系：Income − Expense − Debt − Payment → Residual → FPD/Bad → EL/Margin。

12）练习

10,000−4,000−3,000−1,400=1,600。

Income Volatility｜收入波动度

1）是什么：3-6个月收入/净流入稳定程度。

2）重要性：区分平均收入相同但现金流稳定性不同的用户。

3）公式：内部示例CV = Std(monthly verified net inflow) ÷ Mean(monthly verified net inflow)不存在行业统一算法。

4）高低：高波动通常更谨慎，但季节性/佣金职业需分行业解释。

5）七步案例：高波动客占比14→24%，高波动×高PTI组FPD7=27%；拆Employer/Industry/Score；决策高波动降额、补收入证据。

6）诊断：覆盖月数 → Payroll → Seasonality → Employer → DTI/PTI → FPD。

7）动作：高波动降额/缩短暴露；稳定复借可用行为数据；识别错误先修数据。

8）误区：单月代表长期；奖金月拉高均值；所有转入都算工资；Missing=波动。

9）拆分：Employer、Industry、Region、Channel、Income、Score、Cycle。

10）预警：按职业/收入类型历史分位数，高波动占比与FPD/EL同步升高再告警。

11）关系：Payroll/Employer → Volatility → Affordability → FPD/Cure → EL。

12）练习

8k/12k/10k和10k/10k/10k平均相同，但前者波动更高。
