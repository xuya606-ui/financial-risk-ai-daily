今日联合判断框架

Early Roll → Cure → Net Flow → DPD30+ Stock → Bad / Charge-off → Recovery / LGD → EL / Margin

Roll回答风险流入速度，Cure回答资产回流速度，Net Flow把两者合成一个方向判断；Charge-off必须和Recovery/LGD联合，避免“核销让DPD下降=风险改善”的误判。

Ever 30+ Rate｜曾经进入30+逾期比例

1）是什么：固定放款Cohort在观察窗口内，曾经至少一次达到DPD30+的账户/金额比例。

2）重要性：成熟信用表现指标，比Current快照更少被后续Cure、核销和资产年龄结构掩盖。

3）公式：Ever30+ = 窗口内任一时点达到DPD≥30的成熟账户 ÷ 同Cohort成熟账户件数与金额分开；固定MOB窗口。

4）高低：通常越低越好；观察窗口越长天然越高，跨MOB不能直接比较。

5）七步案例：Channel B提额后，N10k、Avg EAD 1,600→2,050、Ever30+@MOB2 14%→19%、Current30+ 11%→12%、FPD7 15%→18%；风险集中Low Score×High Limit；先局部降额并观察后两个Vintage。

6）诊断：窗口/成熟度 → Current vs Ever → Channel/Score/Limit → Cure/Roll → Bad/EL。

7）动作：局部异常先降额/降量；全局多Segment恶化再收准入；技术假逾期先修支付。

8）误区：不同MOB直接比；Current=Ever；件数金额混用；核销后忘记历史逾期。

9）拆分：Vintage、MOB、Channel、Campaign、Score、Limit、Term、新老客、Strategy。

10）预警：同MOB历史带+最小样本量；连续两个成熟Vintage超稳定区间可设内部黄灯。

11）关系：FPD/Roll → Ever30+ → Bad → Recovery/LGD → EL。

12）练习

成熟10,000单，1,800单曾进30+，其中600已Cure；Ever30+=18%，不能用期末12%替代。

Early-to-30 Roll Rate｜1-29天滚入30+率

1）是什么：期初1-29DPD的账户/余额中，有多少在固定窗口进入30+。

2）重要性：贷后同步/领先指标，常在Bad完全成熟前发现风险。

3）公式：Roll 1-29→30+ = 期初1-29且进入30+ ÷ 期初Eligible 1-29固定快照、件数/金额、展期/重组规则。

4）高低：一般越低越好；展期/技术延期可能人为压低。

5）七步案例：12k到期账户，Roll 28%→39%，30+Cure 31%→22%，MOB1 DPD30+ 12.5%→16.8%；Channel B×Low Score×High Limit=52%；局部降额并恢复高风险早期触达。

6）诊断：Bucket/快照 → Payment Failure → Channel/Score/Limit → RPC/PTP → Cure → DPD30+/Bad。

7）动作：技术异常先修支付；RPC下降改触达；信用风险集中则降额/收准入。

8）误区：新增放款混分母；展期不单列；只看件数；不同观察周期横比。

9）拆分：Channel、Score、Limit、Term、Payment Method、RPC、Strategy、Region。

10）预警：同账龄历史带；Roll上升+Cure下降为组合黄灯。

11）关系：Payment/RPC → Early Roll → 30+ Balance → Bad/Charge-off。

12）练习

期初1-29有2,000单，780单进入30+，Roll=39%。

Net Flow to 30+｜30+余额净流入率

1）是什么：流入30+的余额减去从30+真实Cure/Recovery/Settlement流出的余额，判断风险池净增长。

2）重要性：同步指标，把Roll与Cure合成一个方向判断。

3）公式：Net Flow Rate = (Inflow to 30+ − Cure/Recovery/Settlement Outflow) ÷ Opening 30+ BalanceWrite-off、资产出售和重组独立列示。

4）高低：长期正值通常代表风险池扩张；负值若来自核销，不能当改善。

5）七步案例：Opening 8.0m、Inflow 3.6m、真实流出1.7m，Net +1.9m，Rate=23.75%；流入主要来自Channel B高Limit；动作同时降低Inflow、提升Cure。

6）诊断：Opening Balance → Inflow来源 → Cure/Recovery → Write-off/Restructure → Segment → Bad/EL。

7）动作：Inflow驱动做准入/额度/早催；Cure下降做支付/RPC/Collection；核销异常查政策。

8）误区：核销当Cure；期初期末口径不一致；件数金额混用；Net Flow下降就说信用变好。

9）拆分：Vintage、MOB、Channel、Score、Limit、Collection Strategy、Vendor、Region。

10）预警：连续多期正净流入 + MOB1 DPD30+/EL恶化，可作为红灯候选。

11）关系：Roll In − Cure Out → Net Flow → DPD30+ Stock → Bad/Charge-off → Recovery/LGD。

12）练习

3.6m−1.7m=1.9m；1.9/8.0=23.75%。

Charge-off / Write-off Rate｜核销率

1）是什么：达到内部核销政策条件并从账面冲销的账户/余额比例。

2）重要性：滞后损失确认指标，连接Bad、Recovery、LGD和财务损失；不等于债务免除。

3）公式：常见为期间Gross Write-off ÷ 平均/期初贷款余额或Cohort累计核销/原始放款本金；固定gross/net、Recovery-after-write-off、MOB和币种。

4）高低：通常越低越好；核销政策改变会改变指标。

5）七步案例：原始本金20m，MOB4 Gross核销1.8m=9%，上一Vintage8%，Recovery-after-write-off 1.5%→2.5%，高Limit占增量多数；高风险高Limit降额，后段催收分层，最终看Net Charge-off、Recovery、LGD、Margin。

6）诊断：Write-off Policy → Gross vs Net → Vintage/MOB → Score/Limit → Recovery → LGD/EL。

7）动作：信用驱动收准入/降额；Recovery低优化催收/法律策略；政策变化先重算可比口径。

8）误区：核销=免债；Gross=Net；不同核销天数直接比；错误余额分母。

9）拆分：Vintage、MOB、Score、Limit、Channel、Term、Collection Vendor、Fraud/Credit。

10）预警：同政策同MOB；Gross Charge-off 与 Recovery/LGD/Net Loss 联动，不使用行业统一绝对阈值。

11）关系：DPD90+/Bad → Charge-off → Recovery-after-write-off → LGD → Actual Loss/Margin。

12）练习

原始本金20m，Gross核销1.8m=9%；后续回收0.4m，净损失约7%。
