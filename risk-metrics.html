海外现金贷 / 消费金融风控指标集合

每个核心指标固定按“是什么 → 为什么重要 → 精确口径 → 如何看高低 → 案例七步法 → 诊断 → 策略动作 → 常见误区 → 拆分维度 → 预警 → 指标关系 → 小练习”学习。案例优先使用墨西哥现金贷模拟业务场景；模拟数字不代表真实公司数据或行业统一标准。

今日重点：FPD时间梯度怎么读

FPD1 → FPD3 → FPD7 → FPD30不是四个互相独立的指标，而是一条早期风险“衰减曲线”。FPD1对支付失败、提醒失败、欺诈和极弱偿付能力都敏感；FPD3/7逐步过滤短暂技术问题；FPD30更接近实质信用损失，但成熟更慢。

典型判断：FPD1大涨、FPD3快速回落 → 先查支付；FPD1/3/7同步恶化 → 更像客群/准入；件数稳定但金额恶化 → 优先查高额度坏客。

一、今日新增完整学习卡

FPD1｜First Payment Default Day 1｜首期逾期1天

1 指标是什么：第一期账单到期后的第1天，仍未完成约定还款的成熟订单占比。大白话：最早看“第一次还款马上掉链子”的比例。

2 为什么重要：领先指标，适合监控支付链路、身份欺诈、极高风险客群和策略突变；但噪声最大，不宜单独作为信用策略结论。

FPD1件数率 = 首期到期+1天仍逾期订单数 ÷ 已成熟到首期+1天订单数
FPD1金额率 = 对应逾期首期应还金额 ÷ 已成熟首期应还金额

3 精确口径：建议按订单/账单计算；分母只纳入成熟到D+1的首期；自动扣款失败、节假日、展期和部分还款需固定处理。

4 如何看高低：通常越低越好，但FPD1高不一定代表信用变坏；若D+1支付故障，FPD1会虚高。

5 案例七步法｜FPD1突然恶化（模拟）

背景：墨西哥首贷7天期，策略未改但支付SDK升级。
数据：成熟3,200笔；FPD1 20%→29%；FPD3 17%→19%；自动扣款失败4%→12%；FPD7历史均值15%。
现象：FPD1剧烈恶化，但FPD3只小幅上升。
拆解：按支付方式发现自动扣款用户最明显，现金/转账还款组基本稳定。
根因：支付失败与FPD1恶化高度一致；尚不能把全部变化归因于信用风险。
决策：修复扣款重试与提醒；风控策略暂不全局收紧。
观察：未来3-7天看支付失败、FPD3/7是否回归基线。

6 诊断：成熟度/节假日 → 支付失败 → 渠道×Score → Limit → 欺诈。

7 动作：支付故障修链路；欺诈上升加强KYC/设备；低Score上升收准入；高额度异常降Limit。

8 误区：把技术失败全算信用风险；用未成熟订单做分母。

9 拆分：支付方式、渠道、Score、Limit、到期日、策略版本、设备风险。

10 预警：建议对同产品最近8周D+1成熟样本做动态基线，并附最小样本量；阈值用内部波动校准。

11 关系：支付失败/欺诈 → FPD1 → FPD3 → FPD7 → FPD30。

12 小练习

FPD1从18%升至27%，FPD3仍19%，支付失败从3%升至11%。优先动作？答案：先修支付/重试与提醒，同时按支付方式拆分，不应立即全局收准入。

FPD3｜First Payment Default Day 3｜首期逾期3天

1 指标是什么：首期到期3天后仍未还好的成熟订单比例。它比FPD1更能过滤短暂支付失败。

2 为什么重要：领先指标，适合渠道、准入、额度和支付问题的早期诊断。

FPD3件数率 = 首期+3天仍逾期订单数 ÷ 已成熟到首期+3天订单数

3 口径：成熟到D+3；件数与金额同时报；建议固定到期日Cohort。

4 如何看：FPD1高、FPD3低说明短暂失败被治愈；FPD1/3同步高则更需要关注客群质量。

5 案例｜渠道C FPD3恶化（模拟）

背景：TikTok新Campaign扩量。
数据：样本1,800；FPD1 25%、FPD3 23%、FPD7 21%；旧Campaign对应20%/16%/15%；新Campaign平均Score低35分。
现象：逾期没有在D1→D3明显回落。
拆解：低Score+Limit≥MXN2,000组FPD3达31%。
根因：客群/额度结构与风险恶化相关，需用策略对照进一步验证因果。
决策：新Campaign降量；低Score限额；保留小比例挑战组。
观察：下一批FPD3/7、金额FPD和CAC。

6 诊断：FPD1衰减 → 渠道/Campaign → Score → Limit/Term → 欺诈。

7 动作：渠道降量、边缘Score收紧、额度分层、欺诈规则加强。

8 误区：只看件数；忽略D+3尚未成熟的最新放款。

9 拆分：渠道、Campaign、Score、Limit、产品、新老客。

10 预警：同到期Cohort环比 + 同渠道历史基线；同时看FPD1→3衰减幅度。

11 关系：FPD1 → FPD3 → FPD7；与支付失败、Score和金额FPD联动。

12 小练习

A渠道FPD1/3=28%/18%，B渠道=25%/23%。哪个更值得先查客群？答案：B，因D1→D3衰减很弱，更像实质风险；A先查支付/提醒。

FPD30｜First Payment Default Day 30｜首期逾期30天

1 指标是什么：第一期账单到期30天后仍然逾期的成熟订单比例。

2 为什么重要：比FPD1/3/7更接近实质信用风险和最终坏账，是相对滞后的早期信用指标。

FPD30金额率 = 首期+30天仍逾期订单对应未还本金/应还金额 ÷ 已成熟到D+30的同口径金额

3 口径：必须等到D+30成熟；定义本金/首期应还/余额口径，保持一致。

4 如何看：通常越低越好；但如果审批大幅收紧，FPD30下降可能伴随规模和利润下降，需看Contribution Margin。

5 案例｜FPD7稳定、FPD30恶化（模拟）

背景：额度上调后，早期还款表现看似稳定。
数据：FPD7 15%→16%；FPD30 20%→27%；件均MXN1,300→1,650；8-30 Roll 30%→42%。
现象：风险不是首周爆发，而是在后段加速迁徙。
拆解：高额度+长周期组最差。
根因：额度/期限改变可能提高后段偿付压力。
决策：限制高额度长周期组合，并强化D1-7早催。
观察：后续Vintage MOB1/2、Roll Rate和Bad Rate。

6 诊断：FPD7 → Roll Rate → Limit/Term → 渠道/Score → 催收Cure。

7 动作：额度/期限重配、早催加强、边缘客限额。

8 误区：用未成熟数据；把FPD30和Current DPD30+混为一谈。

9 拆分：Vintage、Score、Limit、Term、策略版本、渠道。

10 预警：同Vintage同成熟期比较；样本不足时不做强结论。

11 关系：FPD7 → Roll → FPD30 → Ever DPD30+ → Bad Rate。

12 小练习

FPD7没变但FPD30升8个百分点，先看什么？答案：先看7-30/8-30迁徙率和额度/期限结构。

Ever DPD30+｜曾经30天以上逾期

1 指标是什么：在指定观察期内，账户是否“曾经达到过DPD30+”。即使后来还清或治愈，Ever标签仍保留。

2 为什么重要：适合做信用历史标签、复借策略和模型Bad定义的中间标签；属于历史累积指标。

Ever DPD30+件数率 = 观察期内曾达到DPD≥30的成熟账户数 ÷ 已成熟账户数

3 口径：明确观察期、账户/订单/用户层级；用户多笔贷款是否“一次命中即Ever”必须固定。

4 如何看：越高通常风险历史越差；但观察期越长自然越容易命中，因此不同窗口不能直接比较。

5 案例｜复借客当前正常但历史Ever差（模拟）

背景：复借提额策略只看当前DPD=0。
数据：当前正常客10,000人；其中Ever DPD30+=1,400；该组下一笔FPD7=19%，无Ever历史组=8%。
现象：只看Current会把历史深逾期客误判成优质。
拆解：Ever30+且最近6个月Cure的用户风险最高。
根因：当前回正掩盖了历史偿付脆弱性。
决策：复借提额增加Ever30+降级或观察期，不必一刀切拒绝。
观察：复借FPD、Vintage、额度使用率。

6 诊断：观察期 → 用户/订单层级 → 当前状态 → 最近一次Ever日期 → 复借表现。

7 动作：复借限额、提额冷静期、风险定价、强化还款能力复核。

8 误区：不同观察期横比；把Ever当Current。

9 拆分：距最近Ever时间、最大DPD、复借次数、Score、Limit。

10 预警：同观察窗比较；跟踪Ever历史人群的复借表现。

11 关系：Current DPD → Ever DPD → Bad Rate → 复借准入/额度。

12 小练习

两名用户当前DPD都为0，其中一人3个月前Ever60+。提额是否完全同档？答案：不应只凭Current同档，应把Ever严重度和距今天数纳入分层。

Current Rate｜当前正常率

1 指标是什么：观察日仍处于Current/正常状态的账户或余额占比。大白话：今天资产池里有多少“现在没逾期”。

2 为什么重要：同步指标，用于资产池当前健康度和贷后运营；但受新放款占比和成熟度影响非常大。

Current Rate（余额） = 观察日DPD=0的未偿本金余额 ÷ 观察日总未偿本金余额

3 口径：DPD=0是否包含提前结清/展期必须固定；件数和余额建议同时报。

4 如何看：通常越高越好，但业务快速扩量时新资产大量进入Current会机械抬高该指标，造成“资产变好”的错觉。

5 案例｜Current Rate上升其实是新资产稀释（模拟）

背景：7月放款额增长50%。
数据：Current Rate 78%→84%；但7月Vintage MOB1 DPD7+从14%→18%，MOB2 DPD30+从13%→17%。
现象：时点Current更好，同MOB资产质量却变差。
拆解：新放款占余额从28%升至45%。
根因：新增未成熟资产稀释逾期余额。
决策：Current只做时点运营监控，信用策略改用Vintage/MOB判断。
观察：未来MOB1/2迁徙和Bad Rate。

6 诊断：新资产占比 → MOB结构 → Vintage → Roll/Cure → 核销/结清口径。

7 动作：不因Current升高直接放宽准入；使用同MOB风险指标。

8 误区：把Current当Vintage；忽略新放款稀释。

9 拆分：MOB、Vintage、产品、渠道、Score、Limit。

10 预警：Current变化须同时报告MOB结构；同MOB/同Vintage验证。

11 关系：放款增长 → MOB结构 → Current Rate；Vintage/Roll决定后续Current变化。

12 小练习

Current Rate从80%升到86%，能否直接认为风控改善？答案：不能，先看新放款占比和同MOB Vintage。

二、历史核心指标学习卡（持续升级）

Approval Rate｜审批通过率

大白话：真正进入审批的人里，有多少被风控放行。

Approval Rate = 审批通过有效申请数 ÷ 进入审批有效申请数

案例：策略V3使审批率30%→36%，放款率24%→29%，但金额FPD7 16%→20%；拆解发现新增通过集中于低Score+高Limit。决策不是全量回滚，而是限制边缘客高额度并保留挑战组。

诊断：渠道结构 → Score → Limit/Term → 欺诈 → FPD/Vintage/EL。

关系：申请率 → Approval → 放款 → FPD → EL → Contribution Margin。

FPD7｜首期逾期7天

FPD7件数率 = D+7仍逾期订单 ÷ 已成熟到D+7订单
FPD7金额率 = 对应逾期首期应还金额 ÷ 已成熟首期应还金额

案例：A渠道件数FPD18%、金额17%；B渠道件数14%、金额22%。B看起来件数更好，但高额度低Score坏客造成金额风险更差。

诊断：口径 → 件数/金额 → 渠道×Score×Limit → 欺诈/支付 → Vintage。

DPD30+ Rate｜当前30天以上逾期率

DPD30+金额率 = 观察日DPD≥30未偿本金 ÷ 同口径未偿本金

关键：Current DPD30+与Ever DPD30+不能混用；快照、余额、核销口径固定。

诊断：Vintage/MOB → 渠道 → Score → Limit → Roll Rate。

Vintage｜同批次资产表现

示例：Vintage DPD30+ @ MOB2 = 某放款批次MOB2时DPD30+余额 ÷ 原始放款本金

核心：必须同MOB比较。业务扩量时总体逾期可能被新资产稀释，Vintage用来识别真实风险趋势。

案例：整体DPD30+下降，但7月MOB2为16.8%，高于5月13.2%和6月13.5%，说明7月批次实际恶化。

MOB｜Months on Book｜账龄

大白话：贷款“长到第几个月”，是Vintage、Bad Rate和Recovery的成熟度坐标。MOB0/MOB1、自然月/账期月必须统一。

Bad Rate｜坏账率

Bad Rate = 达到Bad定义的成熟样本 ÷ 已成熟样本

关键：先定义Bad（Ever90+/核销/损失事件等），再定义成熟期。未成熟样本不能进入普通Bad Rate分母。

Roll Rate｜迁徙率

Roll Rate(x→y) = 从x桶迁移到y桶的账户/余额 ÷ x桶期初账户/余额

案例：DPD30+稳定但1-7→8-30从28%升至38%，说明风险在前端积累；先区分支付失败和客群质量。

Cure Rate｜治愈率

Cure Rate = 达到Cure标准的期初逾期账户/余额 ÷ 期初该逾期桶账户/余额

误区：展期、部分还款、重组是否算Cure不统一会造成虚高。

RPC → PTP → Collection → Recovery

指标大白话核心风险
RPC是否真正联系到本人短信送达/第三方接听不能算本人有效触达
PTP本人是否承诺在某日还款必须继续看PTP Kept，不能把承诺当回款
Collection Rate可催的钱实际催回多少分母要固定为到期额/逾期余额/分案余额之一
Recovery Rate坏资产最终追回多少固定窗口，Gross/Net Recovery区分

KS / AUC / PSI / Bad Capture

KS：好坏客累计分布最大差异，衡量排序区分度。

AUC：随机好坏样本对中模型正确排序的概率能力；高AUC不等于利润更高。

PSI：Σ(Actual_i-Expected_i)×ln(Actual_i/Expected_i)只说明分布漂移，不说明风险方向。

Bad Capture：策略拦截到的Bad占全部Bad的比例。规则命中高但Bad Capture低，可能误杀多。

诊断：PSI → 分渠道分群 → KS/AUC → 校准/Bad Rate → Cutoff与Approval/利润。

CAC / LTV / PD-LGD-EAD / Expected Loss / Contribution Margin

CAC：首贷CAC = 投放成本 ÷ 首贷放款用户数CPI便宜不代表首贷CAC便宜。

LTV：生命周期收入扣除信用损失、资金成本、支付/运营/催收成本后的客户价值。

PD/LGD/EAD：分别回答“会不会坏 / 坏了损失比例 / 坏时暴露多少钱”。

Expected Loss = PD × LGD × EAD

Contribution Margin：≈ 利息/费用收入 - 资金成本 - CAC - EL - 支付/运营/催收可变成本

案例：PD18%、LGD70%不变，平均EAD从MXN1,200升至1,600，单客EL从151.2升至201.6，约+33%；件数Bad不变也不代表金额风险没上升。

指标关系树｜8月19日版

漏斗：曝光 → 点击 → 安装 → 申请 → KYC → Approval → 放款 → CAC

早期风险：支付/欺诈/多头 → FPD1 → FPD3 → FPD7 → FPD30

成熟风险：Vintage / MOB → Current/Ever DPD → Roll → Bad Rate → PD/LGD/EAD → EL

催收：RPC → PTP → PTP Kept → Collection → Cure / Recovery → LGD

模型：PSI → KS/AUC → Bad Capture → Approval / Bad Rate

利润：CAC + 收入 + 资金成本 + EL + 运营成本 → Contribution Margin → LTV / ROI
