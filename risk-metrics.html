Fraud Capture Rate / Recall｜欺诈捕获率

1）是什么：真实Fraud中被系统成功识别的比例；看“真正欺诈里抓住多少”。

2）为什么重要：贷前/欺诈滞后Outcome指标，反映漏Fraud风险，但不能单独代表经济价值。

3）公式：Recall = TP ÷ (TP+FN)固定Fraud Definition、成熟窗口、预测时点、订单/用户与件数/金额口径；Hard Decline/Review/Alert的“捕获”定义也要固定。

4）高低：通常高更好，但通过无限降阈值可机械提高Recall并推高FPR、误杀和Review。

5）墨西哥七步案例：背景：50k首贷、真实Fraud 2k；数据：A抓1560/Recall78%、B抓1800/90%，但B多误拒2760个Good；现象：Recall增12pp但净价值未必增；拆解：增量TP集中Channel C新设备，FP集中稳定设备中高Score；根因：阈值更宽确认提高Recall，是否更优需经济验证；决策：高风险群B、低风险群A、灰区Step-up；结果：两个成熟Cohort看Net Fraud Loss与Margin。

6）诊断：标签成熟度 → Base Rate → Channel/Device/Score → FNR/FPR/Precision → Fraud Loss/Approval/Margin。

7）动作：Recall低/FNR高则补高风险信号或分层阈值；Recall升而FPR爆炸则灰区Step-up；渠道漏Fraud则独立策略；整体漂移则校准/Challenger。

8）误区：Alert=TP；未成熟标签；只看件数；Recall越高越好；不同Fraud Definition横比。

9）拆分：Channel、Campaign、Fraud Type、Device、KYC Vendor、Score、Limit、Region、Model/Rule Version。

10）预警：同标签/同模型稳定基线+最小样本。示例黄灯：连续两个成熟Cohort Recall低于历史P10且FNR/Net Loss同步恶化；非行业标准。

11）关系：Base Rate → Threshold → Recall↔FNR → Prevented Loss；Threshold同时影响FPR→Approval/Lost Margin。

12）练习

Fraud 1000、抓850，Recall=85%。如再多抓70却多误拒5000个Good，不能只凭Recall选新阈值。

False Positive Rate / FPR｜好客误杀率

1）是什么：真实Good中被错误判为Fraud的比例。

2）为什么重要：贷前/欺诈滞后Outcome指标，连接Approval、客户体验、投诉和Lost Good Margin。

3）公式：FPR = FP ÷ (FP+TN)分母是真实Good，不是全部Decline；固定成熟期、Action定义、订单/用户口径。

4）高低：一般低更好，但极低可能来自过松策略并提高FNR；Good基数大时小比例也可能是大量误杀。

5）墨西哥七步案例：背景同上；数据A FP4440/48k=9.25%，B FP7200=15%；现象B多误杀2760；拆解误报集中稳定设备中高Score；根因阈值放宽，同时排查Device Vendor漂移；决策该Segment提高Hard Decline阈值/灰区Step-up；结果看Approval、投诉、Fraud Loss。

6）诊断：Good标签 → FP绝对量/FPR → Reason/Channel/Device → Precision/Recall → Lost Margin/Complaint。

7）动作：高FPR弱规则降级；Vendor漂移修数据；高价值好客加入可信历史信号；高FPR低Recall增量规则做下线Challenger。

8）误区：FP÷Decline当FPR；未成熟样本当Good；只看比例不看FP数量；投诉率替代FPR。

9）拆分：Rule/Model、Channel、Device、Score、Limit、KYC、新老客、Region、Strategy。

10）预警：同模型稳定基线+FP绝对量/Lost Margin；示例黄灯：FPR连续两个成熟Cohort高于历史P90且Recall未相应提升。

11）关系：Threshold↓ → FPR↑ → Approval↓/Review↑ → Lost Margin/Complaint↑；与Recall形成权衡。

12）练习

Good 20,000、误拒1,200，FPR=6%。仍需结合Recall、误拒价值和投诉判断可接受性。

False Negative Rate / FNR｜欺诈漏判率

1）是什么：真实Fraud中被误判正常而漏掉的比例。

2）为什么重要：贷前/欺诈滞后Outcome指标，直接连接Fraud Loss；同一二分类定义下FNR=1-Recall。

3）公式：FNR = FN ÷ (TP+FN) = 1−Recall区分模型初始FNR和Review/Step-up后的最终Decision FNR；件数与金额分开。

4）高低：通常越低越好，但压得过低可能造成FPR激增；件数FNR下降也可能掩盖高EAD漏Fraud。

5）墨西哥七步案例：背景A/B；数据A FNR22%、B10%，但B剩余漏Fraud平均EAD更高；现象件数改善但金额风险仍高；拆解集中High Limit+Bank Change；根因缺账户变化/受益人信号；决策针对高EAD+Bank Change Step-up而非全量降阈值；结果看件数/金额FNR与Net Loss。

6）诊断：成熟标签 → 件数/金额FNR → Fraud Type → Channel/Device/Bank Change/Limit → Data/Model Blind Spot。

7）动作：金额FNR高补EAD/账户变化控制；Fraud Type漏判补图谱/设备信号；PSI高且全局恶化则重校准/重训；FNR低但FPR爆炸则提高阈值。

8）误区：只报件数；模型FNR/最终Decision FNR混用；未成熟Fraud漏记；无差别全量收紧。

9）拆分：Fraud Type、EAD、Channel、Device、Bank Change、Score、Limit、Region、Model Version。

10）预警：件数与金额双轨，同成熟Cohort+最小样本。示例红灯候选：金额FNR连续两个Cohort显著超历史稳定区间且Net Loss同步升高。

11）关系：Recall=1-FNR；FNR×Fraud EAD×不可追回比例 → Fraud Loss → Net Fraud Loss → Margin。

12）练习

Fraud 500、TP425、FN75：FNR=15%，Recall=85%。还应查看FN金额和类型。

Precision / PPV｜查准率 / 阳性预测值

1）是什么：所有被判Fraud的人里，最后真正Fraud的比例。

2）为什么重要：贷前/欺诈滞后Outcome指标，衡量Decline/Alert/Review队列纯度，决定Review效率和误杀成本；受Fraud Base Rate影响大。

3）公式：Precision = TP ÷ (TP+FP)固定阳性Action、成熟期、订单/用户口径；Case Precision可另定义为Confirmed Fraud Cases÷成熟Reviewed Cases。

4）高低：通常高更好，但极高Precision可能来自过严阈值并导致Recall很低；Base Rate上升也会自然推高Precision。

5）墨西哥七步案例：背景A/B；数据A Precision=1560/6000=26%，B=1800/9000=20%；现象B Recall高但队列更脏；拆解低Precision来自稳定设备中高Score；根因边际入队用户Fraud密度低；决策高Precision信号Hard Decline、中等Step-up/Review、低Precision弱信号降级；结果看Case Capacity、Cost、Loss、Approval。

6）诊断：Base Rate → TP/FP定义 → Rule/Score Band → Recall/FPR → Review Cost/Lost Margin。

7）动作：低Precision高量规则收窄；低Precision但高金额Fraud转Step-up；Reviewer队列低Precision优化Case Priority；高Precision低Recall加第二层覆盖。

8）误区：Precision与FPR混淆；不同Base Rate渠道横比；只看Precision不看Recall；未成熟Good当FP。

9）拆分：Rule/Alert、Model Score Band、Channel、Device、KYC Vendor、Fraud Type、Limit、Region、Strategy。

10）预警：同Base Rate相近样本/同成熟窗口比较。示例黄灯：Case Precision持续下降且Backlog/Cost上升；Fraud Loss也升再升级。

11）关系：Base Rate+Threshold → Precision；Alert Volume×Precision → Confirmed Fraud/Prevented Loss；FP同时进入FPR→Lost Good Margin。

12）练习

拒绝2,000，其中400确认Fraud，Precision=20%。另一规则Precision35%但Recall20%，不能仅凭Precision判断更优。
