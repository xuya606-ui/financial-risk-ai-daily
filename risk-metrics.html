今日核心指标速学

Fraud Alert Rate｜欺诈告警率

触发至少1个Fraud Alert的Eligible事件 ÷ Eligible风险事件

看系统打出多少风险信号。Alert突然上升既可能是攻击增加，也可能是重复规则/数据异常；必须与FPR、Case Backlog、Confirmed Fraud和Net Fraud Loss一起看。

Alert-to-Case Conversion｜告警转案件率

由Unique Alert创建的调查Case ÷ Eligible Unique Alerts

反映告警是否真正值得调查以及Case容量是否匹配。下降不一定意味着告警变差，也可能是审核积压。

TTD｜Time to Detect

Alert Time − First Detectable Risk Event Time

看坏事发生后多久被发现；适合ATO、支付欺诈和团伙风险，建议报P50/P90而不是只看平均值。

TTC｜Time to Contain

Containment Effective Time − Alert Time

看发现后多久真正阻止后续损失。检测快但Contain慢，仍可能产生大量Post-alert Loss。

常用指标字典｜口径提醒

指标核心定义/提醒
Fraud Alert RateEligible事件触发告警的比例；区分Alert次数、Unique Event、Unique User。
Alert-to-CaseUnique Alert中进入调查Case的比例；和Case Backlog/Confirmed Fraud一起看。
TTD / TTC分别衡量“多久发现”和“多久真正控制”；必须固定起点/终点并看P90。
KS / AUC排序区分度；不能替代Calibration、EL或利润。
PSI当前分布相对基准变化；漂移不代表风险方向，不机械套0.1/0.25。
O/E Bad Ratio实际成熟Bad ÷ 平均预测PD；预测窗口、Bad定义和成熟期必须一致。
Delegated Payment RateAgent成功执行 ÷ Eligible已授权支付；不要把建议算执行。
Policy Breach Rate被金额/频率/收款方/账户状态规则阻止的Agent尝试 ÷ Agent尝试；保留Reason Code。
Agentic Payment Dispute成熟争议Agent支付 ÷ 成熟Agent成功支付；件数与金额双报。
CAC可归因获客成本 ÷ 固定口径客户；注册/申请/首贷分母不能混。
LTV生命周期净价值；收入、Funding、风险损失、支付/运营/催收、激励与观察窗口统一。
Contribution MarginRevenue − Funding Cost − CAC − EL − Variable Cost。
Break-even Bad Rate由收入/成本/Recovery/EAD反推内部可承受Bad；不是监管或行业标准。
PD / LGD / EAD / ELPD概率、LGD违约后损失比例、EAD违约暴露；EL=PD×LGD×EAD为业务简化口径。
Redraw / Time-to-Redraw复借活跃与Debt Cycling需与Inquiry、多头、Utilization、Vintage联动。
Bureau Hit / Inquiry / Multi-BorrowingNo-file、技术失败、身份不匹配分开；近期查询比历史账户总数更实时。
Approval / KYC / Take-up / Disbursement漏斗分母固定；技术失败不能混入信用拒绝。
Payment Failure / Auto-debit支付技术风险和信用风险分开归因；Error Code、Provider、Retry可追踪。
FPD1/3/7/30首期对应观察日仍逾期的成熟订单；件数和金额同时看。
DPD30+ / Vintage / MOB总体DPD可能被新资产稀释；优先同Vintage同MOB。
Roll / Cure / Recovery迁徙、治愈、回收固定Bucket和观察窗口；Cash Cure与Extension Cure分开。
RPC / PTP / PTP Kept触达→承诺→兑现→回款；只考核PTP会诱导低质量承诺。
ATO / Fraud Loss / Step-up账户接管件数和金额双看；Step-up联动Pass、Abandon、Complaint。
Precision / Recall / FPR / FNR必须将FP/FN真实业务成本、Approval、Bad Capture和利润一起评估。
Limit Utilization / Ticket / DTI / PTI额度、实际EAD与偿付能力联合；一次性与循环额度口径不同。
APR / CAT / Funding Cost / ROI价格、资金和收益跨期限统一；高价格不能自动覆盖高风险。

指标关系树｜当前版

获客经营：Spend → CAC → Application/KYC → Approval → First Disbursement

征信/收入：Bureau Hit → Inquiry/Active Lenders → Income/DTI/PTI → Approval/Limit

欺诈闭环：Signal → Fraud Alert → Alert-to-Case → TTD/TTC → Confirmed Fraud → Recovery → Net Fraud Loss → Feedback

报价/授信：Funding Cost → Price/APR/CAT → Take-up → Customer Mix → EAD/PD → EL → Contribution Margin

支付/Agent：Authorization → Delegated Payment → Policy Breach/Step-up → Payment Success → Dispute/ATO/Fraud Loss

复借：Repayment → Redraw/Time-to-Redraw → Frequency/Utilization/Balance Rebound → EAD → Vintage/EL

信用：FPD → DPD → Vintage/MOB → Roll/Cure → Bad → PD×LGD×EAD → EL

催收：RPC → PTP → PTP Kept → Collection → Cure/Recovery → LGD

模型治理：Data/Population → PSI → AUC/KS → Calibration/OE → Lift/Bad Capture → Cutoff → Approval → EL/Profit

利润：CAC + Funding + Revenue + EL + Variable Cost → Contribution Margin → LTV/ROI/Risk-adjusted Return
