今日核心指标速学

Approval Rate｜审批通过率

Approved Eligible Applications ÷ Eligible Applications Entering Defined Approval Funnel

必须先固定分母。Approval上升不一定是好事，可能是Cutoff放宽、流量变好，也可能让边缘Score和EAD膨胀；Approval下降也可能只是OCR/Bureau技术事故。

Credit Approval Rate｜信用审批通过率

Credit-approved Applications ÷ Applications Actually Evaluated by Credit Decision

把没有真正进入信用决策的KYC/技术/Fraud硬拒剔除后，更适合看模型、Score Cutoff和信用策略本身。

Policy / Fraud Decline Rate｜政策/欺诈拒绝率

Final Policy/Fraud Declined Applications ÷ Eligible Applications Evaluated by those Controls

要区分Rule Hit、First-hit和Final Decline。拒绝率上升并不自动证明欺诈控制更强，必须与Confirmed Fraud、FPR、Fraud Loss和投诉一起看。

Approval-to-Disbursement Rate｜批准到放款转化率

Successful Disbursed Approved Users/Orders ÷ Approved Users/Orders with Mature Offer Window

连接批准和真实EAD。下降可能是低意愿批准、Offer问题，也可能是CLABE/Payment Provider技术失败。

Approval Rate｜主字典完整学习卡

1. 是什么：定义审批漏斗内最终获批的比例。

2. 为什么重要：贷前同步指标，连接风险偏好、资产形成和利润，但不能单独代表风险质量。

3. 精确定义：Approved ÷ Eligible applications entering the fixed funnel固定漏斗起点、去重、技术失败、批准有效期、用户/订单口径。

4. 如何看：高可能流量好或策略宽，也可能增加边缘风险；低可能收紧或技术故障。

5. 墨西哥案例：首贷40,000申请，Approval 30%→35%，平均批准额度1,500→1,850，Approval-to-Disbursement 74%→67%，FPD7 14%→17%，金额FPD 15%→21%，Contribution Margin/Approved 86→61；拆解后新增批准集中渠道C×低Score×Limit≥2,000。相关性明确，但Cutoff/Limit/Channel同时变化，因果仍需Challenger验证。

6. 诊断：分母/数据 → KYC/Technical/Fraud/Credit → Channel/Score/Limit → Take-up/Disbursement/EAD → Mature FPD/EL/Margin。

7. 动作：技术问题修流程；Fraud问题强身份/图谱；低Score高Limit收紧；中Score低Limit用Challenger验证。

8. 误区：Approval越高越好；总拒绝=信用拒绝；技术失败算风险；只看件数风险；不同漏斗口径横比。

9. 拆分：Channel、Campaign、Score、Limit、Term、New/Repeat、Region、Vendor、Strategy Version、Reason。

10. 预警：使用同产品同策略稳定历史与成熟Cohort；Approval偏离必须与边际批准客的EL/Margin一起触发，不使用行业统一阈值。

11. 关系：Traffic/KYC → Fraud/Policy → Approval → Limit → Take-up → Disbursement → EAD → FPD/Vintage → EL → Margin

12. 小练习

Approval +6pp但EAD +45%、FPD7 +2pp，是否可判定策略更优？答案：不能，需计算EL和Contribution Margin，并拆边际批准人群。

常用指标字典｜口径提醒

指标核心定义/提醒
Approval / Credit Approval总Approval先固定漏斗分母；Credit Approval只看真正进入信用决策的申请。
Policy/Fraud DeclineFinal Decline与Rule Hit分开；和FPR、Confirmed Fraud、Fraud Loss联动。
Approval-to-Disbursement批准后成功到账；与Take-up、Payment/Disbursement Failure分开。
Fraud Alert / Alert-to-CaseAlert数量不等于价值；Unique Entity、Case容量和Confirmed Fraud一起看。
TTD / TTC分别衡量“多久发现”和“多久真正控制”；固定起点/终点并看P90。
KS / AUC排序区分度；不能替代Calibration、EL或利润。
PSI当前分布相对基准变化；漂移不代表风险方向，不机械套0.1/0.25。
O/E Bad Ratio实际成熟Bad ÷ 平均预测PD；预测窗口、Bad定义和成熟期必须一致。
Delegated Payment / Policy BreachAgent成功执行和被规则阻止的动作分别管理；保留授权和Reason Code。
CAC / LTVCAC分母固定，LTV包含风险与Funding；低CAC不等于好渠道。
Contribution MarginRevenue − Funding Cost − CAC − EL − Variable Cost。
Break-even Bad Rate内部可承受Bad；不是监管或行业标准。
PD / LGD / EAD / ELEL=PD×LGD×EAD为业务简化口径；时间窗口一致。
Redraw / Time-to-Redraw复借活跃与Debt Cycling需与Inquiry、多头、Utilization、Vintage联动。
Bureau Hit / Inquiry / Multi-BorrowingNo-file、技术失败、身份不匹配分开；近期查询比历史账户总数更实时。
Payment Failure / Auto-debit支付技术风险和信用风险分开归因；Error Code、Provider、Retry可追踪。
FPD1/3/7/30首期对应观察日仍逾期的成熟订单；件数和金额同时看。
DPD30+ / Vintage / MOB总体DPD可能被新资产稀释；优先同Vintage同MOB。
Roll / Cure / Recovery迁徙、治愈、回收固定Bucket和观察窗口；Cash Cure与Extension Cure分开。
RPC / PTP / PTP Kept触达→承诺→兑现→回款；只考核PTP会诱导低质量承诺。
ATO / Fraud Loss / Step-up账户接管件数和金额双看；Step-up联动Pass、Abandon、Complaint。
Precision / Recall / FPR / FNR将FP/FN真实业务成本、Approval、Bad Capture和利润一起评估。
Limit Utilization / Ticket / DTI / PTI额度、实际EAD与偿付能力联合；一次性与循环额度口径不同。
APR / CAT / Funding Cost / ROI价格、资金和收益跨期限统一；高价格不能自动覆盖高风险。

指标关系树｜当前版

审批漏斗：Application → KYC/Technical → Fraud/Policy → Credit Approval → Approved Limit → Take-up → Disbursement

征信/收入：Bureau Hit → Inquiry/Active Lenders → Income/DTI/PTI → Credit Approval/Limit

欺诈闭环：Signal → Fraud Alert → Alert-to-Case → TTD/TTC → Confirmed Fraud → Recovery → Net Fraud Loss → Feedback

报价/授信：Funding Cost → Price/APR/CAT → Take-up → Customer Mix → EAD/PD → EL → Contribution Margin

支付/Agent：Authorization → Delegated Payment → Policy Breach/Step-up → Payment Success → Dispute/ATO/Fraud Loss

复借：Repayment → Redraw/Time-to-Redraw → Frequency/Utilization/Balance Rebound → EAD → Vintage/EL

信用：FPD → DPD → Vintage/MOB → Roll/Cure → Bad → PD×LGD×EAD → EL

催收：RPC → PTP → PTP Kept → Collection → Cure/Recovery → LGD

模型治理：Data/Population → PSI → AUC/KS → Calibration/OE → Lift/Bad Capture → Cutoff → Approval → EL/Profit

利润：CAC + Funding + Revenue + EL + Variable Cost → Contribution Margin → LTV/ROI/Risk-adjusted Return
