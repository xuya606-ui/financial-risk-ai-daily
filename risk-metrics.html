指标字典2026-08-18升级

海外现金贷 / 消费金融风控指标集合

本页不再只做“指标定义表”，而是按“指标说明 → 公式口径 → 如何看高低 → 案例 → 诊断 → 策略动作 → 误区 → 预警 → 练习”的方式学习。案例优先使用墨西哥现金贷场景，并明确区分模拟数据与真实外部事实。

统一的“指标学习卡”逻辑

① 指标是什么

中文名、英文名、缩写，再用一句大白话说明它到底在看什么。

② 为什么重要

解决什么业务问题；属于领先、同步还是滞后指标；对应贷前/贷中/贷后。

③ 精确口径

公式、分子、分母、时间窗口、成熟期、件数/金额、用户/订单/账户/余额。

④ 如何看高低

升高和下降各意味着什么；哪些情况下“越高越好/越低越好”会误导。

⑤ 案例七步法

背景 → 数据 → 现象 → 拆解 → 根因 → 决策 → 观察结果。

⑥ 诊断与动作

异常时先看什么、再看什么；最终落到准入、额度、定价、反欺诈、催收或渠道动作。

案例统一介绍模板

背景：国家/产品/新老客/渠道/策略变化。

数据：至少3-6个指标，包含样本量、件数或金额。

现象：先描述发生了什么，不急着下结论。

拆解：优先渠道 × Score × Limit × Term × Strategy Version。

根因：先证明关联，再判断是否具有因果证据。

决策：给风控、产品、运营、数据具体动作。

结果：说明要观察多久、看哪些指标、什么情况下认为策略有效。

A. 获客 / 漏斗指标

Approval Rate｜审批通过率

漏斗贷前同步指标

1. 一句话说明

它回答的是：进入真正审批环节的申请里，有多少最终被风控放行。

2. 为什么重要

审批率决定放款漏斗规模，但它本身不是经营目标。审批率提高可能来自客群变好，也可能来自策略放松；必须与FPD、Vintage、Expected Loss和贡献利润一起看。

3. 精确定义

Approval Rate = 审批通过的有效申请数 ÷ 进入审批的有效申请数

关键口径：必须统一“有效申请”。资料不完整、重复申请、系统异常、前置反欺诈硬拒是否进入分母，需要固定。

4. 如何看高低

审批率上升不一定好：如果新增通过的是临界高风险客群，短期放款增长，后续FPD和EL可能更差。审批率下降也不一定坏：如果是主动拦截欺诈或低利润客群，利润可能改善。

5. 墨西哥现金贷案例｜审批率提升但利润下降（模拟数据）

背景：墨西哥首贷产品，Meta渠道，策略V3放宽Score下限。
数据：样本20,000；审批率30%→36%；放款率24%→29%；平均件均MXN1,500→1,620；FPD7金额率16%→20%；首贷CAC MXN310→305。
现象：获客成本略降、放款量明显增加，但早期风险同步恶化。
拆解：按Score发现新增通过主要集中在最低两个Score段；再按Limit发现MXN1,800+额度档FPD7最差。
根因：“审批率提高”只是表象，真正变化是临界Score客群被放行且同时拿到了更高额度。这里可以确认相关性；是否由策略V3直接导致，需要用策略版本对照或Champion/Challenger验证。
决策：不直接恢复旧策略；先保留部分新增客群，但限制高额度，低Score段做10%-20%挑战组。
观察结果：至少观察到FPD7成熟，并继续追MOB1 DPD30+和Contribution Margin。若放款量仍提升但EL回落，说明优化有效。

6. 异常诊断顺序

① 看渠道结构是否变化 → ② 看Score分布 → ③ 看Limit/Term变化 → ④ 看反欺诈拒绝是否下降 → ⑤ 看FPD/Vintage/EL。

7. 策略动作

如果审批率升高且风险恶化：优先收紧边缘Score、限制额度、恢复部分规则；如果审批率下降但风险稳定：检查是否误杀、KYC失败或规则重复。

8. 常见误区

误区1：把注册用户数当分母。误区2：只追求审批率，不看边际利润。

9. 推荐拆分

渠道、Campaign、Score、Limit、Term、新老客、策略版本、地区、设备风险。

10. 预警方式

建议同时设置“审批率偏离 + FPD/EL变化”联合预警。数值阈值应使用内部历史基线，不建议直接套行业值。

11. 指标关系

申请率 → 审批率 → 放款率 → FPD → Vintage → EL → Contribution Margin。

12. 小练习

某策略审批率由28%升至34%，FPD7件数率由14%升至15%，但金额FPD7由15%升至20%。你应该优先排查什么？

参考答案：优先看额度档和新增通过客群的Score分布，因为件数风险变化不大而金额风险明显恶化，常见原因是高风险用户集中拿到了更高额度。

C. 信用表现指标

FPD7｜First Payment Default at Day 7｜首期逾期第7天

早期风险首贷重点领先指标

1. 一句话说明

它看的是：第一期账单到期后7天，仍然没还好的客户有多少。 对短周期现金贷，它通常是最早能反映渠道质量、欺诈和准入变化的核心指标之一。

2. 为什么重要

FPD出现早，适合快速评估投放渠道、首贷策略和反欺诈策略；但它不是最终损失，需要继续追踪DPD30+、Vintage和Bad Rate。

3. 精确定义与公式

FPD7件数率 = 首期到期后第7天仍逾期的成熟订单数 ÷ 已成熟到首期+7天的订单数
FPD7金额率 = 上述逾期订单对应首期应还金额 ÷ 已成熟首期应还金额

成熟期：只有已经到首期应还日并经过7天观察窗口的订单进入分母。

4. 如何看高低

通常越低越好，但不能孤立看：如果审批大幅收紧，FPD下降只是因为放款量和客群结构改变；如果件数FPD稳定、金额FPD恶化，通常需要重点查高额度坏客。

5. 墨西哥现金贷案例｜渠道A看起来更差，其实渠道B金额风险更高（模拟数据）

背景：两个投放渠道A/B，均为首贷7天期产品。
数据：A样本2,000笔、件均MXN1,000、FPD7件数18%、FPD7金额17%；B样本2,100笔、件均MXN2,000、FPD7件数14%、FPD7金额22%。
现象：只看件数B优于A，但金额口径显示B实际损失暴露更大。
拆解：B渠道的高额度用户集中在低Score段，且MXN2,500+额度档FPD7金额达到29%。
根因：渠道B不是“客户整体更坏”，而是“高风险客户拿到更高额度”的结构问题。
决策：渠道B不必直接停量，先降低低Score用户额度上限，并对高额度档收紧准入。
结果：观察下一批成熟FPD7金额率以及MOB1 DPD30+；如果金额FPD下降而CAC与放款量可接受，说明策略有效。

6. 诊断逻辑

① 先确认成熟度和口径 → ② 件数/金额同时看 → ③ 拆渠道×Score×Limit → ④ 查欺诈/支付失败 → ⑤ 再追Vintage确认是否真正改善。

7. 策略动作

渠道型异常：降量或换素材/媒体位；Score型异常：收紧准入；额度型异常：降Limit；欺诈型异常：强化设备/身份/团伙策略；支付型异常：不要误当信用风险。

8. 常见误区

误区1：未成熟样本直接进分母。误区2：把支付失败全部算信用风险。误区3：只看件数不看金额。

9. 推荐拆分

渠道、Campaign、Score、Limit、Term、欺诈标签、新老客、策略版本。

10. 预警

推荐以稳定历史cohort为基线，设置件数+金额双预警，并要求最低成熟样本量。阈值应按内部历史确定。

11. 指标关系

渠道质量/欺诈 → FPD1/3/7 → DPD30+ → Vintage → Bad Rate → EL。

12. 小练习

件数FPD7下降2个百分点，但金额FPD7上升3个百分点，最值得先看哪两个维度？

参考答案：Limit和Score，优先确认高额度坏客是否集中于边缘风险段。

DPD30+ Rate｜30天以上逾期率

一句话：看当前已经逾期30天以上的资产占比，是比FPD更成熟的风险结果指标。

DPD30+金额率 = 观察日DPD≥30的未偿本金 ÷ 同口径未偿本金

怎么看：通常越低越好，但要区分Current DPD30+和Ever DPD30+；扩量期整体余额快速增长会稀释时点DPD30+。

案例逻辑：若整体DPD30+下降，但同Vintage同MOB的DPD30+上升，应优先判断是“新增资产稀释”而不是真实风险改善。

诊断：成熟度 → Vintage/MOB → 渠道 → Score → Roll Rate/Cure。

动作：如果同MOB恶化，才进入准入/额度/催收策略调整；不要只看全量时点值。

Bad Rate｜坏账率

一句话：看已经成熟到“坏”的账户或金额占比，属于更滞后的最终风险结果。

Bad Rate件数 = 达到Bad定义的成熟账户 ÷ 成熟账户
Bad Rate金额 = Bad暴露金额 ÷ 成熟暴露金额

关键：先统一Bad定义，例如Ever DPD90+、核销或其他内部损失标签；未成熟样本不能直接进入普通Bad Rate分母。

案例逻辑：如果FPD稳定但Bad Rate恶化，应重点看期限、Roll Rate、Cure和催收，而不应直接归因于贷前。

D. 迁徙 / 贷后指标

Roll Rate｜逾期迁徙率

贷后领先于深度坏账

1. 一句话说明

它看的是：逾期客户正在往更坏的桶走，还是被催收拉回正常。

Roll Rate(DPD x → DPD y) = 从x桶迁移到y桶的账户/余额 ÷ x桶期初账户/余额

为什么重要：DPD30+告诉你“现在坏了多少”，Roll Rate告诉你“风险正在往哪走”。

案例｜DPD30+没变，但早期迁徙已经恶化（模拟数据）

背景：墨西哥首贷，渠道C扩量。

数据：整体DPD30+ 12.1%→12.0%；但1-7→8-30余额Roll Rate从34%升到43%，Cure从28%降到21%，RPC从62%降到54%。

现象：表面深度逾期稳定，但早期账户正更快向坏方向迁移。

拆解：异常集中在渠道C、新设备用户和晚间申请客群。

根因：目前只能判断渠道C与迁徙恶化高度相关；需要进一步排查支付失败、欺诈与催收触达后再判断因果。

决策：暂缓渠道C扩量、加强新设备验证、提高早期催收触达。

结果：未来2-3个周度快照观察1-7→8-30 Roll、Cure和MOB1 DPD30+。

诊断顺序：Bucket口径 → 支付失败 → 渠道/Score/Limit → RPC/PTP → Cure/Recovery。

常见误区：不同时间周期比较；件数和余额混用；把展期当Cure。

Cure Rate｜治愈率

Cure Rate = 观察期内从逾期回到规定正常状态的账户/余额 ÷ 期初该逾期桶账户/余额

一句话：看催收或用户自身还款后，有多少逾期真正回正。

案例逻辑：如果Collection Rate上升但Cure不升，可能只是部分还款、展期或账务处理，并不代表资产质量真正修复。

诊断：回款类型 → 展期/重组 → Bucket → RPC/PTP → 后续再逾期。

Recovery Rate｜回收率

Recovery Rate = 固定观察窗口内实际回收现金净额 ÷ 期初违约/核销暴露

一句话：看已经坏掉的资产，最后还能拿回来多少钱。

案例逻辑：外包催收使Recovery从18%升到24%，但催收费用从4%升到11%，此时应同时看Net Recovery，而不是只看毛回收。

关联：Recovery ↑ 通常对应 LGD ↓，但观察窗口和成本口径必须一致。

Collection Rate｜催收回款率

Collection Rate = 观察期实际回款 ÷ 同期可催收应收金额

一句话：看催收池里应该收的钱，有多少真的收回来。

案例逻辑：若DPD1-7 Collection上升，但8-30 Roll不降，需检查是否只是部分还款延缓了风险。

误区：分母用“逾期余额”“分案金额”“当期到期额”会得到不同结果，必须固定。

RPC｜Right Party Contact｜本人有效触达率

RPC Rate = 成功确认本人有效触达案件数 ÷ 尝试联系的可催收案件数

一句话：看催收到底有没有真正联系到借款人本人。

案例逻辑：某渠道RPC显著低，但前期FPD正常，可能意味着贷后联系方式质量差，后续LGD可能更高。

关系链：RPC → PTP → Collection → Cure/Recovery。

E. 模型 / 策略指标

PSI｜Population Stability Index

PSI = Σ(Actualᵢ - Expectedᵢ) × ln(Actualᵢ / Expectedᵢ)

一句话：看当前客群或变量分布跟基准期相比“变了多少”。

重要提醒：PSI高只说明分布漂移，不代表坏账一定变差；必须联动Bad Rate、KS/AUC和渠道结构。

案例逻辑：Score PSI突然升高时，先拆渠道和Campaign；如果新渠道占比暴增但同渠道Bad稳定，可能是客群结构变了，而不是模型失效。

F. 经营 / 利润指标

Expected Loss｜预期损失（EL）

经营桥梁信用风险

1. 一句话说明

它把“会不会坏、坏了损失多少、暴露多大”合成一个金额，是把风控真正连接到利润和额度决策的核心指标。

Expected Loss = PD × LGD × EAD

口径：PD、LGD、EAD必须是兼容时间窗口和产品范围的参数。

案例｜件数坏账没变，但提额后EL显著增加（模拟数据）

背景：复借用户平均额度从MXN2,000提到MXN2,800。

数据：PD维持10%；LGD维持70%；EAD由MXN1,800升至MXN2,500。

计算：原EL=10%×70%×1,800=MXN126；新EL=10%×70%×2,500=MXN175。

现象：PD没变，但单客预期损失增加约39%。

拆解：进一步按Score和Limit发现高额度增量主要集中于中风险客群。

根因：风险恶化不是PD，而是EAD扩张。

决策：提额不能只看还款次数，要增加边际EL和贡献利润约束。

结果：观察提额组未来MOB1/2 DPD30+、实际使用率、EL和Contribution Margin。

诊断：EL上升时分别拆PD、LGD、EAD，不要直接归因于“客群变坏”。

关系：Score/准入 → PD；额度/提款 → EAD；催收/回收 → LGD；最终共同影响EL和利润。

指标关系树｜学习版

获客：曝光 → 注册 → 申请 → KYC → Approval → Disbursement

贷前风险：Fraud / Score / 多头 → Approval / Limit

早期风险：FPD1/3/7 → DPD

成熟风险：Vintage + MOB → DPD30+/60+/90+ → Bad Rate

迁徙催收：Roll → RPC → PTP → Collection → Cure / Recovery

模型：PSI + KS/AUC + Bad Capture

经营：PD + LGD + EAD → Expected Loss → Contribution Margin → ROI / LTV
