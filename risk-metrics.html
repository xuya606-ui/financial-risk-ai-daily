Repeat Rate｜Repeat Borrowing Rate｜复借率

1）是什么：成熟首贷或Eligible客群中再次实际借款的比例，看“有多少客户又借了一次”。

2）为什么重要：生命周期增长同步/滞后指标，是LTV上游；高复借可能来自忠诚，也可能来自资金紧张、优惠刺激或冷静期过短。

3）公式：Cohort Repeat Rate = N天内再次放款唯一用户 ÷ 成熟到N天的首贷放款唯一用户Eligible Repeat Take-up = 实际复借唯一用户 ÷ 已看到有效复借Offer的Eligible唯一用户固定N天、Cycle、Offer有效期和用户去重。

4）高低：高不一定好；必须与Repeat Bad、金额FPD、EAD、EL、Cycle Margin联看。

5）墨西哥七步案例：背景：首贷10k结清后复借；数据：Eligible5.5k、复借3.85k，Cohort Repeat38.5%、Eligible Repeat70%，Channel C低Score Repeat75%但Cycle2 FPD7 18%；现象：高复借集中高风险；拆解：Channel×Score×Limit×结清间隔；根因：需求与提额共同变化；决策：低Score/短间隔限额，优质客保留；结果：看两个成熟Cycle的Bad/EL/LTV。

6）诊断：Eligibility → Offer Exposure → Apply → Approval → Disbursement → FPD/Bad → LTV。

7）动作：优质低Repeat优化Offer；高风险高Repeat降额/延长冷静期；技术曝光低先修触达；Margin低减少优惠。

8）误区：分母混用；未成熟Cohort；用户多笔重复；只追求高Repeat；Eligibility等同所有首贷。

9）拆分：Channel、Campaign、First Score、Cycle、Limit、Term、Days-since-payoff、Prior DPD、Region、Device、Coupon、Strategy。

10）预警：同首贷Vintage/同观察窗+最小样本量；Repeat↑且连续两个成熟Cycle Amount Bad/EL恶化可作为内部黄灯。

11）关系：First Cure → Eligibility → Repeat → EAD → Repeat Bad → Cycle Margin → LTV。

12）练习

首贷8,000、Eligible4,000、曝光3,600、复借2,520：Cohort Repeat=31.5%，Eligible Repeat=63%，Exposed Take-up=70%。

Repeat Approval Rate｜复借审批通过率

1）是什么：进入复借重新决策的申请中最终获批的比例。

2）为什么重要：贷前同步指标，反映复借风险偏好和重评强度，决定后续Limit/EAD和Repeat Bad。

3）公式：Repeat Approval Rate = 最终批准的复借唯一申请 ÷ 实际完成复借重新决策的Eligible复借唯一申请自动预授信、Eligibility、Offer展示和最终审批分开。

4）高低：高可能是幸存者客群好，也可能是重评不足；低可能是真收紧或Vendor/征信故障。

5）墨西哥七步案例：背景：V6自动预授信；数据：Approval88%→94%、Avg Limit+45%、Cycle2 FPD7 9%→13%、Amount FPD11%→17%、Inquiry>3占比10%→18%、Margin145→108；现象：审批提高、风险和利润变差；拆解：Prior DPD×Inquiry×Score×Limit Increase；根因：策略+客群共同变化；决策：恢复最新Bureau/Inquiry重评并限制高多头提额；结果：两个成熟Cycle验证。

6）诊断：Re-underwrite分母 → Score/Bureau/Inquiry → Prior DPD → Limit/Term → FPD/Bad/EL。

7）动作：高Approval高Bad收准入/降额；技术No-hit走Fallback；优质老客流程简化；高风险账户变化增加Step-up。

8）误区：Eligibility=Approval；预授信=最终批；只看首贷还款；技术失败当信用拒绝；不同Cycle横比。

9）拆分：Cycle、Prior DPD、Score、Inquiry、Limit Increase、Term、Days-since-payoff、Channel、Device、Strategy。

10）预警：同Cycle同成熟Vintage；Approval↑且EAD/Bad/EL同步恶化为内部黄灯；Margin转负升级。

11）关系：Eligibility → Re-underwrite → Approval → Limit/EAD → Repeat Bad → EL → LTV。

12）练习

Approval从90%到95%，件数FPD仅+0.5pp，但EAD+40%、金额FPD+5pp：不能判断策略更好。

Repeat Bad Rate@MOB / Cycle Bad Rate｜复借周期坏账率

1）是什么：同Cycle、同MOB/成熟窗口达到统一Bad定义的件数或金额比例。

2）为什么重要：成熟信用表现指标，避免资产年龄和幸存者选择掩盖真实复借风险。

3）公式：Bad Rate(cycle c, MOB m) = 同Cycle/MOB成熟Bad账户 ÷ 同Cycle/MOB成熟账户金额口径固定Origination Exposure或Outstanding；固定Bad、展期/重组、Cycle、MOB。

4）高低：通常低更好，但后续Cycle天然更筛选；提额会导致件数Bad稳定、金额Bad先恶化。

5）墨西哥七步案例：背景：Cycle3提额；数据：Cycle2 EAD2.1k、件数Bad10%、金额12%；Cycle3 EAD2.7k、件数11%、金额18%；低Score×Limit≥3k金额Bad25%；现象：金额风险跳升；拆解：First Score×Cycle×Limit×Prior DPD；根因：EAD是重要驱动但需控制客群；决策：低Score限额，中高ScoreChallenger；结果：看MOB1/2、EL、LTV。

6）诊断：成熟度 → Cycle/MOB → 件数vs金额 → Score/Limit/EAD → Prior DPD/Cure → EL/Margin。

7）动作：金额Bad恶化件数稳→降额；件数/PD同步恶化→重评准入；支付异常先修支付；Cure问题优化贷后。

8）误区：不同MOB/不同Cycle直接比；只看件数；忽略幸存者偏差；Bad定义不一致；小样本。

9）拆分：First Vintage、Cycle、MOB、First/Current Score、Limit、Term、Prior DPD、Channel、Region、Strategy。

10）预警：同Cycle同MOB+最低样本量/金额门槛；连续两个Cohort Amount Bad和EL双升可作为红灯候选。

11）关系：Repeat Approval/Limit → EAD + Bad@MOB → EL → Cycle Margin → Cum LTV。

12）练习

件数Bad10%→10.5%，金额Bad12%→18%，EAD+40%：风险不能视为稳定。

Risk-adjusted LTV / LTV:CAC｜风险调整客户终身价值

1）是什么：客户多个Cycle收入扣除Funding、风险损失、服务/催收和增量激励后的累计价值；LTV:CAC衡量其对初始获客成本的覆盖。

2）为什么重要：经营/利润滞后指标，把首贷、复借、风险、催收和获客统一成一个长期经济指标。

3）公式：RALTV_N = Σ[Revenue − Funding − EL(or mature loss) − Variable/Servicing/Collection − Incremental Incentive]_cycleLTV:CAC = RALTV ÷ Initial Acquisition CAC是否折现、是否扣CAC、EL/Actual Loss口径须统一，禁止重复扣CAC。

4）高低：通常高更好，但未来Cycle未成熟、尾部LGD尚未出现时可能被高估；高价格高风险也可制造短期高LTV。

5）墨西哥七步案例：背景：10k首贷跟踪3Cycle；数据：Cycle贡献800k+519.75k+252k=1.57175m，约157.2/首贷用户；CAC90→LTV:CAC≈1.75；Channel C低Score高Limit尾部损失较高；现象：整体可覆盖CAC但子Segment差异大；拆解：Channel×First Score×Cycle×Limit×Funding；根因：留存、EAD和Bad共同决定LTV；决策：削减低LTV渠道/高风险提额；结果：Bad/Recovery成熟后持续重估。

6）诊断：Cohort删失/成熟 → Revenue → Funding/CAC/优惠 → EL/Actual Loss/Recovery → Cycle Retention → Cum LTV。

7）动作：低LTV高CAC降量；高Repeat低LTV收优惠/限额；Funding高调资金；高LTV低Repeat优化产品；LGD高优化贷后。

8）误区：Gross Revenue=LTV；未来损失按0；CAC重复扣；漏复借营销/催收成本；只看平均值；幸存者偏差；不同窗口横比。

9）拆分：Acquisition Channel、Campaign、First Vintage、First Score、Cycle、Limit、Term、Region、Funding Source、Coupon、Strategy。

10）预警：同首贷Vintage、同生命周期窗口、同成熟度比较；成熟LTV/CAC低于公司内部资本/固定成本盈亏线才升级，不采用行业通用阈值。

11）关系：CAC → First Margin → Repeat/Cycle EAD&Bad → Recovery → RALTV → LTV:CAC → Portfolio Allocation。

12）练习

RALTV=180、CAC=120，LTV:CAC=1.5；是否优秀还取决于资本占用、固定成本、成熟度和公司目标回报。
