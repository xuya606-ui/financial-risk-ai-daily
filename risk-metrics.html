今日核心指标速学

CAC｜Customer Acquisition Cost

大白话：为了获得一个真正成功首贷的新客户，花了多少可归因营销成本。

First-disbursement CAC = 可归因营销成本 ÷ 成功首贷人数

业务重点：必须固定分母和归因窗口；CAC要和FPD/EL/LTV联合判断。

LTV｜Lifetime Value

大白话：客户从首贷到生命周期结束，最终带来的净经济价值。

简化LTV = 生命周期收入 − Funding − Credit Loss − Payment/Ops/Collection − Incentive

业务重点：高复借并不自动等于高LTV，Debt Cycling可能放大EAD和损失。

Contribution Margin｜贡献利润

大白话：收入扣除资金、获客、风险和其他变动成本后还剩多少钱。

Contribution Margin = Revenue − Funding Cost − CAC − EL − Variable Cost

业务重点：它是业务、风控和数据共同评估策略价值的核心结果指标。

Break-even Bad Rate｜盈亏平衡坏账率

大白话：按当前价格、成本、EAD和LGD，公司最多承受多高坏账仍不亏。

Break-even Credit Loss = Revenue − Funding − CAC − Other Variable Cost；再结合EAD×LGD换算

业务重点：它是内部管理阈值，不是监管/行业统一标准；件数Bad和金额风险不可混。

常用指标字典｜口径提醒

指标核心定义/提醒
CAC可归因获客成本 ÷ 固定口径客户；至少保留First-disbursement CAC，并统一归因窗口/补贴。
LTV生命周期净价值；收入、Funding、风险损失、支付/运营/催收、激励与观察窗口需统一。
Contribution MarginRevenue − Funding Cost − CAC − EL − Variable Cost；按Loan/User/Vintage口径固定。
Break-even Bad Rate由收入/成本/Recovery/EAD反推内部可承受Bad；不是统一行业阈值。
PD固定风险窗口内发生既定Default的概率；需明确Default、成熟期、用户/订单口径和Calibration。
LGDDefault后最终损失比例；同Recovery月龄比较，Gross/Net与成本/折现口径必须固定。
EAD违约时真实暴露金额；Approved Limit、Disbursed Amount、Current Balance与Default EAD不可混用。
Expected Loss业务简化EL = PD×LGD×EAD；时间窗口必须兼容，并与Contribution Margin联合判断。
Redraw Rate具备再次提款资格且窗口成熟用户中，N天内再次成功提款的比例。
Time-to-RedrawFull Repayment到下一次成功提款的时间；建议看Median和0-24h/1-3d/4-7d等分桶。
Drawdown Frequency7/30/90天真实独立提款次数；技术重试、拆单需去除。
Balance Rebound还款后余额恢复到还款前高位/当前额度的程度；需固定观察时点。
Bureau Hit Rate可用征信结果 ÷ 完成查询申请；No-file、技术失败、身份不匹配必须分开。
Recent Inquiry Rate近期Hard Inquiry高密用户占比/人均查询数；7/30天、去重和Hard/Soft口径需固定。
Multi-Borrowing Rate当前活跃Lender达到内部阈值的用户比例；历史账户不能混入Active。
Application VelocityUser/Device/Phone/IP滚动窗口申请密度；去除技术重试并排除公共IP/NAT误伤。
Approval Rate审批通过有效申请 ÷ 进入审批有效申请；前置硬拒和技术失败是否入分母必须固定。
KYC Pass Rate通过KYC ÷ 完成对应KYC流程；OCR/Face/Liveness/Bank-name应拆开。
Take-up Rate成功提款/放款用户 ÷ 获得有效可用额度用户；需固定额度有效期。
Disbursement Rate成功到账订单 ÷ 进入放款执行的有效订单；支付/CLABE失败不能误当信用拒绝。
Payment Failure Rate失败支付尝试 ÷ 有效支付尝试；必须拆错误码、Provider、Bank、版本和技术/余额原因。
Auto-debit Success成功自动扣款 ÷ 有效自动扣款；建议同时看首次成功与重试后最终成功。
Bank Account Match账户持有人与借款人一致的账户 ÷ 完成校验账户；姓名标准化规则必须固定。
Repayment Success成功还款订单 ÷ 到期/进入还款流程订单；Full/Partial/Pending需分开。
FPD1/3/7/30首期到期后对应观察日仍逾期的成熟订单比例；件数和金额必须同时看。
DPD30+观察日DPD≥30的账户/余额比例；Current DPD和Ever DPD不可混用。
Vintage同一放款批次在相同MOB下比较风险；可识别扩量导致的“资产稀释”。
MOBMonths on Book，账龄坐标；自然月/账期月定义必须统一。
Roll Rate从一个DPD Bucket迁移到另一个Bucket的期初账户/余额比例。
Cure Rate期初逾期桶中恢复Current的账户/余额比例；Cash Cure与Extension Cure建议分开。
Recovery Rate违约/核销暴露中实际收回现金比例；Gross与Net Recovery分开。
RPC / PTP / PTP Kept本人有效触达 → 承诺还款 → 承诺兑现，不能只用PTP作为催收KPI。
ATO Rate确认账户接管账户 ÷ 可观察活跃账户；需结合检测覆盖和金额损失。
Fraud Loss Rate确认欺诈净损失 ÷ 放款本金/EAD；与件数Fraud Rate分开。
Step-up Challenge触发额外验证的eligible关键操作 ÷ eligible操作；需与Pass/Abandon/Fraud一起看。
Override Rate人工改变原始模型/规则决策 ÷ 可Override决策；需拆Approve/Decline。
KS / AUC / Gini模型排序区分度；不代表PD校准准确，也不直接代表利润。
PSI分布漂移指标；只能说明分布变了，不能单独说明风险方向。
Precision / Recall / FPR / FNR必须与FP/FN真实业务成本、Approval、Bad Capture和利润一起评估。
Bad Capture成熟Bad中被规则/模型捕获的比例；拒绝样本存在Reject Bias。
Limit Utilization实际使用额度 ÷ Approved/Current Limit；一次性贷款与循环额度口径不同。
Average Ticket成功放款总本金 ÷ 成功放款笔数；与Average Limit不是同一指标。
DTI / PTI总债务偿付/收入与本笔还款/同周期收入；收入验证和周期匹配是核心。
APR / CAT价格/综合成本表达必须与期限、费用、Take-up和合规要求一起看，不能只比较一个数字。
Funding Cost利息+承诺费+管理/对冲等All-in成本，不只看票面利率。
ROI风险调整后收益与投入成本/资本基数关系；不能用收入替代ROI。
Risk-adjusted Return风险调整后收益 ÷ 平均EAD/本金/资本基数；跨期限需校正。

指标关系树｜当前版

获客经营：Spend → CAC → Application/KYC → Approval → First Disbursement

征信/贷前：Bureau Hit → Recent Inquiry → Active Lenders → DTI/PTI → Approval/Limit

收入/偿付：Income Verification → DTI/PTI → PD/Limit → Take-up/EAD

定价：Funding Cost → Price/APR/CAT → Take-up → Customer Mix → EAD/PD → EL → Contribution Margin

实时申请/欺诈：Application Velocity + Device/Identity/Graph Risk → Step-up/Reject → Fraud Loss

漏斗：注册 → 申请 → KYC → Approval → Limit → Take-up → Disbursement

复借/Debt Cycling：Repayment → Redraw/Time-to-Redraw → Frequency → Utilization/Balance Rebound → EAD → Vintage/EL

支付：Bank Match / Mandate → Payment Failure / Auto-debit Success → Repayment Success → FPD1 → DPD/Cure

信用：FPD → DPD → Vintage/MOB → Roll/Cure → Bad Rate → PD × LGD × EAD → Expected Loss

催收：RPC → PTP → PTP Kept → Collection → Cure/Recovery → LGD

模型治理：PSI → AUC/KS/Gini → Precision/Recall/FPR/FNR → Bad Capture → Override → Strategy Value

利润：CAC + Funding + Revenue + EL + Variable Cost → Contribution Margin → LTV/ROI/Risk-adjusted Return；Actual Bad vs Break-even用于内部风险预算。
