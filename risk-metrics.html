FPD1｜First Payment Default 1 Day

1）是什么：首期到期后D+1仍未满足还款标准的成熟首贷账户/金额比例；看“刚到期时多少新客没按时还”。

2）为什么重要：极早期同步指标，快速暴露支付故障、欺诈、现金流或准入变化，但噪声最大。

3）公式：

FPD1 = D+1仍逾期的成熟首贷账户/余额 ÷ 首期到期且成熟至D+1的账户/应还余额

固定Grace Period、Partial、Extension、技术挂账、账户/订单和件数/金额。

4）高低：通常越低越好，但支付SDK/银行延迟可推高；激进展期可人为压低。必须联动Payment Failure、FPD3/7。

5）案例：墨西哥14天首贷，新支付SDK上线；N=20,000，FPD1 20%→29%，Payment Failure 5%→14%，Auto-debit Success 84%→70%，FPD7仅14.8%→15.6%。拆Provider×Error×Version后新增异常集中Timeout；先恢复备用路由，不全量收准入，24-72小时看支付与FPD1，D+7再看信用。

6）诊断：成熟度/到期日 → Payment/Error/节假日 → Channel×Score×Limit → Fraud/ATO → FPD3/7。

7）动作：技术异常修支付；欺诈加强KYC/设备；低Score高Limit深度风险同步恶化再降额/收准入。

8）误区：所有D+1未还=信用恶化；未成熟样本比较；件数/金额混用；展期抹掉原始逾期。

9）拆分：Channel、Campaign、Score、Limit、Term、Provider、Bank、App/SDK、新老客、Region、Strategy。

10）预警：同星期/同到期结构稳定基线；技术可小时监控，信用按成熟Cohort。阈值为内部标准。

11）关系：Payment/KYC/Fraud → FPD1 → FPD3 → FPD7 → DPD30+ → EL。

12）练习

FPD1+9pp、FPD7+0.5pp、Timeout+9pp，优先什么？答案：支付技术。

FPD3｜First Payment Default 3 Days

1）是什么：首期D+3仍逾期的成熟账户/金额比例。

2）为什么重要：比FPD1更能过滤临时支付时差，是早期信用质量重要同步指标。

3）公式：FPD3 = D+3仍逾期的成熟首贷账户/余额 ÷ 首期到期且成熟至D+3的账户/应还余额

4）高低：FPD1稳定而FPD3升，通常更需要查Early Cure、现金流和渠道/准入；越低通常更好，但展期会影响。

5）案例：渠道C低Score占比18%→32%，平均EAD1,350→1,720，FPD1 21%→22%、FPD3 16%→21%、FPD7 14%→18%；风险集中低Score×Limit≥2,000。决策是收缩该组合、保留中Score低额度Challenger，等两个FPD7 Cohort确认。

6）诊断：FPD1→FPD3 Cure → Channel/Score/Limit → Payment/RPC → FPD7/Amount。

7）动作：边缘Score降额；渠道问题降量；支付/早催问题修流程；欺诈加Step-up。

8）误区：FPD3/7混用；不同成熟窗口横比；只看件数；实时未成熟样本与完整Cohort比较。

9）拆分：Channel、Score、Limit、Term、Cycle、Payment、Strategy、Region、Device。

10）预警：同Vintage/同到期结构；可内部监控FPD1→3留存比，但不套统一阈值。

11）关系：FPD1 × Early Cure → FPD3 → FPD7 → Roll → DPD30+。

12）练习

FPD1稳定、FPD3跳升，先查？答案：D+1到D+3治愈和Channel×Score×Limit。

FPD7｜First Payment Default 7 Days

1）是什么：首期D+7仍逾期的成熟首贷比例。

2）为什么重要：比FPD1/3更接近真实早期信用质量，适合渠道/准入/额度评估，但仍不是最终Bad。

3）公式：FPD7 = D+7仍逾期的成熟账户/余额 ÷ 首期到期且成熟至D+7的账户/应还余额

4）高低：通常越低越好，但必须与金额FPD、EAD、展期和后续Vintage一起看。

5）案例：额度V4把中低Score最高额度1,500→2,100；N=18,000，Approval31%→34%，Avg EAD1,420→1,790，FPD7件数14.5%→16.0%，金额FPD15.2%→19.8%，EL/Loan132→176。风险集中低Score高额度；保留中Score小步提额、收缩低Score。

6）诊断：成熟度 → Channel/Score → Limit/EAD → Payment/Fraud → Amount FPD → DPD30+/Vintage/EL。

7）动作：PD问题收准入；EAD问题降额；欺诈加强KYC；支付问题修支付。

8）误区：FPD7=最终Bad；只看件数；不同期限横比；展期美化；首贷复借混用。

9）拆分：Channel、Score、Limit、Term、新老客、Region、Income/DTI、Device、Strategy。

10）预警：成熟Cohort、件数+金额联合；阈值由自身历史和样本量决定。

11）关系：Approval/Limit → EAD+FPD7 → Roll → DPD30+ → Bad/LGD → EL/Margin。

12）练习

件数FPD7下降但EAD和金额FPD升，风险改善吗？答案：不能这样判断。

DPD30+｜30 Days Past Due Plus

1）是什么：观察时点DPD≥30的账户/余额比例。

2）为什么重要：更滞后的深逾指标，适合Vintage/MOB、贷后策略和坏账预算；会被资产年龄结构影响。

3）公式：Current DPD30+ = 观察日DPD≥30账户/余额 ÷ 观察日资产池账户/余额Vintage DPD30+@MOBn = 某Vintage在MOBn时DPD≥30账户/余额 ÷ 该Vintage成熟资产

4）高低：通常越低越好，但快速扩量时Current DPD30+可被新资产稀释，优先同Vintage同MOB。

5）案例：业务扩量40%，Current DPD30+仅11.8%→12.0%，但MOB1 DPD30+ 9.5%→13.8%，渠道C18%，FPD7金额16%→20%，Early Roll29%→39%，Avg EAD1,480→1,820。根因是新资产分母稀释；决策改用Vintage/MOB Gate。

6）诊断：资产年龄 → Current vs Vintage → MOB → Channel/Score/Limit → Cure/Roll/Extension → Bad/Recovery/EL。

7）动作：新Vintage恶化收缩高风险组合；Cure问题优化催收；展期拆Cash Cure；金额风险处理Limit/EAD。

8）误区：Current判断高速增长业务；不同MOB横比；件数金额混用；Ever与Current混用；忽略核销/重组。

9）拆分：Vintage、MOB、Channel、Score、Limit、Term、Cycle、Region、Collection Strategy、Extension。

10）预警：优先同Vintage同MOB并设最小成熟样本；内部黄/红灯结合历史P分位与EL。

11）关系：FPD7 → Roll/Cure → DPD30+ → Bad/Write-off → Recovery/LGD → EL/Margin。

12）练习

总体DPD30+稳定但新Vintage MOB1从10%升15%，优先相信哪个？答案：同Vintage同MOB的恶化。
