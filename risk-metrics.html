指标字典2026-08-18继续扩充

海外现金贷 / 消费金融风控指标集合

每个指标固定按“是什么 → 为什么重要 → 精确口径 → 如何看高低 → 案例七步法 → 诊断 → 策略动作 → 常见误区 → 拆分维度 → 预警 → 指标关系 → 小练习”学习。案例优先使用墨西哥现金贷模拟业务场景。

案例七步法

背景 → 数据 → 现象 → 拆解 → 根因 → 决策 → 观察结果

所有案例中的模拟数据均用于训练分析逻辑，不代表真实公司经营数据。

一、贷前与漏斗

Approval Rate｜审批通过率

大白话：真正进入审批的人里，有多少被风控放行。

Approval Rate = 审批通过有效申请数 ÷ 进入审批有效申请数

为什么重要：它决定漏斗规模，但不是越高越好。审批率提高如果来自临界高风险客群放宽，后续FPD、Vintage和Expected Loss可能恶化。

如何看：必须与放款率、件均、FPD7、Vintage、EL、Contribution Margin联动。

案例：审批率提高，利润反而下降

背景：墨西哥首贷，Meta渠道，策略V3下调Score准入门槛。
数据：样本20,000；审批率30%→36%；放款率24%→29%；件均MXN1,500→1,620；FPD7金额率16%→20%；CAC MXN310→305。
现象：流量更便宜、放款更多，但风险损失上升更快。
拆解：新增通过集中于低Score段，且MXN1,800+额度档FPD7最差。
根因：审批放宽与高额度叠加形成结构性风险；是否完全由V3导致需Champion/Challenger验证。
决策：不全量回滚；保留边缘客群试验，但限制高额度，设置10%-20%挑战组。
观察：FPD7成熟后继续追MOB1 DPD30+与Contribution Margin。

诊断顺序：渠道结构 → Score分布 → Limit/Term → 欺诈拒绝 → FPD/Vintage/EL。

误区：把注册人数当分母；把审批率当经营目标。

关系链：申请率 → Approval Rate → 放款率 → FPD → Vintage → EL → 利润。

二、早期信用风险

FPD7｜First Payment Default at Day 7

大白话：第一期到期7天后还没还好的客户有多少。

FPD7件数率 = 首期+7天仍逾期订单数 ÷ 已成熟到首期+7天订单数
FPD7金额率 = 对应逾期首期应还金额 ÷ 已成熟首期应还金额

关键口径：必须明确成熟期、到期日Cohort、技术扣款失败、展期、件数/金额。

如何看：通常越低越好，但件数稳定、金额恶化时要优先查高额度坏客。

案例：渠道B件数更好，但金额风险更坏

背景：A/B两个首贷渠道。
数据：A样本2,000、件均MXN1,000、FPD7件数18%、金额17%；B样本2,100、件均MXN2,000、件数14%、金额22%。
现象：件数看B更好，金额口径却明显更差。
拆解：B的低Score用户集中在MXN2,500+额度档，该档金额FPD7达到29%。
根因：不是所有B渠道用户更差，而是高风险用户拿到了更高额度。
决策：不直接停B；先降低低Score额度上限，控制高额度审批。
观察：下一批FPD7金额率、MOB1 DPD30+、渠道CAC。

诊断：先口径 → 件数/金额 → 渠道×Score×Limit → 欺诈/支付失败 → Vintage。

动作：渠道异常降量；Score异常收准入；Limit异常降额度；欺诈异常加强设备/身份策略。

DPD30+ Rate｜30天以上逾期率

大白话：当前资产里，有多少已经逾期30天以上。

DPD30+金额率 = 观察日DPD≥30未偿本金 ÷ 同口径未偿本金

关键：Current DPD30+与Ever DPD30+不能混用；快照口径、余额口径、核销处理必须固定。

案例逻辑：某Vintage整体DPD30+从12%升至15%，按渠道拆发现只有渠道C升到23%，再按Score×Limit发现低Score高额度档贡献了70%的增量坏账。此时应优先处理渠道C的高额度策略，而不是全局收紧。

关系：FPD → Roll Rate → DPD30+ → Bad Rate → EL。

三、成熟度与资产质量

Vintage｜同批次资产表现

大白话：把同一批放款放在相同账龄下比较，看哪一批客群真正更差。

示例：Vintage DPD30+ @ MOB2 = 某放款批次在MOB2的DPD30+余额 ÷ 该批次原始放款本金

为什么重要：扩量时大量新资产会稀释整体逾期率，Vintage可以消除“成熟度错觉”。

如何看：必须同MOB比较，不要拿MOB1和MOB3横比。

案例：总体逾期下降，但7月Vintage实际恶化

背景：7月首贷扩量并提额。
数据：总体DPD30+从11.5%降至10.8%；5月MOB2 DPD30+=13.2%；6月=13.5%；7月=16.8%；7月件均MXN1,350→1,550。
现象：整体指标变好，但同MOB的7月批次明显更差。
拆解：渠道B、Score 550-600、Limit≥MXN2,000的MOB2 DPD30+达到22%。
根因：扩量导致新资产占比高使整体逾期被稀释；同时高额度边缘客风险后移。
决策：收紧该Score×Limit组合，不对其他层级全局降额。
观察：下一Vintage的MOB1 FPD、MOB2 DPD30+及EL。

诊断：同MOB → 渠道 → Score → Limit → Term → 策略版本。

误区：不同成熟度横比；用未成熟月份判断最终坏账。

MOB｜Months on Book｜账龄

大白话：贷款“长到第几个月”了，是所有Vintage和坏账成熟度分析的时间坐标。

关键：MOB0/MOB1定义、自然月/账期月必须统一。

案例：7月批次MOB1看起来正常，但MOB2 DPD30+明显高于5月/6月同MOB，说明风险后移而非真正改善。

关系：MOB不是风险率，而是Vintage、Bad Rate、Recovery、模型标签的成熟度坐标。

Bad Rate｜坏账率

大白话：已经成熟的客户里，有多少最终达到公司定义的“坏客户”。

Bad Rate = 达到Bad定义的成熟样本 ÷ 已成熟样本

关键：先定义Bad（例如Ever DPD90+、核销或损失事件），再定义成熟期。

案例：首贷策略A/B的FPD7分别14%/15%，看似接近；但成熟后Bad Rate为24%/31%，说明B的风险主要在后段迁徙，需要看Roll Rate而不是仅用FPD判断。

误区：未成熟样本进入分母；不同Bad定义跨团队比较。

四、迁徙与催收

Roll Rate｜逾期迁徙率

大白话：现在处于某个逾期桶的客户，有多少继续滚向更严重的逾期。

Roll Rate(x→y) = 从x桶迁移到y桶的账户/余额 ÷ x桶期初账户/余额

案例：DPD30+没变，但风险正在前面积累

数据：DPD30+稳定在12%；但DPD1-7→8-30余额Roll由28%升至38%，连续两周上升。
拆解：渠道D、周末到期、自动扣款失败用户最明显。
根因：可能既有支付问题也有客群质量问题，需区分技术失败与真实偿付能力。
决策：先修支付与提醒链路，同时对渠道D新增客降量；避免直接全局收准入。
观察：看Cure、8-30→31-60 Roll和后续DPD30+。

关系：FPD → Roll Rate → DPD30+ → Bad Rate。

Cure Rate｜治愈率

大白话：已经逾期的人里，有多少真正回到正常状态。

Cure Rate = 达到Cure标准的期初逾期账户/余额 ÷ 期初该逾期桶账户/余额

关键：展期、重组、部分还款是否算Cure必须明确；建议把“真实回正”单独报。

案例：DPD1-7 Cure从42%升至55%，但8-30 Roll未改善，拆解发现大量“部分还款后短暂回正”。如果定义不严，会虚高Cure。

RPC｜Right Party Contact｜本人有效触达率

大白话：催收真正联系到借款人本人的比例。

RPC = 本人有效触达案件数 ÷ 尝试联系的可催收案件数

案例：渠道E的RPC只有38%，其他渠道55%，即使FPD差异不大，后续Recovery可能更弱；应检查号码质量、触达时段和渠道获客真实性。

关系链：RPC → PTP → Collection Rate → Recovery Rate。

PTP｜Promise to Pay｜承诺还款率

大白话：成功触达后，有多少客户明确承诺在某日期还款。

PTP Rate = 形成有效还款承诺的RPC案件数 ÷ RPC案件数

关键：PTP不能当回款。必须继续看PTP Kept Rate（承诺兑现率）。

案例：PTP很高，但回款很差

数据：RPC 60%；PTP 72%；PTP Kept仅34%；Collection Rate 21%。
现象：催收员“承诺率”很好看，但真实回款没有改善。
拆解：发现部分团队为了KPI记录低质量承诺，且承诺日期过于宽松。
决策：将考核从PTP改为PTP Kept + 净回款，并限制无效重复承诺。
观察：2-4周看PTP Kept、Collection、投诉率和净回收。

Collection Rate｜催收回款率

Collection Rate = 观察期实际回款 ÷ 同期可催收应收金额

大白话：应该催回来的钱，实际催回了多少。

关键：分母必须固定：到期额、逾期余额还是分案余额，不能混用。

关系：RPC、PTP是上游；Collection与Cure、Roll、Recovery要联动。

Recovery Rate｜回收率

Recovery Rate = 固定窗口实际回收现金净额 ÷ 期初违约/核销暴露

大白话：已经坏掉的资产，最后还能追回多少钱。

关键：明确观察窗口，建议同时报Gross Recovery与Net Recovery（扣催收成本）。

关系：Recovery越高通常LGD越低，但时间窗口和成本口径必须匹配。

五、模型与策略

KS｜Kolmogorov-Smirnov

大白话：模型把好客户和坏客户拉开的最大距离。

KS = max |CDF_bad(score) - CDF_good(score)|

为什么重要：反映排序区分度，但不是利润指标，也不能说明校准是否准确。

案例：KS下降，风险并没有立刻恶化

数据：开发集KS 42；线上从39降至31；Approval稳定35%；FPD7暂时稳定。
拆解：PSI显示新渠道用户Score分布明显漂移，且新渠道样本尚未成熟。
根因：模型区分度可能下降，但当前FPD未恶化不能证明没问题，因为标签尚未完全成熟。
决策：先做分渠道KS、PSI、校准；必要时Champion/Challenger而非立刻换模。
观察：等Bad标签成熟后复核KS、AUC、Bad Rate。

误区：只看总KS；把KS阈值当全行业统一标准。

AUC｜Area Under ROC Curve

大白话：随机拿一个坏客户和一个好客户，模型把坏客户排得更“坏”的概率能力。

如何看：AUC越高通常排序能力越强，但不代表审批策略、概率校准或利润一定更好。

案例：模型B AUC高于模型A，但B把大量高价值低风险客户挤到拒绝边缘，导致Approval和利润变差；应同时看Cutoff、Lift、Approval、Bad Capture和Contribution Margin。

PSI｜Population Stability Index

PSI = Σ(Actual_i - Expected_i) × ln(Actual_i / Expected_i)

大白话：当前客群分布和基准时期相比“变了多少”。

关键：PSI高只说明漂移，不说明风险一定变坏；必须联动Bad Rate、KS/AUC、渠道结构。

案例：Score PSI明显升高，拆分发现主要来自TikTok新渠道占比上升；若该渠道坏账未成熟，应先限制扩量并等待标签，而不是直接认定模型失效。

Bad Capture Rate｜坏客户捕获率

大白话：被拒绝/拦截的人里，抓住了多少未来真正会坏掉的客户。

Bad Capture Rate = 被策略拦截的Bad样本数 ÷ 全部Bad样本数

为什么重要：评价规则或Cutoff是否抓到了风险，而不是只看命中率。

案例：某规则命中率8%，Bad Capture只有5%，说明虽然拦很多人，却没抓住真正坏客；应检查误杀和规则价值。

关系：Rule Hit Rate + Bad Capture + Approval + FPD/Bad Rate一起评估。

六、经营与利润

CAC｜Customer Acquisition Cost｜获客成本

大白话：获得一个真正有业务价值的客户要花多少钱。

首贷CAC = 投放成本 ÷ 首贷放款用户数

关键：CPI不是CAC；注册便宜不代表放款便宜，更不代表风险调整后便宜。

案例：CPI下降但首贷CAC变差

数据：CPI MXN40→32；申请率45%→38%；审批率34%→27%；放款率25%→18%；首贷CAC MXN260→356；FPD7由15%→18%。
根因：素材吸引了大量低意图/低质量用户，前端便宜但后端转化和风险更差。
决策：投放优化目标从Install切到更深层事件，按渠道×Campaign看首贷CAC+FPD+LTV。

关系：CPI → 申请率 → Approval → 放款率 → 首贷CAC → LTV/ROI。

LTV｜Lifetime Value｜客户生命周期价值

大白话：一个客户从首贷到流失，最终能贡献多少净价值。

简化LTV = 生命周期收入 - 信用损失 - 资金成本 - 支付/运营/催收成本

关键：现金贷LTV必须扣风险损失；只累加利息收入会严重高估。

案例：渠道A CAC高但复借率强、Bad低，12个月LTV为MXN900；渠道B CAC低但首贷风险高、复借差，LTV只有MXN420。渠道A反而更值得扩量。

PD / LGD / EAD｜违约概率 / 违约损失率 / 违约暴露

大白话：PD看“会不会坏”，LGD看“坏了损失多少比例”，EAD看“坏的时候暴露多少钱”。

Expected Loss = PD × LGD × EAD

案例：Bad Rate没变，但提额导致EL明显上升

数据：PD维持18%；LGD 70%；平均EAD由MXN1,200升至1,600。
计算：单客EL从151.2升至201.6 MXN，约增长33%。
现象：件数Bad Rate可能没变化，但金额风险显著增加。
决策：额度策略必须看边际EL，不只看件数坏账。
观察：提额组的金额FPD、Vintage、EL、Contribution Margin。

Contribution Margin｜贡献利润

大白话：把这笔贷款真正能赚的钱减掉主要可变成本后，还剩多少。

Contribution Margin ≈ 利息/费用收入 - 资金成本 - CAC - Expected Loss - 支付/运营/催收可变成本

为什么重要：这是连接投放、风控、额度、定价和复借的核心经营指标。

案例：通过率和收入都增长，但贡献利润下降

数据：单客收入MXN420→470；资金成本80→90；CAC300→290；EL110→190；其他成本40→42。
计算：贡献利润从-110变为-142，业务规模变大但单客亏损扩大。
决策：不能只追审批率/放款额；应重新收紧高EL客群或提高差异化定价。

关系链：Approval → 放款 → 收入/件均 → PD/LGD/EAD → EL → Contribution Margin → ROI。

本周指标关系树

获客：曝光 → 点击 → 安装 → 申请 → KYC → Approval → 放款 → CAC

早期风险：欺诈率 → FPD → Roll Rate → DPD30+

成熟风险：Vintage / MOB → Bad Rate → PD/LGD/EAD → EL

催收：RPC → PTP → PTP Kept → Collection → Cure / Recovery → LGD

模型：PSI → KS/AUC → Bad Capture → Approval / Bad Rate

利润：CAC + 收入 + 资金成本 + EL + 运营成本 → Contribution Margin → LTV / ROI
