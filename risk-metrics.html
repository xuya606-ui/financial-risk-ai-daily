今日联合判断框架

Population Drift → PSI ｜ Rank Performance → AUC / KS ｜ Calibration → O/E

PSI高+排序/校准稳定：优先查流量与数据；AUC/KS下降+PSI稳定：查特征-风险关系和Selection；AUC/KS稳定+O/E高：优先Recalibration；四者与FPD/EL/Margin同时恶化：重训/策略回滚红灯候选。

PSI｜Population Stability Index｜群体稳定性指数

1）是什么：当前样本分布与基准分布差异；看“今天来的客户/分数/特征还是不是参考期那批人”。

2）重要性：领先/同步指标，坏账未成熟前发现渠道、客群、Feature或策略漂移。

3）公式：PSI = Σ (Actual_i − Expected_i) × ln(Actual_i / Expected_i)固定Reference、分箱、Missing、窗口和用户/订单口径；零占比按内部规则平滑。

4）高低：高=分布更不同，不等于风险一定高；低也不代表校准正常。

5）七步案例：背景：Model V6、Channel C扩量并提额；数据：N50k、PSI0.06→0.24，C渠道0.37，O/E1.55、FPD7 14.8%→17.2%、EAD1,500→1,800；现象：分布与风险恶化；拆解：C×Low Score×High Limit集中；根因：流量/额度是强候选，仍排除Missing；决策：C降量、低Score高Limit回滚；结果：两个成熟Vintage看PSI/O-E/FPD/EL/Margin。

6）诊断：Data/Missing → Channel/Campaign → Feature/Score PSI → Strategy → AUC/KS/O-E。

7）动作：先修数据；单渠道漂移降量；季节性更新稳定基线；PSI+O/E持续坏再Recalibration/重训评估。

8）误区：PSI高=模型失效；临时换箱；只看总体；忽略样本和季节性。

9）拆分：Channel、Campaign、Score、Feature、Region、Device、Product、Model/Strategy。

10）预警：用自身历史+最小样本；内部示例“连续两个周期超历史P90”黄灯，叠加O/E/FPD恶化升级。0.1/0.25不冒充行业标准。

11）关系：Traffic/Data → PSI → AUC/KS/O-E → FPD/Vintage → EL/Margin。

12）练习

PSI高、AUC/KS/O-E稳定，先查渠道/数据结构，不直接重训。

AUC｜Area Under ROC Curve｜ROC曲线下面积

1）是什么：模型整体排序能力；随机一好一坏，模型把坏客判得更风险的概率。

2）重要性：滞后性能指标，标签成熟后判断排序是否退化。

3）定义：ROC曲线面积；固定Bad Definition、预测窗口、成熟期、Score方向、样本口径。

4）高低：高通常排序强，但不等于校准好或利润高。

5）七步案例：背景：C渠道扩量；数据：AUC0.73→0.72，C0.69、其他0.73，PSI0.24、O/E1.28、FPD7+2.4pp；现象：整体排序仅小幅降；拆解：局部C更弱；根因：总体更像Population/Calibration变化；决策：C渠道Challenger与特征审计，不全量重训；结果：成熟Cohort看AUC CI、O/E和Margin。

6）诊断：标签/方向 → Segment → Feature Missing → PSI/O-E → FPD/EL。

7）动作：局部下降分群治理；全局持续下降重训；AUC稳O/E差优先Recalibration。

8）误区：AUC高=校准好；未成熟标签；窗口不同横比；只看总体。

9）拆分：Channel、Product、Vintage、MOB、Score、Region、Model/Strategy。

10）预警：同成熟期+置信区间+最低Bad数，关注相对基线持续下降，不用统一绝对阈值。

11）关系：Feature/Score → AUC↔KS → Rank Quality；AUC+O/E → Approval/EL/Margin。

12）练习

AUC稳定、O/E=1.4，不代表模型正常：排序稳但PD可能低估。

KS｜Kolmogorov–Smirnov Statistic｜好坏区分度

1）是什么：好坏客户累计分布最大距离。

2）重要性：滞后排序/区分指标，辅助Cutoff和Champion/Challenger。

3）公式：KS = max_t |CDF_good(t) − CDF_bad(t)|固定标签、窗口、成熟期、Score方向、样本。

4）高低：通常高表示分离更强，但只取最大差点，不代表所有区间，也不代表校准准确。

5）七步案例：背景：C渠道扩量；数据：KS0.38→0.36，C0.30、其他0.37，C PSI0.37、O/E1.55；现象：C分离下降；拆解：Low Score×High Limit/新设备；根因：客群和特征覆盖变化相关，尚不能说全局失效；决策：C限量+数据审计+Challenger；结果：成熟Cohort看KS/AUC/O-E/EL/Margin。

6）诊断：标签/方向 → KS Cut-point → Segment → Feature/PSI → AUC/O-E → Bad/EL。

7）动作：局部分群治理；全局持续降才重训；KS稳但O/E差做校准。

8）误区：KS高=赚钱；窗口混比；Selection Bias；只看最大点。

9）拆分：Channel、Score、Vintage、Product、Region、Device、Model/Strategy。

10）预警：同标签成熟期+最低Bad样本；连续两个成熟Cohort低于稳定区间为内部黄灯示例。

11）关系：Population/Feature → Score → KS/AUC → Approval → Bad/EL；不替代Calibration。

12）练习

KS降但PSI稳：优先查特征-风险关系、数据质量和策略选择。

O/E｜Observed / Expected Ratio｜实际/预期坏账比

1）是什么：成熟实际Default数量 ÷ 模型预测Default数量。

2）重要性：滞后校准指标，连接PD、EL、Price、Limit。

3）公式：O/E = Σ Observed Default_i ÷ Σ Predicted PD_i固定Default Definition、预测窗口、决策时点和成熟样本；Loss O/E另定义，不能混用。

4）高低：约1表示总体校准接近；>1通常实际坏账高于预测；小样本/未成熟/策略变化会制造假信号。

5）七步案例：背景：C扩量提额；数据：O/E1.02→1.28，C1.55、其他1.05，AUC0.72、PSI0.24、EAD+20%、FPD7+2.4pp；现象：新增客群风险被低估；拆解：Low Score×High Limit；根因：Base Rate/客群与额度结构变化，排序仍可用；决策：Segment Recalibration+限额回滚；结果：两个Vintage看O/E、EL、Margin。

6）诊断：Default/成熟期 → PD版本 → Segment O/E → PSI → AUC/KS → EAD/LGD/EL。

7）动作：排序稳O/E高先Recalibrate；单Segment做Segment PD/价额；排序也恶化再重训。

8）误区：未成熟Bad；窗口混用；Default/Loss O/E混用；O/E>1=模型必坏。

9）拆分：Channel、Score、Vintage、MOB、Product、Term、Limit/EAD、Region、Model/Strategy。

10）预警：成熟Cohort+置信区间/最低事件数；连续偏离自身稳定区间为内部黄灯，EL/Margin同步坏升级。

11）关系：PD → Expected Defaults → O/E → Recalibration → EL/Price/Limit → Margin。

12）练习

ΣPD=1,200，实际Default=1,500，则O/E=1.25，表示实际Default比预测高25%。
