Take-up Rate｜报价接受/提款转化率

1）是什么：成熟有效Offer中，真正接受方案的比例；看“获批后到底愿不愿意借”。

2）为什么重要：贷前→放款同步指标，连接Price、Limit、Term、优惠和最终EAD；高Take-up也可能来自边缘风险客的强资金需求。

3）公式：Take-up = 成熟有效Offer中已接受Offer用户/订单 ÷ 成熟有效Offer用户/订单必须固定Offer有效期、用户/订单去重、接受定义；点击不等于成功放款。

4）高低：高可能产品吸引力强，也可能逆向选择；低可能价格/额度/体验问题，也可能优质客选择更多。

5）案例：墨西哥30天首贷A→B：Approval30%→36%、Take-up60%→72%、Avg Ticket1,400→1,900、EL/Loan120→205、Margin75→47。Channel C×Low Score×Limit≥2,000 Take-up82%但Margin约-35；Medium Score×Limit≤1,800 Margin约+82。确认边际经济性恶化，但不能把单一因素当唯一因果；低Score高Limit降额，中风险正利润段保留Challenger，观察两个FPD7 Cohort/MOB1。

6）诊断：Offer口径/技术 → Price/Term/Limit → Channel/Score → Disbursement → FPD/EL/Margin。

7）动作：低Take-up低风险优化Offer；高Take-up高风险降额/收紧；渠道异常降量；技术失败先修链路。

8）误区：点击=Take-up；未成熟Offer入分母；越高越好；忽略Selection Bias。

9）拆分：Channel、Campaign、Score、Limit、Term、Price、Coupon、新老客、Strategy。

10）预警：同Offer Version历史基线；Take-up突然上升且低Score/EL同步上升可作内部黄灯，Margin转负升级红灯。

11）关系：Approval → Offer → Take-up → Disbursement → EAD → EL → Margin → LTV。

12）练习

Take-up 55%→72%，EL 130→210、Margin80→45，是否把72%设增长目标？答案：不应。

Average Ticket｜平均放款件均

1）是什么：成功放款的平均实际本金。

2）为什么重要：同步风险/经营指标，直接影响EAD、资金占用、收入和金额坏账。

3）公式：Average Ticket = 成功放款本金总额 ÷ 成功放款贷款数实际Disbursed Amount，不用Approved Limit；同时建议报Median/P90。

4）高低：高可增收入也会放大EL；低可降风险也可能损害Take-up/LTV。

5）案例：复借提额：Ticket1,500→1,980、件数FPD7 9.8%→10.4%、金额FPD10.5%→14.8%、Funding75→108、Margin96→70；风险集中Low Score×Limit≥2,400。低Score恢复旧Limit，高Score保留提额，观察两个Vintage。

6）诊断：Limit → Take-up/Utilization → Score/Channel → 件数vs金额FPD → Funding/EL/Margin。

7）动作：低Score高Ticket降额；高Score正Margin可提额；资金紧张优先控高Ticket低ROI段。

8）误区：Limit=Ticket；均值掩盖长尾；只看件数FPD；新老客混用。

9）拆分：Score、Limit、Term、Channel、Cycle、Income、DTI/PTI、Strategy。

10）预警：Average/Median/P90与Amount FPD/EL联合；阈值来自自身历史。

11）关系：Limit → Take-up/Utilization → Ticket/EAD → Revenue & Funding → EL → Margin。

12）练习

件数FPD下降但Ticket+40%、金额FPD上升，风险改善吗？答案：不能。

Funding Cost｜资金成本

1）是什么：支持贷款资产所承担的利息、Spread、Commitment、结构/对冲/流动性等可归属成本。

2）为什么重要：经营利润上游约束，决定Price/Limit/Term是否有经济空间。

3）公式：Funding Cost/Loan = 贷款生命周期可归属利息 + Spread/Commitment/Structure/FX/Liquidity Cost年化Funding Rate可另算，但必须固定平均资金余额和天数口径。

4）高低：通常低更好，但低利率可能伴随短期限或严格Covenant；高成本资金也可能支持高ROI Segment。

5）案例：Funding/Loan70→108、Ticket1,400→1,900、Revenue390→480、EL120→205、Margin75→47、Facility Utilization62%→84%。高Limit段资金占用与风险成本共同压缩Margin；将有限资金优先分配给正ROI Segment。

6）诊断：合同口径 → Reference Rate/Spread → Utilization/Commitment → Term/FX → Segment Margin。

7）动作：重谈Spread、优化提款计划、对冲币种、优先投向高ROI Segment。

8）误区：Banxico政策利率=Funding Cost；漏算Commitment Fee；年化率与单笔成本混用；忽略FX。

9）拆分：Funding Source、Currency、Product、Term、Score、Limit、Vintage。

10）预警：Reference Rate、Spread、Utilization、Covenant、Maturity Ladder联合；Funding/Loan上升且Margin下降作为内部黄灯。

11）关系：Reference Rate + Spread/Fees → Funding → Price/Limit → Margin → LTV/ROI。

12）练习

Revenue+80，Funding+38，EL+85，其他不变，Margin改善吗？答案：不改善，净约-43。

Risk-adjusted ROI｜风险调整后投资回报率

1）是什么：风险调整后的净贡献相对于实际占用资金/资本的效率。

2）为什么重要：把增长、风险和资金分配统一成可比较的经营结果。

3）公式：不存在唯一行业口径。内部示例：Risk-adjusted ROI = (Revenue − Funding − CAC − EL/Actual Loss − Variable Cost) ÷ Average Funded Capital预测期用EL、成熟期可用Actual Loss；分母必须固定。

4）高低：通常越高越好，但未成熟坏账、极高价格或低规模可制造虚高ROI；要看LTV、投诉和合规。

5）案例：A总Margin270k、平均资金占用3.2m，简化ROI≈8.4%；B总Margin243.6k、资金占用6.0m，ROI≈4.1%。B放款更多但资本效率更差；Low Score×High Limit为负ROI。削减负ROI段，保留正ROI Challenger，等待FPD7/MOB1/Repeat成熟。

6）诊断：分母/资本口径 → Revenue → Funding/CAC → PD×LGD×EAD → Segment/Vintage → LTV。

7）动作：PD问题收准入；EAD问题降额；Funding问题调资金；CAC问题换渠道；高ROI低量谨慎扩量。

8）误区：Revenue/Principal=ROI；未成熟Bad按0；不同资本分母横比；漏CAC/Funding。

9）拆分：Channel、Campaign、Score、Limit、Term、New/Repeat、Funding Source、Strategy。

10）预警：同成熟期同资本口径；Marginal ROI≤0且EL持续恶化可作内部红灯。

11）关系：CAC → Approval/Take-up → EAD → Margin → Capital → Risk-adjusted ROI → LTV/Portfolio Allocation。

12）练习

A 270k/3.2m，B 243.6k/6.0m，谁ROI更高？答案：A约8.4%，B约4.1%。
