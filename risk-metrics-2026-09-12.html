PD / LGD / EAD / Expected Loss 完整指标学习卡

今日围绕“风险损失从哪里来”统一四个高频信用风险指标。示例为墨西哥现金贷内部训练数据，不代表行业统一水平或监管标准。

PD｜Probability of Default｜违约概率

1）指标是什么：在固定预测窗口内，一笔贷款或一个客户发生“Bad/Default”的概率。大白话：这个客户未来变坏的可能性有多大。

2）为什么重要：PD是贷前/贷中领先风险指标，是准入、额度、定价和EL的核心输入；但真正Observed Bad需要成熟后才能验证，所以同时也是模型校准治理对象。

3）精确定义与公式：PD = P(Default within fixed horizon | information at decision time)必须固定Default定义（如90+ DPD / Write-off）、预测窗口、观察时点、账户/用户口径。不能把FPD7直接当12个月PD，也不能把不同模型时间窗口混用。

4）如何看高低：PD通常越低代表信用风险越低，但低PD不一定利润更高：低风险客可能价格低、额度高、获客贵。PD变低还可能来自客群选择性变严，而非模型变好。

5）墨西哥七步案例：背景：30天首贷，Strategy B提高部分边缘用户Limit。数据：成熟申请20k；A平均PD12%、Avg EAD MXN1,500、LGD70%、EL/Loan MXN126；B平均PD13%、Avg EAD MXN1,900、LGD72%、EL/Loan约MXN178；Approval 31%→35%。现象：PD只升1pp，但EL升约41%。拆解：Channel C×低Score×Limit≥2,000的PD约19%，同时EAD更高。根因：PD与额度结构同时变化，不能把EL恶化只归因于PD。决策：低Score高Limit降额，中Score保留Challenger；PD用于排序/定价但Limit独立约束。结果：看两个成熟FPD7与MOB1 DPD30+ Cohort，同时比较O/E与EL/Loan。

6）诊断逻辑：Default定义/成熟期 → Score/PD分布 → O/E Calibration → Channel/Score/Limit → FPD/Vintage → EL/Margin。

7）策略动作：PD整体上移且PSI高：先查流量/数据漂移；PD稳定但Observed Bad高：Recalibration/Overlay；边缘PD+高EAD风险高：优先降额度；特定渠道PD异常：降量或独立Cutoff。

8）常见误区：把Score当PD；把FPD7直接当PD；不同预测窗口横比；PD低就无限提额；未成熟Observed Bad做校准。

9）推荐拆分：Channel、Campaign、Score Decile、Limit、Term、新老客、Region、Bureau Hit、Model Version、Strategy Version。

10）预警方式：使用稳定模型版本与成熟Cohort比较平均PD、Score Band O/E及PSI；示例黄灯可定义为连续两个成熟Cohort O/E显著高于历史稳定区间且样本量达内部门槛，非行业统一阈值。

11）与其他指标关系：Population/Score → PD → Approval/Price/Limit → EAD；PD × LGD × EAD → EL → Contribution Margin。

12）小练习

A客户PD=10%、LGD=70%、EAD=MXN1,500；B客户PD=8%、LGD=70%、EAD=MXN3,000。谁的EL更高？

答案：A EL=105；B EL=168。B虽然PD更低，但更高EAD使预期损失更高。

LGD｜Loss Given Default｜违约损失率

1）指标是什么：客户已经违约后，最终有多少风险暴露无法净回收。大白话：坏了以后到底会亏掉几成。

2）为什么重要：LGD是贷后/信用损失的滞后成熟指标，也是定价、催收、资产出售和EL的重要输入；它把“会不会坏”与“坏了亏多少”分开。

3）精确定义与公式：LGD@N = (Default EAD − Net Recoveries within N months) ÷ Default EADNet Recoveries应扣除催收、诉讼或处置成本；必须固定Default EAD时点、Recovery窗口、折现规则和核销/重组口径。

4）如何看高低：通常越低越好，但不同Recovery MOB不可直接比较；更长回收窗口自然可能让LGD下降。通过高成本催收把Gross Recovery做高，也可能让Net LGD改善有限。

5）墨西哥七步案例：背景：两个催收Vendor处理相同风险层Default资产。数据：各Default EAD MXN10m；A 6个月Gross Recovery 2.6m、Cost0.5m，Net Recovery21%，LGD79%；B Gross3.0m、Cost1.1m，Net Recovery19%，LGD81%；B投诉率2.4% vs A1.1%。现象：B毛回收更高，但净损失率更差。拆解：高余额、低Contactability案件上B的增量回收不足以覆盖成本。根因：Vendor策略与成本相关，但仍需控制案件分配差异。决策：用Net Recovery/LGD分案，高余额高可联系案件才使用高强度策略。结果：同Default Vintage、同Recovery MOB观察9-12个月Net LGD。

6）诊断逻辑：Default EAD → Recovery Window → Gross/Net Recovery → Vendor/DPD/Balance → Cost/Complaint → LGD。

7）策略动作：LGD高但RPC低：提升触达/支付路径；高成本拖累：优化Vendor与数字催收；高余额LGD高：提高人工优先级；Fraud Default单独管理，避免混入普通Credit LGD。

8）常见误区：Recovery Rate=1-LGD但口径不一致；不同Recovery MOB横比；只看Gross Recovery；Default前正常还款算Recovery；展期算现金回收。

9）推荐拆分：Default Vintage、Recovery MOB、DPD、Score、Balance/EAD、Vendor、Region、Payment Method、Fraud/Credit Type。

10）预警方式：同Default Vintage、同Recovery MOB比较Net LGD；需设最小Default EAD门槛。示例红灯候选：Net LGD连续两个成熟Vintage恶化且Collection Cost、Complaint同步上升。

11）与其他指标关系：Collection/RPC/PTP → Recovery → LGD；PD × LGD × EAD → EL。

12）小练习

Default EAD=MXN5m，回收现金1.5m，催收成本0.3m。Net LGD是多少？

答案：Net Recovery=1.2m；LGD=(5-1.2)/5=76%。

EAD｜Exposure at Default｜违约风险暴露

1）指标是什么：客户发生违约时，机构真正暴露在风险中的金额。大白话：如果此刻坏掉，我们到底有多少钱在外面。

2）为什么重要：EAD是额度策略和金额风险的核心同步/领先指标。PD只描述概率，EAD决定同样违约概率下会损失多少钱。

3）精确定义与公式：固定分期现金贷可用违约时未偿本金/风险余额；循环额度还需要估计未来提款：EAD = Current Drawn Balance + CCF × Undrawn Committed Limit必须固定观察时点、应计利息/费用是否纳入、账户/订单口径与币种。

4）如何看高低：高不一定坏，高质量客户高EAD可能创造更多利润；真正要看PD × LGD × EAD及Margin。平均EAD也可能掩盖P90/P95高暴露。

5）墨西哥七步案例：背景：复借提额策略将部分用户Limit从MXN2,000提至3,500。数据：PD从8.5%降至8.0%，Avg EAD 1,650→2,450，LGD68%→69%，金额FPD7 12.5%→16.8%，EL/Loan约95→135。现象：件数风险没有恶化，但金额风险显著上升。拆解：Score中档×高Utilization用户贡献主要增量EAD。根因：提额与更高提款利用率共同增加暴露，不能因为PD下降就认为风险改善。决策：按PD/LTV/历史还款分层提额，增加Utilization Cap。结果：看金额FPD、MOB1 DPD30+、EL与Margin。

6）诊断逻辑：Limit → Utilization/Drawdown → Avg/P90 EAD → Score/PD → Amount FPD/Vintage → EL/Margin。

7）策略动作：高PD高EAD：降额/拒绝；低PD高EAD：看Margin与资本占用；EAD突升但Limit不变：查Utilization或重复放款；循环产品加入CCF并限制高风险未用额度。

8）常见误区：Approved Limit=EAD；只报平均EAD；件数风险下降就忽略金额风险；循环额度忽略未提款转换；不同币种直接相加。

9）推荐拆分：Score、Limit、Utilization、Term、Channel、Cycle、新老客、Income/DTI、Strategy Version、Funding Source。

10）预警方式：Avg/Median/P90 EAD与Amount FPD、EL同步；示例黄灯：P90 EAD连续上升且金额FPD/EL同步高于内部稳定区间。

11）与其他指标关系：Approval → Limit → Utilization → EAD → Amount FPD/Bad；PD × LGD × EAD → EL → Funding/Capital → Margin。

12）小练习

循环额度已用MXN1,200，未用额度MXN1,800，内部CCF=40%。EAD是多少？

答案：1,200 + 40%×1,800 = MXN1,920。CCF是内部/模型参数，不是行业固定值。

Expected Loss / EL｜预期损失

1）指标是什么：在固定风险窗口内，综合“会不会坏、坏了亏多少、坏的时候暴露多少”得到的期望信用损失。大白话：平均来看，这笔贷款应该预留多少钱给信用损失。

2）为什么重要：EL是贷前、贷中和经营利润的统一桥梁，可用于准入、额度、定价、预算、渠道和组合管理；它不是实际已发生损失，也不能替代会计减值框架。

3）精确定义与公式：EL = PD × LGD × EAD必须确保三者预测窗口、Default定义和币种一致；组合EL应按账户逐笔求和，而不是简单用平均PD×平均LGD×平均EAD，除非确认加权口径一致。

4）如何看高低：低通常更好，但完全追求低EL会损害增长与利润。判断应使用EL/Loan、EL/EAD、Contribution Margin和Risk-adjusted ROI共同评估。

5）墨西哥七步案例：背景：Strategy A/B对边际首贷客提额。数据：A：PD12%、LGD70%、EAD1,500，EL=126；Revenue450、Funding85、CAC80、Variable40，Margin约119。B：PD13%、LGD72%、EAD1,900，EL约178；Revenue510、Funding112、CAC75、Variable45，Margin约100。现象：B收入更高但风险和资金成本吃掉大部分增量。拆解：Channel C×Low Score×High Limit EL/Loan最高。根因：PD、LGD、EAD均小幅/显著变化共同驱动EL上升。决策：边际低Score恢复旧Limit，中Score保留Challenger；价格只在平台/法律允许范围内评估，不用高价掩盖失控风险。结果：两个成熟Cohort比较Actual Credit Loss vs EL、O/E、Margin。

6）诊断逻辑：先做EL Bridge：PD Effect → LGD Effect → EAD Effect → Channel/Score/Limit → Actual Loss/O-E → Margin。

7）策略动作：PD驱动：收准入/校准模型；LGD驱动：催收/Recovery/担保或支付优化；EAD驱动：降额度/Utilization；Funding与EL双升：优先减低ROI资产。

8）常见误区：EL=实际损失；只用件数Bad不看金额；平均数直接相乘导致加权错误；不同窗口PD/LGD/EAD混用；用未成熟实际损失判断模型。

9）推荐拆分：Channel、Campaign、Score、Limit、Term、Vintage、MOB、新老客、Region、Funding Source、Strategy Version。

10）预警方式：EL/Loan、EL/EAD和Actual/Expected Loss联动；示例内部红灯：连续两个成熟Cohort Actual Loss明显高于EL且Contribution Margin转负，需进入策略/模型治理。

11）与其他指标关系：Score/Income/Bureau → PD；Collection/Recovery → LGD；Limit/Utilization → EAD；PD×LGD×EAD → EL → Provision/Pricing → Contribution Margin/LTV。

12）小练习

PD=15%、LGD=65%、EAD=MXN2,000，EL是多少？如果收入480、Funding100、CAC80、Variable40，风险调整Contribution Margin是多少？

答案：EL=MXN195；Margin=480−100−80−40−195=MXN65。
