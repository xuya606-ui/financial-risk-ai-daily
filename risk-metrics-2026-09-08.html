2026-09-08 风控指标学习卡

今日完整升级5个高频指标：Vintage DPD30+@MOB、MOB、Bad Rate、Recovery Rate、Collection Rate。所有阈值/案例数字均为内部学习示例，不代表行业统一标准。

1｜Vintage DPD30+@MOBn｜同批次同账龄30+逾期率

1）指标是什么：同一放款Vintage在相同MOB年龄时，有多少账户/余额已达到DPD≥30。大白话：同一批贷款长到同样年龄后，谁更差。

2）为什么重要：属于滞后信用表现指标，适用于贷中/贷后和策略复盘。它能剥离高速增长或收缩导致的资产年龄结构影响，比Current DPD30+更适合比较策略、渠道和额度版本。

3）精确定义与公式：件数Vintage DPD30+@MOBn = Vintage V在MOBn时DPD≥30且已成熟账户 ÷ Vintage V在MOBn时可观察/成熟账户金额Vintage DPD30+@MOBn = 同Vintage同MOB下DPD≥30风险余额 ÷ 约定的同Vintage风险余额分母金额分母可以采用期末Outstanding或Origination Exposure，但全公司必须固定一种定义；Vintage、MOB0/1起点、快照日、核销/重组/展期处理也必须统一。

4）如何看高低：通常越低越好；但展期、核销、资产出售或快速Cure会改变期末余额，因此件数与金额要同时看。低Current DPD不能替代低Vintage DPD。

5）墨西哥七步案例：
背景：30天首贷产品6月上线额度V5并扩大渠道C。
数据：4月Vintage N=18,000、MXN26m；5月N=19,500、MXN29m；6月N=27,000、MXN47m。Current DPD30+ 12.1%→11.7%，但MOB1 DPD30+分别9.8%、10.4%、14.6%；6月Avg EAD MXN1,740，前两月约1,440；低Score×Limit≥MXN2,000占比9%→21%。
现象：总体Current DPD看起来改善，最新Vintage同MOB却显著恶化。
拆解：Channel C×低Score×Limit≥2,000的MOB1 DPD30+约21%，其他组合约10%-12%，金额口径更差。
根因：可以确认新Vintage风险恶化，但额度、渠道、客群同时变化，不能把任何一个变量直接写成唯一因果。
决策：低Score高额度恢复旧Limit，渠道C缩量；中Score低额度保留V5 Challenger。
结果：观察后续两个Vintage的MOB1/MOB2 DPD30+、Bad、EL/Loan和Contribution Margin；风险回落且利润改善才视为有效。

6）诊断逻辑：①核对Vintage/MOB/快照与成熟度 → ②Channel×Score×Limit×Term×Strategy → ③FPD/Cure/Roll → ④件数vs金额/EAD → ⑤Bad/EL/Margin。

7）策略动作：若风险集中于边缘Score高Limit则降额/收紧；集中于单一渠道则降量/停量；若支付或催收异常先修流程；异常组合用Challenger/回滚验证。

8）常见误区：把不同MOB直接比较；用Current DPD替代Vintage；件数/金额混用；分母随团队变化；忽略核销/资产出售造成的幸存者偏差。

9）推荐拆分：Channel、Campaign、Product、Score、Limit、Term、New/Repeat、Region、Device、Strategy Version。

10）预警方式：同MOB连续两个Vintage高于自身历史稳定P75/P90可作为内部黄灯示例；样本量需达到内部门槛。金额风险、EL和Margin同步恶化时可升级红灯。以上非行业统一阈值。

11）与其他指标关系：Traffic/Approval → Limit/EAD → FPD → Vintage DPD30+@MOB → Bad → Recovery/LGD → EL → Margin。

12）小练习

Current DPD30+从12%降至11%，但最新两批MOB1从10%升14%、16%，同时放款量+60%。是否风险改善？答案：不能；优先相信同Vintage同MOB恶化，并检查新资产分母稀释。

2｜MOB｜Month on Book｜在账月龄

1）指标是什么：贷款从放款日起到观察时点的“年龄坐标”。它不是坏账率，而是告诉你资产长到第几个月。

2）为什么重要：属于风险分析的成熟度/时间轴指标，贯穿贷中与贷后。没有统一MOB，就不能公平比较DPD、Bad、Recovery和Vintage。

3）精确定义与公式：MOB没有唯一行业公式。可按日龄映射，也可按自然月快照；示例算法可为MOB ≈ floor((Observation Date − Origination Date) / 30)但生产环境更建议通过统一Calendar Mapping定义MOB0、MOB1和月末快照。订单/账户、放款日、续借/重组后是否重置MOB必须写入数据字典。

4）如何看高低：MOB高或低本身没有“好/坏”。MOB越高代表资产更成熟，更多风险有机会显现；MOB低的资产用最终Bad结论往往不成熟。

5）墨西哥七步案例：背景：业务单月扩量60%。数据：MOB0资产占比35%→63%，Current DPD30+ 12%→10.9%，但同MOB1 DPD30+ 10.2%→14.8%，FPD7金额16%→20%，Avg EAD+28%。现象：总体风险看似下降。拆解：按MOB归一后最新资产明显更差。根因：新资产分母稀释是主要解释，但具体风险恶化仍需拆渠道/额度。决策：经营看板强制同MOB比较。结果：等MOB1/2成熟后评估策略。

6）诊断逻辑：①MOB起点/日历 → ②资产年龄分布 → ③提前结清/核销/重组 → ④同Vintage同MOB风险 → ⑤策略版本。

7）策略动作：统一数据字典；所有DPD/Vintage看板加MOB；低MOB只用早期指标做可回滚动作，不提前下最终Bad结论。

8）常见误区：把MOB越高理解为风险越高；30天算法与自然月混用；某团队从MOB0起、另一个从MOB1起；重组/复借后随意重置MOB。

9）推荐拆分：Vintage、Product、Term、Cycle、New/Repeat、Strategy Version。

10）预警方式：先做数据质量预警，例如负MOB、MOB空值、异常跳月占比达到内部门槛；业务风险比较固定同MOB，不套行业统一阈值。

11）关系：Origination → Vintage → MOB → DPD/Bad Maturity → Recovery/LGD → EL。

12）小练习

90天产品的MOB0 Current DPD与成熟MOB3直接比较有意义吗？答案：没有，应在同MOB或定义一致的成熟窗口比较。

3｜Bad Rate｜坏账率/违约率

1）指标是什么：满足公司固定Default/Bad Definition的成熟账户或金额比例。大白话：最终真正“坏掉”的贷款有多少。

2）为什么重要：属于滞后信用结果指标，适用于贷后、模型校准、EL预算和经营复盘，是PD预测最终需要对照的真实结果之一。

3）精确定义与公式：件数Bad Rate = 成熟样本中达到Bad Definition的账户/订单 ÷ 同一成熟期Eligible账户/订单金额Bad Rate = 达到Bad的定义风险金额 ÷ 约定的成熟风险金额分母必须固定Bad Definition（例如Ever 60+/90+、Write-off或公司自定义）、预测窗口、成熟期、重组/展期、欺诈Bad是否单列、件数/金额和用户/订单口径。

4）如何看高低：通常越低越好，但用大量拒绝好客也能降低Bad却损害利润；因此必须与Approval、EAD、Revenue、EL和Margin一起看。

5）墨西哥七步案例：背景：首贷Cutoff与额度同步放宽。数据：90天成熟N=10,000；Bad定义=90天内Ever DPD60+；件数Bad 13%→16%；金额Bad 14%→20%；Avg EAD 1,420→1,860；Approval 30%→35%；Contribution Margin 82→58 MXN/loan。现象：新增资产规模增长，但金额坏账恶化更快。拆解：低Score×Limit≥2,000贡献新增Bad的约一半。根因：额度和边际客群均相关，需Challenger验证因果。决策：恢复边缘客额度、保留中Score小流量。结果：观察两个成熟Vintage的Bad/EL/Margin。

6）诊断逻辑：Bad定义/成熟度 → Vintage/MOB → Channel×Score×Limit → Fraud/Payment → Recovery/LGD → EL/Margin。

7）策略动作：PD型恶化收准入；金额恶化优先控Limit/EAD；欺诈Bad单独加强KYC；回收差则改善催收而非只收贷前。

8）常见误区：FPD直接当Bad；未成熟样本进分母；Write-off口径与Ever DPD混用；件数改善就忽略金额恶化。

9）推荐拆分：Vintage、MOB、Channel、Score、Limit、Term、Cycle、Region、Fraud/Credit、Strategy Version。

10）预警方式：仅用成熟Cohort；同Vintage/同MOB比较，设置最小样本量。黄/红灯基于自身历史稳定分布并与金额Bad/EL联动。

11）关系：Score/PD → Approval/Limit → Bad Rate → LGD/EAD → EL → Contribution Margin。

12）小练习

件数Bad 14%→13%，但金额Bad 15%→21%、Avg EAD +35%。能否说风险改善？答案：不能，金额风险明显恶化。

4｜Recovery Rate｜回收率

1）指标是什么：已经Default/Write-off的风险金额中，后续真正收回多少现金。大白话：坏掉以后还能拿回来多少。

2）为什么重要：典型滞后贷后指标，直接影响LGD和EL，也决定催收供应商、债务出售和重组策略的经济价值。

3）精确定义与公式：Gross Recovery Rate@N = Default Cohort在N个月内回收现金 ÷ Default时EADNet Recovery Rate@N = (回收现金 − 可归因催收/诉讼成本) ÷ Default时EAD必须固定Default Vintage、Recovery MOB/窗口、EAD口径、是否计入利息/费用、债务出售收入和成本。

4）如何看高低：通常越高越好，但Gross高不代表Net高；观察窗口越长通常累积回收越多，不能用3个月Recovery与12个月Recovery直接比较。

5）墨西哥七步案例：背景：两家催收Vendor各分配MXN10m Default EAD。数据：A Gross Recovery=2.1m、成本0.4m，Net=17%；B Gross=2.5m、成本0.9m，Net=16%；A投诉0.9%，B=2.1%。现象：B账面回款更多但净价值更低。拆解：按DPD、Balance、Score、Region看B对高余额案件增加大量人工/法律成本。根因：额外回收未覆盖边际成本，不能用Gross单独评价。决策：低余额Digital First，高余额才给高成本Vendor。结果：同Default Vintage看3/6/12月Net Recovery、Complaint、LGD。

6）诊断逻辑：Default Cohort/成熟期 → Vendor/DPD/Balance → RPC/PTP/Cure → Gross Cash → Cost/Complaint → Net Recovery/LGD。

7）策略动作：按余额/可联系性分案；优化支付通道和和解；淘汰Net Recovery差的Vendor；欺诈违约与信用违约分层。

8）常见误区：未成熟Recovery窗口横比；Gross与Net混用；Default前正常还款计为Recovery；Extension/Restructure直接当现金回收。

9）推荐拆分：Default Vintage、Recovery MOB、DPD、Vendor、Balance、Score、Channel、Region、Fraud/Credit。

10）预警方式：同Default Vintage、同Recovery MOB比较；达到最小Default EAD后看Net Recovery与Complaint共同黄/红灯，阈值均为内部标准。

11）关系：RPC/PTP/Collection → Recovery → LGD ↓ → EL ↓ → Margin/LTV ↑。

12）小练习

A回收21%成本4%，B回收25%成本9%，均以Default EAD计。哪个Net Recovery更高？答案：A=17%，B=16%，A更高。

5｜Collection Rate｜催收回款率

1）指标是什么：进入固定催收窗口/队列的应收金额中，期间实际收回多少现金。它看的是“催收阶段收了多少”，与Default后的Recovery不是同一指标。

2）为什么重要：属于贷后同步/滞后经营指标，连接支付体验、RPC/PTP、Cure、Roll和催收成本。

3）精确定义与公式：Cash Collection Rate@N = 固定催收Cohort在N日/月内实际收到的现金 ÷ 该Cohort约定的可催收应收金额/期初逾期余额分母可选“到期应收”或“期初逾期余额”，但必须固定，不能混用。建议同时报Gross Collection与Net Collection=(Cash−Collection Cost)/同分母。

4）如何看高低：通常越高越好，但高回款如果靠高成本、高投诉或大量展期实现，经济价值可能更差；应同时看Cash Cure、Forward Roll、Cost和Complaint。

5）墨西哥七步案例：背景：DPD1-30两个催收策略各有MXN8m期初应收。数据：A Cash=2.40m、Cost=0.45m、Gross=30.0%、Net=24.4%、投诉1.8%；B Cash=2.25m、Cost=0.18m、Gross=28.1%、Net=25.9%、投诉0.7%，B的Cash Cure还高2pp。现象：A Gross更高但B净效率和体验更优。拆解：A高频人工触达集中在低余额客群。根因：额外人工成本没有带来足够边际回款。决策：低风险低余额Digital First，高余额/高Forward Roll人工。结果：观察2-4周Net Collection、Cure、Roll、Complaint和最终Recovery。

6）诊断逻辑：分母/账单 → Payment Success → RPC/PTP/PTP Kept → Cash Cure/Roll → Cost/Complaint → Recovery。

7）策略动作：支付故障先修通道；低Contactability改善触达；低PTP Kept调整策略/话术；高成本低增量客群转Digital；高余额高风险优先人工。

8）常见误区：Collection和Recovery混用；展期当Cash；期初余额与当期应还分母混用；件数回款率与金额回款率混用。

9）推荐拆分：DPD、Score、Limit、Balance、Vendor/Collector、Payment Method、Region、Cycle、Strategy Version。

10）预警方式：同DPD/同年龄稳定历史作基线；Gross下降但Net上升不一定坏。红灯应叠加Forward Roll、Cost和Complaint，而非单一比例；阈值为内部标准。

11）关系：Payment UX/RPC → Collection → Cure/Roll → DPD30+ → Recovery/LGD → EL/Margin。

12）小练习

A Gross 30%、Net 24.4%、投诉1.8%；B Gross 28.1%、Net 25.9%、投诉0.7%。若其他风险相近，优先哪个？答案：B更可能具有更高风险调整价值。

Vintage/MOB → DPD30+/Bad → Collection/Cure/Roll → Recovery/LGD → EL → Contribution Margin。
