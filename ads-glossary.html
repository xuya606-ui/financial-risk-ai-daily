一、账户结构与素材

Ads

中文：广告/广告体系泛称。Google Ads 是平台名；Ad 是具体广告；Ads 本身不是固定层级。

Ad Account

广告账户，承载账单、权限、时区、事件源和多个 Campaign。

Campaign

中文：广告系列/广告活动。位于 Ad Account 下、Ad Set/Ad Group 之上。现金贷例：Mexico_iOS_NewUser_Apply_TikTok。

Ad Set

Meta 常用广告组层级，常配置 Audience、Placement、Budget、Optimization Event。

Ad Group

Google/TikTok 常用广告组层级，用于组织 Keyword、Audience、Bid、Placement、Creative、URL。

Ad

最终展示给用户的具体广告。

Creative

广告创意/素材，包括视频、图片、文案、Hook、CTA、UGC 脚本。现金贷要继续接 Approve/Disburse/FPD。

Hook

素材开头吸引注意力的“钩子”；金融广告不能靠保证放款、秒批等夸大承诺换 CTR。

UGC

User-Generated Content 或 UGC 风格内容。

CTA

Call To Action，行动号召，如 Apply Now / Learn More。

二、Google Search / AI Max / 合规资产

AI Max for Search

Google Search AI 增强套件，包含 Search Term Matching、Text Customization、Final URL Expansion 等；不等于 PMax。

Google 官方

Search Term / Query

用户实际输入的搜索内容。

Keyword

广告主设置、希望购买的搜索意图。

Match Type

Keyword 与 Search Term 允许差多远的匹配规则，常见 Broad / Phrase / Exact。

Negative Keyword

否定关键词，用于排除不需要的搜索意图。

Keyword Prioritization

同一 Search Term 可被多个 Keyword/Search Theme 匹配时，Google 用匹配身份、相关性和 Ad Rank 决定谁进入竞价。

Responsive Search Ad / RSA

Google 会从多个 Headline / Description 中组合实际展示版本。

Text Disclaimer

Search Ad 文本免责声明资产。用于广告层必须展示的条款/披露；不能替代贷款 LP/App 的政策披露。

Google 官方

Text Customization / ACA

原 Automatically Created Assets。根据 Domain、Landing Page、已有 Ads 和 Keyword 自动创建额外标题/描述。

Google 官方

Final URL Expansion / FUE

Google 根据搜索意图把用户送到同域名更相关页面。现金贷需要 URL Eligibility / Disclosure Registry。

Google 官方

Dynamic Search Ads / DSA

基于网站内容动态匹配搜索和 Landing Page 的 Search 广告形式；当前 Google Help Center 指向 2027-02 开始自动升级到 AI Max。

Google 官方

Compliance Asset Stack

内部治理概念：把 RSA、Text Disclaimer、Text Customization、FUE、Landing Page Disclosure 作为一条合规链管理。

Disclosure Version Registry

记录贷款页面、广告 Disclaimer、产品参数和 disclosure_version 的映射与生效时间。

三、Placement / Publisher / TikTok Ad Network

Placement

广告版位/流量环境，如 Feed、Search、Reels、TikTok Ad Network。

Publisher

第三方 Ad Network 中真正承载广告的 App/网站。现金贷应按 Publisher 看 Fraud、Verified Install、Approve、Disburse、FPD/LTV。

TikTok Ad Network

TikTok 第三方 App 广告网络，旧称 Pangle。适合扩量，但需 Publisher 级治理。

TikTok 官方

Pangle

TikTok Ad Network 的旧名称/历史叫法。

Block List

屏蔽指定媒体 App/Publisher 的名单。现金贷应基于成熟 Fraud/CAC/FPD 证据，而不是单日 CTR/CPI。

Brand Safety / Suitability

控制广告出现在哪些内容/媒体环境；不等于业务 Fraud 或信用风险。

Endcard

TikTok Ad Network 可使用的广告尾卡，可能引用 App Store 信息。

Publisher Quality Registry

内部登记表，记录 Spend、Valid Install、Fraud、Approve、Disburse、CAC、FPD、LTV 与 Publisher 状态。

四、出价与自动化

Optimization Event

告诉平台最希望算法寻找什么行为，如 Install、Apply、Disburse。

Bid Strategy

平台出价策略，决定更偏拿量、控 CPA 还是控 Value/ROAS。

Cost Cap

围绕目标 CPA 控制长期平均成本，不是每笔转化硬上限。

Maximum Delivery

以预算为主要约束尽量获取更多结果。

Learning Phase

平台积累转化信号、探索人群/素材/版位/Bid 的阶段。

CBO

Campaign Budget Optimization，Campaign 级预算分配。

Smart+

TikTok 自动化投放体系。

Performance Max / PMax

Google 跨 Search、YouTube、Display、Discover、Gmail、Maps 等资源的自动化 Campaign。

Demand Gen

Google 视觉化中下漏斗 Campaign。

UAC / App Campaign

Google 应用广告系列。行业仍常说 UAC，官方通常称 App Campaign。

AEO

App Event Optimization，按应用内事件优化。

VBO

Value-Based Optimization，按事件价值优化。

MAI

Mobile App Install，移动 App 安装优化。

五、线索、转化与产品链路

Conversion

转化。现金贷必须写清具体事件：Install、Register、KYC、Apply、Approve、Disburse。

Raw Lead

刚产生的表单、消息、注册或申请，尚未完成资格验证。

Qualified Lead

通过最低业务资格验证、值得继续审批/跟进的 Lead。

Converted Lead

更接近业务结果的深层 Lead，可按公司定义为 Approve 或 Disburse。

Deep Link

广告、Push、短信等点击后直接打开 App 指定页面。

Web-to-App

广告 → Web LP → App Store/App → App 内转化。

六、归因、事件与反作弊

MMP

Mobile Measurement Partner。连接广告触达与 Install、Register、Apply、Disburse 等 App 事件；MMP 是归因层，不等于业务真相。

Pixel

浏览器侧事件采集器。

Events API

TikTok 服务器侧营销事件回传接口。

Conversions API / CAPI

Meta 服务器侧营销数据连接接口。

S2S / Server-to-Server

服务器到服务器事件或归因数据连接。

Postback

设备、MMP 或平台发送的归因/事件结果通知。

Event Deduplication

Browser + Server 同时上报同一事件时，用 event_id 等避免重复计数。

Attribution Window

广告接触后多长时间内的转化仍有资格算给该广告。

Conversion Lag

广告互动到转化发生/被记录的延迟。

Incrementality

回答“如果没有广告，这个用户是否仍会转化”，通常需 Holdout/Lift/Geo Experiment。

SDK Spoofing

模拟 SDK 请求制造虚假 Install/In-app Event。

Install Hijacking

真实用户安装，但欺诈方伪造最后触点抢走归因。

Device Farm

批量真机、云设备或 Emulator 制造 Install/Event。

七、iOS 隐私归因与 Campaign Capacity

AdAttributionKit

Apple 隐私广告归因框架。

Apple 官方

SKAdNetwork / SKAN

Apple 隐私广告归因基础设施，数据聚合、延迟且粒度可能受隐私阈值限制。

Fine Conversion Value

细粒度转化值。

Coarse Conversion Value

粗粒度转化值，如 low / medium / high；不等于信用风险等级。

Reengagement

已安装用户通过可归因广告重新回到 App 并互动。

2026-09-06

iOS 14.5+ Dedicated Campaign

中文：iOS 14.5+ 专用投放系列。

类别/层级：TikTok App Promotion 的 Campaign 类型，服务于 Apple SKAdNetwork 环境。

准确解释：用于向 iOS 14.5+ 设备投放并在 SKAN 框架下管理归因的专用 Campaign。TikTok 当前要求 MMP 支持 SKAdNetwork、App 完成验证后才能创建。

现金贷例子：Mexico iOS 新客 Install/Apply 采用 Dedicated Campaign，并把 TikTok 与 Ad Network 的后端首贷质量分开看。

适用：iOS App Install / App Promotion 的隐私归因投放。

误区：Dedicated 不等于“应该拆得越多越好”。它受 Quota 约束。

关系：与 Dedicated Campaign Quota、Placement、SKAN、MMP、Postback 直接相关。

TikTok 官方

Dedicated Campaign Quota

中文：专用 Campaign 配额。

类别：TikTok iOS Campaign Capacity。

准确解释：每个 iOS App 当前最多 30 个 Dedicated Campaign：TikTok Placement 最多 15，TikTok Ad Network 最多 15。

现金贷例子：Mexico iOS 若已有 13 个 TikTok Dedicated Campaign，只剩 2 个 TikTok Quota Slot 可用于新实验。

适用：Campaign 架构规划、实验排期、应急重建。

误区：30 是上限，不是建议建满数量。

关系：Automatic Placement 会同时消耗两个 Quota Pool。

TikTok 官方

Automatic Placement

中文：自动版位。

类别/层级：Ad Group / Placement 配置。

准确解释：让平台在可用 Placement 间自动分配流量。在 iOS Dedicated Campaign 场景，如果可能同时投 TikTok 与 TikTok Ad Network，当前会在两个 Dedicated Quota Pool 各消耗 1 个 Slot。

现金贷例子：一个 Mexico iOS Automatic Placement Campaign 表面只有 1 个 Campaign，但 Quota 视角占 2 个 Slot。

适用：需要跨 Placement 扩展 Delivery。

误区：“一个 Campaign 只占一个 Quota”。

关系：与 Placement、Quota Pool、TikTok Ad Network、Publisher Quality 相连。

TikTok 官方

Quota Pool

中文：配额池。

类别：iOS Campaign Capacity 内部管理术语。

解释：将 TikTok Placement 的 15 个 Dedicated Slot 与 TikTok Ad Network 的 15 个 Dedicated Slot 分开管理。

现金贷例子：Feed 实验占 TikTok Pool，Ad Network Publisher 扩量实验占 Ad Network Pool。

误区：把 30 个 Quota 当成一个完全共享的池。

关系：Dedicated Campaign Quota、Automatic Placement、Quota Headroom。

Quota Headroom

中文：剩余配额缓冲。

类别：内部运营/Capacity 指标。

解释：保留给新实验、紧急重建、事件切换的未占用 Slot。

现金贷例子：Mexico iOS 不把 15 个 TikTok Slot 全部占满，预留若干用于合规/事件异常后的快速重建。

误区：Headroom 是平台规定的固定比例。实际比例应由内部治理决定。

Crowd Anonymity

中文：群体匿名性。

类别：Apple 隐私归因。

准确解释：Apple 根据归因下载的匿名性水平决定 Postback 可以返回多少细节；数据越能保护个体隐私，系统才会开放相应字段/粒度。

现金贷例子：某 Mexico iOS Campaign 的 Fine CV Availability 下降，不应直接解释为 Apply/Approve 下降。

适用：解释 SKAN/AdAttributionKit 的数据缺失与粒度变化。

误区：把 Crowd Anonymity 当成“反作弊分数”或信用风险等级。

关系：决定 Postback Data Tier，并影响 Conversion Value、Source Identifier、Publisher Item ID 等可见性。

Apple 官方

Postback Data Tier

中文：回传数据层级。

类别：Apple AdAttributionKit / SKAN。

解释：Apple 根据 Crowd Anonymity 为归因下载分配的数据层级，该层级决定 Postback 可以包含哪些条件字段和 Source Identifier 的粒度。

现金贷例子：同样的真实首贷表现下，不同 Cohort 可能因为 Data Tier 不同而获得 Fine、Coarse 或无 Conversion Value。

误区：把 Data Tier 当成媒体质量等级。

关系：与 Crowd Anonymity、Fine/Coarse CV、Source Identifier 直接相关。

Apple 官方

Source Identifier

中文：来源标识符。

类别：Apple Postback 字段。

解释：广告网络在展示广告时提供的分层来源标识，用于表达 Campaign 等投放信息；Postback 返回的位数可能受 Data Tier 影响。

现金贷例子：通过 Source Identifier 聚合 Mexico iOS Campaign/Creative 质量，但不要期待每次都拿到完整粒度。

误区：Source Identifier 等同于用户 ID。

关系：Postback Data Tier、Campaign Mapping、MMP。

Apple 官方

SKAN Capacity Planner

中文：SKAN 投放容量规划器。

类别：内部产品/运营治理。

解释：统一管理 iOS Dedicated Campaign Quota、实验优先级、Postback Signal Density、后端样本成熟度和 Slot 释放计划。

现金贷例子：新建 Mexico iOS Campaign 前先确认业务假设、Quota Pool、预期样本量和退出规则。

误区：只按剩余 Quota 决定能不能建；真正还要看业务必要性。

关系：Quota Registry、MMP、AdAttributionKit、First-loan CAC、FPD/Vintage。

八、AI Agent / 自动化治理

AI Agent

理解高层目标、读取上下文、调用工具并执行动作的 AI 系统。

MCP

Model Context Protocol，标准化 AI Agent 调用外部工具的协议层。

MCP Tool

具体动作，如 get report、update budget、pause ad group。

Human-in-the-loop / HITL

AI 分析/建议，高风险动作仍由人工确认。

Approval Gate

Write 操作执行前的数据成熟、风险、合规与权限闸门。

Rollback

异常变更恢复到上一个稳定配置。

Kill Switch

出现合规、风险或技术异常时立即停止自动化 Write 权限。

九、金融广告准入与 Mexico

Restricted Vertical

受限行业，如金融、博彩、医药，通常有额外准入和内容要求。

Advertiser Eligibility

广告主是否有资格在目标国家推广某金融产品。

Ad Review

针对具体 Ad/Creative、文案和 Landing Page 的审核。

TikTok Financial Services Policy

Mexico 当前：当地/区域许可、必要披露、18+；may-be-allowed 示例含 mortgage、consumer finance、P2P、BNPL；明确禁止示例含 APR ≥50% High APR Loan、Payday Loan、≤90 天 Short-term Loan。

TikTok 官方

Google Personal Loans

只允许需要 61 天或以上才能全部偿还的 personal loan，并要求 LP/App 显著披露最短/最长期限、最高 APR/当地等效口径和代表性总成本。

Google 官方
