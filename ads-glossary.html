一、金融广告准入与平台治理｜2026-08-28 重点

合规

Restricted Vertical

中文：受限行业/受限垂类。金融、博彩、医药等通常会比普通商品广告有额外准入要求。

现金贷：不能只按普通广告流程“建 Campaign → 审素材”，要先确认市场、产品、主体和平台许可。

TikTok

Financial Services Policy

TikTok 对金融服务按市场设置的广告政策。规则会按国家与产品类别更新。

墨西哥当前关键点：当地/区域许可、TikTok Sales Representative application permission、18+，并核对禁止类别。

TikTok 官方原文
Policy

Market-specific Requirements

中文：市场特定要求。同一平台对不同国家的允许/禁止产品、资质、年龄和 disclosure 可能不同。

误区：把美国/加拿大或其他市场限制直接套到 Mexico。

准入

Advertiser Eligibility

中文：广告主资格。回答“这个主体是否有资格在这个国家推广这个金融品类”。

现金贷：需要核对 advertiser entity、lender entity、牌照/许可、账户主体和产品类型。

准入

Platform Permission

中文：平台许可/额外准入。即便当地法律允许、广告主有资质，平台仍可能要求额外申请后才允许投放。

TikTok Mexico：当前官方市场段落要求通过 TikTok Sales Representative 的 application process 取得 permission。

TikTok

Sales Representative Permission

中文：TikTok 销售代表许可。不是普通客服咨询，而是金融广告准入流程中的平台 permission。

建议 evidence：审批邮件、ticket、case ID、账户/产品范围、有效期或书面确认。

准入

Application Process

中文：平台申请流程。通常用于提交主体、许可证、产品和账户信息以取得受限垂类投放许可。

行业术语

Allowlisting / Whitelisting

中文：白名单/准入名单。行业常用词，不一定是平台当前官方措辞。

注意：TikTok 当前 Mexico 官方写法是通过 Sales Representative 的 application process 获取 permission；内部可以把它归入“allowlisting”，但对外应引用平台原文。

审核

Ad Review

中文：广告审核。针对具体 Ad/Creative、文案、目标 URL、Landing Page 等的审核。

关键区别：Ad Review 通过 ≠ Advertiser Eligibility / Platform Permission 已永久满足。

审核

Policy Rejection

中文：因平台政策被拒审/限制。原因可能来自行业准入、资质、文案、素材、LP、目标 URL、年龄或地区等。

审核

Appeal

中文：申诉/复审。对错误或有争议的审核结果申请重新评估。

现金贷：申诉材料应包含主体、牌照、产品说明、政策对照、页面截图和 permission evidence。

金融产品

P2P Lending

中文：点对点借贷。借款人与资金提供者通过平台撮合。

TikTok Mexico：当前 Financial Services Policy 的 Mexico 市场组禁止清单包含 P2P lending。

TikTok 官方
金融产品

Credit Repair

中文：信用修复服务。当前 TikTok Mexico 市场组禁止清单包含 credit repair services。

金融产品

Debt Consolidation / Refinancing

中文：债务整合/再融资。当前 TikTok Mexico 市场组禁止清单包含 debt consolidation services and refinancing。

治理

Eligibility Evidence

中文：准入证据。用于证明某国×平台×产品组合具备当前可投资格的可追溯证据：官方 URL、牌照、平台 permission、审批记录、reviewed_at。

内部产品

Financial Ads Eligibility Registry

中文：金融广告准入登记表。

字段：platform / country / product_type / business_model / advertiser_entity / lender_entity / license_status / platform_permission / age_gate / prohibited_category_check / disclosure_version / destination_url / evidence_url / status / reviewed_at / owner。

政策纠偏：2026-08-28 核对当前 TikTok Mexico 市场段落后，不再把“APR ≥50% / Payday Loan / ≤90 天”作为 TikTok 墨西哥当前明确规则引用。历史日报若有该说法，以今天的纠偏和当前官方页面为准。

二、账户结构与投放基础

Ads

广告，或广告平台/体系的泛称。Google Ads 是平台名；Ad 是具体广告；Ads 不等于 Campaign。

Campaign

广告系列/广告活动，位于 Ad Account 下、Ad Set/Ad Group 之上。

Ad Set

Meta 常用广告组层级，常承载受众、版位、预算/排期、优化事件。

Ad Group

Google/TikTok 常用广告组层级，用于管理相似关键词、受众、版位、Bid 或优化逻辑。

Ad

具体广告，由素材、文案、CTA 和目标链接组成。

Creative

广告素材/创意，含视频、图片、文案、Hook、CTA、UGC 脚本。

Asset Group

资产组/创意资产容器，用于组织素材、文案、URL 等。

Placement

广告版位，如 Feed、Stories、Reels、Search、Pangle/Audience Network。

Publisher

实际提供流量的媒体/发布商；现金贷应分 Publisher 看欺诈、授信、放款和 FPD。

Audience

受众，包括地区、年龄、自定义受众、相似人群、再营销。

Broad

宽泛定向。减少人工约束，让算法寻找转化人群；不要和 Search Broad Match 混淆。

Lookalike Audience

相似受众；现金贷种子优先使用成熟优质客户。

Retargeting

再营销/重定向，如安装未注册、注册未申请、审批未提款。

三、预算、出价与扩量

CBO

Campaign Budget Optimization，Campaign 级统一预算，由系统在多个 Ad Group/Ad Set 间分配。

Ad Group Budget / ABO

广告组级预算；ABO 是行业常用相对称呼。

Bid Strategy

决定平台更偏拿量还是围绕成本/价值目标控制效率。

Cost Cap

围绕设定 CPA 目标优化平均成本，不是每笔转化硬上限。

Maximum Delivery

以预算为主要约束，尽可能获取更多结果。

Learning Phase

平台积累转化信号、探索人群/素材/竞价组合的阶段。

Budget Pacing

预算在一天、小时或活动周期中的分配和消耗节奏。

Scale Guardrail

内部扩量护栏：加 Budget/Bid 前检查媒体、CAC、成熟度、FPD/Vintage、LTV，并支持回滚。

Bid Target Adjustment Tool

Google 用于检查 2026-08-17 起 Limited by budget + target-based bidding 变化影响的工具。

Google 官方

四、Google Search 与 AI Max

AI Max for Search

Google Search 的 AI 增强套件，不等于 Performance Max。核心是 Search Term Matching + Asset Optimization。

Google 官方

Search Term Matching

利用 broad match、素材与 Landing Page 等信号扩大/优化可触达查询。

Text Customization / ACA

根据域名、Landing Page、已有 Ads/Keywords 生成标题和描述。

Final URL Expansion / FUE

Google 可把用户送到同域名更相关 URL；金融广告必须治理 URL eligibility。

URL Inclusions

限制/指定可用于动态 Landing Page 的 URL 范围。

URL Exclusions

排除还款、催收、过期活动、无完整贷款披露等不应承接广告的页面。

RSA

Responsive Search Ad，响应式搜索广告。

Pinned Asset

固定某标题/描述位置；AI Max/FUE 某些场景下可能不按原方式遵循。

DSA

Dynamic Search Ads，动态搜索广告。

AI Max Experiment

在现有 Campaign 内做 Control/Treatment 的 AI Max 实验。

Landing Page Eligibility Registry

记录每个 URL 的产品、期限/APR/费用披露、主体、ad_eligible、fue_allowed 等。

五、TikTok Smart+、App 与 Search

Smart+

TikTok 自动化投放体系，可在 full / partial / manual 不同控制程度间切换。

TikTok 官方

App Promotion

应用推广目标/场景，用于 App Install、AEO、Retargeting 等。

MAI

Mobile App Install，移动应用安装优化。

AEO

App Event Optimization，应用内事件优化。

VBO

Value-Based Optimization，价值优化。

Spark Ads

使用品牌或授权创作者已发布 TikTok 原生内容进行广告放大。

Search Ads Campaign

通过 Keyword 参与 TikTok 搜索结果竞价。

Keyword

广告主希望购买的搜索意图。

Search Term / Query

用户实际输入的搜索词。

Match Type

Keyword 与 Search Term 允许差异的匹配规则。

Negative Keyword

明确排除不希望购买的搜索意图。

Keyword Planner

关键词搜索量、竞争和机会研究工具。

六、价值、归因、数据与实验

Value-based Bidding / VBB

基于 Conversion Value 而不是单纯转化数量出价。

Conversion Value

赋给转化的价值；现金贷不应直接把放款本金当利润型 value。

tROAS

Target ROAS，目标广告支出回报。

Split Test / A/B Test

随机分流、单变量比较不同方案。

Incrementality

回答“如果没有广告，这个转化是否仍会发生”。

Holdout

留出对照组估计真实增量。

MMP

Mobile Measurement Partner，移动归因/衡量合作伙伴。

SKAN / AdAttributionKit

Apple 隐私型广告归因体系。

Attribution Window

广告触达后多长时间内的转化有资格归因。

Attribution Model

多个触点都合格时决定信用如何分配。

Assisted Conversion

某渠道参与早期路径，但其他渠道完成最后一步。

Deep Link

让用户直接进入 App 指定页面。

Web-to-App

广告→Web LP→App Store/App→App 内转化。

Pixel

网页浏览器侧事件采集器。

Events API

TikTok 服务器侧营销事件回传接口。

Conversions API / CAPI

Meta 的服务器数据连接接口。

Event Deduplication

Browser + Server 同时报送时避免重复计数。

UTM Parameters

URL 营销追踪参数，如 utm_source、utm_medium、utm_campaign、utm_id。

七、素材与创意

Creative Fatigue

素材疲劳，常表现为 Frequency 上升、CTR/CVR 走弱、CPA 变差。

Hook

开头几秒吸引注意力的钩子；金融广告不能靠夸大承诺换点击。

UGC

User-Generated Content 或 UGC 风格内容。

CTA

Call To Action，行动号召。
