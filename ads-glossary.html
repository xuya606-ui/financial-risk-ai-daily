先理解账户层级

Ad Account → Campaign → Ad Set / Ad Group → Ad / Creative

Meta 常见 Campaign → Ad Set → Ad；Google Ads 和 TikTok 常见 Campaign → Ad Group → Ad。不同平台的预算、出价、受众和优化事件设置层级并不完全一致。

基础

Ads

中文：广告，或广告体系的泛称。

例：Google Ads 指平台；“这条 Ad CTR 高”指具体广告。

误区：Ads 不是 Campaign 的同义词。

账户结构

Campaign

中文：广告系列/广告活动。

层级：广告账户下，Ad Set/Ad Group 上。

现金贷例：Mexico_NewUser_Disburse 可作为墨西哥新客放款 Campaign。

误区：拆太细会稀释样本、影响学习。

账户结构

Ad Set

中文：广告组（Meta 常用）。

常承载受众、版位、预算/排期、优化事件等。

账户结构

Ad Group

中文：广告组（Google/TikTok 常用）。

管理相似关键词、受众、版位或优化逻辑的广告。

素材

Creative

中文：广告素材/创意。

视频、图片、文案、Hook、封面、CTA、UGC 脚本等。

现金贷：不能只看 CTR，还要看 Apply CVR、CAC、FPD。

流量

Placement

中文：广告版位。

如 Feed、Stories、Reels、Search、Audience Network。

流量

Publisher

中文：流量媒体/发布商。

第三方网络中应分 Publisher 看欺诈率、授信率、放款率和 FPD。

定向

Audience

中文：受众。

包括地区、年龄、自定义受众、相似人群、再营销人群等。

定向

Broad

中文：宽泛定向。

减少人工限制，让算法自主寻找转化用户；现金贷必须同步看风险质量。

定向

Retargeting

中文：再营销/重定向。

面向访问未安装、安装未注册、注册未申请、审批未提款等用户。

算法

Optimization Event

中文：优化事件。

告诉平台最希望系统寻找哪一种行为。现金贷可从 Install 逐步测试 Apply、Disburse 等更深事件。

算法

Learning Phase

中文：学习期。

平台积累转化信号、探索人群/版位/出价组合的阶段；频繁改预算和事件会增加波动。

TikTok

Smart+

中文：TikTok 自动化投放体系。

自动化越强，深层事件回传和后端用户质量越重要。

官方原文：TikTok Smart+

Google

Performance Max / PMax

中文：效果最大化广告系列。

Google 跨多种资源自动寻找转化机会。

官方原文：Google PMax

Google

Demand Gen

中文：需求开发广告。

偏视觉化、发现式需求拓展；不能直接拿 Search 的 CPA 门槛机械比较。

官方原文：Google Demand Gen

Google

UAC / App Campaign

中文：Google 应用广告系列。

行业仍常叫 UAC；Google 当前称 App campaigns。

官方原文：Google App campaigns

App优化

AEO

App Event Optimization｜应用内事件优化

不只优化安装，而是寻找更可能完成某个 App 内事件的人。

现金贷：可测试 KYC Complete / Apply；事件太深但量不足会学不动。

官方原文：TikTok AEO

价值优化

VBO

Value-Based Optimization｜价值优化

从“是否转化”升级到“转化价值有多高”。

现金贷：价值信号应偏向风险调整贡献/LTV，避免直接用放款金额奖励高风险大额用户。

App优化

MAI

Mobile App Install｜移动应用安装目标

适合冷启动或深层事件量不足阶段，但后续要穿透到 Apply、Disburse、FPD。

归因

MMP

Mobile Measurement Partner｜移动归因/衡量合作伙伴

连接广告点击/展示与安装、注册、申请、放款等 App 事件，支持跨渠道归因和反作弊。

iOS归因

SKAN / StoreKit Ad Network

中文：苹果隐私保护广告归因机制。

影响 iOS 归因粒度、回传延迟和深层事件设计。

官方原文：Apple StoreKit Ad Network

归因

Attribution Window

中文：归因窗口。

点击/展示后多长时间内的转化可以归给这次广告。不同平台窗口不同，不能直接用后台 CPA 横比。

回传

Postback

中文：转化回传/回调。

MMP 或服务器把安装/事件结果发送给广告平台。

回传

S2S / Server-to-Server

中文：服务器对服务器回传。

放款、还款等后端事件适合 S2S；必须有 event_id 和去重逻辑。

产品

Deep Link

中文：深度链接。

把用户直接打开到 App 内指定页面，而不是只进首页。

现金贷例：已 KYC 用户从 Search 广告直达 Apply。

官方原文：Google App Connect / Deep linking

Google

App Connect

中文：Google Ads 的 Web↔App 连接中心。

用于 Deep Link、App conversion tracking 和 Web/App 协同优化。

现金贷：适合 Search/PMax 等 Web Campaign 把已安装 App 用户送到正确业务页面。

官方原文：Google：About App Connect

实验

Deep Linking A/B Test

中文：深链 A/B 测试。

Google App Connect 中对比“流量进入 App”与“继续走移动 Web”的受控实验。

适用：当前官方说明主要面向符合条件的 Search Campaign。

官方原文：Google：About the A/B test

实验

UHA

Users Who Have App｜已安装 App 用户

App Connect A/B test 中用于观察真正有能力被 Deep Link 导入 App 的用户子集。

为什么重要：整体流量含未安装用户，可能稀释 Deep Link 的真实效果。

归因

Conversion Lag

中文：转化延迟。

从广告点击/曝光到最终转化被记录之间的时间差。

现金贷：Apply、Disburse、FPD 的成熟速度不同，实验不能只看头几天。

Google

Primary Conversion

中文：主要转化操作。

在 Google Ads 中用于报告和/或自动出价优化的核心 conversion action。App Connect A/B test 要求 Web/App 都有可出价的 Primary Conversion。

现金贷：应明确平台优化的是 Register、Apply 还是更深事件。

技术

Redirect URL

中文：重定向链接。

先经过中间地址再跳到最终目的地。Google App Connect A/B test 对 redirect URL 有兼容性风险，官方建议使用 direct deep link。

官方原文：Google：Fix A/B test issues

出价

Bid Strategy

中文：出价策略。

平台如何决定每次竞价出多少钱，如 Maximize Conversions、tCPA、tROAS、Cost Cap 等。

预算

Budget Pacing

中文：预算节奏。

控制预算在一天/时段/活动周期内如何消耗。

官方原文：TikTok Time-based pacing

受众

Lookalike Audience

中文：相似受众。

用种子人群找相似新用户；现金贷应优先用优质放款/正常还款用户做种子。

搜索

Keyword Match

中文：关键词匹配方式。

常见 Broad、Phrase、Exact；最终仍按首贷 CAC 和风险质量判断。

素材

Hook

中文：素材开头钩子。

前几秒/第一屏抓注意力的表达；金融类不能用虚假额度、保证放款等误导钩子。

素材

UGC

User-Generated Content｜用户生成内容风格素材

更像真实用户分享；金融类不能伪造审批结果或收益。

素材/产品

CTA

Call to Action｜行动号召

如 Apply Now、Check Eligibility、Learn More；应与真实下一步一致。

【墨西哥重点】术语必须穿透到后端经营指标

“Campaign CPA 很低”“AEO 学习稳定”“Deep-link uplift 很高”都只是投放/体验层结论。对墨西哥现金贷，还要继续检查 Approve Rate、Disburse Rate、首贷 CAC、FPD/Vintage、LTV、Payback 与 ROI。
