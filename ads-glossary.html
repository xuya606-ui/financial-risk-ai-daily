一、账户结构与投放基础

基础

Ads

中文：广告，或广告平台/体系的泛称。Google Ads 是平台名；Ad 是具体广告。Ads 不等于 Campaign。

账户结构

Campaign

中文：广告系列/广告活动。位于 Ad Account 下、Ad Set/Ad Group 上。现金贷例：Mexico_NewUser_Disburse。

Meta

Ad Set

中文：广告组（Meta 常用）。常承载受众、版位、预算/排期、优化事件。

Google/TikTok

Ad Group

中文：广告组。管理相似关键词、受众、版位或优化逻辑。

账户结构

Ad

中文：具体广告。通常由素材、文案、CTA 和目标链接组成。

素材

Creative

中文：广告素材/创意。视频、图片、文案、Hook、封面、CTA、UGC 脚本等。现金贷应继续看 Apply CPA、CAC、FPD。

素材

Asset Group

中文：资产组/创意资产容器，用于组合素材、文案和 URL。

流量

Placement

中文：广告版位。如 Feed、Stories、Reels、Search、Pangle/Audience Network。

流量

Publisher

中文：流量媒体/发布商。第三方流量应结合欺诈率、授信率、放款率、FPD 看质量。

定向

Audience

中文：受众。包括地区、年龄、自定义受众、相似人群、再营销等。

定向

Broad

中文：宽泛定向。减少人工限制，让算法找转化用户；不要与 Search 的 Broad Match 混淆。

定向

Lookalike Audience

中文：相似受众。现金贷种子优先使用优质、成熟 Cohort，而不是只用安装用户。

定向

Retargeting

中文：再营销/重定向。访问未安装、安装未注册、审批未提款等都是典型对象。

二、算法、出价与价值优化

算法

Optimization Event

中文：优化事件。告诉平台最希望找到什么行为；事件越深越接近业务价值，但需要足够样本。

出价

Bid Strategy

中文：出价策略。如 Maximize Conversions、tCPA、Maximize Conversion Value、tROAS、Cost Cap、Highest Value。

算法

Learning Phase

中文：学习期。系统积累转化信号、探索人群/版位/出价组合的阶段。

预算

Budget Pacing

中文：预算节奏。控制预算在一天、小时或活动周期内如何消耗。

官方原文：TikTok Time-based pacing

App

AEO

App Event Optimization｜应用内事件优化。从安装升级到优化指定 App 事件。

App

MAI

Mobile App Install｜移动应用安装。

价值优化

VBO

Value-Based Optimization｜价值优化。从“是否转化”升级到“转化价值多高”。TikTok App VBO 可使用 Highest Value 或 Target ROAS。

现金贷：不要把 loan amount 直接当业务 value；应先定义风险调整价值。

官方原文：TikTok App VBO

Google / 通用

Value-based Bidding / VBB

中文：基于价值的出价。算法不是只追求转化数量，而是根据不同 Conversion Value 优化总价值。

关系：Maximize Conversion Value 和 Target ROAS 都属于价值型 Smart Bidding。

现金贷例：两个 Disburse 数量相同的 Campaign，如果成熟风险调整贡献不同，价值型评价应优先保留更高贡献的一方。

常见误区：把放款本金、审批额度或敏感信用属性直接作为广告价值。

官方原文：Google Value-based Smart Bidding

Value

Conversion Value

中文：转化价值。用于表达不同转化对业务的相对/商业价值。

现金贷：内部可建立 Risk-adjusted Value；真正外发的平台 value 必须满足平台数据政策与隐私要求。

官方原文：Google Conversion Values Best Practices

Google

Maximize Conversion Value

中文：最大化转化价值。Google Smart Bidding 策略，在预算内尽量取得最大总 conversion value。

与 tROAS 的区别：无 target 时更偏“在预算内拿最多 value”；加入 ROAS 目标后更关注效率约束。

官方原文：Google Maximize conversion value

出价

Target ROAS / tROAS

中文：目标广告支出回报。告诉算法希望平均实现的 conversion value / cost 比例。

App Campaign：Google 官方说明 tROAS 需要 Firebase，并依赖带动态 value 的 first-party in-app event。

官方原文：Google App Campaign bidding

TikTok

Highest Value

中文：最高价值出价。TikTok VBO 的一种策略，目标是在预算内获得尽可能高的总 value。

官方原文：TikTok App VBO

Value

Dynamic Value / Dynamic Revenue Value

中文：动态价值。不同转化事件传入不同 value，而不是所有转化使用同一个固定值。

现金贷：必须有稳定、可解释、可版本化的 value 生成逻辑。

Google

Conversion Value Rules

中文：转化价值规则。Google 可按支持的条件调整 conversion value，并用于报告与价值型 Smart Bidding。

Credit 注意：Google 明确提示，Housing、Employment、Credit 相关广告的部分条件可能不可用。

官方原文：Google Conversion Value Rules

Google

Bid Target Adjustment Tool

中文：出价目标调整工具。Google 用于帮助检查/调整受 2026-08-17 target-based bidding 变化影响的 Campaign。

当前状态：Google FAQ 表示 rollout 是渐进式；工具未显示时会随着部署继续自动开放。

官方原文：Google Target-based bidding FAQ

TikTok

Smart+

中文：TikTok 自动化投放体系。

官方原文：TikTok Smart+ Upgraded Experience

Google

Performance Max / PMax

中文：效果最大化广告系列。跨多个 Google 库存自动寻找转化机会。

Google

Demand Gen

中文：需求开发广告。偏视觉/发现式流量，意图与 Search 不同。

Google

UAC / App Campaign

中文：Google 应用广告系列。可优化安装、应用内行为和价值。

官方原文：Google App Campaign bidding

TikTok

App Promotion

中文：应用推广目标/场景，用于安装或应用内行为获客。

三、Search 搜索投放

Search

Search Ads Campaign

中文：搜索广告系列。根据 Keyword 参与搜索结果竞价。

Search

Keyword

中文：关键词。广告主主动选择的搜索意图。

Search

Search Term / Query

中文：搜索词/实际查询。用户真实输入内容；与 Keyword 不同。

Search

Match Type

中文：关键词匹配方式。

Search

Broad Match

中文：广泛匹配。量大但需加强 Search Terms 和后端质量监控。

Search

Phrase Match

中文：词组匹配。

Search

Exact Match

中文：精确匹配。平台仍可能覆盖近义/语义变体。

Search

Negative Keyword

中文：否定关键词。明确排除不想购买的搜索意图。

Search

Keyword Planner

中文：关键词规划工具。

四、归因、数据连接与事件治理

归因

MMP

Mobile Measurement Partner｜移动归因/衡量合作伙伴。连接广告触达与安装、注册、申请等 App 事件。

Apple

SKAN / AdAttributionKit

中文：Apple 隐私型广告归因体系。

归因

Attribution Window

中文：归因窗口。规定广告触达后多长时间内的转化有资格归因。

归因

CTC

Click-through Conversion｜点击后转化。

归因

EVC

Engaged-view Conversion｜互动观看后转化。

归因

VTC

View-through Conversion｜浏览后转化。

归因

Attribution Model

中文：归因模型。多个触点都在窗口内时决定信用如何分配。

归因

Last Click

中文：末次点击归因。

数据

Conversion Lag

中文：转化延迟。

内部治理

Conversion Maturity

中文：转化成熟度。

归因

Postback

中文：事件/归因回传。

数据

S2S / Server-to-Server

中文：服务器到服务器回传。

产品

Deep Link

中文：深度链接，直接进入 App 指定页面。

链路

Web-to-App

中文：网页到 App 的获客/转化链路。

数据连接

Pixel

中文：网页浏览器事件采集器。

TikTok

Events API

中文：TikTok 服务器事件回传。

Meta

Conversions API / CAPI

中文：Meta 服务器数据连接。

数据质量

Event Deduplication

中文：事件去重。

数据质量

Event Match Quality / EMQ

中文：事件匹配质量。数据连接健康不等于授信/风险质量。

五、广告主信任与增量归因

Google Policy

Limited Ad Serving

中文：限制广告展示。未被判定为合格广告主时，部分场景可能受限。

官方原文：Google Limited ad serving

Google Policy

Qualified Advertiser

中文：合格广告主。属于广告主信任/资格评估，不等于金融牌照。

Google

Advertiser Verification

中文：广告主验证。

TikTok

Attribution Analytics

包含 Attribution Window、Time to Conversion、Touchpoints、Assisted 等分析。

官方原文：TikTok Attribution Analytics

TikTok

Referred Conversion

中文：最后触点/直接归因转化。

TikTok

Assisted Conversion

中文：辅助转化。TikTok 参与早期路径，但其他渠道完成最后一步。

Journey

Touchpoint

中文：触点。转化前的一次可记录广告互动/曝光。

Measurement

Incrementality

中文：增量性。回答“没有这笔广告，这个转化还会不会发生”。

Experiment

Holdout

中文：留出对照组，用于估计真正增量。

Tracking

UTM Parameters

中文：URL 营销追踪参数，如 utm_source、utm_medium、utm_campaign、utm_id。

六、素材与创意

TikTok

Spark Ads

中文：原生内容放大广告。

素材

Creative Fatigue

中文：素材疲劳。

素材

Hook

中文：开头钩子。金融广告不能以夸大承诺换 CTR。

素材

UGC

User-Generated Content｜用户生成内容/UGC 风格。

素材

CTA

Call To Action｜行动号召。

【墨西哥重点】所有术语最终都要回到合规 + 风险 + 利润

“Campaign CPA 低”“VBO ROAS 高”“Assisted 很高”“Qualified Advertiser”“EMQ 高”都只是局部信号。墨西哥现金贷最终仍要穿透到 Approve Rate、Disburse Rate、成熟首贷 CAC、FPD/Vintage、Risk-adjusted LTV，并满足金融广告准入和数据使用边界。
