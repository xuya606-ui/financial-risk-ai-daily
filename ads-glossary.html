Ads广告/广告体系广告业务的泛称；Google Ads 也可指平台名称。泛概念Mexico consumer loan ads。泛指广告投放。把 Ads 当成固定账户层级。应与 Ad、Campaign 区分。
Ad Account广告账户承载账单、权限、事件源和 Campaign 的账户容器。账户层Mexico TikTok Ads Account。权限、资产、账单管理。与 Business Center/Manager Account 混同。上接 Business Center，下接 Campaign。
Campaign广告系列围绕 Objective、Budget、Bid Strategy 组织投放的高层容器。账户下MX_TT_App_NewUser。按目标/产品/实验拆分。无限拆分导致信号过碎。下接 Ad Set/Ad Group。
Ad Set广告组（Meta）Meta 常用层级，用于 Audience、Placement、Budget、Optimization 等设置。Campaign 下MX Broad Android。人群/版位/预算实验。与 Google/TikTok Ad Group 直接等同。Meta 专有命名。
Ad Group广告组Google/TikTok 常用层级，承载 Audience、Bid、Keyword、Placement、Creative 等。Campaign 下MX Lead Higher Intent。出价/定向/表单设置。跨平台字段完全照搬。下接 Ad/Creative。
Ad具体广告实际审核并展示给用户的广告单元。广告层贷款期限/费用透明型视频广告。素材测试。只看 Campaign 不看单 Ad。关联 Creative、CTA、URL/Form。
Creative广告素材/创意视频、图片、文案、Hook、CTA、UGC 等构成的素材资产。素材层Mexico 信任型素材。CTR/CVR/质量测试。CTR 高就判定优质。应连接 Qualified Lead、CAC、FPD/LTV。
Placement版位广告展示的位置或流量环境。Ad Set/Ad Group 配置TikTok Feed、Search、Ad Network。流量结构拆分。与 Publisher 混为一谈。Network 下还可拆 Publisher。
Publisher媒体发布者Ad Network 中真正承载广告的具体 App/网站。Network 下游第三方 App Publisher。反作弊/质量治理。只按 CPI 拉黑。Placement → Network → Publisher。
Audience受众平台用于定向或探索潜在用户的集合。定向层Mexico 18+ broad users。Prospecting/Retargeting。把 Audience 当信用风险标签。Broad、Retargeting。
Broad宽泛定向/广泛匹配给算法更大探索空间；Search 中也可指 Broad Match。受众/关键词策略Mexico Broad Audience。拓量。Broad=完全不受控制。仍受 Event、Budget、Policy Guardrail 约束。
Retargeting再营销再次触达曾访问、安装或互动但未完成目标的人群。受众策略KYC 未完成用户召回。漏斗召回。与催收/风险营销混用。Deep Link、Audience、Attribution。
Conversion转化被定义为营销或业务目标的动作。事件层Register、Apply、Disburse。优化/衡量。只写 Conversion 不写事件名。CPA、Optimization Event。
Optimization Event优化事件平台算法重点寻找的目标行为。算法目标从 Install 升级到 Valid Apply。深层优化。越深越好，不看事件量和延迟。Learning Phase、Signal Density。
Learning Phase学习期平台积累信号并探索受众、素材和出价的阶段。算法状态新 Mexico Lead Campaign 初始学习。新建/大改后。频繁修改导致学习波动。Budget、Bid、Event。
Upgraded Smart+TikTok 升级版 Smart+把 Manual 与 Smart+ 统一到同一创建流程，可按模块采用 full automation、partial automation 或 fully manual；支持 Traffic、Sales、Lead Generation、App Promotion。TikTok Campaign 体系Mexico Lead Campaign 让 Audience 自动探索，但锁定 Destination 与 Disclosure。需要兼顾算法扩量和控制时。Smart+=必须全自动。TikTok 官方
Automation Surface自动化控制面把自动化拆成 Audience、Budget、Placement、Bid/Optimization、Creative、Destination 等可独立治理模块。治理概念自动 Audience + 手动 Placement + 锁定贷款 URL。解释 Smart+ 配置差异。只用 Smart+/Manual 二元字段。与 automation_version、Guardrail 配合。
Full Automation全自动化尽可能把可用模块交给平台算法自动配置或探索。自动化策略Audience、Budget、Placement、Creative 都开放自动。信号充分、产品稳定时。认为无需合规/业务约束。TikTok 官方
Partial Automation部分自动化部分模块交由算法，部分模块保留人工控制。自动化策略自动 Audience + 自动 Budget，但手动 Placement/URL。金融/高约束业务常用。把部分自动化理解成“半失效”。TikTok 官方
Audience Controls受众控制Upgraded Smart+ 下用于设置最低边界的受众参数，如 Location、Minimum Age、Language、Exclude Audience。TikTok TargetingMexico + 18+ 作为金融广告基础边界。自动定向但需要底线约束。把 Controls 当精准定向。TikTok 官方
Audience Suggestions受众建议给自动定向模型提供引导信号，而不是强制边界。TikTok Targeting建议 25–44 岁用户，但仍允许模型探索。需要给算法方向时。把 Suggestion 当硬限制。TikTok 官方
Custom Targeting手动/自定义定向切换到更精细的手动定向配置。TikTok Targeting特定设备/兴趣/行为组合。需要更强控制时。越精准一定越高效。TikTok 官方
Automatic Campaign Budget自动 Campaign 预算输入一个 Campaign 预算，由系统在 Ad Groups 间自动分配。TikTok Budget多个 Mexico Ad Group 共享预算池。让算法跨组分配时。无法解释增量去向。TikTok 官方
Custom Ad Group Budgets自定义广告组预算为不同 Ad Group 单独设置预算和优化参数。TikTok BudgetBrand/Non-brand 或不同产品线独立预算。需要业务配额/实验控制。预算拆太细导致学习不足。TikTok 官方
Creative Combination Control素材组合控制控制自动生成/组合的视频、文本等资产，并查看组合表现。TikTok Creative贷款视频 + 合规文案组合。大素材池自动优化。让系统自由改写金融事实。TikTok 官方
Asset Group资产组在升级版 Smart+ 中，单个 Ad 可类似 Asset Group，拥有独立 Destination、Product Set 和多项 Creative Assets。TikTok Ad/Creative同一 Campaign 下不同贷款页面和素材池。多 URL/多素材治理。Asset Group=Ad Group。TikTok 官方
Automatic Placement自动版位平台自动选择符合条件的版位以优化结果。Placement StrategyTikTok/Ad Network 自动分配。扩量。无法再拆 Publisher 质量。与 Select Placement 相对。
Select Placement选择版位升级版 Smart+ 可在支持场景下手动选择版位。TikTok Placement只保留 TikTok Feed，排除不适配的流量。需要流量环境控制。手动版位一定更好。TikTok 官方
Recommended Creatives推荐创意Smart+ Symphony 中的 GenAI 工具，可根据网站/表现生成或推荐素材资产。TikTok Creative AI生成贷款素材候选，再进入合规审核。扩充素材池。AI 生成后可直接上线金融广告。TikTok 官方
Automatic Enhancements自动增强自动进行尺寸适配、质量增强、翻译、配音等素材优化。TikTok Creative AIes-MX 视频自动字幕/配音。多语言/多版位素材扩展。自动翻译不会改变金融含义。TikTok 官方
Destination Guardrail落地目的地约束对 Landing URL/App Destination/Deep Link 建立产品版本、披露版本、合规和回滚约束。产品治理只有完成期限/APR/总成本披露 QA 的 URL 可被自动化使用。AI/自动化多 URL 场景。只审核广告素材，不审核目的地。与 disclosure_version、Product Version 绑定。
Smart+TikTok Smart+ 自动化投放TikTok 的 AI-powered campaign automation 体系。TikTok CampaignMexico App/Lead Smart+。规模化投放。自动化=无需 Guardrail。TikTok 官方
PMax / Performance MaxGoogle 效果最大化广告Google 跨渠道自动化 Campaign 类型，使用目标、素材和转化信号跨 Google Inventory 优化。Google CampaignWeb-to-App 或品牌增长场景。跨渠道自动化。与 App Campaign/UAC 混同。Google 官方
Demand GenGoogle Demand Gen面向 YouTube、Discover、Gmail 等视觉化需求生成场景的 Campaign。Google Campaign贷款品牌/教育型素材触达。中上层漏斗与转化。等同 Search。Google 官方
UAC / App CampaignGoogle 应用广告系列Google 面向 App Install/In-app Action 的自动化 Campaign。Google App UAMexico Android 现金贷拉新。App 安装/事件优化。仍使用旧名 UAC 就认为产品逻辑没变化。Google 官方
MMP / Mobile Measurement Partner移动归因平台跨渠道测量 App Install、Re-engagement 和 Post-install Events 的第三方平台。Measurement把 TikTok/Google/Apple 安装归因到 App 用户。移动归因与对账。MMP 就是唯一真实值。与 SKAN/AdAttributionKit/SAN/S2S 配合。
Deep Link深度链接把用户直接打开到 App 内指定页面的链接机制。产品/归因广告点击直达 KYC 或优惠券页。Web-to-App、召回。没有 Fallback 也没关系。Deferred Deep Link、Fallback、MMP。
Web-to-App网页到 App 链路用户先进入 Web/LP，再通过 Deep Link/App Store 进入 App。增长产品链路Google Search → LP → App KYC。搜索/内容承接。只看 Web Conversion。LPV、Deep Link、MMP。
AEO / App Event Optimization应用事件优化以特定 In-app Event 作为优化目标。App Optimization优化 Completed KYC。安装后深层事件。事件越深越好。与 MAI、VBO、Event Volume 相关。
VBO / Value-Based Optimization价值优化用 Conversion Value 让算法优化更高价值转化。Optimization只能使用合规、非敏感的业务价值信号。有稳定 Value 体系时。把用户级信用风险直接上传平台。与 tROAS、Value Schema 相关。
MAI / Mobile App Install移动应用安装以 App Install 为主要目标的投放/优化方式。App UAMexico 新用户安装。冷启动、量级不足。安装成本低就代表业务好。CPI、AEO、Disburse。
SKAN / SKAdNetworkApple 隐私归因框架（旧称）Apple 的隐私保护移动广告归因框架；目前演进到 AdAttributionKit 体系。iOS AttributioniOS Campaign 使用匿名 Postback 衡量安装/事件。iOS 隐私归因。SKAN Postback 可以用户级匹配。Apple 官方
Attribution Window归因窗口广告互动与 Conversion 之间允许被归因的最大时间范围。AttributionClick 7d、View 1d 等。跨平台对账。不同平台窗口不一致仍直接比较 CPA。与 Conversion Lag、Reporting Gap 相关。
Postback回传平台、MMP 或归因框架把归因/转化信息发送给广告主或服务器的数据消息。MeasurementSKAN/AdAttributionKit Postback。归因与事件回传。Postback=实时且用户级。S2S、Dedup、Delay。
S2S / Server-to-Server服务器到服务器回传后端直接向平台或测量系统发送事件。Measurement InfrastructureBackend Valid Apply 回传。提高事件稳定性。无需 event_id/去重。Events API、MMP、Dedup。
AdServices Attribution APIApple Ads AdServices 归因 APIApple Ads 的隐私归因接口，提供 Campaign、Placement、Ad Group、Keyword 等层级的 Apple Ads 归因信息；仅使用 Apple first-party data。Apple Attribution评估 App Store Search Results 广告带来的下载。Apple Ads 归因。AdServices 能看见所有第三方广告触点。Apple 官方
AdAttributionKitApple 广告归因框架Apple 提供的隐私保护跨广告网络归因框架；在已注册网络中采用相应归因逻辑并限制可返回的数据粒度。Apple Attribution对比 Apple Ads 与其他已注册 App 广告网络。iOS 跨渠道测量。与 AdServices 完全相同。Apple 官方
tCPA / Target CPA目标转化成本告诉平台希望围绕某个优化事件达到的平均目标成本。BiddingApply tCPA=200 MXN。稳定事件量下的自动出价。tCPA=首贷 CAC。Business-derived Target、Actual CPA。
tROAS / Target ROAS目标广告支出回报让算法围绕目标 Conversion Value/Spend 优化。Bidding用合规 Value Schema 优化高价值事件。有稳定 Value 信号时。把放款本金直接等同利润价值。VBO、ROAS。
TopSearchTikTok 搜索首位广告竞得后展示在对应关键词第一条 Sponsored Position 的 Search Ads 方案。TikTok Search品牌/高意图搜索词。搜索可见度。没赢第一位会自动下沉。TikTok 官方
Impression Share搜索展示份额获得的符合资格 Search Impressions 占可获得 Eligible Impressions 的比例。TikTok Search Metric判断高质量搜索词是否还有扩量空间。Search 扩量诊断。Share 低就一定加预算。TikTok 官方
