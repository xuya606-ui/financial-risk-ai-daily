二、2026-09-10 新增：Landing Page / Web Traffic

2026-09-10

Landing Page View / LPV

中文：落地页成功加载/落地页浏览。

准确解释：TikTok Traffic Objective 下的优化目标；只有用户点击广告且目标 Landing Page 成功加载时才计入。该指标由 TikTok 在页面加载时计算。

层级/类别：TikTok Traffic Optimization / Page Event。

现金贷例子：用户点击 Mexico préstamo 广告并成功打开 H5 贷款说明页，计 1 次 LPV。

适用场景：Web-to-App、H5 预审页、页面加载质量治理。

常见误区：LPV=GA Page View/Session；LPV 高=首贷质量高。

关系：Click、Traffic Objective、Default Page View、View Content、Smart+ Traffic。

TikTok 官方原文

Click

中文：广告点击。

准确解释：用户对广告执行点击动作；它只证明发生点击，不证明目标页面已经成功加载。

层级/类别：Interaction / Traffic Metric。

现金贷例子：点击“查看可借额度”但弱网下页面未打开。

适用场景：CTR、CPC、Click→LPV 漏斗。

常见误区：把 Click 当作有效网站访问。

关系：LPV、CTR、CPC。

Traffic Objective

中文：流量目标。

准确解释：TikTok Campaign Objective，用于获取网站/页面访问；当前可按 Click 或 LPV 等目标优化。

层级/类别：TikTok Campaign Objective。

现金贷例子：Mexico 上层 H5 贷款教育/预审页面引流。

适用场景：上层流量、像素信号不足、Web-to-App 前段。

常见误区：深层 Apply 事件量已经足够仍长期只优化 Traffic。

关系：Smart+ Traffic、LPV、Smart+ Web。

TikTok 官方原文

Smart+ Traffic Campaign

中文：TikTok Smart+ 流量广告。

准确解释：使用 TikTok AI 自动化帮助扩大高质量网站流量的 Smart+ Campaign；官方当前建议主要目标为 Click/LPV 时使用，而有 Pixel/Events API 且要推动具体网站 Conversion 时优先考虑 Smart+ Web。

层级/类别：TikTok Smart+ / Traffic Campaign。

现金贷例子：Mexico 贷款知识页/预审页先优化 LPV，再验证 Apply 质量。

适用场景：流量上层、页面质量测试。

常见误区：Smart+ Traffic=自动优化到首贷；它仍取决于所选 Optimization Goal。

关系：Traffic Objective、LPV、Smart+ Web。

TikTok 官方原文

Default Page View

中文：默认页面浏览事件。

准确解释：由广告主通过 TikTok Pixel / Events API 向 TikTok 分享的网站页面事件；不是 TikTok 计算的 LPV。

层级/类别：Website Event / Measurement。

现金贷例子：H5 页面脚本成功触发并回传 Page View。

适用场景：网站事件分析、Pixel/Events API。

常见误区：与 LPV、GA Page View 完全等同。

关系：LPV、View Content、Pixel、Events API。

TikTok 官方原文

View Content

中文：查看内容事件。

准确解释：广告主通过 Pixel/Events API 分享的页面/内容浏览事件，具体触发逻辑由站点事件配置决定。

层级/类别：Website Conversion Event。

现金贷例子：用户成功打开“贷款产品详情/费用说明”页面并触发 View Content。

适用场景：中上层网站事件衡量。

常见误区：只要页面加载就一定等于同一次 TikTok LPV。

关系：Default Page View、LPV、Pixel/Events API。

TikTok 官方原文

Instant Page

中文：TikTok 即时页面。

准确解释：TikTok 体系内承载的落地页类型，LPV 当前支持第三方 Landing Page 与 TikTok Instant Page。

层级/类别：TikTok Landing Page Product。

现金贷例子：用即时页面承载合规贷款教育，再引导到 App/站点。

适用场景：希望减少外部网页加载损耗的流量承接。

常见误区：Instant Page 可以绕过贷款披露或目标国家金融广告政策。

关系：LPV、Traffic Objective、Landing Page。

TikTok 官方原文

Lowest Cost

中文：最低成本出价。

准确解释：TikTok 的一种竞价策略，在预算约束下尽量获取更多所选优化结果；LPV 当前支持 Lowest Cost。

层级/类别：TikTok Bidding Strategy。

现金贷例子：LPV 冷启动阶段先以 Lowest Cost 获取页面到达信号。

适用场景：不设置明确单次成本上限的扩量。

常见误区：最低媒体成本=最低首贷 CAC。

关系：Cost Cap、Optimization Event、Budget。

TikTok LPV 官方可用性

Cost Cap

中文：成本上限/目标成本约束。

准确解释：TikTok 竞价策略之一，围绕广告主设置的目标成本管理交付；LPV 当前支持 Cost Cap。

层级/类别：TikTok Bidding Strategy。

现金贷例子：对 Cost/LPV 设置约束，同时仍用首贷 CAC 和风险作业务 Guardrail。

适用场景：需要平衡规模与成本稳定。

常见误区：Cost Cap 是每一次转化绝不超过的硬上限。

关系：Lowest Cost、LPV、Bid Strategy。

TikTok LPV 官方可用性

Matched-cell Test

中文：匹配单元对照测试。

准确解释：内部实验方法：在平台原生 Split Test 不可用时，用尽量可比的人群、素材、预算、时间等构造 Control/Treatment，并只改变一个核心变量。

层级/类别：Experiment Design / Internal Governance。

现金贷例子：两个 Mexico Ad Group 分别优化 Click 与 LPV，其他条件尽量一致。

适用场景：LPV 当前与 TikTok Split Test 不兼容时的受控验证。

常见误区：Matched cell 等同随机实验；它仍可能有流量分配偏差。

关系：A/B Test、Control、Treatment、Incrementality。

TikTok 官方：LPV 当前不支持 Split Test

Landing Page Performance Contract

中文：落地页性能与经营契约。

准确解释：内部跨团队治理方案，把页面技术性能、金融披露、埋点、Deep Link、产品漏斗和风险结果绑定到版本化验收。

层级/类别：Product + Growth Governance。

现金贷例子：lp_version → load_rate → apply → approve → disburse → fpd。

适用场景：Landing Page 改版、Web-to-App、流量规模扩张。

常见误区：页面提速只由研发负责；或为了速度删除必要披露。

关系：LPV、Disclosure Version、Deep Link、Backend Funnel。

三、2026-09-09：素材自动化与 Lead Quality

Auto-Selection for Lead Generation

中文：Lead Generation 自动素材选择。

准确解释：TikTok Q3 2026 公布的 Lead Generation 能力，可从品牌上传素材、Creator Content 与 AI-generated Content 中自动寻找、测试并放大高表现资产。

层级/类别：TikTok Lead Generation / Creative Automation。

现金贷例子：Mexico Lead Campaign 在合规素材池中自动轮转费用透明、KYC 引导、信任型素材。

适用场景：素材量大、需要持续测试与轮转时。

常见误区：把所有未审核素材直接交给算法；只按 CPL 让平台决定赢家。

关系：Custom Selection、Asset Pool、Creative Fatigue、Qualified Lead、Smart+。

TikTok 官方原文

Custom Selection

中文：自定义素材选择。

准确解释：与 Auto-Selection 配套的控制方式，广告主可主动加入、排除素材或采用平台推荐资产。

层级/类别：TikTok Creative Control。

现金贷例子：只允许 disclosure_version 当前有效的贷款素材参与选择。

适用场景：受监管品类、产品参数频繁变化、需要人工合规门槛时。

常见误区：以为 Custom Selection 就不需要持续监控素材质量。

关系：Auto-Selection、Compliance Whitelist、Asset Eligibility。

TikTok 官方原文

Creative Fatigue

中文：素材疲劳。

准确解释：受众反复接触相似素材后，注意力、互动或转化效率逐步下降。

层级/类别：Creative Performance。

现金贷例子：“快速借款”视频曝光频次持续上升，CTR/CVR 逐步下降。

适用场景：常青素材、大预算扩量、Smart+/自动轮转。

常见误区：只看 CTR；忽略 KYC/Approve/FPD 等后端质量漂移。

关系：Auto-Selection、Creative Quality Drift、Frequency。

Asset Pool

中文：素材资产池。

准确解释：允许某个 Campaign/自动化系统调用的一组视频、图片、文案、Creator/AI 素材。

层级/类别：Creative Operations。

现金贷例子：Mexico 新客贷款 Campaign 的合规视频、图片、CTA 统一池。

适用场景：Auto-Selection、Smart+、多素材轮转。

常见误区：资产池只记录文件，不记录产品版本、批准状态和失效时间。

关系：Compliance Whitelist、Creative Asset Registry、Auto-Selection。

Compliance Whitelist / Asset Eligibility

中文：合规白名单 / 素材可选资格。

准确解释：内部治理机制：只有通过法务/产品/平台要求检查、且 disclosure_version 仍有效的素材才能进入自动选择池。

层级/类别：Compliance + Creative Governance。

现金贷例子：期限/APR/费用或主体变化后，旧版素材自动变成 Ineligible。

适用场景：金融 Auto-Selection、AI 素材、Creator 素材。

常见误区：广告审核通过=产品事实永远有效。

关系：Asset Pool、Disclosure Version、Creative Asset Registry。

Qualified Lead

中文：合格线索。

准确解释：已满足业务定义的最低有效资格、值得进入下一阶段申请/审批流程的线索。

层级/类别：Lead Lifecycle / Business Event。

现金贷例子：完成基础身份校验、联系方式有效、形成可评估申请意向的用户；具体定义需由业务固定。

适用场景：Lead Quality、深层优化、渠道/素材比较。

常见误区：由平台把任何表单提交都叫 Qualified。

关系：Lead、Valid Application、Approve、Qualified Lead CPA。

CRM Sync

中文：CRM 同步。

准确解释：将广告线索与 CRM/后端业务状态连接，使后续 Qualified/Apply/Disburse 等阶段可被运营和测量。

层级/类别：Data / Lead Operations。

现金贷例子：lead_id → user_id → application_id → loan_id。

适用场景：Lead Gen、Web-to-App、深层事件回传。

常见误区：只同步手机号，不保存 campaign/creative/event_id，后续无法归因。

关系：S2S、MMP、Lead Quality Feedback Loop。

SIPRES

英文/全称：Sistema de Registro de Prestadores de Servicios Financieros。

中文：墨西哥金融服务提供者登记系统。

准确解释：CONDUSEF 提供的金融机构登记查询系统，消费者可用于核验机构相关登记信息。

层级/类别：Mexico / CONDUSEF / Trust & Compliance。

现金贷例子：品牌在信任教育页引导用户核验正规主体，并确保展示名称与实际登记主体一致。

适用场景：用户信任、主体核验、反诈骗教育。

常见误区：把“在 SIPRES 可查”误当作对具体广告、产品费率或单笔贷款的全面合规背书。

关系：CONDUSEF、Montadeudas、Financial Services Policy。

CONDUSEF SIPRES 官方查询

Montadeudas

中文：“网贷陷阱/敲诈型贷款 App”常用称呼。

准确解释：CONDUSEF 用于提醒消费者的一类非法/欺诈贷款 App 风险，可能涉及欺骗性贷款、过度权限、骚扰、威胁或敲诈。

层级/类别：Mexico Consumer Protection / Fraud Pattern。

现金贷例子：合法 App 通过费用透明、最小权限、主体可核验和隐私说明与此类风险体验区分。

适用场景：墨西哥市场信任建设、反诈骗教育、权限/隐私设计。

常见误区：把任何高成本贷款都直接称为 Montadeudas。

关系：SIPRES、CONDUSEF、Trust Creative、Permissions。

CONDUSEF 官方

四、2026-09-08：Google Target-based Bidding

Target CPA / tCPA

中文：目标每次转化成本。

解释：平台尝试以指定平均目标成本获取转化。

类别：Google Smart Bidding。

例子：Search 优化 Apply，tCPA=200 MXN。

误区：把 tCPA 当首贷 CAC或单笔硬上限。

关系：Actual CPA、Optimization Event、Business-derived Target。

Google 官方

Target ROAS / tROAS

中文：目标广告支出回报率。

解释：平台最大化 conversion value，同时尝试达到设置的平均 ROAS。

类别：Value-based Bidding。

例子：用合规、稳定的风险调整 Value 信号优化。

误区：把放款本金直接当利润型 conversion value。

关系：VBO、Conversion Value、Risk-adjusted LTV。

Google 官方

Limited by budget

中文：受预算限制。

解释：Campaign 因平均日预算限制而无法捕获全部符合条件流量。

类别：Google Campaign Status。

例子：Mexico Search 核心贷款词有流量但 Budget 卡住。

误区：看到状态就直接加预算，不先检查 target 和首贷 CAC。

关系：Target CPA、Target ROAS、Target Gap。

Target Gap

中文：目标差距。

解释：平台 target 与成熟实际表现之间的差距。

类别：内部投放治理。

例子：tCPA=400、成熟实际=240。

误区：只因为 Gap 大就机械下调，不看业务允许 CAC 与延迟。

关系：Business-derived Target、Mature Actual CPA。

Business-derived Target

中文：业务反推目标。

解释：从 Allowable First-loan CAC、成熟漏斗和 Risk-adjusted LTV 反推平台 target。

类别：经营→投放翻译层。

例子：Allowable CAC=800、Apply→Disburse=25%，Apply tCPA≈200。

误区：业务参数变了仍长期沿用旧 target。

关系：First-loan CAC、FPD、LTV、Target Gap。

五、归因 / 平台 / 产品补充

Attribution Analytics

中文：TikTok 归因分析。

解释：分析窗口、Time to Conversion、Referred/Assisted 等客户旅程。

类别：TikTok Measurement。

例子：识别 TikTok 先影响、Search 后转化的路径。

误区：Assisted=Incremental。

SAN — Self-Attributing Network

中文：自归因网络。

解释：媒体平台自身识别符合归因规则的 App 转化并与 MMP 集成。

类别：App Measurement。

误区：SAN 上线后 MMP 不再需要。

关系：MMP、CTA/EVTA/VTA。

PineDrama

中文：TikTok 体系短剧 App / Placement。

类别：TikTok Placement。

例子：Mexico Smart+ 的新增流量环境。

误区：Mexico 可用=所有账户都已开放。

SDK Spoofing

中文：SDK 请求伪造。

类别：移动反作弊。

例子：MMP Apply 很多但 Backend 无对应申请。

误区：平台有转化就一定有真实用户。

Install Hijacking

中文：安装归因劫持。

类别：归因欺诈。

例子：Organic 安装被某 Publisher 抢归因。

Device Farm

中文：设备农场。

类别：反作弊。

例子：安装便宜但 KYC/Approve 极低且 IP/设备聚集。

六、金融广告准入与 Mexico

TikTok Financial Services Policy

中文：TikTok 金融服务广告政策。

类别：平台政策。

解释：Mexico 当前要求当地/区域许可、必要披露、18+；禁止示例含 APR≥50% High APR Loan、Payday Loan、≤90 天 Short-term Loan。

现金贷例子：上线前核对期限/APR/主体。

适用：TikTok Mexico。

误区：其他国家规则直接套 Mexico。

TikTok 官方

Google Personal Loans

中文：Google 个人贷款广告政策。

类别：Google Ads Policy。

解释：只允许需要 61 天或以上才能全部偿还的 personal loan，并要求 LP/App 显著披露最短/最长期限、最高 APR/当地等效口径和代表性总成本。

现金贷例子：Mexico Search LP Disclosure Audit。

适用：Direct lender、Lead Generator、Connector。

误区：广告文案写 APR 就能省略 LP 披露。

Google 官方
