一、账户结构与投放基础

基础

Ads

中文：广告，或广告平台/广告体系的泛称。

例：Google Ads 指平台；“这条 Ad CTR 高”指具体广告。

误区：Ads 不是 Campaign 同义词。

账户结构

Campaign

中文：广告系列/广告活动。

层级：广告账户下，Ad Set/Ad Group 上。

现金贷例：Mexico_NewUser_Disburse 可代表墨西哥新客放款 Campaign。

误区：拆太细会稀释转化样本。

Meta

Ad Set

中文：广告组（Meta 常用）。

常承载受众、版位、预算/排期、优化事件等。

Google/TikTok

Ad Group

中文：广告组。

管理相似关键词、受众、版位或优化逻辑的广告；TikTok Search 关键词在 Ad Group 层管理。

素材

Creative

中文：广告素材/创意。

视频、图片、文案、Hook、封面、CTA、UGC 脚本等。

现金贷：不能只看 CTR，还要看 Apply CPA、CAC、FPD。

流量

Placement

中文：广告版位。

如 Feed、Stories、Reels、Search、Pangle/Audience Network 等。

流量

Publisher

中文：流量媒体/发布商。

第三方网络中应按 Publisher 看欺诈率、授信率、放款率与 FPD。

定向

Audience

中文：受众。

地区、年龄、自定义受众、相似人群、再营销人群等。

定向

Broad

中文：宽泛定向。

减少人工受众限制，让算法寻找转化用户。不要与 Search 的 Broad Match 混淆。

定向

Retargeting

中文：再营销/重定向。

面向访问未安装、安装未注册、注册未申请、审批未提款等用户。

定向

Lookalike Audience

中文：相似受众。

用种子用户找相似新客；现金贷优先用优质放款/正常还款用户，而不是只用安装用户。

算法

Optimization Event

中文：优化事件。

告诉平台最希望找到哪种行为；现金贷可从 Install 逐步测试 Apply、Disburse 等更深事件。

算法

Learning Phase

中文：学习期。

系统积累转化信号、探索人群/版位/出价组合的阶段；频繁改参数会增加波动。

出价

Bid Strategy

中文：出价策略。

平台如何决定竞价出价，如 Maximize Conversions、tCPA、tROAS、Cost Cap、Highest Value。

预算

Budget Pacing

中文：预算节奏。

控制预算在一天、小时或活动周期内如何消耗。

官方原文：TikTok Time-based pacing

二、TikTok Smart+ 与创意体系

TikTok

Smart+

中文：TikTok 自动化投放体系。

2026 年 8 月升级后，Manual 与 Smart+ 进入统一创建流程，可选择全自动、部分自动或手动控制，并支持更灵活的多 Ad Group、创意组合与预算管理。

现金贷：自动化越强，深层事件回传与创意/产品一致性越重要。

官方原文：TikTok Smart+ Upgraded Experience

TikTok/素材

Spark Ads

中文：原生内容放大广告。

把品牌自己或经授权创作者的 organic TikTok post 作为广告素材；推广带来的播放、评论、点赞、分享和关注会归到原 organic post。

现金贷例：用已合规审核的“申请流程说明”品牌账号视频做 Spark Ads。

误区：原生感强 ≠ 可减少费率/期限披露；互动高也不代表 FPD 好。

官方原文：TikTok：About Spark Ads

TikTok/素材

Non-Spark Ads

中文：非 Spark 广告。

广告素材不直接绑定某个原生 organic post。适合标准化批量素材测试，但不会把推广互动沉淀到某个 organic post。

关系：可与 Spark Ads 做受控对照，但必须保持受众/事件/LP 等大变量尽量一致。

Smart+

Asset Group

中文：资产组/创意资产容器。

TikTok 升级 Smart+ 中，一个 Ad 可以像 Asset Group 一样承载创意、文案、URL、产品集等；官方说明可组合最多 50 个创意资产。

现金贷：按产品版本或内容主题分 Asset Group，避免不同期限/费用内容混用。

官方原文：TikTok Smart+ upgrade

Smart+

Paid & Organic Optimization

中文：付费与自然流量联合优化。

在部分 Smart+ 场景中，TikTok 可把 paid 和 organic 信号联合用于投放，并提供平台侧的统一结果视角。

适用：已有稳定 organic 内容、且账户开放该功能时。

误区：不是所有账户都可用，且自然互动不能直接等价为业务利润。

官方原文：TikTok Paid & Organic Optimization

Smart+

Organic Anchor / Anchor Link

中文：自然内容锚点链接。

在支持场景下给 organic post 增加可点击目的地链接，用于把自然内容的兴趣导向网站或 App。

现金贷：锚点必须落到与视频所述产品一致的页面，不能“视频讲 A 产品，链接跳 B 产品”。

Smart+

Multi-URL

中文：多目标 URL 能力。

升级 Smart+ 支持同一广告组/活动中管理多个目标 URL。

风险：现金贷多 URL 会显著增加创意—产品—披露错配风险，必须做 URL 与产品版本映射。

AI素材

Recommended Creatives

中文：推荐创意。

Smart+ Symphony 相关能力，可根据已有输入/表现推荐或生成更多创意资产。

现金贷：AI 生成或推荐后仍需人工检查额度、期限、APR/费用、资格和保证性表述。

官方原文：TikTok Smart+ upgrade

AI素材

Automatic Enhancements

中文：自动素材增强。

可做尺寸适配、质量增强、翻译、配音等自动处理。

现金贷：翻译/配音后的金融术语必须复核，特别是 APR、期限、费用和“批准/放款”措辞。

素材

Creative Fatigue / Ad Fatigue

中文：素材疲劳。

同一受众反复看到相似素材后，CTR/CVR 逐步下降、频次上升、成本变差的现象。

判断：结合 Frequency、CTR、CVR、CPA 与受众覆盖一起看，不以单日 CPA 波动定义疲劳。

治理

Creative Registry

中文：素材台账（内部治理概念）。

把 creative_id、脚本版本、CTA、URL、产品期限/费用、国家、审批状态与业务表现集中管理。

价值：Smart+ 资产池越大，越需要可审计的素材版本管理。

三、Google / App / 归因

Google

Performance Max / PMax

中文：效果最大化广告系列。

Google 跨多种资源自动寻找转化机会；现金贷必须把平台 value 穿透到风险调整价值。

官方原文：Google PMax

Google

Demand Gen

中文：需求开发广告。

偏视觉化、发现式需求拓展；不要直接拿 Search 的 CPA 阈值机械比较。

官方原文：Google Demand Gen

Google/App

UAC / App Campaign

中文：Google 应用广告系列。

行业仍常叫 UAC；Google 当前称 App campaigns。

官方原文：Google App campaigns

TikTok/App

App Promotion

中文：应用推广目标。

用于 App 安装或应用内事件。注意：TikTok Search Ads 与 Smart+ App Campaign 是不同产品路径；Smart+ App Campaign 当前官方设置明确 Search placement 不支持。

官方原文：TikTok Smart+ App Campaigns

App优化

AEO

App Event Optimization｜应用内事件优化

不只优化安装，而是寻找更可能完成指定 App 事件的人。

价值优化

VBO

Value-Based Optimization｜价值优化

从“是否转化”升级到“转化价值多高”；现金贷 value 应偏风险调整贡献/LTV，而不是只回传放款金额。

App优化

MAI

Mobile App Install｜移动应用安装

适合冷启动/深层事件量不足阶段，但必须继续追 Apply、Disburse 与 FPD。

归因

MMP

Mobile Measurement Partner｜移动归因/衡量合作伙伴

连接广告点击/展示与安装、注册、申请、放款等 App 事件，支持跨渠道归因与反作弊。

iOS

SKAN / StoreKit Ad Network

中文：苹果隐私保护广告归因机制。

影响 iOS 归因粒度、回传延迟与深层事件设计。

官方原文：Apple StoreKit Ad Network

归因

Attribution Window

中文：归因窗口。

点击/展示后多长时间内的转化可以归给这次广告；不同平台窗口不同，后台 CPA 不宜直接横比。

回传

Postback

中文：转化回传/回调。

MMP 或服务器把安装/事件结果发送给广告平台。

回传

S2S / Server-to-Server

中文：服务器对服务器回传。

放款、还款等后端事件适合 S2S；必须有 event_id、幂等、重试和去重。

产品

Deep Link

中文：深度链接。

把用户直接打开到 App 内指定页面，而不是只进首页。

Google

App Connect

中文：Google Ads Web↔App 连接中心。

用于 Deep Link、App conversion tracking 和 Web/App 协同优化。

官方原文：Google App Connect

实验

Deep Linking A/B Test

对比“进入 App 指定页”和“继续移动 Web”的受控实验。

实验

UHA

Users Who Have App｜已安装 App 用户

用于观察真正可被 Deep Link 导入 App 的用户子集。

归因

Conversion Lag

中文：转化延迟。

点击/曝光到目标转化被记录的时间差；现金贷 Apply、Disburse、FPD 的成熟速度不同。

四、Search 搜索投放

TikTok Search

Search Ads Campaign

使用关键词在 TikTok Search Results Page 触达主动搜索用户。

官方原文：TikTok Search Ads setup

搜索

SRP / Search Results Page

中文：搜索结果页。

用户输入查询后看到结果的页面，也是 Search Ads 核心版位。

搜索

Keyword

中文：关键词。

广告主主动选择、希望匹配某类搜索意图的词或短语；TikTok Search 在 Ad Group 层管理。

搜索

Search Term / Query

中文：用户真实搜索词。

必须与 Apply、Approve、Disburse、FPD 串起来，才能判断搜索意图价值。

搜索

Match Type

中文：关键词匹配方式。

决定 Keyword 与 Search Term 要多接近才可竞价；TikTok 主要包括 Broad、Phrase、Exact。

搜索

Broad Match

中文：广泛匹配。

覆盖最大、探索性强；必须配合 Search Terms Report 和 Negative Keywords。

搜索

Phrase Match

中文：词组匹配。

比 Broad 更收窄，但仍按语义/意图理解，不是机械逐字包含。

搜索

Exact Match

中文：精确匹配。

覆盖最窄，但平台仍可能匹配同义/近义和语义变体，不等于字符完全一致。

搜索

Negative Keyword

中文：否定关键词。

明确排除不希望触发广告的查询；现金贷可排除与实际业务不符的房贷、车贷、企业贷等意图。

搜索

Keyword Planner

中文：关键词规划工具。

投放前查看搜索量、竞争度与关键词机会；TikTok 官方支持 Mexico。

搜索

Automatic Search Placement

中文：自动搜索版位。

把其他广告自动扩展到搜索结果环境；不同于广告主手选关键词的 Search Ads Campaign。

搜索

Search Terms Report

中文：搜索词报告。

展示实际触发广告的用户查询，是扩词、否词和判断真实意图质量的核心报表。

搜索

Keyword Quality

中文：关键词质量/相关性。

用于判断关键词与广告内容是否相关；搜索量大不代表业务质量高。

五、素材表达

素材

Hook

中文：素材开头钩子。

前几秒抓注意力的表达；金融类不能用虚假额度、保证放款等误导性钩子。

素材

UGC

User-Generated Content｜用户生成内容/UGC 风格

更像真实用户分享；金融类不得伪造审批结果、收益或用户身份。

素材/产品

CTA

Call to Action｜行动号召

如 Apply Now、Check Eligibility、Learn More；CTA 应与真实下一步和资格条件一致。

【墨西哥重点】任何术语都要回到经营与合规

“Smart+ 自动化”“Spark Ads 互动高”“Campaign CPA 低”“Search CTR 高”都只是投放层结论。对墨西哥现金贷，必须继续看产品是否满足平台准入、广告与 LP 是否一致，以及 Approve Rate、Disburse Rate、首贷 CAC、FPD/Vintage、LTV、Payback 与 ROI。
