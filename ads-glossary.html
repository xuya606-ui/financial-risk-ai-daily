先理解账户层级

Ad Account → Campaign → Ad Set / Ad Group → Ad / Creative

Meta 常见 Campaign → Ad Set → Ad；Google Ads 和 TikTok 常见 Campaign → Ad Group → Ad。不同平台的预算、出价、受众、关键词和优化事件设置层级并不完全一致。

基础

Ads

中文：广告，或广告体系的泛称。

例：Google Ads 指平台；“这条 Ad CTR 高”指具体广告。

误区：Ads 不是 Campaign 的同义词。

账户结构

Campaign

中文：广告系列/广告活动。

层级：广告账户下，Ad Set/Ad Group 上。

现金贷例：Mexico_NewUser_Disburse 可作为墨西哥新客放款 Campaign。

误区：拆太细会稀释样本、影响学习。

账户结构

Ad Set

中文：广告组（Meta 常用）。

常承载受众、版位、预算/排期、优化事件等。

账户结构

Ad Group

中文：广告组（Google/TikTok 常用）。

管理相似关键词、受众、版位或优化逻辑的广告。TikTok Search Ads 的关键词就是在 Ad Group 层管理。

素材

Creative

中文：广告素材/创意。

视频、图片、文案、Hook、封面、CTA、UGC 脚本等。

现金贷：不能只看 CTR，还要看 Apply CVR、CAC、FPD。

流量

Placement

中文：广告版位。

如 Feed、Stories、Reels、Search、Audience Network。

流量

Publisher

中文：流量媒体/发布商。

第三方网络中应分 Publisher 看欺诈率、授信率、放款率和 FPD。

定向

Audience

中文：受众。

包括地区、年龄、自定义受众、相似人群、再营销人群等。

定向

Broad

中文：宽泛定向。

减少人工限制，让算法自主寻找转化用户；现金贷必须同步看风险质量。不要和 Search Ads 的 Broad Match 混淆。

定向

Retargeting

中文：再营销/重定向。

面向访问未安装、安装未注册、注册未申请、审批未提款等用户。

算法

Optimization Event

中文：优化事件。

告诉平台最希望系统寻找哪一种行为。现金贷可从 Install 逐步测试 Apply、Disburse 等更深事件。

算法

Learning Phase

中文：学习期。

平台积累转化信号、探索人群/版位/出价组合的阶段；频繁改预算和事件会增加波动。

TikTok

Smart+

中文：TikTok 自动化投放体系。

自动化越强，深层事件回传和后端用户质量越重要。

官方原文：TikTok Smart+ Upgraded Experience

Google

Performance Max / PMax

中文：效果最大化广告系列。

Google 跨多种资源自动寻找转化机会。

官方原文：Google PMax

Google

Demand Gen

中文：需求开发广告。

偏视觉化、发现式需求拓展；不能直接拿 Search 的 CPA 门槛机械比较。

官方原文：Google Demand Gen

Google

UAC / App Campaign

中文：Google 应用广告系列。

行业仍常叫 UAC；Google 当前称 App campaigns。

官方原文：Google App campaigns

TikTok/App

App Promotion

中文：应用推广目标。

用于推动 App 安装或应用内事件。TikTok 2026 年 8 月 Search Ads 设置文档把 App Promotion 列为支持目标之一，但具体市场/账户权限仍需看 Ads Manager。

现金贷：若墨西哥账户开放，可单独测试 Search→App；未开放则先用 Web Conversion。

官方原文：TikTok Search Ads setup

App优化

AEO

App Event Optimization｜应用内事件优化

不只优化安装，而是寻找更可能完成某个 App 内事件的人。

现金贷：可测试 KYC Complete / Apply；事件太深但量不足会学不动。

官方原文：TikTok AEO

价值优化

VBO

Value-Based Optimization｜价值优化

从“是否转化”升级到“转化价值有多高”。

现金贷：价值信号应偏向风险调整贡献/LTV，避免直接用放款金额奖励高风险大额用户。

App优化

MAI

Mobile App Install｜移动应用安装目标

适合冷启动或深层事件量不足阶段，但后续要穿透到 Apply、Disburse、FPD。

归因

MMP

Mobile Measurement Partner｜移动归因/衡量合作伙伴

连接广告点击/展示与安装、注册、申请、放款等 App 事件，支持跨渠道归因和反作弊。

iOS归因

SKAN / StoreKit Ad Network

中文：苹果隐私保护广告归因机制。

影响 iOS 归因粒度、回传延迟和深层事件设计。

官方原文：Apple StoreKit Ad Network

归因

Attribution Window

中文：归因窗口。

点击/展示后多长时间内的转化可以归给这次广告。不同平台窗口不同，不能直接用后台 CPA 横比。

回传

Postback

中文：转化回传/回调。

MMP 或服务器把安装/事件结果发送给广告平台。

回传

S2S / Server-to-Server

中文：服务器对服务器回传。

放款、还款等后端事件适合 S2S；必须有 event_id 和去重逻辑。

产品

Deep Link

中文：深度链接。

把用户直接打开到 App 内指定页面，而不是只进首页。

现金贷例：已 KYC 用户从 Search 广告直达 Apply。

官方原文：Google App Connect / Deep linking

Google

App Connect

中文：Google Ads 的 Web↔App 连接中心。

用于 Deep Link、App conversion tracking 和 Web/App 协同优化。

官方原文：Google：About App Connect

实验

Deep Linking A/B Test

中文：深链 A/B 测试。

Google App Connect 中对比“流量进入 App”与“继续走移动 Web”的受控实验。

官方原文：Google：About the A/B test

实验

UHA

Users Who Have App｜已安装 App 用户

App Connect A/B test 中用于观察真正有能力被 Deep Link 导入 App 的用户子集。

归因

Conversion Lag

中文：转化延迟。

从广告点击/曝光到最终转化被记录之间的时间差。

现金贷：Apply、Disburse、FPD 的成熟速度不同，实验不能只看头几天。

Google

Primary Conversion

中文：主要转化操作。

Google Ads 中用于报告和/或自动出价优化的核心 conversion action。

技术

Redirect URL

中文：重定向链接。

先经过中间地址再跳到最终目的地；Deep Link 实验中需注意兼容性和参数丢失。

官方原文：Google：Fix A/B test issues

出价

Bid Strategy

中文：出价策略。

平台如何决定每次竞价出多少钱，如 Maximize Conversions、tCPA、tROAS、Cost Cap 等。

预算

Budget Pacing

中文：预算节奏。

控制预算在一天/时段/活动周期内如何消耗。

官方原文：TikTok Time-based pacing

受众

Lookalike Audience

中文：相似受众。

用种子人群找相似新用户；现金贷应优先用优质放款/正常还款用户做种子。

TikTok Search

Search Ads Campaign

中文：搜索广告系列。

使用关键词把广告匹配给正在搜索相关内容的用户，广告主要出现在 TikTok Search Results Page。

层级：Campaign → Ad Group → Keyword / Ad。

现金贷：可用于承接主动搜索个人信贷/贷款服务的高意图用户，但金融服务属于受限行业，关键词需要审核。

官方原文：TikTok Search Ads setup

搜索

SRP / Search Results Page

中文：搜索结果页。

用户在 TikTok 输入搜索词后看到结果的页面，也是 Search Ads 的核心广告版位。

关系：Search Ads Campaign 是主动关键词投放；Automatic Search Placement 则是把其他广告自动延伸到搜索结果环境。

搜索

Keyword

中文：关键词。

广告主主动选择、用来告诉平台希望匹配什么搜索意图的词或短语。

层级：TikTok Search Ads 只在 Ad Group 层管理。

现金贷例：préstamo personal、crédito en línea 等合规且与真实产品一致的词。

误区：Keyword 不是用户真实搜索内容；后者叫 Search Term。

官方原文：TikTok Search Ads keywords

搜索

Search Term / Search Query

中文：搜索词 / 搜索查询。

用户真实在搜索框里输入的内容。

现金贷：应把 Search Term 与 Apply、Approve、Disburse、FPD 串起来，看哪类真实意图最有价值。

误区：只看 Keyword 表现，不看实际触发广告的 Search Terms。

搜索

Match Type

中文：关键词匹配方式。

决定 Keyword 与用户 Search Term 需要多接近才有资格参加竞价。TikTok 主要包括 Broad、Phrase、Exact。

关系：覆盖越宽通常量越大，但相关性控制更弱；现金贷要用 Search Terms Report + Negative Keywords 配合。

官方原文：TikTok 匹配类型

搜索

Broad Match

中文：广泛匹配。

用户搜索意图与你的 Keyword 相关即可进入匹配范围，覆盖最大、相关性控制相对最弱。

适用：冷启动、扩量、探索新查询；TikTok 建议尽可能使用 Broad 增加学习空间。

误区：Broad 后不看 Search Terms，容易买到无关意图。

搜索

Phrase Match

中文：词组匹配。

比 Broad 更收窄，但 TikTok 按语义/意图理解，不是简单的逐字包含。

适用：需要保留一定扩展空间，同时提高意图相关性。

搜索

Exact Match

中文：精确匹配。

覆盖最窄、相关性通常最高，但 TikTok 官方说明仍可能匹配近义词、同义表达、语序变化或语义改写，并不等于字符完全一致。

误区：以为 Exact 一定是逐字完全相同。

搜索

Negative Keyword

中文：否定关键词。

明确告诉平台哪些搜索查询不要触发你的广告。

现金贷例：如果只做无抵押个人贷款，可排除 hipoteca、crédito automotriz、préstamo empresarial 等无关意图。

注意：TikTok 不会自动把单复数、拼写错误、同义词都一起屏蔽，需要按实际 Search Terms 持续维护。

官方原文：TikTok Negative Keywords

搜索

Keyword Planner

中文：关键词规划工具。

在投钱前查看搜索量、竞争度和关键词机会，并把候选词加入计划或 Ad Group。

墨西哥：TikTok 官方列明 Mexico 在 Keyword Planner 支持地区中。

官方原文：TikTok Keyword Planner

搜索

Automatic Search Placement

中文：自动搜索版位。

把已有 Feed 广告自动扩展到 TikTok 搜索结果环境，不是传统的手工关键词 Search Ads Campaign。

区别：Search Ads Campaign 由广告主选 Keyword；Automatic Search Placement 由系统根据 App 名称、视频内容、URL、标题等自动判断搜索相关性。

官方原文：TikTok Automatic Search Placement

搜索

Search Terms Report

中文：搜索词报告。

展示实际触发广告的用户查询，是扩词、否词、判断关键词真实意图质量的核心报表。

现金贷：建议每周把 Search Term 关联到 Apply/Approve/Disburse/FPD，而不是只看 CTR/CPC。

搜索

Keyword Quality

中文：关键词质量 / 关键词-广告相关性。

TikTok 用关键词与创意的相关性、搜索量等帮助判断 Search Ad Group 是否健康。官方建议加入足够相关的词；Health Module 中“Relevant”状态要求超过 50% 的关键词至少与一个 Ad 相关。

误区：搜索量大就一定是好词；金融行业更要看合规和后端风险。

官方原文：TikTok Keyword Quality ｜ Health Module

素材

Hook

中文：素材开头钩子。

前几秒/第一屏抓注意力的表达；金融类不能用虚假额度、保证放款等误导钩子。

素材

UGC

User-Generated Content｜用户生成内容风格素材

更像真实用户分享；金融类不能伪造审批结果或收益。

素材/产品

CTA

Call to Action｜行动号召

如 Apply Now、Check Eligibility、Learn More；应与真实下一步一致。

【墨西哥重点】术语必须穿透到后端经营指标

“Search CTR 高”“Broad Match 量大”“Keyword Quality 健康”“Campaign CPA 很低”都只是投放层结论。对墨西哥现金贷，还要继续检查 Approve Rate、Disburse Rate、首贷 CAC、FPD/Vintage、LTV、Payback 与 ROI。
