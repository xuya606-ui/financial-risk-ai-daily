一、账户结构与素材

Ads

中文：广告/广告体系泛称。Google Ads 是平台名；Ad 是具体广告；Ads 本身不是固定层级。

常见误区：把 Ads、Ad、Campaign 混为一谈。

Ad Account

中文：广告账户。通常承载账单、权限、时区、事件源和多个 Campaign。

Campaign

中文：广告系列/广告活动。

层级：Ad Account 下、Ad Set/Ad Group 之上。

现金贷例子：Mexico_NewUser_Disburse_Search。

Ad Set

Meta 常用广告组层级，常配置 Audience、Placement、Budget/排期、Optimization Event。

Ad Group

Google/TikTok 常用广告组层级，用于组织 Keyword、Audience、Bid、Placement、Creative、URL。

Ad

具体广告，由视频/图片、标题、正文、CTA 与目标链接组成。

Creative

广告创意/素材，包括视频、图片、文案、Hook、CTA、UGC 脚本。现金贷不能只按 CTR 评价，要接 Approve/Disburse/FPD。

Hook

素材开头吸引注意力的“钩子”。金融广告不能靠保证放款、秒批等夸大承诺换 CTR。

UGC

User-Generated Content 或 UGC 风格内容。

CTA

Call To Action，行动号召，如 Apply Now / Learn More。

二、Placement / Publisher / TikTok Ad Network｜2026-09-04 新增

2026-09-04

Placement

中文：广告版位/流量环境。

解释：广告具体在哪里展示，如 TikTok、Search、Feed、Reels、TikTok Ad Network。

现金贷例子：同一 App Promotion Campaign 在 TikTok Feed 与第三方 App Network 上的用户质量可能完全不同。

误区：把不同 Placement 合并看 CPA。

Publisher

中文：媒体发布商/承载广告的 App 或网站。

解释：在第三方 Ad Network 中，真正产生 Impression/Click/Install 的具体媒体。

现金贷：必须按 Publisher 看 Fraud、Backend Verified Install、Approve、Disburse、FPD/LTV。

关系：Placement 是环境，Publisher 是环境中的具体流量来源。

TikTok Ad Network

旧称：TikTok Pangle。

解释：TikTok for Business 的第三方 App 广告网络。当前官方说明覆盖接近 40 万个 App/Publisher，并强调 Publisher 透明度、实时 anti-fraud 与第三方 post-bid brand safety measurement。

现金贷：可用于 App 获客扩量，但必须独立观察 Publisher 质量。

TikTok 官方｜September 2026

Pangle

中文：TikTok Ad Network 的旧名称/历史叫法。

注意：部分 Ads Manager、旧文档、MMP 或报表字段仍可能保留 Pangle 命名。看到 Pangle 时应与当前 TikTok Ad Network 口径映射。

Managed Account

中文：平台托管/客户经理管理账户。

解释：由 TikTok 销售/客户团队管理的广告账户，可用地区与能力可能不同于 Self-serve。

Mexico：当前 TikTok Ad Network managed accounts 的可投地区列表包含 Mexico。

TikTok 官方

Self-serve Account

中文：自助广告账户。

解释：广告主自行创建和管理；可投地区通常受 account region 限制。

现金贷：不能因为 managed account 文档支持某地区，就推断 self-serve 账户一定可用。

Block List

中文：媒体屏蔽名单。

解释：阻止 TikTok Ad Network 广告出现在指定不希望的媒体 App/Publisher。

现金贷：应基于成熟的 Fraud/CAC/FPD 证据进入 Observe→Limit→Block。

误区：只因单日 CTR/CPI 差就永久拉黑；TikTok 也提醒 Block List 会缩小流量并可能影响 Performance。

TikTok 官方

Post-bid Measurement

中文：竞价后第三方测量。

解释：广告已经投放后，由 DoubleVerify、IAS 等第三方独立评估 Brand Safety/Suitability 等质量。

关系：不等于业务 Fraud 检测；现金贷仍需 MMP + Backend 反作弊。

Brand Safety / Brand Suitability

中文：品牌安全/适宜性。

解释：控制广告是否出现在不适合品牌的内容或媒体环境。它解决“在哪里出现”，不直接解决“用户是否高风险”。

Hybrid Bidding

中文：混合出价。

所属：TikTok Ad Network oCPM 可用的 Bid Strategy 之一。

注意：与 Cost Cap、Maximum Delivery、Target ROAS 同属媒体出价策略，具体适用性以账户界面为准。

TikTok 官方

Standard Ad Delivery

中文：标准投放节奏。

在预算周期内相对平稳地消耗预算。

Accelerated Ad Delivery

中文：加速投放。

解释：更积极地获取可用流量、加快预算消耗。

现金贷：加速拿量前必须确认 Backend、风控和客服/审核容量能承接。

Endcard

中文：广告尾卡。

解释：TikTok Ad Network 可在视频/图片广告结尾自动附加互动卡片，可能引用 App Store 的 App icon、名称、评分、描述与 CTA。

现金贷：商店页描述必须与真实贷款产品、品牌主体和披露保持一致。

TikTok 官方

Publisher Quality Registry

中文：Publisher 质量登记表。

内部产品概念：记录 Publisher 的 Spend、Valid Install、Fraud、Approve、Disburse、CAC、FPD、LTV 与状态。

推荐状态：New → Observe → Eligible → Limited → Blocked → Re-test。

三、出价与自动化

Optimization Event

告诉平台最希望算法寻找什么行为，如 Install、Apply、Disburse。事件越深越接近经营价值，但需要足够样本量。

Bid Strategy

出价策略，决定平台更偏拿量、控 CPA 还是控 Value/ROAS。

Cost Cap

围绕目标 CPA 控制长期平均成本，并不是每笔转化硬上限。

Maximum Delivery

以 Budget 为主要约束，尽量获取更多结果。

Learning Phase

平台积累转化信号、探索人群/素材/版位/Bid 组合的阶段。

CBO

Campaign Budget Optimization，Campaign 级预算分配。

Smart+

TikTok 自动化投放体系，可自动化受众、版位、素材、Budget/Bid 等模块。

TikTok 官方

Performance Max / PMax

Google 跨 Search、YouTube、Display、Discover、Gmail、Maps 等资源的自动化 Campaign。

Demand Gen

Google 视觉化中下漏斗 Campaign，可覆盖 YouTube、Discover、Gmail、Maps、GDN 等库存。

UAC / App Campaign

Google 应用广告系列。行业仍常说 UAC，Google 当前通常称 App Campaign。

AEO

App Event Optimization，按应用内事件优化。

VBO

Value-Based Optimization，按事件价值优化。

MAI

Mobile App Install，移动 App 安装优化。

四、Agentic Advertising

TikTok Agentic Hub

TikTok AI Agent 解决方案/Skills 的发现与分发层。

TikTok 官方

TikTok for Business MCP Server

把 Campaign Management、Reporting、Audience、Creative Operations 等能力暴露给 AI Agent。

MCP

Model Context Protocol，标准化 AI Agent 发现和调用外部工具的协议层。

AI Agent

能够理解高层目标、读取上下文、调用工具并执行动作的 AI 系统。

AI Skill

把多个 Tool、规则和步骤组合成可复用业务工作流。

MCP Tool

具体可执行动作，如 get report、update budget、pause ad group。

Human-in-the-loop / HITL

AI 分析/建议，高风险动作仍由人工确认。

Approval Gate

Write 操作执行前必须通过数据成熟、风险、合规和权限检查。

Rollback

异常变更恢复到上一个稳定配置。

Kill Switch

出现合规、风险或技术异常时立即停止自动化 Write 权限。

五、Google Search / AI Max

AI Max for Search

Google Search AI 增强套件，包含 Search Term Matching、Text Customization、Final URL Expansion 等能力；不等于 PMax。

Google 官方

Keyword Prioritization

同一 Search Term 可被多个 Keyword/Search Theme 匹配时，Google 用匹配身份、AI relevance 与 Ad Rank 决定谁进入竞价。

Search Term / Query

用户实际输入的搜索内容。

Keyword

广告主设置、希望购买的搜索意图。

Match Type

Keyword 与 Search Term 允许差多远的规则，常见 Broad / Phrase / Exact。

Negative Keyword

否定关键词，用于排除不需要的搜索意图。

Text Customization / ACA

根据网站、现有 Ads 和 Keyword 自动创建/调整 Search 文案。

Final URL Expansion / FUE

Google 根据搜索意图将用户送到同域名更相关页面。现金贷需要 URL Eligibility Registry 与 Exclusion。

六、线索、转化与产品链路

Conversion

转化。现金贷必须说明具体事件：Install、Register、KYC、Apply、Approve、Disburse。

Lead Journey Mapping

把广告互动后的 Raw Lead、Qualified Lead、Converted Lead 与最终业务结果串成一个漏斗。

Raw Lead

刚产生的表单、消息、注册或申请，尚未完成资格验证。

Qualified Lead

通过最低业务资格验证、值得继续审批/跟进的 Lead。

Converted Lead

比 Qualified Lead 更接近最终结果的深层 Lead，可按公司定义为 Approve 或 Disburse。

Deep Link

广告、Push、短信等点击后直接打开 App 指定页面。

Web-to-App

广告 → Web LP → App Store/App → App 内转化。

七、归因、事件与反作弊

MMP

Mobile Measurement Partner。连接广告触达与 Install、Register、Apply、Disburse 等 App 事件。MMP 是归因层，不等于业务真相。

Pixel

浏览器侧事件采集器。

Events API

TikTok 服务器侧营销事件回传接口。

Conversions API / CAPI

Meta 服务器侧营销数据连接接口。

S2S / Server-to-Server

服务器到服务器事件或归因数据连接。

Postback

设备、MMP 或平台发送的归因/事件结果通知。

Event Deduplication

Browser + Server 同时上报同一事件时，利用 event_id 等避免重复计数。

Attribution Window

广告接触后多长时间内的转化仍有资格算给该广告。

Conversion Lag

广告互动到转化发生/被记录的延迟。

Incrementality

回答“如果没有广告，这个用户是否仍会转化”，通常需要 Holdout/Lift/Geo Experiment。

SDK Spoofing

攻击者模拟 SDK 请求，制造虚假 Install/In-app Event。

Install Hijacking

真实用户安装 App，但欺诈方伪造最后触点抢走归因。

Device Farm

批量真机、云设备或 Emulator 制造 Install/Event。

八、iOS 隐私归因

AdAttributionKit

Apple 隐私广告归因框架。

Apple 官方

SKAdNetwork / SKAN

Apple 隐私广告归因基础设施，数据聚合、延迟且粒度可能受隐私阈值限制。

Fine Conversion Value

细粒度转化值，用整数表示更细的漏斗/价值信号。

Coarse Conversion Value

粗粒度转化值，常见 low / medium / high；不等于信用风险高/中/低。

Reengagement

已安装用户通过可归因广告重新回到 App 并互动。

九、金融广告准入与墨西哥政策

Restricted Vertical

受限行业/垂类，如金融、博彩、医药，通常有额外准入和内容要求。

Advertiser Eligibility

广告主是否有资格在目标国家推广某金融产品。

Platform Permission

某些受限产品需要平台额外批准；不要扩大成“所有金融广告都必须白名单”。

Ad Review

针对具体 Ad/Creative、文案和 Landing Page 的审核。

TikTok Financial Services Policy

Mexico 当前：当地/区域许可、必要披露、18+；may-be-allowed 示例含 mortgage、consumer finance、P2P、BNPL；明确禁止示例含 APR ≥50% High APR Loan、Payday Loan、≤90 天 Short-term Loan。

TikTok 官方

Google Personal Loans

只允许需要 61 天或以上才能全部还清的 personal loan，并要求 LP/App 显著披露最短/最长期限、最高 APR/当地等效口径和代表性总成本。

Google 官方
