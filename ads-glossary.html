Attribution Analytics

中文：归因分析中心。

类别：TikTok Ads Manager Analytics/Measurement。

准确解释：TikTok 用于查看 CPA/Spend、Average Time to Conversion、不同 Click/View Attribution Window 表现，以及 Referred/Assisted Journey Impact 的分析模块。当前 Overview 页面标注 2026-09 更新。

现金贷例子：分析 TikTok 是否先影响用户，后续用户再通过 Search/Web 完成申请。

适用：理解非线性旅程、窗口差异和渠道参与。

常见误区：把 Attribution Analytics 当 MMP/Backend 替代品，或把 Assisted 直接当新增首贷。

关系：Referred、Assisted、Attribution Window、Conversion Lag、Incrementality。

TikTok 官方（Sep 2026）

Referred Conversion

中文：推荐/最后触点转化。

类别：TikTok Attribution Analytics。

解释：用户转化前最后一次互动来自 TikTok，因此 TikTok 是最终触点。

现金贷例子：用户点击 TikTok 后直接进入 Web/App 完成 Apply。

适用：理解 TikTok 的最终触点贡献。

误区：Referred 就等于广告真正新增的转化。

关系：与 Assisted 对照；两者都不等于 Incremental。

TikTok 官方

Assisted Conversion

中文：助攻转化。

类别：TikTok Attribution Analytics / Journey。

解释：TikTok 在更早的路径中被点击/观看，但最终转化前最后触点是搜索、直接访问或其他渠道。

现金贷例子：先看 TikTok 贷款教育素材，后从 Google 品牌词进入并申请。

适用：发现上游种草/发现价值。

误区：把 Assisted 数量直接加到 Last-click Loan，或用 Assisted 证明因果增量。

关系：需进一步用 Incrementality 验证。

TikTok 官方

CTA — Click-through Attribution

中文：点击归因。

类别：TikTok App/SAN Attribution Window。

解释：用户点击广告后，在设定天数内发生转化则可被 TikTok Ads Manager 归因。当前 SAN App 设置提供 1 天或 7 天。

现金贷例子：点击广告第 3 天完成 Apply，在 7d CTA 中可归因，在 1d CTA 中不计。

适用：App 报表口径。

误区：CTA 窗口设置会自动改变 MMP 报表。

关系：EVTA、VTA、MMP Window。

TikTok 官方

EVTA — Engaged View-through Attribution

中文：深度观看归因。

类别：TikTok App/SAN Attribution。

解释：用户达到 TikTok 定义的有效观看互动后，在窗口内转化所使用的归因类型。当前 SAN App 设置提供 1 天或 7 天。

现金贷例子：用户未点广告，但产生有效观看后几天完成申请。

适用：衡量视频深度观看影响。

误区：EVTA=用户点击；或 EVTA 转化一定是增量。

关系：CTA、VTA、Attribution Analytics。

TikTok 官方

VTA — View-through Attribution

中文：浏览归因。

类别：TikTok App/SAN Attribution。

解释：用户观看广告但未点击，随后在窗口内转化。当前 SAN App 设置为 Off 或 1 天。

现金贷例子：当天看到广告，稍后从其他入口打开 App 并 Apply。

适用：衡量曝光影响。

误区：把所有 VTA 视为广告直接创造的新增用户。

关系：与 EVTA、CTA、Incrementality 区分。

TikTok 官方

SAN — Self-Attributing Network

中文：自归因网络。

类别：TikTok App Measurement / MMP Integration。

解释：TikTok 自身识别符合窗口的 App 转化并向 MMP/Ads Manager 提供测量信号的集成方式；MMP 仍用于跨渠道/最终归因分析。

现金贷例子：TikTok Ads Manager 可能识别更多 TikTok 触点转化，但财务/业务仍用 MMP + Backend 成熟 Cohort 对账。

适用：App Campaign 归因。

误区：SAN 上线后 MMP 不再需要。

关系：CTA/EVTA/VTA、MMP、Backend。

TikTok 官方

PineDrama

中文：TikTok 体系短剧 App / 版位。

类别：TikTok Placement / Smart+ Inventory。

解释：独立短剧 App；TikTok 当前 Placement 文档列出 Mexico 可用，PineDrama Performance Auction 支持 Smart+ + Automatic Placement 下的 App Promotion、Lead Generation、Sales（非 TikTok Shop）。

现金贷例子：Mexico Smart+ App Promotion 的部分流量可能被分配到 PineDrama，需要单独看首贷 CAC 和 FPD。

适用：新增流量环境/短剧场景。

误区：Mexico 可用=你的账户一定已开放；或 Banco Azteca K-Drama 案例=PineDrama 案例。

关系：Placement、Automatic Placement、Creative Storytelling。

TikTok Placement 官方（Sep 2026） ｜ PineDrama 官方

Measurement Contract / Attribution Governance Registry

中文：测量契约 / 归因治理登记表。

类别：内部产品与数据治理。

解释：统一记录 Platform/MMP/Backend 的事件定义、Attribution Window、数据源、成熟时间、Schema Version 和责任人的治理机制。

现金贷例子：规定 Apply 以 Backend 为业务真相，TikTok/MMP 只保留归因维度；首贷与 FPD 必须成熟后才能做最终 ROI。

适用：多平台、多窗口、Web-to-App 对账。

误区：只写事件名不写来源/窗口/成熟度。

关系：MMP、SAN、S2S、Conversion Lag、Source of Truth。

三、归因 / 产品 / 反作弊补充词条

Incrementality

中文：增量效果。

解释：广告真正造成、如果没有广告就不会发生的额外转化。

类别：因果测量。

现金贷例子：Holdout 组与投放组比较新增首贷。

适用：预算价值验证。

误区：Assisted=Incremental。

关系：Holdout/Lift/Geo Experiment。

Conversion Lag

中文：转化延迟。

解释：广告互动到业务事件发生/记录的时间差。

类别：测量成熟度。

现金贷例子：Click→Disburse P50=2d/P90=6d。

适用：选择窗口和等待成熟。

误区：用未成熟 D0 数据直接比较渠道。

关系：Attribution Window、Maturity。

Event Deduplication

中文：事件去重。

解释：Browser/SDK/S2S 同报一个事件时用 event_id 等防重复计数。

类别：数据质量。

现金贷例子：Apply 同时由 SDK 与 Server 回传。

适用：多源回传。

误区：只按时间戳模糊去重。

关系：S2S、MMP、Events API/CAPI。

SDK Spoofing

中文：SDK 请求伪造。

解释：攻击者模拟 SDK 请求制造虚假安装/事件。

类别：移动反作弊。

现金贷例子：MMP Apply 很多但 Backend 无对应申请。

适用：联盟/Ad Network 流量审计。

误区：平台有转化就一定有真实用户。

关系：MMP-to-Backend Gap、Fraud Prevention。

Install Hijacking

中文：安装归因劫持。

解释：真实安装被欺诈方伪造最后触点抢走归因。

类别：归因欺诈。

现金贷例子：本应 Organic 的安装被某 Publisher 计走。

适用：Publisher/联盟审计。

误区：有真实用户就不存在 Fraud。

关系：MMP、Publisher。

Device Farm

中文：设备农场。

解释：批量真机、云机或 Emulator 制造行为。

类别：反作弊。

现金贷例子：安装正常但 KYC/Approve 极低且设备/IP 聚集。

适用：低价 Network 排查。

误区：只用 CTR/CPI 识别。

关系：Fraud、Publisher Quality。

Fine / Coarse Conversion Value

中文：细/粗粒度转化值。

解释：隐私条件允许时回传不同粒度的转化信号。

类别：iOS Postback。

例子：用 CV 映射 Register/KYC，不编码信用评分。

适用：SKAN Schema。

误区：Coarse low/medium/high=信用风险等级。

关系：Crowd Anonymity/Data Tier。

解释：TikTok 为 SKAN 环境设计的专用 App Campaign。

类别：TikTok App Campaign。

例子：Mexico iOS 新客 Apply。

适用：iOS App Promotion。

误区：Dedicated=拆越多越好。

关系：Quota、SKAN、MMP。

五、金融广告准入与 Mexico

Restricted Vertical

中文：受限行业。

解释：金融等行业有额外资质、内容、年龄或市场限制。

类别：广告合规。

例子：贷款广告需要平台/当地规则检查。

适用：上架前和投放前。

误区：Ad Review 通过=所有资质永久有效。

关系：Advertiser Eligibility、Financial Services Policy。

TikTok Financial Services Policy

中文：TikTok 金融服务广告政策。

解释：Mexico 当前要求当地/区域许可、必要披露、18+；may-be-allowed 包括 consumer finance/P2P/BNPL 等，明确禁止示例含 APR≥50% High APR Loan、Payday Loan、≤90 天 Short-term Loan。

类别：平台政策。

例子：Mexico Cash Loan 上线前做期限/APR/主体检查。

适用：TikTok 金融广告。

误区：其他国家政策直接套用 Mexico。

关系：Restricted Vertical、Disclosure。

TikTok 官方

Google Personal Loans

中文：Google 个人贷款广告政策。

解释：只允许需要 61 天或以上才能全部偿还的 personal loan，并要求 LP/App 显著披露最短/最长期限、最高 APR/当地等效口径和代表性总成本。

类别：Google Ads Policy。

例子：Mexico Google Search LP Disclosure Audit。

适用：Direct lender、Lead Generator、Connector。

误区：广告文案有 APR 就能省略 LP 披露。

关系：Text Disclaimer、Landing Page Disclosure。

Google 官方
