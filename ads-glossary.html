一、账户结构与素材

Ads

广告或广告平台体系的泛称。Google Ads 是平台名；Ad 是具体广告；Ads 不等于 Campaign。

Campaign

中文：广告系列/广告活动。通常位于 Ad Account 下、Ad Set/Ad Group 之上，承载目标、预算/出价和核心投放逻辑。

现金贷例子：Mexico_NewUser_Apply_TikTok。

Ad Set

Meta 常用广告组层级，常设置受众、版位、排期、优化事件等。

Ad Group

Google/TikTok 常用广告组层级，用于组织关键词、受众、版位、Bid 与 Creative。

Ad

具体广告，由素材、标题/正文、CTA 和目标链接组成。

Creative

素材/广告创意，包括视频、图片、文案、Hook、CTA、UGC 脚本等。

Placement

广告版位，如 Feed、Stories、Reels、Search、Pangle、Audience Network。

Publisher

实际提供流量的网站、App、媒体或联盟子渠道。现金贷要按 Publisher 看 Fraud、Approve、Disburse、FPD。

Audience

受众，包含年龄、地区、兴趣、自定义受众、相似受众、再营销等。

Retargeting

再营销/重定向，如安装未注册、注册未申请、审批未提款用户。

Hook

素材开头抓住注意力的钩子。金融广告不能靠夸大“秒批/保证放款”换 CTR。

UGC

User-Generated Content 或 UGC 风格内容。

CTA

Call To Action，行动号召，如 Apply Now / Learn More。

二、出价、自动化与平台产品

Bid Strategy

出价策略，决定平台更偏拿量、控 CPA 还是控价值/ROAS。

Cost Cap

围绕设定 CPA 目标控制平均成本，不是每笔转化硬上限。

Maximum Delivery

以预算为主要约束，尽量获取更多结果。

Learning Phase

平台积累信号并探索人群、素材、版位和 Bid 组合的阶段。

Smart+

TikTok 自动化投放体系，可自动化受众、预算、版位、素材等模块。

TikTok 官方

Performance Max / PMax

Google 跨 Search、YouTube、Display、Discover、Gmail、Maps 等资源的自动化 Campaign 类型。

Demand Gen

Google 偏发现式、视觉化需求开发广告。

UAC / App Campaign

Google 应用广告系列。行业仍常说 UAC，Google 当前通常称 App Campaign。

AEO

App Event Optimization，按应用内事件优化。

VBO

Value-Based Optimization，价值优化。

MAI

Mobile App Install，移动 App 安装优化。

AI Max for Search

Google Search 的 AI 增强套件，核心包含 Search Term Matching、Text Customization、Final URL Expansion；不等于 PMax。

Final URL Expansion / FUE

Google 根据搜索意图把用户送到同域名更相关页面。现金贷需维护可投 URL 白名单/排除表。

三、搜索广告术语

Keyword

广告主设置、希望购买的搜索意图。

Search Term / Query

用户实际输入的搜索内容。

Match Type

Keyword 与 Search Term 允许差多远的匹配规则，常见 Broad / Phrase / Exact。

Negative Keyword

否定关键词，用于排除不需要的搜索意图。

Keyword Planner

研究搜索量、竞争度和关键词机会的工具。

四、归因、事件与数据连接

MMP

Mobile Measurement Partner。连接广告触达与 Install、Register、Apply、Disburse 等 App 事件，常见 AppsFlyer、Adjust、Singular。

关键：MMP 是归因层，不等于业务真相；现金贷必须与 backend 对账。

Pixel

浏览器侧事件采集器。

Events API

TikTok 服务器侧营销事件回传接口。

Conversions API / CAPI

Meta 服务器侧数据连接接口。

S2S / Server-to-Server

服务器到服务器事件或归因数据连接。

Postback

MMP/平台将归因或事件结果回传给广告网络或合作方的数据通知。

Event Deduplication

Browser + Server 同时上报同一事件时，利用 event_id 等避免重复计数。

Deep Link

点击广告、Push、短信后直接打开 App 指定页面。

Web-to-App

广告 → Web Landing Page → App Store/App → App 内转化。

Attribution Window

广告接触后多长时间内的转化仍有资格算给该广告。

Attribution Model

多个触点都合格时，决定转化信用如何分配。

Conversion Lag

从广告互动到转化发生/被记录的时间延迟。

Incrementality

回答“如果没有广告，这个用户是否仍会转化”。通常需要 Holdout/Lift/Geo Experiment。

Protect360 的 Android 高级安全模块，在首次启动后、归因前评估可疑活动，目标是识别 Attribution Spoofing 和 manipulated traffic。

AppsFlyer 官方
Fraud

SDK Spoofing

中文：SDK 请求伪造。欺诈者模仿真实 App SDK 网络请求，向 MMP 服务器发送假的 Install 或 in-app event，而真实设备可能根本没有安装/运行 App。

现金贷：MMP 看到 Apply，但 backend 没有 user/application，是典型高风险信号。

Fraud

Attribution Spoofing

中文：归因伪造。通过伪造 engagement、install 或 event，使 MMP 把原本不属于某渠道的转化归给它。

Fraud

Install Hijacking

中文：安装归因劫持。真实用户确实安装 App，但欺诈方伪造最后触点抢走 Attribution。

关系：不是 Fake Install；用户是真的，归因是假的。

Fraud

Device Farm

中文：设备农场。批量真机、云设备或模拟器制造安装/事件，常伴随 IP/ASN/设备特征聚集。

Fraud

Emulator

中文：模拟器。在虚拟设备环境中运行 App；并非所有模拟器都是欺诈，但大规模营销流量中需要单独识别。

AppsFlyer

Validation Rules

AppsFlyer 自定义校验规则，可针对错误 Geo、OS、Media Source、被劫持/伪造的 Install 与 Event 做阻断或重新归因。

官方原文
Fraud

Real-time Blocking

在归因写入或事件计入前识别并阻断欺诈。对实时优化和媒体结算价值最高。

Fraud

Post-attribution Fraud

安装已归因后，MMP 通过后续统计/异常检测才识别出的 Fraud。投放复盘和结算必须二次扣除。

Data

Fraud Raw Data Report

包含被阻断 Click/Install/In-app Event、原因、Media Source/Publisher 等明细，用于对账、优化和供应商结算。

Adjust

Untrusted Devices

Adjust 在 Anonymous IP Filtering 中用于承接来自 VPN、Tor、数据中心等高风险匿名网络的归因分类。

Adjust 官方
Fraud

Organic Fraud

欺诈流量被识别或迁移到 Organic 口径。Organic 不应被当成绝对干净基线。

内部产品

Attribution Trust Layer

内部归因可信层：把 MMP fraud flags、backend verification、设备/网络异常、Publisher 历史和事件时序结合起来，为事件/流量打 Trusted / Review / Blocked 状态。

六、金融广告准入与墨西哥政策

Restricted Vertical

受限行业/垂类。金融、博彩、医药等通常存在额外准入与内容要求。

Advertiser Eligibility

广告主是否有资格在目标国家推广某一金融产品。

Platform Permission

某些受限产品需要平台额外批准。不要把这一概念扩大成“所有金融广告都必须额外白名单”。

Ad Review

针对具体 Ad/Creative、文案、Landing Page/URL 的审核；通过 ≠ 所有上层准入永久满足。

TikTok Financial Services Policy

Mexico 当前普通金融服务/贷款核心要求：当地/区域许可、必要披露、18+；官方 may-be-allowed 示例包含 mortgage、consumer finance、P2P、BNPL。

当前明确禁止示例：APR ≥50% High APR Loan、Payday Loan、≤90 天 Short-term Loan 等。Crypto/NFT 等特定类别另有 Sales Representative application permission。

TikTok 官方

Google Personal Loans

Google 只允许需要 61 天或以上才能全部还清的 personal loan，并要求在 LP/App 显著披露最短/最长期限、最高 APR/当地等效口径和代表性总成本。

Google 官方
