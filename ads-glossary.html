海外投放术语词典｜现金贷 APP

持续从每日海外投放日报中抽取术语并沉淀。重点解释：是什么、在哪一层、怎么用于现金贷、最常见误区、和哪些概念相关。

先理解广告账户层级

Ad Account → Campaign → Ad Set / Ad Group → Ad / Creative

Meta 常见：Campaign → Ad Set → Ad；Google Ads 和 TikTok 常见：Campaign → Ad Group → Ad。预算、出价、受众、优化事件究竟在哪一层设置，要以平台具体产品为准。

基础

Ads

中文：广告，或广告投放体系的泛称。

解释：不是固定层级。Google Ads 是平台名，而 “an ad” 通常指具体广告。

现金贷例子：“Google Ads 成本上涨”说的是渠道；“这条 Ad CTR 高”说的是具体广告。

账户结构

Campaign

中文：广告系列 / 广告活动。

层级：广告账户下，Ad Set / Ad Group 上。

作用：承载投放目标、预算/出价逻辑、地域或产品线等核心设置。

现金贷例子：Mexico_NewUser_Disburse 可作为“墨西哥新客放款”Campaign。

误区：拆太多 Campaign 会稀释转化样本，导致学习不稳定。

账户结构

Ad Set

中文：广告组，Meta 常用叫法。

层级：Campaign 与 Ad 之间。

常见设置：受众、版位、预算/排期、优化事件。

账户结构

Ad Group

中文：广告组，Google/TikTok 常见叫法。

作用：管理相似受众、关键词、版位或优化逻辑的广告。

注意：和 Ad Set 概念接近，但平台能力并不完全相同。

账户结构

Ad

中文：具体广告。

组成：视频/图片、标题、正文、CTA、落地页或商店链接。

素材

Creative

中文：广告创意 / 素材。

包括：视频、图片、文案、Hook、封面、CTA、UGC 脚本。

现金贷判断：不能只看 CTR，还要看 Apply CVR、首贷 CAC、FPD。

流量

Placement

中文：广告版位。

例子：Feed、Stories、Reels、Search、Audience Network。

误区：低 CPA 的版位未必风险质量好。

流量

Publisher

中文：流量媒体 / 发布商。

用法：程序化、联盟或第三方流量中，用于识别真实提供流量的网站或 App。

现金贷：应分 Publisher 看欺诈率、授信率、放款率、FPD。

定向

Audience

中文：受众。

包括：地区、年龄、兴趣、自定义受众、相似人群、再营销。

定向

Broad

中文：宽泛定向。

解释：减少人工限制，让算法自主找转化用户。

适合：转化量足且事件回传质量高时。

定向

Retargeting

中文：再营销 / 重定向。

对象：访问未安装、安装未注册、注册未申请、审批未提款等用户。

转化

Conversion

中文：转化。

现金贷：Install、Register、KYC、Apply、Approve、Disburse 都可能被定义为转化。

误区：说“转化率”却不说明具体事件和分母。

算法

Optimization Event

中文：优化事件。

解释：告诉平台最希望其寻找哪种行为。

现金贷：可从 Install 逐步升级到 Apply、Disburse，但深层事件需要足够样本。

算法

Learning Phase

中文：学习期。

解释：算法积累转化信号、探索人群/版位/出价组合的阶段。

误区：频繁改预算、受众、事件或素材，会增加波动甚至重新学习。

TikTok

Smart+

中文：TikTok 自动化投放体系。

现金贷：自动化越强，深层事件回传和风险质量监控越重要。

官方原文：TikTok Smart+

Google

Performance Max / PMax

中文：效果最大化广告系列。

解释：Google 跨多个资源自动寻找转化机会的 Campaign 类型。

现金贷：需看首贷 CAC、FPD、LTV，而不只看平台 Conversion。

官方原文：Google Performance Max

Google

Demand Gen

中文：需求开发广告。

解释：偏发现式、视觉化的需求拓展 Campaign。

现金贷：用户意图通常不同于 Search，不宜用同一个 CPA 门槛直接比较。

官方原文：Google Demand Gen

Google

UAC / App Campaign

中文：Google 应用广告系列。

说明：行业仍常叫 UAC；Google 当前通常称 App campaigns。

官方原文：Google App campaigns

归因

MMP

英文：Mobile Measurement Partner。

中文：移动归因/衡量合作伙伴。

作用：连接广告点击/展示与安装、注册、申请、放款等 App 事件，并支持跨渠道归因和反作弊。

产品

Deep Link

中文：深度链接。

作用：让用户直接打开 App 指定页面。

现金贷例子：审批通过未提款用户点击 WhatsApp 后直达提款确认页。

链路

Web-to-App

中文：网页到 App 获客链路。

路径：广告 → Landing Page → 应用商店 → 安装 → App 内转化。

App优化

AEO

英文：App Event Optimization。

中文：应用内事件优化。

解释：不只优化安装，而是让平台尽量找到更可能完成某个 App 内事件的人。

现金贷例子：从 Install 优化切到 Apply 或 KYC Complete 优化。

误区：事件太深但量不足，算法反而学不动。

官方原文：TikTok App Event Optimization

价值优化

VBO

英文：Value-Based Optimization。

中文：价值优化。

解释：优化目标从“有没有转化”升级到“转化价值高不高”。

现金贷例子：理论上可用风险调整贡献或预测 LTV 作为价值信号，而不是只把所有 Apply 当作相同价值。

误区：直接用放款金额当价值，可能奖励高风险大额用户。

App优化

MAI

英文：Mobile App Install。

中文：移动应用安装目标。

解释：主要优化“获得更多安装”。

现金贷：适合冷启动或深层事件量不足阶段，但后续必须逐步观察 Apply、Disburse、FPD。

iOS归因

SKAN / StoreKit Ad Network

中文：苹果隐私保护下的广告归因机制。

解释：通过隐私保护方式向广告网络回传安装/转化信号，不直接暴露用户级标识。

现金贷：iOS 投放中会影响归因粒度、回传延迟和深层事件设计。

官方原文：Apple StoreKit Ad Network

归因

Attribution Window

中文：归因窗口。

解释：广告点击或展示之后，多长时间内发生的转化可以被归给这次广告。

现金贷：Click→Install 可能很快，但 Install→Disburse 可能跨天；窗口过短会漏掉慢转化。

误区：不同平台窗口不同，却直接比较平台后台 CPA。

数据回传

Postback

中文：转化回传 / 回调。

解释：当安装或事件发生后，由 MMP/服务器向广告平台发送转化信号。

现金贷：Apply、Approve、Disburse 的回传质量会直接影响算法优化和数据对账。

数据回传

S2S / Server-to-Server

中文：服务器对服务器回传。

解释：由后端服务器直接把事件发送给 MMP/广告平台，而不是依赖客户端 SDK 单独触发。

现金贷：放款、首期正常还款等后端事件更适合通过 S2S 保证一致性。

误区：没有 event_id / 去重机制会重复记转化。

出价

Bid Strategy

中文：出价策略。

解释：平台如何决定每次竞价愿意出多少钱，例如最大化转化、tCPA、tROAS 等。

现金贷：选择出价策略前应先确定“真正的业务目标事件”是什么。

预算

Budget Pacing

中文：预算节奏 / 预算消耗控制。

解释：控制预算在一天、时段或活动周期内如何分配和消耗。

现金贷：可按高质量时段加权，但不能只根据便宜 CPA 分配。

官方原文：TikTok Time-based budget pacing

受众

Lookalike Audience

中文：相似受众。

解释：平台基于一组种子用户寻找特征相近的新用户。

现金贷：种子最好优先使用高质量放款/良好还款用户，而不只是注册用户。

误区：种子本身质量差，Lookalike 会放大错误信号。

搜索广告

Keyword Match

中文：关键词匹配方式。

常见：Broad、Phrase、Exact。

现金贷：Broad 适合扩词，Phrase/Exact 适合收敛高意图词；最终仍应按首贷 CAC 和 FPD 判断。

素材

Hook

中文：素材开头钩子 / 第一吸引点。

解释：视频前几秒或图文第一屏用来抓住注意力的表达。

现金贷：可以用“临时资金缺口”“账单场景”等真实需求切入，但不能靠虚假额度、保证放款等误导表达。

素材

UGC

英文：User-Generated Content。

中文：用户生成内容风格素材。

解释：看起来更像真实用户分享，而不是传统广告。

现金贷：可提高自然感和信任，但金融类不能伪造真实用户收益/审批结果。

素材/产品

CTA

英文：Call to Action。

中文：行动号召。

例子：Apply Now、Check Eligibility、Learn More。

现金贷：CTA 应与用户下一步真实动作一致，避免“Guaranteed Approval”之类误导性承诺。

【墨西哥重点】术语必须和后端质量一起解释

例如“Campaign CPA 很低”“Broad 扩量成功”“AEO 学习稳定”都只是投放层结论。对墨西哥现金贷，还必须继续检查 Approve Rate、Disburse Rate、首贷 CAC、FPD/Vintage、LTV 和渠道 ROI。知识库会持续把术语词典与指标词典互相连接。
