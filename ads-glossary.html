账户：Ad Account → Campaign → Ad Set / Ad Group → Ad / Asset Group / Creative

一、账户结构与投放基础

基础

Ads

中文：广告，或广告平台/体系的泛称。Google Ads 是平台名；Ad 是具体广告。误区：Ads 不等于 Campaign。

账户结构

Campaign

中文：广告系列/广告活动。通常位于 Ad Account 下、Ad Set/Ad Group 上。

现金贷例：Mexico_NewUser_Disburse 可作为墨西哥新客放款 Campaign。拆得太细会稀释学习样本。

Meta

Ad Set

中文：广告组（Meta 常用）。常承载受众、版位、预算/排期、优化事件等。

Google/TikTok

Ad Group

中文：广告组。管理相似关键词、受众、版位或优化逻辑；TikTok Search 的关键词在 Ad Group 层管理。

账户结构

Ad

中文：具体广告。通常由素材、文案、CTA 和目标链接组成。

素材

Creative

中文：广告素材/创意。视频、图片、文案、Hook、封面、CTA、UGC 脚本等。现金贷要继续看 Apply CPA、CAC、FPD。

流量

Placement

中文：广告版位。如 Feed、Stories、Reels、Search、Pangle/Audience Network 等。

流量

Publisher

中文：流量媒体/发布商。联盟或第三方网络中应按 Publisher 看欺诈率、授信率、放款率、FPD。

定向

Audience

中文：受众。包括地区、年龄、自定义受众、相似人群、再营销人群等。

定向

Broad

中文：宽泛定向。减少人工限制，让算法找转化用户；不要与 Search 的 Broad Match 混淆。

定向

Retargeting

中文：再营销/重定向。面向访问未安装、安装未注册、注册未申请、审批未提款等用户。

定向

Lookalike Audience

中文：相似受众。现金贷种子优先选优质放款/正常还款 Cohort，而不是只用安装用户。

二、算法、出价与自动化

算法

Optimization Event

中文：优化事件。告诉平台最希望找到什么行为；事件越深越接近业务价值，但需要足够转化量。

算法

Learning Phase

中文：学习期。系统积累转化信号、探索人群/版位/出价组合的阶段；频繁改参数会增加波动。

出价

Bid Strategy

中文：出价策略。如 Maximize Conversions、tCPA、tROAS、Cost Cap、Highest Value。

预算

Budget Pacing

中文：预算节奏。控制预算在一天、小时或活动周期内如何消耗。

官方原文：TikTok Time-based pacing

TikTok

Smart+

中文：TikTok 自动化投放体系。2026 年 8 月升级后，Manual 与 Smart+ 进入统一创建流程，可全自动、部分自动或手动控制。

官方原文：TikTok Smart+ Upgraded Experience

TikTok/App

AEO

App Event Optimization｜应用内事件优化。不只优化安装，而是寻找更可能完成指定 App 事件的人。

价值优化

VBO

Value-Based Optimization｜价值优化。从“是否转化”升级到“转化价值多高”。

App

MAI

Mobile App Install｜移动应用安装。常用于冷启动/深层事件量不足阶段。

Google

Performance Max / PMax

中文：效果最大化广告系列。Google 跨多个库存自动找转化机会；现金贷要配合深层事件和后端质量监控。

Google

Demand Gen

中文：需求开发广告。偏视觉与发现式流量，用户意图与 Search 不同。

Google

UAC / App Campaign

中文：Google 应用广告系列。行业仍常说 UAC；当前产品名通常为 App Campaign。

官方原文：Google App campaigns

TikTok

App Promotion

中文：应用推广目标/场景。用于 App 安装或应用内行为获客；具体能力以国家和账户实际界面为准。

三、Search 搜索投放

TikTok Search

Search Ads Campaign

中文：搜索广告系列。根据 Keyword 参与搜索结果竞价，适合高意图需求。

官方原文：TikTok Search Ads setup

Search

SRP

Search Results Page｜搜索结果页。

Search

Keyword

中文：关键词。广告主主动选择的“想买的搜索意图”。

Search

Search Term / Query

中文：搜索词/实际查询。用户真实输入内容；与 Keyword 不是一回事。

Search

Match Type

中文：关键词匹配方式。决定 Keyword 与真实 Search Term 允许差多远。

Search

Broad Match

中文：广泛匹配。允许更宽语义范围，流量大但要加强 Search Terms 和后端质量监控。

Search

Phrase Match

中文：词组匹配。比 Broad 更收敛，但仍允许一定语义/词序变化。

Search

Exact Match

中文：精确匹配。不是字符完全相同；平台仍可能覆盖近义和语义变体。

Search

Negative Keyword

中文：否定关键词。明确排除不想购买的搜索意图。

Search

Keyword Planner

中文：关键词规划工具。用于查看搜索量、竞争度和扩词机会。

Search

Automatic Search Placement

中文：自动搜索版位。把其他广告自动扩展到搜索结果环境；不同于手动关键词 Search Ads。

Search

Search Terms Report

中文：搜索词报告。检查实际触发广告的查询，持续加词、否词和识别高/低质量意图。

Search

Keyword Quality

中文：关键词质量/相关性。搜索量大不等于业务质量高，最终要接 Approve/Disburse/FPD。

四、归因、数据连接与事件治理

归因

MMP

Mobile Measurement Partner｜移动归因/衡量合作伙伴。连接广告触达与安装、注册、申请等 App 事件。

Apple

SKAN / AdAttributionKit

中文：Apple 隐私型广告归因体系。在不提供传统设备级追踪的前提下返回聚合归因信号。

归因

Attribution Window

中文：归因窗口/转换窗口。规定广告触达后多长时间内发生的转化还有资格归给该广告。

现金贷：Apply 和 Disburse 的真实延迟不同，应按事件设窗口。

官方原文：Google Ads：About conversion windows

归因

Lookback Window

中文：回溯窗口。与 Attribution/Conversion Window 高度相关，强调从“转化时点向前看多少天”的口径。

官方原文：Google Analytics：Change the key event lookback window

归因

CTC

Click-through Conversion｜点击后转化。用户点击广告后，在配置窗口内完成目标行为。

2026-08-11 更新：GA 转化的 CTC 窗口可设 1–90 天任意整数。

官方原文：Google Analytics What's New

归因

EVC

Engaged-view Conversion｜互动观看后转化。用户未点击，但达到平台定义的有效视频观看/互动后在窗口内转化。

2026-08-11 更新：GA 转化 EVC 窗口可设 1–30 天任意整数。

官方原文：Google Analytics What's New

归因

VTC

View-through Conversion｜浏览后转化。用户看到广告但未点击/未达到 engaged-view 条件，之后在窗口内完成转化。

误区：VTC 与点击信号因果强度不同，不应机械相加后当“真实新增客户”。

官方原文：Google Ads：About conversion windows

归因

Attribution Model

中文：归因模型。当多个触点都在归因窗口内时，决定转化信用如何分配。

关系：Window 决定“谁有资格”，Model 决定“信用怎么分”。

归因

Data-driven Attribution / DDA

中文：数据驱动归因。平台使用数据估计不同触点对转化的贡献，而不是把信用固定给最后一次点击。

现金贷：可用于媒体评估，但最终仍需内部成熟 CAC、FPD、LTV 复核。

归因

Last Click

中文：末次点击归因。把信用主要/全部给转化前最后一个符合规则的点击触点。

误区：容易低估上游发现型渠道，也可能高估品牌词/召回渠道。

归因

Postback

中文：回传。MMP、平台或服务端把事件/归因结果发送给另一系统。

数据

S2S / Server-to-Server

中文：服务器到服务器回传。不依赖浏览器脚本，由后端直接发送事件。

产品

Deep Link

中文：深度链接。让用户点击后直接进入 App 指定页面，而不是只打开首页。

链路

Web-to-App

中文：网页到 App 的获客/转化链路。典型路径为 Ads → LP → Store/App → in-app event。

Google

App Connect

中文：Google Web-to-App 连接能力。帮助 Search/PMax 等 Web Campaign 把已安装 App 的用户引导到 App 内。

官方原文：Google App Connect

实验

Deep Linking A/B Test

中文：深链 A/B 实验。对比进入 App 指定页面与继续走 Web 页面后的转化差异。

Google

UHA

Users Who Have App｜已安装 App 用户。用于单独看 Deep Link 对已安装用户的真实提升。

数据

Conversion Lag

中文：转化延迟。广告互动到真实转化发生/被记录之间的时间差，是用户行为，不是归因窗口配置。

官方原文：Google Ads：Conversion lag reporting

报告

Days to Conversion

中文：转化所需天数。Google Ads 的分段/报告视角，用于观察从广告互动到转化计入需要多少天。

官方原文：Google Ads：Find conversion lag data

内部治理

Conversion Maturity

中文：转化成熟度。描述某个获客 Cohort 的深层转化是否已经基本回补完成。

现金贷：可用 P90 Lag 定义 Provisional/Mature 状态，避免最近日期 CPA 虚高。

数据连接

Pixel

中文：像素/浏览器事件采集。通过网页端代码把访问、注册、申请等事件发给广告平台。

TikTok

Events API

中文：事件 API / 服务器事件回传。TikTok 的服务器数据连接，可与 Pixel 联合使用。

官方原文：TikTok Data Connection setup methods

Meta

Conversions API / CAPI

中文：转化 API。Meta 的服务器数据连接，用于网站、App、线下和消息事件的优化与衡量。

官方原文：Meta：About Conversions API

数据质量

Event Deduplication

中文：事件去重。Browser + Server 同时上报同一行为时，平台识别为同一事件并只计一次。

官方原文：TikTok：Event Deduplication

数据质量

event_id

中文：事件唯一标识。Browser 与 Server 两条链路使用相同 event_id，帮助正确去重。

数据质量

Event Match Quality / EMQ

中文：事件匹配质量。说明数据连接/匹配健康度，不代表授信率或 FPD 更好。

事件

Standard Event

中文：标准事件。平台预定义、语义固定的事件名称，如 CompleteRegistration、SubmitApplication。

官方原文：TikTok Standard Events

事件

Custom Event

中文：自定义事件。广告主自己定义的业务行为；平台可能限制其优化能力。

数据连接

Browser + Server

中文：浏览器 + 服务器双链路。提高覆盖与稳定性；重叠事件必须去重。

Meta/合规

Business Tool Data

中文：Meta Business Tools 数据。通过 Pixel、CAPI、App Events 等分享的数据，需满足 Meta 条款和适用法律。

官方原文：Meta Business Tools Terms

合规

Sensitive Data

中文：敏感数据。现金贷尤其要警惕金融/信用、健康、生物识别等类别。

默认不要外发：银行账号、收入、信用评分、审批额度、定价/APR、还款/逾期状态、催收/欺诈特征等借款人级字段，除非平台条款和内部合规明确允许。

产品治理

Marketing Event Contract

中文：营销事件契约（内部治理概念）。把事件名、触发条件、字段白名单、event_id、时间戳、平台去向、版本和负责人写成正式规范。

Meta AI

Meta AI Business Connection

中文：Meta AI 业务连接。可在授权后连接 Meta Ads/Workspace 做媒体分析；不应替代首贷 CAC/FPD/LTV 决策。

五、报告、分析与 AI 助手

Google AI

Ask Advisor

中文：Google Ads / Analytics 的对话式分析助手。可回答表现、诊断和使用方法问题，生成洞察；当前部分能力为 Beta。

现金贷：用于发现媒体异常，不代替内部放款/风险/利润判断。

官方原文：Google Ads：Ask Advisor ｜ Google Analytics：Ask Advisor

Google AI

Report Generator

中文：自然语言报告生成器。Google Ads 可用提示词从 500+ 指标构建报告；官方当前说明仅支持英文。

官方原文：Google Ads：Report Generator

分析

Benchmarking

中文：基准对比。Google Analytics 将业务指标与匿名化的相似业务 peer group 进行参考比较。

误区：同行基准不是你的盈利阈值，现金贷最终还是看自有 CAC、风险和 LTV。

官方原文：Google Analytics：Benchmarking

GA4

Campaign Data Import Validation Report

中文：Campaign 数据导入校验报告。用于检查跨渠道导入数据是否缺 cost、click、impression 等关键字段。

现金贷：适合把 Meta/TikTok 等非 Google 渠道汇总到 GA 后先做数据质量检查。

官方原文：Google Analytics What's New（2026-08-10）

六、素材与创意体系

TikTok

Spark Ads

中文：原生内容放大广告。把品牌自己或经授权创作者的 organic TikTok post 作为广告素材。

官方原文：TikTok Spark Ads

TikTok

Non-Spark Ads

中文：非 Spark 广告。标准广告素材，不直接绑定某个原生 organic post。

Smart+

Asset Group

中文：资产组/创意资产容器。承载创意、文案、URL 等组合；现金贷避免不同期限/费用产品混用。

Smart+

Paid & Organic Optimization

中文：付费与自然流量联合优化。在支持场景中联合使用 paid 与 organic 信号。

Smart+

Organic Anchor

中文：自然内容锚点链接。为 organic post 增加可点击目的地链接。

Smart+

Multi-URL

中文：多目标 URL。同一活动管理多个目标 URL；必须保证素材承诺与对应产品一致。

AI Creative

Recommended Creatives

中文：推荐创意。平台根据历史素材与信号推荐可用内容；金融广告仍需合规审核。

AI Creative

Automatic Enhancements

中文：自动创意增强。平台自动调整素材表现形式；自动改写后要检查期限/费用/免责声明一致性。

素材

Creative Fatigue

中文：素材疲劳。同一素材反复曝光后 CTR/CVR 下降、CPA 上升；结合 Frequency、Reach 与受众规模判断。

治理

Creative Registry

中文：素材台账（内部治理概念）。记录 creative_id、版本、CTA、URL、期限、APR/费用口径、适用国家、审核状态。

素材

Hook

中文：开头钩子。视频/文案前几秒抓注意力；金融广告不能靠夸大“秒批/保证放款”换 CTR。

素材

UGC

User-Generated Content｜用户生成内容/UGC 风格。贷款类要防止伪造用户体验、审批结果或误导性承诺。

素材

CTA

Call To Action｜行动号召。如 Apply Now、Learn More；CTA 要与目标页和真实产品条件一致。

【墨西哥重点】术语最终必须回到经营与合规

“Campaign CPA 低”“EMQ 高”“Search Term 很准”“CTC 归因量变多”都只是局部信号。墨西哥现金贷最终仍要穿透到 Approve Rate、Disburse Rate、成熟首贷 CAC、FPD/Vintage、LTV，并满足平台金融广告准入与数据使用边界。
