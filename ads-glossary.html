一、账户结构与投放基础

基础

Ads

中文：广告，或广告平台/体系的泛称。Google Ads 是平台名；Ad 是具体广告。误区：Ads 不等于 Campaign。

账户结构

Campaign

中文：广告系列/广告活动。通常位于 Ad Account 下、Ad Set/Ad Group 上。

现金贷例：Mexico_NewUser_Disburse 可作为墨西哥新客放款 Campaign。拆得太细会稀释学习样本。

Meta

Ad Set

中文：广告组（Meta 常用）。常承载受众、版位、预算/排期、优化事件。

Google/TikTok

Ad Group

中文：广告组。管理相似关键词、受众、版位或优化逻辑。

账户结构

Ad

中文：具体广告。通常由素材、文案、CTA 和目标链接组成。

素材

Creative

中文：广告素材/创意。视频、图片、文案、Hook、封面、CTA、UGC 脚本等。现金贷不能只看 CTR，要继续看 Apply CPA、CAC、FPD。

流量

Placement

中文：广告版位。如 Feed、Stories、Reels、Search、Pangle/Audience Network 等。

流量

Publisher

中文：流量媒体/发布商。联盟或第三方网络中应按 Publisher 看欺诈率、授信率、放款率、FPD。

定向

Audience

中文：受众。包括地区、年龄、自定义受众、相似人群、再营销人群等。

定向

Broad

中文：宽泛定向。减少人工限制，让算法找转化用户；不要与 Search 的 Broad Match 混淆。

定向

Retargeting

中文：再营销/重定向。面向访问未安装、安装未注册、注册未申请、审批未提款等用户。

定向

Lookalike Audience

中文：相似受众。现金贷种子优先选优质放款/正常还款 Cohort，而不是只用安装用户。

二、算法、出价与自动化

算法

Optimization Event

中文：优化事件。告诉平台最希望找到什么行为；事件越深越接近业务价值，但需要足够量。

算法

Learning Phase

中文：学习期。系统积累转化信号、探索人群/版位/出价组合的阶段。

出价

Bid Strategy

中文：出价策略。如 Maximize Conversions、tCPA、tROAS、Cost Cap、Highest Value。

预算

Budget Pacing

中文：预算节奏。控制预算在一天、小时或活动周期内如何消耗。

官方原文：TikTok Time-based pacing

TikTok

Smart+

中文：TikTok 自动化投放体系。2026 年 8 月升级后 Manual 与 Smart+ 进入统一创建流程。

官方原文：TikTok Smart+ Upgraded Experience

App

AEO

App Event Optimization｜应用内事件优化。不只优化安装，而是寻找更可能完成指定 App 事件的人。

价值优化

VBO

Value-Based Optimization｜价值优化。从“是否转化”升级到“转化价值多高”。

App

MAI

Mobile App Install｜移动应用安装。

Google

Performance Max / PMax

中文：效果最大化广告系列。跨多个 Google 库存自动寻找转化机会。

Google

Demand Gen

中文：需求开发广告。偏视觉和发现式流量，意图与 Search 不同。

Google

UAC / App Campaign

中文：Google 应用广告系列。行业仍常说 UAC；当前产品名通常为 App Campaign。

官方原文：Google App campaigns

TikTok

App Promotion

中文：应用推广目标/场景。用于 App 安装或应用内行为获客。

三、Search 搜索投放

Search

Search Ads Campaign

中文：搜索广告系列。根据 Keyword 参与搜索结果竞价，适合高意图需求。

Search

Keyword

中文：关键词。广告主主动选择的“想买的搜索意图”。

Search

Search Term / Query

中文：搜索词/实际查询。用户真实输入内容；与 Keyword 不是一回事。

Search

Match Type

中文：关键词匹配方式。决定 Keyword 与真实 Search Term 允许差多远。

Search

Broad Match

中文：广泛匹配。流量大，但要加强 Search Terms 和后端质量监控。

Search

Phrase Match

中文：词组匹配。比 Broad 更收敛。

Search

Exact Match

中文：精确匹配。不是字符完全相同，平台仍可能覆盖近义和语义变体。

Search

Negative Keyword

中文：否定关键词。明确排除不想购买的搜索意图。

Search

Keyword Planner

中文：关键词规划工具。用于查看搜索量、竞争度和扩词机会。

四、归因、数据连接与事件治理

归因

MMP

Mobile Measurement Partner｜移动归因/衡量合作伙伴。连接广告触达与安装、注册、申请等 App 事件。

Apple

SKAN / AdAttributionKit

中文：Apple 隐私型广告归因体系，以聚合方式返回广告归因信号。

归因

Attribution Window

中文：归因窗口/转换窗口。规定广告触达后多长时间内的转化还有资格归给该广告。

归因

CTC

Click-through Conversion｜点击后转化。

归因

EVC

Engaged-view Conversion｜互动观看后转化。

归因

VTC

View-through Conversion｜浏览后转化。

归因

Attribution Model

中文：归因模型。多个触点都在窗口内时，决定信用如何分配。

归因

Last Click

中文：末次点击归因。容易低估上游发现型渠道，也可能高估品牌词/召回渠道。

数据

Conversion Lag

中文：转化延迟。广告互动到转化发生/被记录之间的真实时间差。

内部治理

Conversion Maturity

中文：转化成熟度。描述某个 Cohort 的深层转化是否已经基本回补完成。

归因

Postback

中文：回传。MMP、平台或服务端把事件/归因结果发送给另一系统。

数据

S2S / Server-to-Server

中文：服务器到服务器回传。

产品

Deep Link

中文：深度链接。让用户直接进入 App 指定页面。

链路

Web-to-App

中文：网页到 App 的获客/转化链路。

Google

App Connect

中文：Google Web-to-App 连接能力。

Google

UHA

Users Who Have App｜已安装 App 用户。

数据连接

Pixel

中文：网页浏览器事件采集器。

TikTok

Events API

中文：TikTok 服务器事件回传。

Meta

Conversions API / CAPI

中文：Meta 服务器数据连接。

数据质量

Event Deduplication

中文：事件去重。Browser + Server 重复上报同一行为时只计一次。

数据质量

Event Match Quality / EMQ

中文：事件匹配质量。说明数据连接健康，不代表授信或风险质量。

五、2026-08-24 新增：广告主信任与增量归因

Google Policy

Limited Ad Serving

中文：限制广告投放/展示。Google 在特定更可能产生负面广告体验的场景中，可能限制未被判定为合格广告主的展示量。

重要：它不是单条广告拒登；账户可能收到通知，限制会随 Google 对账户的持续评估而调整。

现金贷例：贷款广告本身合规，但新账户、品牌识别不清或用户投诉较多时，仍可能出现“审核通过但展示受限”。

常见误区：把 Limited Ad Serving 当成普通 Disapproved Ad；或认为金融资质通过后就不会受此政策影响。

官方原文：August 2026 update ｜ Limited ad serving

Google Policy

Qualified Advertiser

中文：合格广告主。Google 用账户属性、用户活动/举报、账户成熟度、广告格式使用、政策合规历史、行业和验证状态等因素评估。

关系：Qualified Advertiser 是“投放信任资格”，不等于金融牌照/产品合规资格。

官方原文：Google Limited ad serving

Google

Advertiser Verification

中文：广告主验证。Google 用于确认广告主身份/业务信息的验证流程之一。

现金贷：应与网站主体、App 开发者、品牌和客服身份保持可解释一致。

关系：验证状态是 Google 评估 Qualified Advertiser 的因素之一，但不保证无限量投放。

TikTok Analytics

Attribution Analytics

中文：归因分析。TikTok 的归因分析模块，包含 Overview、Window 对比、Time to Conversion、Touchpoints、Assisted Conversions 和部分第三方报告对比。

现金贷：用于解释用户路径和渠道协同，不替代内部增量/利润分析。

官方原文：TikTok Attribution Analytics

TikTok Attribution

Referred Conversion

中文：直接/最后触点转化。TikTok 是用户转化前最后一个广告互动渠道。

关系：比 Assisted 更接近 Last Touch，但仍属于平台归因，不自动等于增量。

官方原文：TikTok Overview

TikTok Attribution

Assisted Conversion

中文：辅助转化。TikTok 出现在用户更早的路径中，但最后由 Search、Direct 等其他渠道完成转化。

现金贷例：TikTok 看贷款素材 → 用户随后搜品牌 → 安装/申请/放款。

常见误区：把 Assisted 当“TikTok 独占新增用户”，与 Search/Direct 再重复计算。

官方原文：TikTok Assisted Conversions

Journey

Touchpoint

中文：触点。用户在完成转化前与广告/Campaign 发生的一次可记录互动或曝光。

现金贷：同一用户可能先看到视频，再搜索品牌，再被 Retargeting 触达，最后直接进入 App。

官方原文：TikTok：触点到转化

Measurement

Incrementality

中文：增量性。回答“如果没有这笔广告，这个转化还会不会发生”。

常用方法：Holdout、Conversion Lift、Geo Experiment、预算断点/准实验。

关键关系：Attributed ≠ Incremental；Assisted 更不等于 Incremental。

Experiment

Holdout

中文：留出对照组。刻意保留一组不接受某广告/策略的人群、地区或时段，用来估计真正增量。

现金贷：比较实验组与对照组的增量首贷、Incremental CAC、FPD/LTV。

Tracking

UTM Parameters

中文：URL 营销追踪参数。常见字段包括 utm_source、utm_medium、utm_campaign、utm_id。

现金贷：Web-to-App 必须保持 UTM 在跳转/Deep Link 中不丢失，方便 TikTok/GA4/数仓对账。

官方原文：TikTok Third-Party Reporting Comparison

Tracking

utm_id

中文：Campaign ID 类 UTM 参数。TikTok 官方第三方报告对比会用 utm_id 进行 TikTok 与 Google Analytics 数据匹配。

误区：只填 utm_campaign 文本名、不维护稳定 utm_id，容易造成跨系统映射不完整。

六、素材与创意

TikTok

Spark Ads

中文：原生内容放大广告。用品牌或授权创作者的 organic post 做广告。

Smart+

Asset Group

中文：资产组/创意资产容器。承载创意、文案、URL 等组合。

素材

Creative Fatigue

中文：素材疲劳。反复曝光后 CTR/CVR 下滑、CPA 上升。

素材

Hook

中文：开头钩子。金融广告不能用夸大“秒批/保证放款”换 CTR。

素材

UGC

User-Generated Content｜用户生成内容/UGC 风格。贷款类要防止伪造体验或误导性承诺。

素材

CTA

Call To Action｜行动号召。如 Apply Now、Learn More；必须与目标页和真实产品条件一致。

七、报告、AI 与数据诊断

Google AI

Ask Advisor

Google Ads/Analytics 对话式分析助手。用于发现媒体异常，不代替首贷 CAC/FPD/LTV 判断。

Google AI

Report Generator

Google Ads 自然语言报告生成器，可从大量指标构建报告。

分析

Benchmarking

与匿名化 peer group 做基准对比。同行基准不是你的盈利阈值。

【墨西哥重点】所有术语最终都要回到合规 + 风险 + 利润

“Campaign CPA 低”“Assisted 很高”“Qualified Advertiser”“EMQ 高”都只是局部信号。墨西哥现金贷最终仍要穿透到 Approve Rate、Disburse Rate、成熟首贷 CAC、FPD/Vintage、LTV，并满足平台金融广告准入与数据使用边界。
