二、2026-09-11 新增：Multilingual / Localization

2026-09-11

Multilingual Tool

中文：TikTok 多语言工具。

准确解释：TikTok Ads Manager 中的 Smart+ 能力，可自动翻译广告音频并生成对应语言字幕，再基于用户设备语言设置交付对应版本。当前官方文档标注 Global，但只适用于 Smart+；自动版位不支持 Search，手动版位支持 TikTok feeds。

层级/类别：TikTok Smart+ / Creative Automation。

现金贷例子：全球英语素材自动生成目标语言音频/字幕后测试 Mexico 用户，但金融关键语义必须先 QA。

适用场景：跨语言素材扩展、App Promotion、Web Conversion。

常见误区：Global=账户支持所有语言；自动翻译=本地合规；CTR 好=翻译正确。

关系：Device Language、Translation、Dubbing、Localization、Smart+、Compliance Lock。

TikTok 官方原文

Device Language

中文：设备语言设置。

准确解释：操作系统/设备偏好语言，可被平台用于选择要交付的语言版本。

层级/类别：User/Delivery Signal。

现金贷例子：Mexico 用户手机语言设为英语，可能收到英语版本广告，但其贷款页面仍需要按实际产品市场与合规 Locale 承接。

适用场景：多语言交付与语言路由分析。

常见误区：设备语言=国籍、居住地、贷款资格或用户真正偏好语言。

关系：Locale、Multilingual Tool、Language Match Rate。

TikTok 官方背景

Translation

中文：翻译。

准确解释：把源语言信息转换为目标语言，重点是语义对应，不包含全部市场本地化要求。

层级/类别：Creative Production。

现金贷例子：将英文“subject to approval”翻译为 es-MX。

适用场景：字幕、文案、语音生成。

常见误区：语法正确就等于金融承诺和法律含义正确。

关系：Localization、Translation Drift、Language QA。

Localization

中文：本地化。

准确解释：在翻译基础上进一步适配目标市场的语言习惯、产品事实、用户理解、监管披露、货币/日期/数字格式和页面体验。

层级/类别：Market + Product + Creative。

现金贷例子：es-MX 使用符合墨西哥用户理解的借款术语、MXN、当前真实期限/费用与合法主体信息。

适用场景：跨国家、跨语言增长。

常见误区：墨西哥、西班牙、阿根廷、哥伦比亚的西语金融文案可以无审核完全复用。

关系：Translation、Locale、Canonical Copy、Compliance Lock。

Dubbing

中文：配音/语音本地化。

准确解释：用另一语言语音替换或叠加原视频音轨；AI 工具可自动生成。

层级/类别：Creative Audio。

现金贷例子：把英语贷款教育视频自动配成西语。

适用场景：短视频跨语言扩展。

常见误区：只审核字幕，不审核实际播出的语音金额、期限与限定词。

关系：Caption、Multilingual Tool、Language QA。

Caption / Subtitle

中文：字幕。

准确解释：视频上展示的文字转写或翻译，可与音频语言一致或不同。

层级/类别：Creative Text Layer。

现金贷例子：西语字幕展示“sujeto a aprobación”等资格限制。

适用场景：无声观看、跨语言视频。

常见误区：字幕正确即可忽略配音中的错误金融承诺。

关系：Dubbing、Translation、Compliance Lock。

Locale

中文：地区语言环境。

准确解释：语言与地区的组合语境，例如 es-MX；它不仅说明语言，也用于区分地区表达、格式和产品承接。

层级/类别：Product/Localization Configuration。

现金贷例子：广告、Landing Page、App 均明确使用 es-MX。

适用场景：Deep Link、页面路由、文案版本。

常见误区：把 language=es 与 locale=es-MX 当完全等价。

关系：Device Language、Locale Routing Contract、Language Match。

Translation Drift

中文：翻译语义漂移。

准确解释：自动翻译/改写后，与原始产品事实或受限表达相比发生语义弱化、强化、遗漏或歧义。

层级/类别：Creative Risk / QA。

现金贷例子：“最高可借”被翻成“可借”；“可能符合资格”被翻成“符合资格”。

适用场景：AI 翻译、自动字幕、AI 改写。

常见误区：只用 BLEU/机器分数或语法检查判断风险。

关系：Language QA、Compliance Lock、Translation Incident Rate。

Language QA

中文：语言质量审核。

准确解释：对自动翻译、字幕和配音进行语言正确性、自然度、数字/金额、限制词和语境检查。

层级/类别：Creative Operations / Quality Gate。

现金贷例子：审核 es-MX 音频中的 MXN 数字、期限和“需审批”表达。

适用场景：多语言素材上线前。

常见误区：Language QA 代替法务/合规审核。

关系：Compliance Lock、Canonical Copy、Localization Compliance Registry。

Compliance Lock

中文：合规语义锁。

准确解释：内部治理机制：把金额、期限、APR/费用、资格/审批限制、主体、必要 Disclaimer 等字段定义为不可被自动工具任意改写的受保护语义。

层级/类别：Compliance + Creative Governance。

现金贷例子：任何 Multilingual Variant 改变“subject to approval”含义就自动变为 Ineligible。

适用场景：AI 翻译、自动配音、生成式素材。

常见误区：把整条素材全部锁死，导致无法做 Creative Optimization；应区分 Creative Layer 与 Regulated Layer。

关系：Canonical Copy、Language QA、Disclosure Version。

Canonical Copy

中文：标准批准文案/基准文案。

准确解释：由产品、合规/法务等确认的目标市场标准表达，作为翻译和生成版本的比对基准。

层级/类别：Content Governance。

现金贷例子：es-MX 的 Amount、Tenor、APR/Fees、Approval Condition、Entity 和 Disclaimer 标准句。

适用场景：多语言、多素材版本管理。

常见误区：产品参数变化后仍沿用旧 Canonical Copy。

关系：product_version、disclosure_version、Compliance Lock。

Localization Compliance Registry

中文：本地化合规登记表。

准确解释：内部跨团队数据资产，记录每个语言/地区素材 Variant 的来源、产品版本、披露版本、QA、批准、失效和经营结果。

层级/类别：Product + Growth Governance。

现金贷例子：es-MX → creative_variant → disclosure_version → approve → FPD。

适用场景：多国家/多语言投放。

常见误区：只记录翻译文本，不记录实际视频/音频 hash、页面 Locale 和生效版本。

关系：Locale Routing Contract、Language QA、Creative Asset Registry。

Locale Routing Contract

中文：地区语言路由契约。

准确解释：内部产品契约，确保广告语言、Deep Link 参数、Landing Page Locale、App Locale 与产品市场按明确规则衔接和回退。

层级/类别：Product / Deep Link / Localization。

现金贷例子：es-MX 广告点击后优先进入 es-MX LP/App，Fallback 也不应跳到错误国家产品。

适用场景：Web-to-App、多语言 App、跨市场投放。

常见误区：只在前端切语言，不校验对应产品参数和披露版本。

关系：Deep Link、Locale、Landing Page、Localization Registry。

三、Landing Page / Web Traffic

Landing Page View / LPV

中文：落地页成功加载/落地页浏览。

解释：TikTok Traffic Objective 下的优化目标；用户点击广告且目标 Landing Page 成功加载时计入。

类别：TikTok Traffic Optimization / Page Event。

例子：点击 Mexico préstamo 广告并成功打开 H5。

误区：LPV=GA Page View/Session；LPV 高=首贷质量高。

TikTok 官方原文

Click

中文：广告点击。

只证明发生点击，不证明页面成功加载。

Traffic Objective

中文：流量目标。

TikTok Campaign Objective，用于获取网站/页面访问，可按 Click/LPV 等目标优化。

Smart+ Traffic Campaign

中文：TikTok Smart+ 流量广告。

主要目标为 Click/LPV 时可用；有 Pixel/Events API 且要推动网站深层 Conversion 时应评估 Smart+ Web。

TikTok 官方原文

Default Page View

广告主通过 TikTok Pixel / Events API 分享的网站页面事件，不等于 TikTok LPV。

View Content

由站点事件配置触发的内容浏览事件。

Instant Page

TikTok 体系内承载的落地页类型。

Matched-cell Test

在原生随机实验不可用时构造尽量可比 Control/Treatment 的内部实验方法，不等同严格随机实验。

Landing Page Performance Contract

把页面技术性能、金融披露、埋点、Deep Link、产品漏斗和风险结果绑定到版本化验收的内部治理方案。

四、素材自动化与 Lead Quality

Auto-Selection for Lead Generation

TikTok Lead Generation 创意自动化能力，可从品牌上传素材、Creator Content 与 AI-generated Content 中自动寻找、测试并放大高表现资产。

TikTok 官方原文

Custom Selection

广告主主动加入、排除素材或采用平台推荐资产的控制方式。

Creative Fatigue

受众反复接触相似素材后，注意力、互动或转化效率下降。

Asset Pool

允许 Campaign/自动化系统调用的一组视频、图片、文案、Creator/AI 素材。

Compliance Whitelist / Asset Eligibility

只有通过产品/法务/平台要求检查且 disclosure_version 有效的素材才能进入自动选择池。

Qualified Lead

满足业务定义最低有效资格、值得进入下一阶段申请/审批流程的线索。

CRM Sync

将广告线索与 CRM/后端业务状态连接，形成 lead_id → user_id → application_id → loan_id。

SIPRES

Sistema de Registro de Prestadores de Servicios Financieros，CONDUSEF 的金融服务提供者登记查询系统。

CONDUSEF SIPRES

Montadeudas

CONDUSEF 用于提醒消费者的一类非法/欺诈贷款 App 风险，可能涉及欺骗性贷款、过度权限、骚扰、威胁或敲诈。

CONDUSEF 官方

五、Google Target-based Bidding

Target CPA / tCPA

平台尝试以指定平均目标成本获取转化。若优化 Apply，它不是首贷 CAC。

Google 官方

Target ROAS / tROAS

平台最大化 conversion value，同时尝试达到设置的平均 ROAS。

Google 官方

Limited by budget

Campaign 因平均日预算限制而无法捕获全部符合条件流量。

Target Gap

平台 target 与成熟实际表现之间的差距。

Business-derived Target

从 Allowable First-loan CAC、成熟漏斗和 Risk-adjusted LTV 反推平台 target。

六、归因 / 平台 / 产品补充

Attribution Analytics

TikTok 的归因分析能力，用于分析窗口、Time to Conversion、Referred/Assisted 等旅程。

SAN — Self-Attributing Network

媒体平台自身识别符合归因规则的 App 转化并与 MMP 集成。

PineDrama

TikTok 体系短剧 App / Placement；Mexico 可用不等于所有账户均已开放。

SDK Spoofing

伪造 SDK/事件请求形成虚假归因或转化。

Install Hijacking

把原本属于 Organic/其他来源的安装抢归因给某渠道/Publisher。

Device Farm

利用大量真实/虚拟设备批量制造安装、点击或事件。

七、金融广告准入与 Mexico

TikTok Financial Services Policy
