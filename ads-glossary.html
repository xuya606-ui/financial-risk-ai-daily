一、账户结构与投放基础

基础

Ads

中文：广告，或广告平台/广告体系的泛称。

例：Google Ads 指平台；“这条 Ad CTR 高”指具体广告。

误区：Ads 不是 Campaign 同义词。

账户结构

Campaign

中文：广告系列/广告活动。

层级：广告账户下，Ad Set/Ad Group 上。

现金贷例：Mexico_NewUser_Disburse 可代表墨西哥新客放款 Campaign。

误区：拆太细会稀释转化样本。

Meta

Ad Set

中文：广告组（Meta 常用）。

常承载受众、版位、预算/排期、优化事件等。

Google/TikTok

Ad Group

中文：广告组。

管理相似关键词、受众、版位或优化逻辑；TikTok Search 关键词在 Ad Group 层管理。

账户结构

Ad

中文：具体广告。

通常由素材、文案、CTA 和目标链接组成。

素材

Creative

中文：广告素材/创意。

视频、图片、文案、Hook、封面、CTA、UGC 脚本等；现金贷不能只看 CTR，还要看 Apply CPA、CAC、FPD。

流量

Placement

中文：广告版位。

如 Feed、Stories、Reels、Search、Pangle/Audience Network 等。

流量

Publisher

中文：流量媒体/发布商。

第三方网络中应按 Publisher 看欺诈率、授信率、放款率与 FPD。

定向

Audience

中文：受众。

地区、年龄、自定义受众、相似人群、再营销人群等。

定向

Broad

中文：宽泛定向。

减少人工限制，让算法找转化用户。不要与 Search 的 Broad Match 混淆。

定向

Retargeting

中文：再营销/重定向。

面向访问未安装、安装未注册、注册未申请、审批未提款等用户。

定向

Lookalike Audience

中文：相似受众。

用种子用户找相似新客；现金贷优先用优质放款/正常还款 Cohort，而不是只用安装用户。

二、算法、出价与自动化

算法

Optimization Event

中文：优化事件。

告诉平台最希望找到哪种行为；事件越深通常越接近业务价值，但需要足够转化量。

算法

Learning Phase

中文：学习期。

系统积累转化信号、探索人群/版位/出价组合的阶段；频繁改参数会增加波动。

出价

Bid Strategy

中文：出价策略。

如 Maximize Conversions、tCPA、tROAS、Cost Cap、Highest Value。

预算

Budget Pacing

中文：预算节奏。

控制预算在一天、小时或活动周期内如何消耗。

官方原文：TikTok Time-based pacing

TikTok

Smart+

中文：TikTok 自动化投放体系。

2026 年 8 月升级后，Manual 与 Smart+ 进入统一创建流程，可选择全自动、部分自动或手动控制。

官方原文：TikTok Smart+ Upgraded Experience

TikTok/App

AEO

App Event Optimization｜应用内事件优化

不只优化安装，而是寻找更可能完成指定 App 事件的人。

价值优化

VBO

Value-Based Optimization｜价值优化

从“是否转化”升级到“转化价值多高”。

App

MAI

Mobile App Install｜移动应用安装

适合冷启动/深层事件量不足阶段。

Google

Performance Max / PMax

中文：效果最大化广告系列。

Google 跨多个库存自动寻找转化机会；现金贷要配合深层事件与业务质量监控。

Google

Demand Gen

中文：需求开发广告。

偏视觉与发现式流量，用户意图与 Search 不同。

Google

UAC / App Campaign

中文：Google 应用广告系列。

行业仍常说 UAC；当前产品名通常为 App Campaign。

官方原文：Google App campaigns

TikTok

App Promotion

中文：应用推广目标/场景。

用于 App 安装或应用内行为获客；具体能力以目标国家和账户实际界面为准。

三、Search 搜索投放

TikTok Search

Search Ads Campaign

中文：搜索广告系列。

根据 Keyword 参与 TikTok 搜索结果竞价，适合承接高意图需求。

官方原文：TikTok Search Ads setup

Search

SRP

Search Results Page｜搜索结果页

Search

Keyword

中文：关键词。

广告主主动选择的“想买的搜索意图”。

Search

Search Term / Query

中文：搜索词/实际查询。

用户真实输入的内容；与 Keyword 不是一回事。

Search

Match Type

中文：关键词匹配方式。

决定 Keyword 与真实 Search Term 允许差多远。

Search

Broad Match

中文：广泛匹配。

允许更宽语义范围，流量大但要更强 Search Terms 与后端质量监控。

Search

Phrase Match

中文：词组匹配。

比 Broad 更收敛，但仍允许一定语义/词序变化。

Search

Exact Match

中文：精确匹配。

不是字符完全相同；平台仍可能覆盖近义和语义变体。

Search

Negative Keyword

中文：否定关键词。

明确排除不想购买的搜索意图。

Search

Keyword Planner

中文：关键词规划工具。

用于查看搜索量、竞争度和扩词机会。

Search

Automatic Search Placement

中文：自动搜索版位。

把其他广告自动扩展到搜索结果环境；不同于手动关键词 Search Ads。

Search

Search Terms Report

中文：搜索词报告。

用于检查实际触发广告的查询，持续加词、否词和识别高/低质量意图。

Search

Keyword Quality

中文：关键词质量/相关性。

搜索量大不代表业务质量高，最终要接 Approve/Disburse/FPD。

四、归因、数据连接与事件治理

归因

MMP

Mobile Measurement Partner｜移动归因/衡量合作伙伴

连接广告触达与安装、注册、申请等 App 事件。

Apple

SKAN / AdAttributionKit

中文：Apple 隐私型广告归因体系。

在不提供传统设备级追踪的前提下返回聚合归因信号。

归因

Attribution Window

中文：归因窗口。

规定广告接触后多长时间内发生的转化可以被归给该广告。

归因

Postback

中文：回传。

MMP、平台或服务端把事件/归因结果发送给另一系统。

数据

S2S / Server-to-Server

中文：服务器到服务器回传。

不依赖浏览器脚本，由后端直接发送事件。

产品

Deep Link

中文：深度链接。

让用户点击后直接进入 App 指定页面，而不是只打开首页。

Google

App Connect

中文：Google Web-to-App 连接能力。

帮助 Search/PMax 等 Web Campaign 把已安装 App 的用户引导到 App 内。

官方原文：Google App Connect

实验

Deep Linking A/B Test

中文：深链 A/B 实验。

对比用户进入 App 指定页面与继续走 Web 页面后的转化差异。

Google

UHA

Users Who Have App｜已安装 App 用户

用于单独看 Deep Link 对已安装用户的真实提升。

数据

Conversion Lag

中文：转化延迟。

广告接触到目标转化被记录之间的时间差。

数据连接

Pixel

中文：像素/浏览器事件采集。

通过网页端代码把访问、注册、申请等事件发给广告平台。

现金贷：适合 Web LP，但会受浏览器、脚本加载、网络和隐私限制影响。

TikTok

Events API

中文：事件 API / 服务器事件回传。

TikTok 的服务器数据连接，可发送 Web、App、Offline/CRM 等营销事件，常与 Pixel 联合使用。

官方原文：TikTok Data Connection setup methods

Meta

Conversions API / CAPI

中文：转化 API。

Meta 的服务器数据连接，用于网站、App、线下和消息事件的优化与衡量；可与 Meta Pixel 联合使用。

误区：CAPI 不是绕过隐私/数据政策的工具。

官方原文：Meta：About Conversions API

数据质量

Event Deduplication

中文：事件去重。

Browser + Server 同时上报同一行为时，平台识别为同一事件并只计一次。

现金贷例：Apply 同时由 TikTok Pixel 与 Events API 回传，event_id 一致时应只记录一个申请。

误区：不去重会虚增转化，导致 CPA 假性下降、算法学错。

官方原文：TikTok：Event Deduplication

数据质量

event_id

中文：事件唯一标识。

为同一业务行为生成稳定唯一 ID；Browser 与 Server 两条链路使用相同 event_id，帮助平台正确去重。

误区：两条链路各生成随机 ID，会把同一事件算成两个转化。

数据质量

Event Match Quality / EMQ

中文：事件匹配质量。

平台评估事件能否有效匹配到广告触达/用户的诊断指标。TikTok Events Manager 有 EMQ Score；Meta 也使用 Event Match Quality 概念。

误区：EMQ 高 ≠ 授信率高、FPD 低；它只说明数据连接/匹配更健康。

事件

Standard Event

中文：标准事件。

平台预定义、语义固定的事件名称。TikTok 例如 CompleteRegistration、SubmitApplication。

现金贷：优先用标准事件表达“提交申请”，不要把敏感信用结果塞进事件名称。

官方原文：TikTok Standard Events

事件

Custom Event

中文：自定义事件。

广告主自己定义的业务行为。适合补充报告和受众，但平台可能限制其优化能力。

TikTok 注意：当前文档明确 Custom Events 不能用于 Campaign optimization。

数据连接

Browser + Server

中文：浏览器 + 服务器双链路。

Pixel/SDK 与 Events API/CAPI 同时发送同一事件，提高覆盖和稳定性；重叠事件必须去重。

Meta/合规

Business Tool Data

中文：Meta Business Tools 数据。

通过 Pixel、CAPI、App Events 等 Meta Business Tools 分享的数据，需满足 Meta 条款和适用法律。

官方原文：Meta Business Tools Terms

合规

Sensitive Data

中文：敏感数据。

现金贷尤其要警惕金融/信用、健康、生物识别等敏感类别。Meta Business Tools Terms 明确禁止分享金融信息等敏感数据；TikTok 也要求事件设置避免发送敏感访客数据。

现金贷默认禁止外发：银行账号、收入、信用评分、审批额度、定价/APR、还款/逾期状态、催收/欺诈特征等借款人级字段，除非平台条款和内部法务/合规明确允许。

官方原文：Meta Business Tools Terms ｜ TikTok Standard Events

产品治理

Marketing Event Contract

中文：营销事件契约（内部治理概念）。

把事件名、触发条件、字段白名单、event_id、时间戳、授权状态、平台去向、版本和负责人写成正式数据产品规范。

Meta AI

Meta AI Business Connection

中文：Meta AI 业务连接。

Meta 2026-08-19 开始推出的新能力，可在授权后连接 Instagram/Facebook、Meta Ads 和 Google Workspace，分析内容和广告表现并生成建议。

现金贷：适合媒体诊断和报表，不应直接读取借款人敏感金融数据，也不能代替首贷 CAC/FPD/LTV 决策。

官方原文：Meta 官方公告

五、素材与创意体系

TikTok

Spark Ads

中文：原生内容放大广告。

把品牌自己或经授权创作者的 organic TikTok post 作为广告素材。

官方原文：TikTok Spark Ads

TikTok

Non-Spark Ads

中文：非 Spark 广告。

标准广告素材，不直接绑定某个原生 organic post。

Smart+

Asset Group

中文：资产组/创意资产容器。

用于承载创意、文案、URL 等组合；现金贷要避免不同产品期限/费用素材混用。

Smart+

Paid & Organic Optimization

中文：付费与自然流量联合优化。

在支持场景中联合使用 paid 与 organic 信号。

Smart+

Organic Anchor

中文：自然内容锚点链接。

为 organic post 增加可点击目的地链接。

Smart+

Multi-URL

中文：多目标 URL。

同一活动管理多个目标 URL；必须保证素材承诺与对应产品一致。

AI Creative

Recommended Creatives

中文：推荐创意。

平台根据历史素材与信号推荐可用内容；金融广告仍需经过合规审核。

AI Creative

Automatic Enhancements

中文：自动创意增强。

平台自动调整素材表现形式；自动改写后要检查期限/费用/免责声明一致性。

素材

Creative Fatigue

中文：素材疲劳。

同一素材反复曝光后 CTR/CVR 下降、CPA 上升；要结合 Frequency、Reach 与受众规模判断。

治理

Creative Registry

中文：素材台账（内部治理概念）。

记录 creative_id、版本、CTA、URL、期限、APR/费用口径、适用国家、产品版本、审核状态。

素材

Hook

中文：开头钩子。

视频/文案前几秒用于抓住注意力；金融广告不能靠夸大“秒批/保证放款”换 CTR。

素材

UGC

User-Generated Content｜用户生成内容/UGC 风格

贷款类要防止伪造用户体验、审批结果或误导性承诺。

素材

CTA

Call To Action｜行动号召

如 Apply Now、Learn More；CTA 要与目标页和真实产品条件一致。

【墨西哥重点】术语最终必须回到经营与合规

“Campaign CPA 低”“EMQ 高”“Search Term 很准”“Spark Engagement 高”都只是局部信号。墨西哥现金贷最终仍要穿透到 Approve Rate、Disburse Rate、首贷 CAC、FPD/Vintage、LTV，并满足平台金融广告准入和数据使用边界。
