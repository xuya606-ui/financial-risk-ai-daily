一、账户结构与素材

Ads

中文：广告/广告体系泛称。Google Ads 是平台名；Ad 是具体广告；Ads 本身不是固定层级。

误区：把 Ads、Ad、Campaign 混为一谈。

Ad Account

中文：广告账户。通常承载账单、权限、时区、像素/事件源以及多个 Campaign。

Campaign

中文：广告系列/广告活动。

层级：Ad Account 下、Ad Set/Ad Group 之上，承载目标、Budget/Bid 和核心投放逻辑。

现金贷例子：Mexico_NewUser_Disburse_Search。

Ad Set

Meta 常用广告组层级，常配置 Audience、Placement、Budget/排期、Optimization Event。

Ad Group

Google/TikTok 常用广告组层级，用于组织 Keyword、Audience、Bid、Creative、URL。

Ad

具体广告，由视频/图片、标题、正文、CTA 与目标链接组成。

Creative

广告创意/素材，包括视频、图片、文案、Hook、CTA、UGC 脚本等。现金贷不能只按 CTR 评价，要接 Approve/Disburse/FPD。

Placement

广告版位，如 Feed、Reels、Stories、Search、Pangle、Audience Network。

Publisher

实际提供流量的网站、App、媒体或联盟子渠道。现金贷应按 Publisher 看 Fraud、Approve、Disburse、FPD。

Audience

受众，包括年龄、地区、兴趣、自定义受众、相似受众、再营销。

Broad

宽泛定向/广泛匹配的泛称；在 Search 中通常指 Broad Match，在 Audience 中可能表示减少人工限制。

Retargeting

再营销/重定向，如安装未注册、注册未申请、审批未提款、沉默老客召回。

Hook

素材开头吸引注意力的钩子。金融广告不能靠“保证放款/秒批”等夸大承诺换 CTR。

UGC

User-Generated Content 或 UGC 风格内容。

CTA

Call To Action，行动号召，如 Apply Now / Learn More。

二、出价与自动化

Optimization Event

告诉平台最希望算法寻找什么行为，如 Install、Apply、Disburse。事件越深越接近经营价值，但需要足够样本量。

Bid Strategy

出价策略，决定平台更偏拿量、控 CPA 还是控 Value/ROAS。

Cost Cap

围绕目标 CPA 控制长期平均成本，并不是每笔转化硬上限。

Maximum Delivery

以 Budget 为主要约束，尽量获取更多结果。

Learning Phase

平台积累转化信号、探索人群/素材/版位/Bid 组合的阶段。

CBO

Campaign Budget Optimization，Campaign 级预算分配。

Smart+

TikTok 自动化投放体系，可自动化受众、版位、素材、Budget/Bid 等模块。

TikTok 官方

Performance Max / PMax

Google 跨 Search、YouTube、Display、Discover、Gmail、Maps 等资源的自动化 Campaign。

Demand Gen

Google 视觉化中下漏斗 Campaign，可覆盖 YouTube、Discover、Gmail、Maps、GDN 等库存。

UAC / App Campaign

Google 应用广告系列。行业仍常说 UAC，Google 当前通常称 App Campaign。

AEO

App Event Optimization，按应用内事件优化。

VBO

Value-Based Optimization，按事件价值优化。

MAI

Mobile App Install，移动 App 安装优化。

三、Agentic Advertising｜2026-09-03 新增

2026-09-03

TikTok Agentic Hub

中文：TikTok AI Agent 解决方案市场/发现层。

解释：TikTok 官方集中分发和管理 AI-powered solutions / AI Skills 的入口。

现金贷例子：寻找自动报告、素材疲劳监测、预算建议等 Skill。

误区：认为从 Hub 安装的 Skill 就天然符合公司的金融合规与风控规则。

TikTok 官方

TikTok for Business MCP Server

中文：TikTok 广告 MCP 连接服务器。

解释：把 Campaign Management、Reporting、Audience、Creative Operations 等能力以结构化工具暴露给 AI Agent。

现金贷：先只读，再逐步开放 Write；Budget/Bid 自动修改必须接业务 Guardrail。

TikTok 官方

MCP / Model Context Protocol

中文：模型上下文协议。

解释：标准化 AI Agent 如何发现、连接和调用外部平台工具，可理解为 AI 工具生态的“通用适配器”。

关系：MCP Server 提供 Tool；AI Agent 调用 Tool；Skill 把 Tool 组合成高层工作流。

AI Agent

中文：AI 智能体。

解释：能够理解高层目标、读取上下文、调用工具并执行决策的 AI 系统。

现金贷例子：每天分析 Campaign + First-loan CAC + FPD7 后生成预算建议。

误区：让 Agent 直接以 Apply CPA 为单目标自动扩量。

AI Skill

中文：AI 工作技能/可复用工作流。

解释：把规则、步骤和多个 Tool 组合成一个业务任务，例如素材疲劳监控或预算优化。

关系：比单个 MCP Tool 更高层。

MCP Tool

中文：MCP 工具函数。

例子：create campaign、get performance report、update audience、pause ad group。

现金贷：Read Tool 与 Write Tool 应分权限。

Human-in-the-loop / HITL

中文：人在回路。

解释：AI 做分析或建议，但高风险动作由人工确认后执行。

现金贷：Budget/Bid、金融 Creative、Landing Page、Targeting 变化建议默认 HITL。

Approval Gate

中文：审批闸门。

解释：Write 操作执行前必须满足数据成熟、风险、合规和权限条件，并由授权角色批准。

Rollback

中文：回滚。

解释：自动/人工修改导致业务指标恶化后恢复到上一个稳定配置。

现金贷：每个 `change_id` 应保存 old/new value 与 rollback_rule。

Kill Switch

中文：紧急停止开关。

解释：出现合规、数据、风险或系统异常时，立即停止 Agent Write 权限或自动化流程。

Agentic Ads Control Center

中文：智能体投放控制中心。

内部产品概念：统一管理 Agent 权限、建议、审批、执行、Change Log、Monitoring、Rollback 和 Kill Switch。

四、Google Search / AI Max

AI Max for Search

Google Search AI 增强套件，包含 Search Term Matching、Text Customization、Final URL Expansion 等能力；不等于 PMax。

Google 官方

AI Max Auto Upgrade

2026 年 9 月起，仍使用 ACA/Text Customization 或 Campaign-level Broad Match Setting 的符合条件 Search Campaign 逐步自动升级到 AI Max。

Keyword Prioritization

同一 Search Term 可被多个 Keyword/Search Theme 匹配时，Google 用匹配身份、AI relevance 与 Ad Rank 决定谁进入竞价。

Search Term / Query

用户实际输入的搜索内容。

Keyword

广告主设置、希望购买的搜索意图。

Match Type

Keyword 与 Search Term 允许差多远的规则，常见 Broad / Phrase / Exact。

Negative Keyword

否定关键词，用于排除不需要的搜索意图。

Search Term Matching

AI Max 中用于扩大可触达 Search 意图的能力。

Text Customization / ACA

根据网站、现有广告和关键词自动创建/调整 Search 文案；金融广告需用 Text Guidelines / 合规流程限制错误承诺。

Final URL Expansion / FUE

Google 根据搜索意图将用户送到同域名更相关页面。现金贷需要可投 URL Registry 与 Exclusion。

AI Max Experiment

在 Search Campaign 中用 Control / Treatment 测试 AI Max。2026 年 9 月 Google 还开始推出跨多个 Search Campaign 测试不同 Budget/ROI Target 的 A/B Test。

Google 官方

Performance Planner

Google Ads 规划工具，可模拟 Bid/Budget Target 变化对 Campaign 表现的影响并应用建议。

五、线索、转化与产品链路

Conversion

转化。现金贷必须说明具体事件：Install、Register、KYC、Apply、Approve、Disburse。

Lead Journey Mapping

把广告互动后的 Raw Lead、Qualified Lead、Converted Lead 与最终业务结果串成一个漏斗。

Raw Lead

刚产生的表单、消息、注册或申请，尚未完成资格验证。

Qualified Lead

通过最低业务资格验证、值得继续审批/跟进的 Lead。

Converted Lead

比 Qualified Lead 更接近最终结果的深层 Lead，可按公司定义为 Approve 或 Disburse。

Deep Link

广告、Push、短信等点击后直接打开 App 指定页面。

Web-to-App

广告 → Web LP → App Store/App → App 内转化。

六、归因、事件与反作弊

MMP

Mobile Measurement Partner。连接广告触达与 Install、Register、Apply、Disburse 等 App 事件。MMP 是归因层，不等于业务真相。

Pixel

浏览器侧事件采集器。

Events API

TikTok 服务器侧营销事件回传接口。

Conversions API / CAPI

Meta 服务器侧数据连接接口。

S2S / Server-to-Server

服务器到服务器事件或归因数据连接。

Postback

归因/事件结果由设备、MMP 或平台发送的数据通知。

Event Deduplication

Browser + Server 同时上报同一事件时，利用 event_id 等避免重复计数。

Attribution Window

广告接触后多长时间内的转化仍有资格算给该广告。

Attribution Model

多个触点都合格时，决定转化信用如何分配。

Conversion Lag

广告互动到转化发生/被记录的时间延迟。

Incrementality

回答“如果没有广告，这个用户是否仍会转化”，通常需要 Holdout/Lift/Geo Experiment。

SDK Spoofing

攻击者模拟 SDK 请求，制造虚假 Install/In-app Event。

Install Hijacking

真实用户安装 App，但欺诈方伪造最后触点抢走归因。

Device Farm

批量真机、云设备或 Emulator 制造 Install/Event。

七、iOS 隐私归因

AdAttributionKit

Apple 隐私广告归因框架，让广告网络、Publisher App 与被推广 App 在不依赖跨 App 个体追踪的前提下获得安装/再互动和转化 Postback。

Apple 官方

SKAdNetwork / SKAN

Apple 隐私广告归因基础设施。数据聚合、延迟且粒度可能受隐私阈值限制。

Fine Conversion Value

细粒度转化值，用整数表示更细的漏斗/价值信号。

Coarse Conversion Value

粗粒度转化值，常见 low / medium / high；不等于信用风险高/中/低。

Postback Data Tier / Crowd Anonymity

Apple 根据隐私条件决定 Postback 可携带的数据粒度。

Reengagement

已安装用户通过可归因广告重新回到 App 并互动。

八、金融广告准入与墨西哥政策

Restricted Vertical

受限行业/垂类，如金融、博彩、医药，通常有额外准入与内容要求。

Advertiser Eligibility

广告主是否有资格在目标国家推广某金融产品。

Platform Permission

某些受限产品需要平台额外批准；不要扩大成“所有金融广告都必须白名单”。

Ad Review

针对具体 Ad/Creative、文案和 Landing Page 的审核；通过不等于所有上层准入永久满足。

TikTok Financial Services Policy

Mexico 当前：当地/区域许可、必要披露、18+；may-be-allowed 示例含 mortgage、consumer finance、P2P、BNPL；明确禁止示例含 APR ≥50% High APR Loan、Payday Loan、≤90 天 Short-term Loan。

TikTok 官方

Google Personal Loans

只允许需要 61 天或以上才能全部还清的 personal loan，并要求 LP/App 显著披露最短/最长期限、最高 APR/当地等效口径和代表性总成本。

Google 官方

使用方式

术语词典回答“这是什么”；指标词典回答“怎么算、怎么看”；每日日报负责把术语和指标放进 Mexico 现金贷真实投放链。平台专有术语优先点击本页官方原文核对最新定义。
