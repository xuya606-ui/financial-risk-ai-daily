SDK 供应链发布门禁

把第三方 SDK 从“研发依赖”升级为“应用商店合规资产”：每次新增、升级、删除 SDK，都检查来源、版本、权限、数据、隐私声明、签名、政策风险、Owner 与回滚方案。

01｜为什么要把 SDK 单独做发布门禁

政策责任

SDK 违规 = APP 风险

Google Play 明确：开发者要确保第三方 SDK 的代码和实践不会导致 APP 违反政策；Apple 同样要求开发者对 APP 中第三方 SDK 的代码和数据实践负责。

隐私

SDK 会改变数据声明

SDK 升级可能新增权限、数据字段、网络域名、标识符或共享方，从而改变 Data safety、App Privacy 和隐私政策。

供应链

版本不是唯一风险

还要关注来源、签名、供应商通知、已知安全问题、政策警告、远程代码能力和回滚版本。

02｜Google Play：SDK 责任与检查

Google Play 的 SDK Requirements 明确指出，如果 APP 包含 SDK，开发者负责确保第三方代码和实践不会导致 APP 违反 Play 政策。Data safety 也必须准确覆盖第三方库/SDK 的数据收集、使用和共享。

Google SDK Requirements 官方原文 ↗Data safety 官方原文 ↗

Play SDK Index

用于查看常见商业 SDK 的信息、权限等，帮助判断某 SDK 是否适合当前 APP。建议每次新增/升级 SDK 前做一次查询并保存结果。

Google Play SDK Index ↗

Android SDK 安全最佳实践

Android 官方建议开发者理解 SDK 使用的权限和数据，并关注 Play SDK Index；对于含运行时解释语言、敏感数据等能力的 SDK，要额外评估政策风险。

官方最佳实践 ↗

供应商警告

SDK 提供方可通过 Play SDK Console 向 APP 开发者传递过时版本、已知问题、政策/安全风险。团队应把这类提示纳入发版阻断条件。

Play SDK Console ↗

03｜Apple：Privacy Manifest + SDK Signature

Apple 要求开发者了解第三方 SDK 的数据收集和使用。对于 Apple 列出的常用第三方 SDK，在适用的新 APP 或新增该 SDK 的更新提交中必须包含 Privacy Manifest；作为二进制依赖时还需要 SDK Signature。Xcode 会把第三方 SDK 的隐私清单聚合成报告，用于帮助维护 App Privacy。

Apple 第三方 SDK 要求 ↗Apple App Privacy ↗
注意：“某 SDK 不在 Apple 列表里”不等于不需要做隐私治理。开发者仍对第三方代码和实际数据行为负责；名单只是明确要求 Privacy Manifest / Signature 的常用 SDK 范围。

04｜建议发布门禁

门禁阶段检查项阻断条件
依赖变更新增/升级/删除 SDK，来源与版本差异来源不可验证、未知二进制、无 Owner
Android 权限Manifest、运行时权限、SDK 间接权限引入贷款类禁止权限或用途无法解释
数据行为采集字段、标识符、共享方、域名、保留期与 Data safety/App Privacy/隐私政策不一致
Google 风险SDK Requirements、Play SDK Index、供应商提示已知政策/安全问题未关闭
Apple 风险Privacy Manifest、Signature、Required Reason API应提供而缺失，或签名来源异常
质量Crash/ANR、启动耗时、网络失败、内存关键指标超过内部阈值
回滚稳定旧版本、Feature Flag、远程停用能力发生问题无法快速回滚
推荐规则
SDK_RELEASE_GATE = 来源可验证 + Owner 明确 + 权限通过 + 数据对账通过 + Google SDK 风险通过 + Apple Manifest/Signature 通过 + 关键回归通过 + 回滚方案存在 任一 P0 项失败 → 不得提审 / 不得放量

06｜🇲🇽 现金贷 APP 专项

风控 SDK

设备 / 反欺诈

重点检查 installed apps、设备标识符、精确定位、联系人、电话号、照片/媒体等能力，避免三方 SDK 间接引入贷款类禁止数据。

归因 / 广告 SDK

标识符关联

关注 AAID/IDFA 与持久设备标识、邮箱、电话号的关联方式，以及是否与声明用途一致。

KYC / OCR / 人脸

高敏感数据

记录图像、证件、人脸、活体结果的处理方、存储地、保留期、训练用途和删除机制，并与隐私政策/商店声明一致。

现金贷发版前最小 SDK 审计
  • 导出 Android Gradle / iOS Pods-SPM 依赖清单。
  • 对比上一个线上版本，标注新增、升级、删除 SDK。
  • 扫描 Manifest / entitlements / Required Reason API。
  • 抓取启动和关键借款流程网络域名。
  • 核对第三方隐私文档、数据字段和保留期。
  • Google：检查 SDK Requirements / Play SDK Index；Apple：检查 Privacy Manifest / Signature。
  • Data safety、App Privacy、隐私政策完成三方对账。
  • 保留稳定 SDK 版本和回滚方案。
