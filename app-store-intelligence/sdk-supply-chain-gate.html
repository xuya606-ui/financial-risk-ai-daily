01｜SDK 数据声明漂移（Disclosure Drift）

SDK 版本变化本身不是最终风险；真正需要阻断的是“构建或运行行为已经变化，但商店声明没有同步变化”。因此将 SDK 变更统一转成四层证据链：

① Dependency Diff

记录新增 / 升级 / 删除、旧版与新版、来源、checksum/signature、Owner。

② Build Evidence

Android merged Manifest / permissions；iOS Privacy Manifest、SDK Signature、Required Reason API、entitlements。

③ Runtime Evidence

登录、KYC、申请、合同、还款等关键链路真实访问域名、数据类型、标识符、共享方和存储行为。

④ Store Disclosure

Google Data safety、Apple App Privacy、隐私政策及贷款权限声明是否需要更新。

if (build_evidence_changed || runtime_evidence_changed) && store_disclosure_not_reconciled: status = DISCLOSURE_DRIFT_BLOCKED submit = false rollout = false

02｜为什么 SDK 必须单独治理

政策责任

SDK 违规 = APP 风险

Google Play 明确要求开发者确保第三方 SDK 的代码和实践不会导致 APP 违反政策；Apple 同样要求开发者对第三方 SDK 的代码与数据实践负责。

隐私

SDK 会改变商店声明

升级可能新增权限、数据字段、网络域名、标识符、共享方或 Required Reason API，从而改变 Data safety、App Privacy 与隐私政策。

供应链

版本不是唯一风险

还要关注来源、签名、供应商警告、已知安全问题、远程代码能力、依赖传递和回滚版本。

03｜Google Play：SDK 责任、Data safety 与权限

Google Play 的 SDK Requirements 明确：APP 包含 SDK 时，开发者仍负责确保第三方代码和实践符合 Play 政策；Data safety 必须准确覆盖第三方库/SDK 的数据收集、使用和共享。现金贷 APP 还需要将 Financial Services 的敏感权限限制作为更高优先级门禁。

Google SDK Requirements ↗Data safety ↗Financial Services ↗

Play SDK Index

每次新增/升级常见商业 SDK 前查询 Play SDK Index，并保留版本、权限与供应商提示证据。

Play SDK Index ↗

Merged Manifest

以最终 AAB/APK 的 merged Manifest 为准，识别 SDK 间接带入的敏感权限，不接受“业务代码没写权限”作为合规结论。

SDK Warning

供应商通过 Play SDK Console 发出的过时版本、政策或安全警告纳入发版阻断。

Play SDK Console ↗

04｜Apple：App Privacy + Privacy Manifest + SDK Signature

Apple 要求 App Privacy 回答覆盖 APP 自身及第三方合作方/SDK 的数据实践。Apple 列出的常用第三方 SDK 在适用提交场景需要 Privacy Manifest；作为二进制依赖时还可能需要 SDK Signature。Xcode 可聚合第三方 Privacy Manifest，帮助形成隐私报告。

Apple 第三方 SDK 要求 ↗Apple App Privacy ↗
注意：某 SDK 不在 Apple 常用 SDK 列表中，不代表可以跳过隐私治理。开发者仍需对第三方代码的实际数据行为负责。

07｜🇲🇽 现金贷 APP 专项

风控 SDK

设备 / 反欺诈

重点检查 installed apps、设备标识符、精确定位、联系人、电话号、照片/媒体等能力，防止第三方 SDK 间接引入贷款类禁止数据。

归因 / 广告 SDK

标识符关联

关注 AAID/IDFA 与持久标识符、邮箱、电话号的关联方式，以及收集/共享目的是否与商店声明一致。

KYC / OCR / 人脸

高敏感数据

记录证件、图像、人脸、活体结果的处理方、存储地、保留期、训练用途和删除机制，并与隐私政策/商店声明一致。

现金贷发版前最小 SDK 审计
  • 导出 Android Gradle / iOS Pods-SPM 依赖并与线上版本做 Diff。
  • 导出 merged Manifest / entitlements / Privacy Manifest / Required Reason API。
  • 抓取登录、KYC、申请、合同、还款等关键流程网络域名与数据类型。
  • 对比第三方隐私文档、供应商警告与实际运行行为。
  • Google：Data safety + Financial Services；Apple：App Privacy + Manifest/Signature 完成对账。
  • 输出 evidence hash、Owner、结论与回滚版本。
