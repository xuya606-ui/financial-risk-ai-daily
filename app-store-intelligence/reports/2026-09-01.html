Google Play｜执行后 P0

P0 · 已生效Target API

API 36：从“截止日”切换为“执行后验证”

自 2026-08-31 起，新的移动 APP 和 APP 更新必须 target Android 16 / API 36+ 才能提交；现有移动 APP 至少需要 target API 35，才能继续面向运行高于 APP target API 的新用户保持正常可发现性。符合条件的受影响 APP 可通过 Play Console 申请延期至 2026-11-01。

今天开始要验证四件事：①每个在架包的 target API 与 extension 状态；②计划更新包是否已达到 API 36；③旧 target APP 是否出现新用户/新系统版本的可发现性限制；④API 36 上线后的 OTP、KYC、OCR/相机、文件、Push、Deep Link、WebView、后台任务及关键 SDK 是否稳定。

Play package 注册进入最后一个月

所有 Play package name 需要完成注册以满足 Android developer verification / Play Console Requirements。未在 9 月 30 日前注册的 Play APP 可能依据 Play Console Requirements 被移除。Google 表示绝大多数 APP 已自动注册，但仍需逐包核对剩余项。

需继续区分：9 月 30 日 Android developer verification 的用户安装层首批执行区域是巴西、印度尼西亚、新加坡和泰国；墨西哥不在首批四国，但 Play package 注册本身仍需处理。

Apple App Store｜今日状态

无审核政策大改

iOS 27 beta 8 已发布，但不等于新的正式提审工具链门槛

Apple 于 2026-08-31 发布 iOS/iPadOS/macOS/tvOS/visionOS/watchOS 27 beta 8。与此同时，App Store Connect 当前最新明确支持的 TestFlight 工具链更新仍是 8 月 25 日的 Xcode 27 beta 6 + beta 6 SDK。产品/研发应继续区分“OS beta 发布”与“App Store Connect 明确接受的构建工具链”，不要从 OS beta 版本号推导正式提交支持。

🇲🇽 墨西哥专项｜最新风险信号

2026-08-31 新数据

Estado de México：18,073 件投诉，催收与欺诈继续是高频风险

CONDUSEF 8 月 31 日公布：2026 年 1–7 月 Estado de México 共处理 18,073 件投诉，同比增长 11.3%，占全国投诉 11.3%；27.1% 与不当催收实践相关，29.7% 与可能的欺诈相关；SOFOM E.N.R. 占当地投诉涉及机构的 9.0%。信用卡、借记卡和个人贷款合计关联 60.4% 的投诉。

这不是新的全国 APP 上架法规，但对现金贷产品/贷后治理非常有价值：应把“催收投诉率、疑似欺诈投诉率、投诉有利解决率、供应商投诉集中度”纳入贷后 Dashboard，并与 APP 版本、渠道、风控策略、催收供应商关联。
