三、金融 / 隐私 / 权限持续规则

Google · 金融

Financial features declaration 继续逐轨维护

发布到 Google Play 的 APP 都需要完成 Financial features declaration；金融 APP 需按实际功能选择直接放贷、贷款撮合、信用、支付等类别，并维护与主体/证明材料一致的声明。个人贷款商店信息继续要求期限、最大 APR、代表性总成本示例和隐私政策；不得要求 60 天或以内全额还清。

36% APR / 60 天规则无变化

四、今日新增长期知识：SDK 数据声明漂移门禁

长期沉淀 · V2

Dependency Diff → Build Evidence → Runtime Evidence → Store Disclosure

每次新增、升级或删除 SDK，不再只核对版本号，而是做四层 Diff：①依赖版本变化；②Android merged Manifest / iOS Privacy Manifest、Signature、Required Reason API 的构建证据；③关键流程真实网络域名、数据类型与共享方；④Google Data safety / Apple App Privacy 的商店声明。只要构建或运行证据变化，而商店声明没有同步变化，就标记 DISCLOSURE_DRIFT_BLOCKED，阻断提审或放量。

建议台账新增：sdk_change_id / old_version / new_version / permission_diff / privacy_manifest_diff / runtime_domain_diff / data_type_diff / data_safety_diff_required / app_privacy_diff_required / evidence_hash / compliance_owner / reviewed_at。
