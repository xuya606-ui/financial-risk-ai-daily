今日结论

截至 2026-08-17，未发现 Google Play 或 Apple 在今天新发布、且直接改变现金贷 APP 审核口径的重大政策。当前最重要的是临近生效的技术/提交门槛：Google Play 2026-08-31 target API 截止、2026-09-30 Android developer verification/package name 节点，以及 Apple 2026 年 9 月起新增的年龄分级“社交媒体能力”必答项。

高风险提醒

Google Play · 2026-08-31

新 App 和更新必须 target Android 16 / API 36

移动端新应用和应用更新自 2026-08-31 起必须 target API 36+。现有移动应用至少 target API 35，才能继续面向运行更高 Android 版本的新用户保持可发现性。官方允许申请延期到 2026-11-01。

产品/研发影响：若现金贷 APP 仍是 API 35 或更低，月底后更新可能无法提交；升级 target API 还可能影响权限行为、通知、后台任务、WebView、相机/文件选择、深链和第三方 SDK。
建议动作：今天完成全量包 targetSdk/compileSdk/关键 SDK 盘点；未完成升级的 APP 进入红色门禁。
📎 查看 Google Play 官方原文：Target API level requirements ↗
Google Play · 2026-09-30

Android developer verification / package name

Google 表示约 99% 的 Play 应用已基于已有信息自动完成注册，但开发者仍需检查 Play Console Home，确保剩余应用 package name 已注册；未完成的 Play package 面临从 Google Play 全球移除风险。

建议动作：建立“开发者账号—package name—签名—验证状态—Owner”台账，并和已上架/测试/计划上线包做一一核对。
📎 查看 Android Developers 官方原文：Developer verification / Google Play Console ↗
Apple · 2026-09

年龄分级新增“社交媒体能力”提审必答

Apple 已在 2026-07-09 更新 App Store Connect 年龄分级问卷；从 2026 年 9 月开始，提交新 App 或更新时必须回答应用是否包含社交媒体能力。

现金贷 APP 判断：通常为“否”；但若 APP 含公开 UGC feed、内容转发/传播、公开互动等能力，应由产品、iOS 和合规共同确认，并提前更新 App Information。
📎 查看 Apple 官方原文：Age rating questionnaire update ↗

金融 / 信贷专项复核

Google Play 当前金融服务政策仍要求任何包含金融功能的 APP 完成 Financial features declaration；个人贷款 APP 还需遵守当地法规和特定贷款披露/权限规则。Apple 的个人贷款规则仍要求显著披露贷款条款，并维持最高 APR 36%（含成本和费用）及不得要求 60 天或更短全额还款的限制。

建议动作：发版时联动检查 Store Listing、APP 借款页、合同、费用页、Financial features declaration、Data safety/App Privacy 和审核测试账号，不要把这些拆成独立团队的孤立检查。

🇲🇽 墨西哥专项

品牌/主体证据

把“防冒名 APP”纳入合规证据治理

CONDUSEF 2026 年持续通报合法金融机构被冒用名称、Logo、网站或移动 APP 的情况；其公开材料持续建议用户通过 SIPRES 核验金融机构身份。2026-07-13 的通报显示，仅 2026 年 6 月就有 11 家已登记金融机构报告身份冒用。

长期动作：固定保存 SIPRES/相关登记、RECA、官网、开发者名称、商店链接、package name/Bundle ID、Logo、客服号码和隐私主体的月度快照；发现仿冒后可更快用于 Google/Apple 投诉、监管举证和用户公告。
