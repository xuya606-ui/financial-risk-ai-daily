今日最重要纠偏：Geofencing 截止日

日期纠偏Google Play

Canonical Policy Deadlines 当前列为 2027-01-27

Google Play 当前英文 Policy Deadlines 总表将“移除 geofencing 作为获批 foreground service 使用场景”的截止日列为 2027-01-27。但 Google 的旧 Policy Preview 页面仍显示 2026-08-26。两个官方页面当前存在日期冲突。

内部处理原则：发版和整改排期优先以当前 canonical Policy Deadlines + Play Console 实际提示为主，并保留旧 Preview 作为历史差异证据；不要继续把 8/26 当成已确认的 Geofencing 强制日。

现金贷例外：日期延后不代表个人贷款 APP 可以使用精确定位。Google Financial Services 当前仍明确禁止个人贷款及贷款导流/撮合等相关 APP 使用 ACCESS_FINE_LOCATION，因此对现金贷 APP，精确位置权限仍属于立即排查的高风险项。

Google Play 高风险节点

P0 · 2026-08-31

Target API 36：仅剩 7 天

从 2026-08-31 起，新的移动 APP 和 APP 更新必须 target Android 16 / API 36 或更高；现有移动 APP 至少需要 target API 35，才能继续面向运行高于应用 target API 的新用户保持可发现性。符合条件的开发者可申请延期至 2026-11-01。

动作：所有计划更新包必须明确 targetSdk、compileSdk、关键 SDK 兼容状态、提审日期、延期状态和回滚方案；回归登录/OTP、KYC、OCR/相机、通知、Deep Link、WebView、后台任务、风控和归因 SDK。

2026-09-30

Play Console Requirements 与区域安装执行要分开理解

Google 的 Play Console Requirements 页面标注 2026-09-30 生效，并要求 Play 开发者注册剩余 package；金融产品和服务开发者必须使用 Organization 账号，组织资料需与 D‑U‑N‑S 等信息保持一致，并在提审前提供有效 demo account / 登录资源。

同时，Android developer verification 的“安装层区域执行”在 9/30 首批仅覆盖巴西、印度尼西亚、新加坡和泰国的参与商店，墨西哥不在首批四国；2027 年及以后扩展到全球认证 Android 设备。

墨西哥团队处理：不要把“墨西哥不在首批区域”理解成可以不做 package 注册。Play Console 侧仍应把 Organization、D‑U‑N‑S、package 注册和审核账号纳入 9/30 前的账号治理。
