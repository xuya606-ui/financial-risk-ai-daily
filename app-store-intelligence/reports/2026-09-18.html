贷款声明 · P0

“声明类别”与“实际产品能力”不一致会直接形成审核风险

声明必须覆盖 App 实际向用户提供的金融功能。Loan facilitator 与 Personal loan direct lender 不应按公司内部称谓选择，而应根据真实业务链路、资金提供方、合同关系、用户流程和 App 实际功能判断。贷款相关功能会触发进一步文档审查。

Apple · 个人贷款

36% APR 与 60 天规则继续有效

Apple 当前 App Review Guidelines 仍要求个人贷款 App 清晰、显著披露贷款条款，包括最大等效 APR 与付款到期日；最大 APR 不得高于 36%（含成本与费用），也不得要求在 60 天或以内全额偿还。

产品 / 研发影响

把 Financial features declaration 从“控制台表单”升级为版本化配置资产

建议每个 App 建立可版本化的 financial_capability_matrix，至少记录：feature_type / user_flow / lender_role / funding_entity / contract_entity / repayment_collection_entity / store_description_claim / declaration_value / evidence_url / owner / last_verified_at。任何产品功能、资金方、主体关系、Store listing、合同或 API 行为变化，都自动触发 Declaration Diff。

发布门禁建议：如果实际能力与声明不一致，进入 FINANCIAL_DECLARATION_DRIFT_BLOCKED；如果贷款机构/主体关系证据缺失，进入 LENDER_RELATION_EVIDENCE_BLOCKED；未解除前禁止提审与放量。
