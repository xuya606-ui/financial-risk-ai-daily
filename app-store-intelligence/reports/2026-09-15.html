今日新增 / 政策变化

Apple · 9/14 官方更新

Xcode 27 稳定版 + 27.0 SDK 已正式支持 App Store 与 TestFlight

App Store Connect Release Notes 已新增 2026-09-14 条目：使用 Xcode 27 和 iOS/iPadOS/macOS/tvOS/visionOS/watchOS 27.0 SDK 构建的 App，现在可以上传 App Store，并用于 TestFlight 内部和外部测试。内部工具链状态应从 RC_APPSTORE_ACCEPTED 更新为 STABLE_APPSTORE_ACCEPTED。

产品/研发影响：可以开始把 Xcode 27 stable 纳入生产 CI，但“Apple 接受上传”与“团队已验证稳定”必须分开记录；KYC、OCR、人脸、归因、支付、WebView/PDF、Push、Deep Link 等关键 SDK 仍需做稳定版回归。

Google Play · 今日生效

Wear OS 64 位要求 2026-09-15 正式生效

Google 官方明确：从今天起，包含原生代码的 Wear OS 新 App 和更新在发布到 Google Play 时，必须提供 64 位版本；Google Play 开始阻止不符合要求的上传。Google 仍允许同时保留 32 位支持。

产品/研发影响：如果墨西哥信贷产品没有 Wear OS artifact，无直接阻断；如果存在 Wear companion、共享 native library 或未来计划上 Wear OS，则立即检查所有 ABI、NDK 依赖和第三方 native SDK。

Apple · 持续

个人贷款 APR / 期限红线无变化

Apple App Review Guidelines 继续要求个人贷款 APP 清晰、显著披露贷款条款，包括最大等效 APR 和付款到期日；最大 APR 不得超过 36%（含成本和费用），不得要求 60 天或以内全额偿还。

今日新增长期知识

长期沉淀 · Release Engineering

稳定工具链激活门禁：Official Accepted ≠ Internal Validated

今天新增长期模型：官方稳定版可上传只意味着平台接受该工具链，不代表团队可以直接切换生产 CI。内部必须再通过签名、CI runner、关键 SDK、KYC/支付/合同链路、上传处理、版本可选、正式送审和 fallback 验证后，才能从 STABLE_APPSTORE_ACCEPTED 升级为 STABLE_INTERNAL_VALIDATED。

建议字段：toolchain_state / official_supported_at / xcode_version / sdk_version / ci_image / upload_ok / processing_ok / selectable_ok / submit_ok / critical_sdk_matrix / regression_pass_rate / fallback_xcode / owner / evidence_hash。
