P0 · 2026-08-31Google Play

Target API 36 进入最后 11 天

从 2026-08-31 起，新移动应用和应用更新必须 target Android 16 / API 36+；现有移动应用至少 target Android 15 / API 35，才能继续面向运行高于其 target API 的新用户保持可发现性。符合条件时可申请延期至 2026-11-01。

产品/研发影响：不要只检查 targetSdk。升级后必须回归登录/OTP、KYC、相机/文件选择、通知、Deep Link、WebView、后台任务、支付/还款以及关键风控/归因 SDK。
今日动作：所有未完成 API 36 的“计划更新包”进入红色发布清单，明确 Owner、提审日期和延期状态。

Apple 最新动态

最近更新 · 2026-08-12App Store Connect

韩国区年龄分级可手动覆盖为地区专属评级

Apple 2026-08-12 的 App Store Connect 更新允许开发者在韩国区把 App 年龄分级覆盖为可用的地区专属等级（All、12+、15+、19+）。这一变化对墨西哥现金贷 APP 没有直接政策影响，但如果同一包同时在韩国分发，应把地区年龄分级差异纳入发布台账。

产品/运营影响：多国家分发时，不要再把“一个全球年龄分级答案”视为全部市场最终展示结果；发布台账应增加 region-specific rating 字段。

今日新增长期知识：Play 政策预检进入研发流水线

新增知识

用 Android 官方 Play Policy Skill 做“提审前静态政策预检”

Android 官方 Skills 已提供“Play policy insights / Audit Play policy compliance”能力，可让支持 Agent Skills 的 AI 工具基于 Google Play 政策检查 Android 项目中的权限、账户删除、Data safety 等风险。它适合做研发阶段的早期发现，但不能替代 Play 正式审核、法务判断或真实运行时数据核验。

推荐流水线：代码/Manifest → 官方 Play Policy Skill 预检 → 权限与 SDK 清单 → Data safety/隐私四方对账 → 人工合规签字 → QA 核心路径 → 提交审核。
管理指标：precheck_findings、high_risk_open、false_positive、remediation_owner、policy_source_date、release_blocked。
