高风险提醒

Google Play · 2026-08-26

地理围栏不再是获批的 Foreground Service 使用场景

Google 已公布，自 2026-08-26 起，geofencing 将从允许的 foreground service 使用场景中移除，官方建议改用 Geofence API。

现金贷 APP 特别注意：个人贷款 APP 当前又被 Financial Services policy 明确禁止申请 ACCESS_FINE_LOCATION。因此现金贷产品不应把这条理解为“从 FGS 迁移到 Geofence API 就一定合规”，而应先确认业务是否本就不应采集精确位置。
今天执行：扫描 Manifest、foregroundServiceType、GeofencingClient、位置 SDK 和风控 SDK；现金贷核心流程中发现精确定位/地理围栏时优先按红色风险处理。

Google Play · 2026-08-31

Target API 36 只剩 12 天

Google 仍要求新的移动 APP 与更新在 2026-08-31 起 target Android 16 / API 36+；现有移动 APP 至少 target API 35 才能继续面向运行更高 Android 版本的新用户保持可发现性。

门禁建议：不能只看 targetSdk 是否改成 36；必须回归登录/OTP、KYC、相机、文件选择、通知、深链、WebView、后台任务、归因与风控 SDK。

Google Play · 2026-09-30

package name 注册：今天开始按“签名密钥资格”盘点

Google 的详细指引说明：Play 开发者需同时完成身份验证和 package name 注册。多数 APP 会自动注册，但并非所有包都能自动完成。

关键规则：若某签名密钥占已知安装量超过 50%，该密钥优先；若没有单一密钥超过 50%，安装量至少 50 的密钥可具备注册资格；若所有密钥都低于 50 次安装，则可出现先到先得的注册情形。无法自动注册时，可在 Play Console 进行手动注册并验证签名密钥。
今天执行：给每个包增加：注册状态、当前签名证书指纹、历史签名密钥、安装量资格、是否需人工申请、Owner、截止日。

暂无新的合规政策，但“Creative Assets”值得提前做金融营销审查

Apple 目前最新的 App Store 官方新闻仍是 8 月 5 日关于新 Creative Assets 的准备说明。Apple 的资产最佳实践明确建议素材不要包含具体价格、折扣、网站 URL、无法验证的奖项/荣誉或其他平台/商店 Logo。
