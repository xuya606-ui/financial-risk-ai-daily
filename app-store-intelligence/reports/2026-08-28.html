Target API 36：进入最后 3 天

从 2026-08-31 起，新移动 APP 和 APP 更新必须 target Android 16 / API 36+；现有移动 APP 至少 target API 35 才能继续面向运行更高 Android 版本的新用户保持可发现性。符合条件的 APP 可申请延期到 2026-11-01。

税费与价格调整：本轮不含墨西哥
