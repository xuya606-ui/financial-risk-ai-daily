Google Play｜高风险节点

P0 · 2026-08-31Google Play

Target API 36：进入最后 4 天窗口

Google 当前官方要求仍未变化：从 2026-08-31 起，新移动 APP 和 APP 更新必须 target Android 16 / API 36+；现有移动 APP 至少 target API 35，才能继续面向运行更高 Android 版本的新用户保持可发现性。符合条件的开发者可申请延期到 2026-11-01。

现金贷 APP 落地：不要只检查 targetSdk=36。必须回归登录/OTP、KYC、OCR/相机、文件选择、Push、Deep Link、WebView、后台任务，以及风控、归因、设备指纹、客服、推送 SDK 的兼容性与权限变化。

现金贷当前红线

Financial Services 敏感权限没有放宽

个人贷款、贷款导流/撮合、额度/信用辅助等相关 APP 仍不得访问多项敏感数据，包括联系人、精确位置、照片/视频、电话号和全量安装包列表等。即使通用权限政策的执行时间存在变化，也不能覆盖 Financial Services 的专项红线。

今日新增 · 2026-08-27立法提案，不是现行法

墨西哥城议会讨论“电话催收骚扰 + 过度广告”治理提案

墨西哥城议会今天发布消息，正在分析向联邦国会提出修法倡议，关注电话催收骚扰和过度广告问题。官方摘要提到，提案方向包括限制将个人信息用于催收，以及要求消费者授权后才能接收广告。

状态必须标注为：PROPOSAL / LEGISLATIVE WATCH。它目前不是已生效的全国现金贷 APP 法规，也不能直接替代 CONDUSEF/REDECO 等现行监管要求。
产品/贷后建议：提前核查催收拨号策略、联系时段、第三方催收商、号码来源、用户同意、退订/拒收机制、营销与催收号码隔离、录音/坐席/话术留痕。若后续立法推进，可快速评估差距。

今日新增长期知识：Apple TestFlight beta 工具链门禁

今天新增一条可长期复用的发布治理规则：把 iOS 工具链按 Beta Testing 与 Production Review 两条通道维护，不再使用一个简单的“Xcode 版本可用/不可用”字段。

维度建议字段判断
TestFlightbeta_xcode_version / beta_sdk / internal_ok / external_ok是否能进入内部/外部测试
Productionproduction_xcode_version / production_sdk / app_review_ok是否能选择该 Build 提交正式审核
证据official_url / checked_at / release_note_date必须引用 Apple 当前官方页面
回退fallback_xcode / fallback_branch / ownerbeta 工具链出现兼容问题时可快速切换
目标：避免“TestFlight 能上传”被误解成“可以直接正式发版”，同时保留稳定生产分支。
