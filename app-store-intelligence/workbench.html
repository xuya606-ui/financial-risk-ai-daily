高风险 · 2026-08-31Google Play

target API：移动应用更新即将强制 API 36

当前仍可提交
距离 2026-08-31 还有较短缓冲期；旧版本可能仍以较低 target API 在架。
新门禁
2026-08-31 起，新移动应用和更新必须 target Android 16 / API 36+。现有移动应用至少 target API 35，才能继续面向更高 Android 版本的新用户保持可发现性。

负责人建议：Android 研发 + QA + 发布负责人。若确实无法按期完成，评估官方延期到 2026-11-01。
