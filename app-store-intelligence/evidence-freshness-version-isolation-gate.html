LONG-TERM KNOWLEDGE · 02/03/04/05/07

证据新鲜度 × 版本隔离门禁

避免新 Build 复用旧声明、旧监管证据或旧审核包。

适用场景

适用于 Google Play / Apple App Store 送审、灰度放量、重大 SDK 升级、贷款参数变化、资金方变化、墨西哥主体/合同变化和政策截止日临近场景。

最小证据字段

build_id、git_commit、artifact_sha256、policy_version、source_checked_at、effective_at、evidence_hash、next_check_at、owner。

状态机

FRESH：政策与版本证据仍在有效窗口；STALE_WARNING：临近刷新；STALE_BLOCKED：超过门禁窗口，禁止提审/放量；VERSION_MISMATCH：证据包绑定的 Build 与实际提交 Build 不一致。

推荐门禁

  1. 每次新增或升级 SDK，重新核对 Data safety / App Privacy / Privacy Manifest。
  2. 资金方、合同主体、APR、费用、还款期限或用户流程变化时，重新核对 Financial features declaration 和 Store listing。
  3. 墨西哥 RECA、SIPRES/PUR、主体、品牌授权和客服证据记录最后核验日期。
  4. 所有申诉材料必须引用与被拒 Build 同一版本的证据，禁止拿新版本材料解释旧版本。
