2026-09-14 官方事件

Apple：Xcode 27 stable 已被 App Store Connect 接受

Apple App Store Connect Release Notes 明确：从 2026-09-14 起，使用 Xcode 27 和 27.0 SDK 构建的 iOS、iPadOS、macOS、tvOS、visionOS、watchOS App 可上传 App Store，也可用于 TestFlight 内外部测试。

正确解释：平台层状态从 RC_APPSTORE_ACCEPTED 进入 STABLE_APPSTORE_ACCEPTED。但内部仍要完成 CI、签名、关键 SDK 和业务回归，才能升级为 STABLE_INTERNAL_VALIDATED。

01｜状态机

BETA_TESTFLIGHT_ONLY

官方只确认 beta 工具链可用于测试，不继承为生产提审资格。

RC_APPSTORE_ACCEPTED

平台明确允许 RC 工具链用于正式上传/送审，但仍是候选版本。

STABLE_APPSTORE_ACCEPTED

平台官方接受稳定版工具链上传。这是“外部平台事实层”。

STABLE_INTERNAL_VALIDATED

团队自己的 CI、签名、SDK、业务链路和提审链路全部通过。这才是“生产默认工具链”。

MANDATORY_SDK

平台进入强制 SDK 日期，旧工具链不再具备发布资格。

FALLBACK_READY

保留上一已验证工具链和 release/hotfix 分支，确保新工具链问题可快速回退。

02｜稳定版激活门禁

门禁验证内容阻断条件
官方支持Release Notes / Developer News / Upcoming Requirements，记录 URL 和核验时间官方仅支持 beta/TestFlight 或信息冲突
CI RunnerXcode/SDK、构建镜像、缓存、包管理、代码签名构建不稳定、签名异常、CI 与本地不一致
依赖兼容KYC/OCR、人脸、支付、归因、风控、客服、Push、WebView/PDF 等 SDKCrash、编译警告升级为错误、隐私/权限漂移
App Store Connectupload → processing → build selectable → submit for review任何一环失败
核心业务登录/OTP → KYC → 报价/APR/费用 → 合同 → 放款/还款核心链路失败或披露错位
隐私/合规Privacy Manifest、App Privacy、第三方 SDK 数据实践、Review Notes声明与构建/运行时行为不一致
回退上一稳定工具链、runner、branch、证书、hotfix SOP无法在紧急场景回退
门禁原则：平台宣布 stable ≠ 团队默认切 stable；内部验证完成前，新稳定版只允许试点分支和低风险版本。

03｜墨西哥现金贷专项回归

KYC / 相机 / OCR / Liveness

重点验证权限提示、相机启动、取景框、图片压缩/上传、SDK 回调、前后台恢复。

贷款披露

金额、期限、APR/CAT、费用、还款日、总成本、合同预览在新 SDK/UI 环境下不得丢失或截断。

支付 / 还款

WebView、Deep Link、外部支付回跳、Session 恢复和防重复提交必须复测。
