Target API 36：继续执行后验证

新移动 APP 和更新必须 target Android 16 / API 36+；现有移动 APP 至少 target API 35，才能继续面向运行更高 Android 版本的新用户保持可发现性。逐包确认 Play Console、延期、可发现性和 API 36 生产稳定性。

提审前必须声明是否包含社交媒体能力

Apple 已明确从 2026 年 9 月起，提交新版本、更新或替代 App 市场 notarization 时，需要声明是否具有社交媒体能力。现金贷 APP 若叠加社区、UGC、公开评论或互动能力，应在提审前由产品、iOS 和合规共同确认答案。

Rosetta 退场：macOS 27 为最后一个支持版本
