今日重点

今天没有新的 Google/Apple 墨西哥现金贷审核大改，但出现一个需要加入发布门禁的高价值知识：Google Play Billing Library 7 的新 APP / 更新截止与 Target API 36 同为 2026-08-31。Apple 最新官方新闻为 8 月 27 日税费与价格调整，本轮不涉及墨西哥 storefront。

P0 · 2026-08-31Google Play

Target API 36：最后 3 天

新移动 APP 和更新从 8 月 31 日起必须 target Android 16 / API 36+；现有移动 APP 至少 target API 35 才能继续向运行更高 Android 版本的新用户保持可发现性。现金贷 APP 要完整回归 OTP/KYC、OCR/相机、文件、Push、Deep Link、WebView、后台任务和关键三方 SDK。
