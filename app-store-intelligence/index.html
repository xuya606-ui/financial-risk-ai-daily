今日重点

今天没有新的 Google/Apple 墨西哥现金贷审核大改。当前 P0 仍是 8 月 31 日 Target API 36；今天新增的长期知识是“第三方 SDK 供应链发布门禁”，把 Google SDK Requirements、Play SDK Index、Apple Privacy Manifest / SDK Signature 统一进发版检查。

P0 · 2026-08-31Google Play

Target API 36：最后 2 天

新移动 APP 和更新从 8 月 31 日起必须 target Android 16 / API 36+；现有移动 APP 至少 target API 35 才能继续向运行更高 Android 版本的新用户保持可发现性。现金贷 APP 需完整回归 OTP/KYC、OCR/相机、文件、Push、Deep Link、WebView、后台任务和关键第三方 SDK。

今日新增SDK 供应链

SDK 不是“研发黑盒”，需要单独发布门禁

Google 明确要求开发者对第三方 SDK 导致的政策违规负责，Data safety 必须覆盖 SDK 数据行为；Apple 也要求开发者对 SDK 代码/数据实践负责，并对列出的常用 SDK 执行 Privacy Manifest 和 SDK Signature 要求。
