P0 · 2026-08-31Google Play

Target API 36：明天截止

新移动 APP 和更新必须 target Android 16 / API 36+；现有移动 APP 至少 target API 35 才能继续对更高 Android 版本新用户保持可发现性。今天应完成最后一轮构建、回归、提审/延期确认。
