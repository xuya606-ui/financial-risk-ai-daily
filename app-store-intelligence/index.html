Apple · 2026-08-18账号治理

新 Developer Program License Agreement：协议接受状态要进入账号台账

Apple 新增 Attachment 14，统一欧盟地区替代分发、替代支付与商业条款，2026-10-01 起生效。Apple 要求 Account Holder 查看并接受更新协议；账户帮助文档同时说明，未按要求接受更新协议可能影响部分会员资源访问。

建议动作：维护 agreement_name、effective_at、account_holder、acceptance_status、accepted_at、affected_regions 和 evidence；每次 iOS 提审前检查账号首页是否存在 pending agreement。

P0 · 2026-08-31Google Play

Target API 36：距截止仅 9 天

8 月 31 日起，新移动应用和更新必须 target Android 16 / API 36+；现有移动应用至少 target API 35，才能继续面向更高 Android 版本的新用户保持可发现性。

建议动作：所有未完成 API 36 的计划更新包明确 Owner、提审日期、延期状态和回滚方案，并完成登录/OTP/KYC/相机/通知/Deep Link/WebView/后台任务与关键 SDK 回归。

P0 · 2026-09-30Android verification

developer verification / package name 继续逐包核对

9 月 30 日起首先在巴西、印度尼西亚、新加坡、泰国的参与商店执行；Google Play 会自动注册约 99% 的 Play 应用，但仍建议开发者在 Play Console 处理剩余 package，并为 2027 年全球扩展做准备。

墨西哥判断：9 月 30 日区域执行不直接包含墨西哥，但 package、签名和身份验证台账仍应提前完成。

Google limited distribution 账号类型边界

Android developer verification 已在 2026 年 8 月开放 limited distribution accounts，面向学生、教师、业余开发者等小规模分发场景。生产金融 APP 不应把这一机制当作正式 Play 分发和 Organization 主体治理的替代方案。
