2026-08-31 起，新移动 APP 和更新必须 target Android 16 / API 36+；现有移动 APP 至少 target API 35，才能继续面向运行更高 Android 版本的新用户保持可发现性。

今日知识沉淀Google User Data

第三方 AI 集成也属于开发者的数据合规责任

Google 当前 Developer Program Policy 明确把 third-party AI integrations 纳入 User Data 责任范围。现金贷 APP 的 KYC/OCR、人脸、反欺诈、评分、LLM 客服/催收都应做字段级数据台账。

建议动作：记录字段、用途、供应商、存储地、保留期、是否用于模型训练、删除机制和隐私披露位置。

Google Developer Program Policy ↗
2027-01-27账户验证

提前迁移 READ_CALL_LOG 验证路径

Google 已公布，2027-01-27 起不再允许把“通过电话呼叫验证账户”作为 READ_CALL_LOG 的允许用途，推荐迁移到 Digital Credentials API、SMS Retriever API 或其他不需要敏感权限的方案。

建议动作：如果注册/登录/KYC 仍依赖闪呼/通话记录验证，现在就建立替代方案和迁移计划。
