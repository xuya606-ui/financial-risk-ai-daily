P0 · 2026-08-31Google Play

Target API 36：最后 4 天

新移动 APP 和更新从 8 月 31 日起必须 target Android 16 / API 36+；现有移动 APP 至少 target API 35 才能继续向运行更高 Android 版本的新用户保持可发现性。现金贷 APP 还要回归 OTP/KYC、相机/OCR、文件、Push、Deep Link、WebView、后台任务和关键三方 SDK。

🇲🇽 今日新增立法提案

墨西哥城议会讨论电话催收骚扰与过度广告治理

8 月 27 日，墨西哥城议会发布消息，正在分析向联邦层面提出修法倡议，涉及限制将个人信息用于催收、广告授权等方向。当前状态是 Proposal / Legislative Watch，不是已经生效的全国现金贷规则。

落地：先做差距预检：催收号码来源、联系时段、用户授权、第三方催收商、营销/催收号码隔离、录音/坐席/话术留痕、退订/拒收机制。

Jalisco：不当催收占投诉 20.8%
