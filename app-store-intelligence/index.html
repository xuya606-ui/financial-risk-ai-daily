今日重点

今天有两项发布治理更新：Apple 9/14 已开放 Xcode 27 stable + 27.0 SDK 的 App Store/TestFlight 上传；Google Wear OS 64 位要求 9/15 正式生效。墨西哥现金贷手机主 APP 当前直接 P0 仍是 9/30 Play package 注册 T-15。

Apple · 9/14

Xcode 27 稳定版已正式支持 App Store 与 TestFlight

App Store Connect Release Notes 已新增 9/14 稳定版条目。内部工具链状态应从 RC_APPSTORE_ACCEPTED 更新为 STABLE_APPSTORE_ACCEPTED，但生产 CI 切换前仍需完成内部验证。

Google · 今日生效

Wear OS 64 位要求 9/15 生效

包含 native code 的 Wear OS 新 App 和更新必须提供 64 位版本；Google Play 开始阻止不符合要求的上传。无 Wear artifact 的手机端信贷 APP 无直接阻断，有 Wear/共享 native library 时立即核验 ABI 与 NDK 依赖。
