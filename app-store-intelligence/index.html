Target API 36：距截止 7 天

8 月 31 日起，新移动 APP 和更新必须 target Android 16 / API 36+；现有移动 APP 至少 target API 35 才能继续面向更高 Android 版本的新用户保持可发现性。

2026-09-30Play Console

金融 APP：Organization + package 注册 + active demo account

Play Console Requirements 当前标记 9/30 生效：金融产品/服务开发者必须使用 Organization 账号；开发者资料与 D‑U‑N‑S 保持一致；提审前准确填写 metadata、Data safety，并提供 active demo account / 登录资源。
