01｜先识别“Google 审核 Session”

强信号

专用审核账号

为 Play 审核提供稳定、长期有效的专用账号，并在后端标记 account_type=GOOGLE_REVIEW。该账号产生的登录与行为是最可靠的审核 Session 起点。

辅助信号

设备 / IP / 地区

IP、ASN、国家、设备型号、Android 版本、User-Agent 只作为辅助特征，不应单独判定“来自 Google”。

关键原则

不要只看 IP

审核环境可能变化，也可能通过不同基础设施访问。核心应是专用账号 + 服务端 Session + 页面事件 + API 调用。

02｜机器审核 vs 人工审核识别模型

行为特征更像机器更像人工
Session 时长非常短、批量快速数分钟以上、有明显阅读时间
页面切换间隔高度规律、秒级甚至更短间隔波动明显
页面停留接近 0 或高度一致不同页面差异较大
返回/重试较少或机械重复返回、重填、重新选择较常见
表单输入少量或模板化真实输入、修改、删除
借款路径快速探测关键页面/APIKYC→额度→借款→合同等较完整路径
API 调用高密度、覆盖广与实际页面操作节奏匹配

建议评分规则

machine_score = 20 * 极短Session + 15 * 页面切换高度规律 + 15 * 平均停留极短 + 15 * 无真实输入 + 15 * 高频重复/遍历 + 20 * API调用密度异常高 human_score = 20 * 页面停留差异明显 + 20 * 有输入/修改行为 + 15 * 有返回/重试 + 20 * 完整业务路径 + 15 * 合同/费率页长停留 + 10 * 页面节奏自然波动
输出标签：Machine ≥70 且 Human <50 → 疑似机器；Human ≥70 且 Machine <50 → 疑似人工；其余统一标记 Unknown。阈值要用你们历史样本校准，不建议直接固定。

04｜现金贷 APP 重点监听页面

KYC / 实名

是否进入实名、证件、人脸、身份验证流程，以及停留和退出位置。

额度 / 借款

是否查看额度、金额、期限、APR、费用、优惠、还款计划。

合同 / 隐私 / 删除

合同页、隐私政策、账号删除、数据删除页面是否被重点查看。

05｜Dashboard 建议

趋势

审核类型趋势

按版本统计疑似机器 / 疑似人工 / Unknown Session 数与占比。

路径

审核访问漏斗

登录 → 首页 → KYC → 额度 → 借款 → 费用 → 合同 → 提交借款。

结果

审核结果关联

分析进入人工审核后的拒审率、重点访问页面与拒审原因之间的关联。

建议核心指标
  • 每版本 Google Review Session 数。
  • 疑似机器 / 人工 / Unknown 占比。
  • 提交 → 首次审核 Session 时间。
  • 首次 Session → 审核结果时间。
  • Google 审核账号登录失败率。
  • 重点页面访问率与平均停留时间。
  • 人工审核后拒审率 vs 仅机器特征 Session 的拒审率。
  • 拒审前最后访问页面、最后业务阶段。
