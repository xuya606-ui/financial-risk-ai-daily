04｜金融 / 贷款披露、声明与发布材料

商店文案不是营销孤岛：APR、期限、费用、代表性总成本、主体名称和资质信息必须与 APP、合同、客服和实际配置一致。

贷款披露

商店 metadata 维护最短/最长期限、最大 APR 或当地一致口径、代表性总成本、隐私政策。

权限红线

个人贷款/贷款导流等 APP 禁止 READ_CONTACTS、ACCESS_FINE_LOCATION、照片/视频读取、READ_PHONE_NUMBERS 等多项敏感权限。

Financial features declaration

直接放贷、撮合、信用辅助等模式要与声明和证明材料一致，主体关系可解释、可验证。

Google Financial Services 官方原文 ↗

  • 公司注册/主体证明及开发者账号关系。
  • 适用许可、登记或合作机构证明。
  • 费率、期限、费用参数表与代表性示例。

07｜长期运营治理

政策雷达

记录公告日、生效日、地区、来源 URL、冲突状态、影响 APP、Owner、截止日和完成状态。

发布门禁

P0 未关闭不提审；技术、商店、主体、隐私、审核账号、协议状态共同纳入。

证据留档

每版保存商店文案、截图、Data safety/App Privacy、隐私政策、审核消息与申诉。

建议月度指标
  • 一次审核通过率、平均审核时长、拒审次数。
  • 贷款/权限/主体/元数据拒审占比。
  • 政策 P0 按期完成率、逾期数、source conflict 未关闭天数。
  • 账号/SDK/package/signing key 台账完整率。
  • 商店声明与实际产品抽检一致率。

08｜术语与学习地图

发布

package name / Bundle ID：应用唯一标识；signing key：Android 包签名身份；targetSdk：Android 行为和 Play 发布门槛。

隐私

Data safety：Google 数据声明；App Privacy：Apple 隐私标签；SDK：第三方软件组件；Private Relay：Apple 隐私邮箱转发。

信贷

APR：年化成本表达；Representative example：代表性总成本示例；SIPRES/RECA/REDECO：墨西哥金融主体、合同和催收投诉相关官方工具。

10｜官方政策冲突处理

2026-08-26 案例

Geofencing 日期冲突

Policy Preview 与 Android Developers 时间轴写 2026-08-26，Policy Deadlines 总表写 2027-01-27。内部状态为 SOURCE_CONFLICT，不再静默选边。

一般 APP：保留双来源证据，检查 Console，优先迁移风险能力；现金贷 APP：Financial Services 已禁止 ACCESS_FINE_LOCATION，直接按 PRODUCT_REDLINE 处理。

进入完整 Source Conflict SOP →
四类状态
  • CONFIRMED：官方来源和 Console 一致。
  • SOURCE_CONFLICT：两个以上当前官方来源不一致。
  • CONSOLE_OVERRIDE：当前账号/APP 的 Console 有明确更具体阻断或截止。
  • PRODUCT_REDLINE：专项金融/儿童/健康政策已经比通用规则更严格。
