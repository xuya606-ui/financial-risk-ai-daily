01｜开发者账户知识体系

账户是 APP 的法律主体、品牌资产和发布权限载体。

Google Play

个人与组织账户

组织账户适合公司主体和受监管业务。长期台账应记录法律实体、注册地址、D‑U‑N‑S、官网、域名邮箱、验证状态、付款资料、管理员和备份管理员。

Apple

Account Holder 与角色

Account Holder 掌握协议、会员和核心权限。建议按 Account Holder、Admin、App Manager、Developer 等角色分工，禁止多人共用主账号。

账号资产台账

账号应关联公司主体、APP、包名/Bundle ID、证书、API Key、双重认证设备、恢复方式、负责人和离职交接记录。

账户安全 SOP
  • 双重认证，不共享验证码和主密码。
  • 研发、运营、财务、法务按最小权限分配角色。
  • 人员离职当天撤销权限、API Key、证书和设备。
  • 主体名称、地址、官网、D‑U‑N‑S 变化时触发商店影响评估。
  • 保存账号验证、协议签署、付款和重大审核事件时间线。
封号/终止风险

重点关注重复违规、误导信息、恶意行为、关联高风险账号、主体无法验证、支付问题、规避审核、批量低质量应用。申诉前先锁定具体政策条款、版本和证据。

03｜隐私、权限、数据与 SDK

数据生命周期

按采集→传输→使用→共享→保存→删除建立数据地图，每个字段记录用途、保存期和第三方接收方。

权限最小化

区分必需、可选、高风险权限；在真正需要时申请，并提供用户可理解的用途说明。

SDK 治理

维护广告、归因、风控、推送、客服、分析 SDK 的版本、采集字段、权限、域名、数据去向和 Owner。

Data safety / App Privacy 四方对账

同时核对真实代码与网络行为、Google 声明、Apple 声明、隐私政策。不要只依赖 SDK 文档或研发口头确认。

账户与数据删除

删除入口应可发现、流程可完成、后端真正执行，并说明依法保留的数据。网页删除入口和商店声明应持续有效。

04｜金融 / 信贷 APP 专项

商店文案不是营销孤岛：APR、期限、费用、还款示例、主体名称和资质信息必须与 APP、合同、客服和实际配置一致。

统一贷款披露

维护利率/APR、期限、费用、代表性总成本、还款计划的单一数据源，产品参数变化自动触发商店复核。

贷款数据红线

把联系人、照片/媒体、电话、精确定位等纳入高风险权限扫描，并检查 SDK 是否间接引入。

金融功能声明

Financial features declaration 与真实业务模式保持一致；直接放贷、撮合、信用相关服务分别维护业务说明和证明。

金融 APP 发布材料包
  • 公司注册/主体证明及其与开发者账号的关系。
  • 适用的许可、注册、合作机构证明或业务模式说明。
  • 费率/期限/费用参数表及代表性示例。
  • 隐私政策、用户协议、合同样本、客服渠道。
  • 审核测试账号和完整借款测试路径。
  • 品牌、运营方、资金/放贷方不同则准备关系说明。

05｜🇲🇽 墨西哥专项知识库

主体

七类主体关系

区分开发者账号、APP 品牌、实际运营、合同、资金/放贷、隐私责任、客服主体，并保存主体之间的法律/商业关系证明。

本地化

墨西哥用户信息

商店、隐私、客服、合同和贷款披露适配西语；MXN、日期、利率、地址和联系方式口径一致。

证据

审核证据库

保存主体文件、许可/注册证明、合作关系、官网、隐私历史版本、商店截图和审核沟通记录。

墨西哥产品 × 商店交叉检查
  • 借款首页和商店描述是否是同一种产品。
  • APR/费用/期限示例是否同一计算口径。
  • APP 公司名称能否与开发者账号和合同建立关系。
  • 隐私政策是否提供本地数据权利和联系方式。
  • 催收、营销需求不得推动申请商店禁止或不必要权限。
  • 更换资金方、主体、品牌时触发完整商店合规评估。

06｜审核、拒审与申诉

拒审类型优先排查动作
贷款政策APR、期限、费用、披露、金融声明先修产品/文案，再回复政策点
权限/隐私Manifest、SDK、运行时权限、声明删除非必要权限并给版本证据
主体/资质开发者、合同、牌照/合作关系提供主体关系和证明
无法审核登录、OTP、地区、风控、测试账号稳定 Demo account + Review Notes
元数据截图、描述、承诺与真实 APP 差异统一真实口径
标准申诉结构

①确认政策问题；②说明根因；③列出已完成修改；④提供版本号、页面路径、截图/证明等验证方法；⑤请求基于新版本重新审核。

07｜长期运营治理

政策雷达

记录发布日期、生效日、平台、影响 APP、风险级别、Owner、截止日、完成和验证状态。

发布门禁

高风险项未关闭不得发布；产品、研发、法务、运营共同确认 Checklist。

证据留档

保存每版商店文案、截图、声明、隐私政策、审核消息和申诉，形成可追溯版本库。

建议月度复盘指标
  • 一次审核通过率、平均审核时长、拒审次数。
  • 因元数据/权限/主体/金融政策导致的拒审占比。
  • 政策变更按期完成率、高风险待办逾期数。
  • 账号管理员和 SDK 台账完整率。
  • 商店声明与真实产品抽检一致率。

08｜术语与学习地图

账户与发布

D‑U‑N‑S：企业身份识别编号。Bundle ID / package name：应用唯一标识。TestFlight / testing tracks：发布前测试渠道。

隐私与数据

Data safety：Google Play 数据声明。App Privacy：Apple 隐私标签。ATT：Apple 跟踪透明度框架。SDK：嵌入 APP 的第三方软件组件。

信贷

APR：年化综合成本表达指标。Loan term：贷款期限。Representative example：帮助用户理解真实成本的代表性借款示例。

推荐学习顺序

先掌握账号与上架 → 隐私与权限 → 审核机制 → 金融专项 → 墨西哥本地化 → 拒审申诉 → 账号/SDK/政策长期治理。知识库后续每日更新时按此结构归档，而不是把新闻无限堆在首页。
