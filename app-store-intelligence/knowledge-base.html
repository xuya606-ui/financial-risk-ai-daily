04｜金融/贷款披露、Financial features declaration、敏感权限与发布材料

核心原则：Store listing → APP 报价 → 合同/RECA/RECO → Backend 参数保持一致；Google 与 Apple eligibility 分开判断。

Google 贷款披露

个人贷款 metadata 维护最短/最长期限、最大 APR/当地一致口径、代表性总成本和隐私政策；不得要求 60 天或以内全额还清。

Financial Services 官方原文 ↗

Google 贷款权限红线

个人贷款及相关 App 继续把敏感权限作为发布门禁，检查最终 merged Manifest + 第三方 SDK。

官方原文 ↗

Financial features declaration

直接放贷、撮合、信用辅助等功能与声明、证明材料和主体关系保持一致；资金方、合同主体、用户流程或 Store listing 变化触发 Declaration Diff。

Declaration 官方原文 ↗Mexico 证据门禁 →

Apple 个人贷款

清晰、显著披露贷款条件，包括最大等效 APR 和付款到期日；最大 APR 不得高于 36%（含成本和费用），且不得要求在 60 天或以内全额偿还。

Apple Review Guidelines ↗四层一致性门禁 →
