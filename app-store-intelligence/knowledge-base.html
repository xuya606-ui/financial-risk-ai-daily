01｜开发者账户与安全治理

Google Play

Personal / Organization

Google Play 提供 Personal 与 Organization 两类开发者账号。组织账号创建与验证会涉及组织身份信息和 D‑U‑N‑S。金融等受监管业务应确保开发者主体与真实业务主体关系清晰。

Google Play Console Requirements ↗
Google Play

开发者身份验证

组织名称、地址、支付资料、D‑U‑N‑S 等发生变化时，要同步评估是否触发重新验证或资料更新。

Google 身份验证原文 ↗
Apple

高监管行业法律实体

Apple 对银行、金融服务等高度监管业务强调应由实际提供服务的法律实体提交，而不是个人开发者。

Apple App Review Guidelines ↗
账户安全 SOP
  • 双重认证，不共享主账号和验证码。
  • 按最小权限分配 Account Holder/Admin/App Manager/Developer。
  • 人员离职当天撤销账号、API Key、证书和设备。
  • 保存账号验证、协议签署、付款和重大审核事件时间线。
  • package name / Bundle ID 与主体、品牌、APP 建立一一映射。

02｜APP 上架、版本发布与审核准备

Google App content / App access

登录受限功能必须提供足够审核访问信息，避免 OTP、地区、风控或环境限制阻断审核。

Google Prepare your app for review ↗

Google Play target API

每次 Android 发版必须把 targetSdk、compileSdk、关键 SDK 兼容性、权限变化和回归结果纳入发布门禁。

Google Target API requirements ↗

Apple App Review

测试账号、Review Notes、受监管业务主体/资质关系、隐私和核心功能应在提审前准备完毕。

Apple App Review 官方说明 ↗
每次发版最低检查集
  • package name/Bundle ID、签名、版本号和环境正确。
  • Google target API / Apple SDK 与当前提交要求满足。
  • 商店描述、截图、隐私、客服与 APP 实际一致。
  • 审核账号可稳定进入完整核心路径。
  • 新增 SDK / 权限 / 数据字段触发隐私重新对账。

03｜隐私、权限、数据生命周期与 SDK

Google Data safety

所有已发布到 Google Play 的 APP 都需要维护 Data safety，第三方 SDK 的数据收集和共享也在开发者责任范围内。

Google Data safety 官方原文 ↗

Google User Data

隐私政策、敏感数据处理、账户删除和商店展示信息需要保持一致，尤其金融 APP 应避免不必要的高敏感数据访问。

Google User Data policy ↗

Apple App Privacy

Apple 要求开发者披露 APP 和第三方合作方收集的数据类型、用途及是否与用户身份关联。

Apple App Privacy Details ↗
四方对账

真实代码与网络行为 ↔ Google Data safety ↔ Apple App Privacy ↔ 隐私政策。新增 SDK、风控字段、广告归因、AI 服务时必须重新核验。

04｜金融 / 贷款披露与发布材料

APR、期限、费用、还款示例、主体名称和资质必须与 APP、合同、客服和商店页一致。
Google Play

Financial Services policy

个人贷款 APP 涉及 Finance 分类、贷款条款披露、Financial features declaration、当地许可和敏感数据限制等要求。

Google 金融服务政策 ↗
Apple

个人贷款审核

Apple 要求个人贷款 APP 显著披露贷款条款，包括等效最大 APR 和到期日；当前指南还限制最高 APR 和过短全额还款周期。

Apple 贷款审核条款 ↗
Apple

隐私与 SDK

贷款 APP 同样要遵守隐私、敏感数据和第三方 SDK 责任要求。

Apple User Privacy & Data Use ↗
金融 APP 发布材料包
  • 开发者主体与实际金融服务主体关系证明。
  • 适用许可、注册、合作方或业务模式说明。
  • APR、期限、费用和代表性总成本参数表。
  • 隐私政策、用户协议、合同样本和客服渠道。
  • 审核测试账号及完整借款路径。

07｜长期运营治理

政策雷达

记录发布日期、生效日、平台、影响 APP、风险级别、Owner、截止日、官方原文和验证状态。

发布门禁

高风险政策未完成不得发布；产品、研发、法务、运营共同确认。

证据留档

保存每版商店文案、截图、声明、隐私政策、审核消息和申诉，形成可追溯版本库。
