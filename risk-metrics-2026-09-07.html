2026-09-07｜FPD1 / FPD3 / FPD7 / DPD30+ 完整指标学习卡

今天重点升级早期信用表现指标。所有阈值仅作为内部示例，必须以自身产品、期限、客群、成熟期和稳定历史建立基线；模拟数字用于训练分析逻辑，不代表墨西哥或行业统一标准。

1. FPD1｜First Payment Default 1 Day｜首期到期后1天逾期率

1）指标是什么：首个应还日后第1天仍未满足还款标准的账户/金额占比。大白话：首期刚到期时，有多少客户没有按时完成应还。

2）为什么重要：属于极早期同步指标，可快速暴露支付故障、反欺诈漏损、现金流紧张或准入变化；适用于贷后最早期监控，但噪声很大。

3）精确定义与公式：

FPD1(件数) = 首期到期后D+1仍逾期的成熟首贷账户数 ÷ 首期到期且已成熟至D+1的首贷账户数FPD1(金额) = 上述逾期账户D+1未偿应还金额 ÷ 首期应还总金额

必须固定：首期定义、Grace Period、D+1观察时点、Full/Partial Payment、技术挂账、展期、账户/订单口径。分母不能混入尚未到期或未成熟贷款。

4）如何看高低：通常下降更好，但不能机械理解“越低越好”。自动扣款重试、支付延迟或节假日可能短期推高FPD1；过度展期也可能压低表面FPD1。需要和Payment Failure、Auto-debit Success、FPD3/7一起看。

5）墨西哥现金贷七步案例

背景：墨西哥14天首贷产品，App v9.3上线新的支付SDK，同时渠道B扩量。
数据：成熟首期样本20,000；FPD1件数20%→29%；金额FPD1 22%→31%；Payment Failure 5%→14%；Auto-debit Success 84%→70%；FPD3 17%→19%；FPD7 14.8%→15.6%。
现象：FPD1暴增9pp，但FPD7只升0.8pp。
拆解：Provider×Error Code×App Version后发现v9.3的Timeout/Bank Routing Error占新增失败大部分；渠道B的Score Mix变化有限。
根因：支付技术变化与FPD1跳升高度相关，但是否全部由SDK导致仍需回滚/备用路由实验确认。
决策：不全量收紧准入；恢复备用支付路由、智能重试，并把Technical FPD与Credit FPD拆开。
结果：先观察24-72小时Payment Success/FPD1恢复，再等FPD3/7成熟；只有深度风险同步恶化才调整信用策略。

6）诊断逻辑：①先看成熟度/到期日 → ②Payment Failure/Error Code/节假日 → ③Channel×Score×Limit×Strategy → ④Fraud/ATO → ⑤FPD3/7是否同向。

7）策略动作：技术异常先修支付；高欺诈组合强化KYC/设备；低Score高Limit同步恶化再降额/收准入；现金流型问题可优化到期提醒和支付路径。

8）常见误区：把所有D+1未还都当信用恶化；未成熟样本直接比较；件数和金额混用；展期后把原始逾期完全抹掉。

9）推荐拆分维度：Channel、Campaign、Score、Limit、Term、Payment Provider、Bank、App/SDK Version、新老客、Region、Strategy Version。

10）预警方式：采用同星期/同到期日结构的稳定基线；技术监控可小时级，信用归因应按成熟Cohort。示例黄灯：FPD1显著偏离历史区间且Payment Failure正常；红灯再叠加FPD3/7和金额风险恶化。

11）与其他指标关系：Payment/KYC/Fraud → FPD1 → FPD3 → FPD7 → DPD30+ → Vintage/Bad → EL。

12）小练习与答案

FPD1从19%升到28%，FPD7只从14%升到14.5%，Payment Timeout从3%升到12%。第一动作是什么？

答案：先处理支付技术链路，不应直接全量降低Approval。

2. FPD3｜First Payment Default 3 Days｜首期D+3逾期率

1）指标是什么：首个应还日后3天仍然逾期的首贷账户/金额比例。大白话：排除一部分当天支付延迟后，还有多少首贷客户持续没还。

2）为什么重要：比FPD1更能过滤支付时差和短暂现金流扰动，是早期信用质量的重要同步指标，适合监控渠道、Score和额度变化。

3）精确定义与公式：

FPD3 = D+3仍满足逾期定义的成熟首贷账户/余额 ÷ 首期到期且成熟至D+3的首贷账户/应还余额

必须固定Grace Period、部分还款、展期和“逾期恢复后又逾期”的处理；账户与金额两套口径均应保留。

4）如何看高低：通常越低越好，但如果D+1支付故障快速恢复，FPD3稳定是积极信号；若FPD1稳定而FPD3上升，说明治愈变差或客户现金流/催收效率恶化。

5）七步案例

背景：渠道C把低Score客群占比从18%提升到32%，额度同时提高。
数据：样本15,000；FPD1 21%→22%；FPD3 16%→21%；FPD7 14%→18%；平均EAD 1,350→1,720 MXN；低Score×Limit≥2,000的FPD3=31%。
现象：FPD1几乎没变，但D+3开始明显恶化。
拆解：Channel×Score×Limit×Strategy发现新增风险集中在渠道C边缘Score高额度组合。
根因：策略放宽与风险恶化高度相关；但仍需排除催收/支付策略变化，不能把相关性直接当因果。
决策：低Score高Limit恢复旧额度或进入Challenger；中Score低额度继续保留流量。
结果：等待两个成熟FPD7 Cohort，并继续观察MOB1 DPD30+、Amount FPD和Contribution Margin。

6）诊断逻辑：FPD1→FPD3 Cure → Channel/Score/Limit → Payment/RPC → FPD7/Amount Risk。

7）策略动作：边缘Score降额；渠道结构问题降量/重定向；支付/早催问题修自助还款与提醒；欺诈问题加Step-up。

8）常见误区：FPD3和FPD7混成同一个“早逾”；不同成熟窗口横比；只看件数；用当天实时样本与历史完整Cohort比较。

9）拆分维度：Channel、Score、Limit、Term、Cycle、Payment Method、Strategy、Region、Device Risk。

10）预警方式：同Vintage/同到期结构监控；FPD3相对FPD1的“留存逾期比例”也可内部监测。阈值只基于自身稳定历史。

11）关系：FPD1 × Early Cure → FPD3 → FPD7 → Early Roll → DPD30+。

12）小练习与答案

FPD1稳定21%，FPD3从16%升到22%，你优先看什么？

答案：看D+1到D+3治愈、Channel×Score×Limit和支付/早催变化，而不是先归因到“到期当天技术问题”。

3. FPD7｜First Payment Default 7 Days｜首期D+7逾期率

1）指标是什么：首期到期后7天仍未恢复正常的首贷比例。大白话：早期短暂延迟基本过滤后，哪些新客真正进入了较深的首期风险。

2）为什么重要：常被用于新客渠道/准入/额度策略的早期风险判断，是FPD1/3之后更接近真实信用表现的同步指标，但仍不是最终Bad。

3）精确定义与公式：

FPD7(件数/金额) = 首期到期后D+7仍逾期的成熟账户数/余额 ÷ 首期到期且已成熟至D+7的账户数/应还余额

需要固定产品期限、D+7时点、部分还款、展期和Write-off规则，并明确首贷/复借是否分开。

4）如何看高低：通常越低越好，但低FPD7也可能由激进展期或高额补贴制造；必须联合EAD、Amount FPD、后续DPD30+和利润。

5）七步案例

背景：首贷额度策略V4把中低Score的最高额度从1,500提高到2,100 MXN。
数据：成熟18,000单；Approval 31%→34%；平均EAD 1,420→1,790；FPD7件数14.5%→16.0%；金额FPD 15.2%→19.8%；低Score×Limit≥1,800组FPD7=27%；预计EL/Loan 132→176 MXN。
现象：件数FPD只升1.5pp，但金额风险和EL增幅更大。
拆解：新增损失主要来自低Score高额度；中Score 1,200-1,500额度仍保持正Margin。
根因：EAD扩张放大了边缘客群损失；件数风险变化不足以反映经济风险。
决策：保留中Score小步提额；低Score收缩额度，不必撤回所有Approval扩张。
结果：观察MOB1/2 DPD30+、Vintage、EL/Loan、Contribution Margin至少1-2个成熟周期。

6）诊断逻辑：成熟度 → Channel/Score → Limit/EAD → Payment/Fraud → Amount FPD → DPD30+/Vintage/EL。

7）策略动作：风险来自PD则收准入；来自EAD则降额度；来自欺诈则加强KYC/设备；来自支付则修支付，不要一律降Approval。

8）常见误区：FPD7=最终Bad Rate；只看件数；不同期限产品直接横比；用展期后的口径美化；新客与复借混用。

9）拆分维度：Channel、Score、Limit、Term、New/Repeat、Region、Income/DTI、Device、Strategy Version。

10）预警方式：以成熟Cohort为主；同时看件数和金额。黄灯/红灯应联合样本量、历史波动、EL与后续Vintage，而非套统一行业值。

11）关系：Approval/Limit → EAD + FPD7 → Early Roll → DPD30+ → Bad/LGD → EL → Contribution Margin。

12）小练习与答案

A方案FPD7从14%降到13%，但平均EAD从1,300升到2,000、金额FPD从15%升到18%。能否说风险改善？

答案：不能；件数改善被金额暴露放大抵消，应继续看EL和后续Vintage。

4. DPD30+｜30 Days Past Due Plus｜30天以上逾期率

1）指标是什么：观察时点处于30天及以上逾期的账户/余额比例。大白话：资产里有多少已经进入较深逾期。

2）为什么重要：属于更滞后的信用质量指标，适合Vintage、MOB、贷后策略和坏账预算；比FPD更稳定，但会受资产年龄结构影响。

3）精确定义与公式：

Current DPD30+ = 观察日DPD≥30的账户/余额 ÷ 同观察日应纳入资产池的账户/余额Vintage DPD30+@MOBn = 某放款Vintage在MOBn时DPD≥30的账户/原始放款金额 ÷ 该Vintage成熟资产

必须明确Current vs Ever、账户 vs 金额、观察日、Vintage/MOB、展期/重组/核销处理。

4）如何看高低：通常越低越好，但总体Current DPD30+可能因大量新放款被“稀释”；同Vintage同MOB更适合比较风险趋势。

5）七步案例

背景：业务连续两月扩量40%，管理层看到总体DPD30+仅11.8%→12.0%，判断风险稳定。
数据：新放款余额占比35%→55%；MOB1 DPD30+从9.5%→13.8%；渠道C MOB1为18%；FPD7金额率16%→20%；1-7→8-30金额Roll 29%→39%；平均EAD 1,480→1,820。
现象：总体Current DPD30+几乎没变，但新Vintage明显恶化。
拆解：Vintage×MOB×Channel×Score×Limit后，风险集中渠道C和边缘Score高额度。
根因：资产快速增长造成分母稀释，Current DPD30+掩盖新客质量恶化。
决策：停止使用单一Current DPD30+做扩量判断；新增MOB1/MOB2 Vintage、Roll和金额风险Gate。
结果：至少等两个Vintage达到同MOB后评价策略；同时看EL、Recovery和Margin。

6）诊断逻辑：资产年龄结构 → Current vs Vintage → MOB → Channel/Score/Limit → Cure/Roll/Extension → Bad/Recovery/EL。

7）策略动作：新Vintage恶化时收缩高风险组合；催收问题优化Cure；大量展期则拆Cash Cure；金额DPD高则处理Limit/EAD。

8）常见误区：用Current DPD30+判断快速增长业务；不同MOB横比；件数/金额混淆；把Ever DPD30+与Current DPD30+混用；忽略核销/重组。

9）推荐拆分：Vintage、MOB、Channel、Score、Limit、Term、Cycle、Region、Collection Strategy、Extension Count。

10）预警方式：优先同Vintage同MOB比较；设置最小成熟样本量。示例红灯只能是内部阈值，例如连续两个成熟Vintage的MOB1 DPD30+超历史P90且EL/Loan同步恶化。

11）关系：FPD7 → Roll/Cure → DPD30+ → Bad/Write-off → Recovery/LGD → EL → Contribution Margin。

12）小练习与答案

总体DPD30+稳定，但MOB1 DPD30+连续两个新Vintage从10%升到15%，新放款占比又大幅提升。应该相信哪个？

答案：优先相信同Vintage同MOB的恶化信号；总体指标可能被新资产分母稀释。

今日指标组合

建议链路：Payment/KYC/Fraud → FPD1 → Early Cure → FPD3 → FPD7（件数+金额） → Early Roll → MOB1/2 DPD30+ → Bad/Recovery → EL / Contribution Margin。

最关键的口径纪律：成熟期、件数/金额、首贷/复借、Current/Vintage、展期/部分还款定义必须写进数据字典。
