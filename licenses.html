墨西哥贷款牌照、资质与 APP 合规专题

面向线上现金贷、消费信贷、数字信贷APP。以下严格区分法律要求、监管实践、市场惯例与分析推断；具体主体上线前仍应由墨西哥律师/合规团队核验最新法律、许可与合同结构。

今日监管核验

CNBV：本轮公开检索未发现过去24小时足以改变线上现金贷经营模式的行业级 IFPE、IFC、银行或 SOFOM 重大新增授权、撤销或处罚。该结论仅表示公开检索未发现，不代表不存在个案行动。

CONDUSEF欺诈提示：9月8日El Economista援引CONDUSEF警示，不要通过SMS、WhatsApp、邮件、社交平台链接下载“银行APP”，应只从官方商店下载并核验真实机构。对贷款APP应纳入Brand Fraud/ATO/KYC联动。

二、业务穿透：六个问题决定真实牌照边界

分析推断：合作一家持牌金融机构，不意味着APP自动继承其全部许可。上线任何新资金方、产品或钱包/支付功能前至少回答：谁审批？谁定价？谁出资？谁持有债权？谁向用户收费？谁催收？

长期维护：Developer → APP Brand → Legal Entity → SOFOM/License Status → SIPRES → RECA → RECO → Actual Lender → Funding Party → Creditor → Collector/REDECO。

三、PLD/FT 与 AML

法律/监管实践：SOFOM E.N.R.适用的PLD/FT义务受CNBV监督；身份/KYC、Beneficial Owner、制裁/PEP、异常第三方还款、Shared Bank/Wallet、Counterparty Graph、Case Outcome应形成闭环。

潜在风险：处罚、整改、合作方/平台审查、声誉和资金通道风险。

CNBV SOFOM E.N.R. FAQ · CNBV SITI PLD

四、征信：贷前查询与放款后报送是两条责任链

CNBV FAQ指出，SOFOM应成为至少一家Sociedad de Información Crediticia的用户，并定期提供其发放的全部信贷信息。内部应分开管理：Loan Disbursed → Bureau Report Due → Report Sent → Accepted/Rejected → Correction → User Dispute Closed。

建议指标：报送完整率、Timeliness、Rejected Record Rate、Correction SLA、Identity Match Rate。

原文：CNBV SOFOM FAQ

五、数据隐私与第三方AI/SDK

法律要求：现行墨西哥私人数据保护法律及主管安排需按最新版本核验；贷款APP应重点管理身份证/OCR、人脸/活体、设备、征信、CLABE/银行卡、支付和行为数据。

建议数据台账：Field → Purpose → Notice/Consent → Vendor/Subprocessor → Storage Region → Cross-border Access → Retention → AI Training Use → Delete/ARCO。

潜在风险：用途超范围、同意不足、敏感/金融数据治理不当、第三方共享不透明及安全事件处置不足，可同时形成监管、投诉与平台审核风险。

原文：现行私人数据保护法

六、Brand Fraud / 假APP：9月8日新增提示

监管/消费者保护实践：据El Economista援引CONDUSEF，SMS、WhatsApp、邮件或社交平台中的APP下载链接可能导向恶意应用并造成个人/金融数据窃取和欺诈。

业务动作：只在官方站点、Google Play、App Store发布下载入口；Brand Fraud Radar覆盖品牌词、域名、APK/包名、WhatsApp、SMS Sender、广告和“非本人申请/提款”投诉；确认样本反馈给ATO/KYC/Device规则。

原文：El Economista（援引CONDUSEF）

七、Google Play 贷款 APP Gate

Target API：自2026-08-31起，新APP和更新需Target Android16/API36或更高；现有手机APP至少Target Android15/API35，才能继续正常面向运行更高Android版本的新用户；符合条件的APP可申请延期至11月1日。

Financial Features Declaration：所有已发布于Closed Testing、Open Testing或Production轨道的APP均需完成声明；贷款相关类别包括Personal loan direct lender、Loan facilitator、Payday loans、Banking、Line of credit等。个人贷款相关APP需说明Lender及与开发者的关系。

Financial Services Policy：个人贷款需披露最短/最长期限、最高APR、代表性总成本及隐私政策；不得推广60天或更短时间内全额还款的个人贷款。READ_CONTACTS、ACCESS_FINE_LOCATION、READ_PHONE_NUMBERS、READ_MEDIA_IMAGES/VIDEO、QUERY_ALL_PACKAGES等权限受到禁止。

潜在下架风险：Target API、声明、Actual Lender/主体关系、商店披露或敏感权限不合规均可能导致提交失败、补件、限制分发或下架。

Google Target API · Financial Features Declaration · Financial Services Policy

八、Apple App Store 贷款产品 Gate

Apple App Review Guidelines 3.2.2(ix)要求个人贷款APP清楚披露全部贷款条款、等效最高APR和到期日；最高APR不得超过36%（包括成本和费用），且不得要求60天或更短时间内全额还款。

必须独立判断：“墨西哥法律允许经营”与“Apple允许App Store分发”是两个Gate，不能互相替代。
