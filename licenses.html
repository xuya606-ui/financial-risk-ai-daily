二、业务穿透：六个问题决定真实许可边界

分析推断：与一家持牌金融机构合作，不意味着 APP 自动继承其全部许可。每次上线新资金方、产品、钱包、还款或催收方案，都必须回答：

谁审批？谁定价？谁出资？谁持有债权？谁向用户收费？谁催收？

长期维护：Developer → APP Brand → Legal Entity → SOFOM/License Status → SIPRES → RECA → RECO → Actual Lender → Funding Party → Creditor → Collector/REDECO。

三、PLD/FT 与 AML

SOFOM E.N.R. 适用的 PLD/FT 义务应持续纳入CNBV监督视角。现金贷应把身份/KYC、Beneficial Owner、制裁/PEP、第三方代还、Shared Bank/Wallet、Counterparty Graph 与 Case Outcome 连成闭环。

潜在风险：监管处罚、整改、支付/资金合作方中止、历史诉讼和声誉损失。

CNBV 监督/处罚公开说明

四、征信：贷前查询与放款后报送分开管理

建议统一流程：Application Bureau Query → Loan Disbursed → Bureau Report Due → Report Sent → Accepted/Rejected → Correction → User Dispute Closed。

建议指标：Bureau Hit、Report Completeness、Timeliness、Rejected Record Rate、Correction SLA、Identity Match Rate。

五、数据隐私与第三方 AI/SDK

身份证/OCR、人脸/活体、设备指纹、征信、CLABE/银行卡、支付和行为数据应进入字段级治理：

Field → Purpose → Privacy Notice/Consent → Vendor/Subprocessor → Storage Region → Cross-border Access → Retention → AI Training Use → Delete/ARCO

潜在风险：超目的处理、授权不足、第三方共享不透明、数据泄露、训练用途不清，以及由此产生的监管、投诉、诉讼和应用商店风险。

Brand Impersonation → Fake Offer/Link/APK → Advance Fee / Credential Theft → Device Compromise / ATO → Bank Change / Drawdown → Fraud Loss

七、Google Play 贷款 APP Gate

Target API：自2026-08-31起，新APP和更新需Target Android16/API36或以上；现有手机APP至少Target Android15/API35，符合条件者可申请延期到11月1日。

Financial Features Declaration：所有Google Play发布应用（包括closed/open testing、production）都需完成声明；贷款功能包括Personal loan direct lender、Loan facilitator、Payday loans、Banking、Line of credit、EWA、Microfinance banking等。个人贷款相关功能还需说明Lender及业务关系，并按适用地区提交许可材料。

Release Gate：API36 + Developer → Legal Entity → APP Brand → Actual Lender → License/Registration → Financial Features Declaration + Sensitive Permission。

风险：补件、拒审、限制分发或下架。

Google Target API · Financial Features Declaration · Financial Services Policy

八、Apple App Store 贷款 APP Gate

Apple App Review Guidelines 3.2.2(ix) 要求个人贷款APP清楚披露贷款条款、最高等效APR和到期日；最高APR不得超过36%（含成本与费用），且不得要求60天或更短期限内全额偿还。

分析：这是平台分发Gate，不与墨西哥本地法律许可混为一谈。法律允许经营 ≠ Apple一定允许分发。

Rates → Funding Cost → Price / Limit → Contribution Margin
