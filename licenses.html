先区分：公司形态 ≠ 金融牌照

S.A. de C.V.、S.A.P.I. de C.V.、S. de R.L. de C.V.等属于公司法律形态；SOFOM E.N.R./E.R.、SOFIPO、IFPE、IFC、银行则属于金融业务身份、监管类别或持牌/登记状态。完成公司注册本身并不等于获得支付、众筹、吸收公众资金或银行业务许可。

SOFOM E.N.R.：法律要求、PLD/FT与征信报送

法律/监管要求：SOFOM主要从事授信、融资租赁或保理，并需要保持CONDUSEF相应登记。CNBV公开资料说明，SOFOM E.N.R.就PLD/FT/FPADM事项接受专项监督；新设SOFOM E.N.R.在取得相关登记前还涉及PLD/FT技术意见等流程。

征信：CNBV FAQ指出，SOFOM应成为至少一家信用信息机构的用户，并定期提供其授信信息。建议建立：Loan Disbursed → Bureau Report Due → Report Sent → Accepted/Rejected → Correction → User Dispute Closed。

监管实践：线上现金贷固定核验：Developer → APP Brand → Legal Entity → SOFOM Status → SIPRES → RECA → RECO → Lender → Funding Party → Creditor → Collector/REDECO。

潜在风险：主体不一致、错误金融身份宣传、PLD/FT缺陷、征信漏报/错报、合同/费用披露不一致、催收和投诉处理问题，都可能形成监管、合作方和应用商店风险。

CNBV—SOFOM FAQ；CNBV—PLD/FT/FPADM

IFPE / IFC / 银行 / 合作放款

法律要求：IFPE、IFC属于Ley Fintech框架内需要CNBV正式授权的机构类型；银行业务需要专门银行授权。CNBV的授权指南明确，提交申请材料并不保证获得授权。

适用模式：现金贷APP如果新增钱包、储值、用户资金留存、电子支付资金、公众资金归集、投资人出资或众筹撮合，应在PRD阶段重新做牌照边界判断。

市场惯例/分析推断：与持牌机构合作不等于“获得合作方牌照”。需要穿透谁审批、谁定价、谁出资、谁持债权、谁收费、谁催收。

CNBV IFPE/IFC授权指南；CNBV Fintech规范

SIPRES / RECA / RECO / REDECO

建议把以下链条做成上线与资金切换的发布阻断表：APP展示主体 → SIPRES → 合同版本/RECA → 费用/RECO → 催收方/REDECO。任一关键节点不一致，应先进入法务/合规复核，而不是上线后补材料。

身份冒用 / Montadeudas｜消费者保护基线

CONDUSEF持续提醒贷款用户警惕冒用正规金融机构名称/Logo、提前收费、不在SIPRES、过度索取联系人/照片等权限、利息和总成本不透明等移动贷款风险。

产品/风控建议：品牌名、域名、APK/包名、WhatsApp、SMS Sender、Meta/TikTok广告和提前收费话术进入Brand Fraud Radar；客服“非本人申请/非本人提款”投诉回流Fraud Ops和ATO策略。

Google Play｜贷款 APP 发布与主体要求

Target API：从2026-08-31起，新应用/更新需要Target Android16/API36或更高；已有手机APP至少Target Android15/API35才能继续正常覆盖更高Android版本的新用户。

Financial Features Declaration：所有含金融功能APP需要完成声明，Personal Loan Direct Lender、Loan Facilitator、Payday Loan、Line of Credit等类别应准确选择。

Developer主体：提供金融产品/服务的开发者应使用Organization Account，并维护Legal Name、Address、D-U-N-S、Payments Profile等一致信息。

贷款政策：个人贷款需要满足适用的期限/总成本披露、隐私和敏感权限政策；Developer与Actual Lender及提交的资质材料之间要可验证。

下架/拒审风险：Target API、金融声明、开发者主体、实际贷款人、受限权限或贷款政策任一不一致，都可能导致审核失败、地区不可用或下架。

Google Target API；Financial Features Declaration；Organization Account；Financial Services Policy

Apple App Store｜个人贷款独立分发Gate

Apple当前3.2.2(ix)要求个人贷款APP清楚披露贷款条款、最高APR和还款日；最高APR不得超过36%（含费用和成本），且不得要求60天或更短时间内全额偿还。

分析原则：“墨西哥法律允许经营”与“Apple允许分发”是两个独立Gate。产品设计、定价和期限在进入iOS版本规划前就应单独做Store Policy Review。

Apple App Review Guidelines

宏观与资金成本｜不要把政策利率当All-in Funding Cost

9月3日官方市场页面显示MXN/USD参考汇率约16.9852，TIIE de Fondeo约6.51%；Banco de México当前目标利率仍为6.50%。

经营模型建议拆分：Reference Rate + Funding Spread + Commitment Fee + Hedging/Structure Cost + Liquidity Cost。汇率变化也应与用户行业、地区、美元计价技术成本和资金来源联动。
