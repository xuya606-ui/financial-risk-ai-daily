二、业务穿透：六个问题决定真实许可边界

分析推断：与持牌机构合作，不意味着 APP 自动继承其全部许可。上线新资金方、产品、钱包、还款或催收方案前必须回答：谁审批？谁定价？谁出资？谁持有债权？谁向用户收费？谁催收？

长期维护：Developer → APP Brand → Legal Entity → SOFOM/License Status → SIPRES → RECA → RECO → Actual Lender → Funding Party → Creditor → Collector/REDECO。

三、PLD/FT 与 AML

SOFOM E.N.R. 适用的 PLD/FT 义务受到 CNBV 监督。身份/KYC、Beneficial Owner、制裁/PEP、异常第三方还款、Shared Bank/Wallet、Counterparty Graph 和 Case Outcome 应形成闭环。

潜在风险：监管处罚、整改、资金/支付合作方中止、历史诉讼与声誉风险。

CNBV 监督/处罚公开说明

四、征信：贷前查询与放款后报送分开管理

SOFOM 的征信治理建议拆成：Application Bureau Query → Loan Disbursed → Bureau Report Due → Report Sent → Accepted/Rejected → Correction → User Dispute Closed。

建议指标：Bureau Hit、Report Completeness、Timeliness、Rejected Record Rate、Correction SLA、Identity Match Rate。

五、数据隐私与第三方 AI/SDK

身份证/OCR、人脸/活体、设备指纹、征信、CLABE/银行卡、支付和行为数据应优先进入字段级治理。

Field → Purpose → Privacy Notice/Consent → Vendor/Subprocessor → Storage Region → Cross-border Access → Retention → AI Training Use → Delete/ARCO

潜在风险：超目的处理、授权不足、第三方共享不透明、数据泄露与AI训练用途不清，可同时形成监管、投诉、诉讼和应用商店风险。

六、Brand Fraud / 假机构 / Malware / ATO

CONDUSEF 9月8日通报：8月有11家登记于 SIPRES 的正规机构被冒用名称、Logo或相关资料，多家为 SOFOM E.N.R.。这类诈骗直接针对寻找贷款的人群。

风险链应统一成：Brand Impersonation → Fake Offer/Link/APK → Advance Fee 或 Credential Theft → Device Compromise/ATO → Bank Change/Drawdown → Fraud Loss。

动作：Brand Fraud Radar 覆盖品牌词、域名、APK/包名、WhatsApp、SMS Sender、广告、收款账户和客服投诉；APP/官网提供 SIPRES/主体核验入口；确认样本反馈给 KYC/Device/ATO/支付风控。

七、Google Play 贷款 APP Gate

Target API：自 2026-08-31 起，新 APP 和更新需 Target Android 16/API36 或以上；现有手机 APP 至少 Target Android15/API35，符合条件可申请延期至11月1日。

Financial Features Declaration：覆盖 Personal loan direct lender、Loan facilitator、Payday loans、Banking、Line of credit、EWA、Microfinance banking 等，贷款类还需额外材料。

风险：Developer、Legal Entity、APP Brand、Actual Lender、声明和实际产品不一致可能导致补件、拒审、限制分发或下架。

Google Target API · Financial Features Declaration

八、Apple App Store 贷款 APP Gate

Apple App Review Guidelines 3.2.2(ix) 要求个人贷款 APP 清楚披露贷款条款、最高等效 APR 和到期日；最高 APR 不得超过 36%（含成本与费用），且不得要求 60 天或更短期限内全额偿还。

分析：这是平台分发 Gate，不应与墨西哥本地法律许可混为一谈。法律允许经营 ≠ Apple 一定允许分发。
