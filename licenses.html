二、业务穿透：六个问题决定真实许可边界

分析推断：与持牌机构合作，不意味着APP自动继承其全部许可。上线新资金方、产品、钱包、还款或催收方案前必须回答：谁审批？谁定价？谁出资？谁持有债权？谁向用户收费？谁催收？

长期维护映射：Developer → APP Brand → Legal Entity → SOFOM/License Status → SIPRES → RECA → RECO → Actual Lender → Funding Party → Creditor → Collector/REDECO。

三、PLD/FT 与 AML

法律/监管实践：SOFOM E.N.R.适用的PLD/FT义务受到CNBV监督。身份/KYC、Beneficial Owner、制裁/PEP、异常第三方还款、Shared Bank/Wallet、Counterparty Graph和Case Outcome应形成闭环。

潜在风险：监管处罚、整改、资金/支付合作方中止、历史诉讼与声誉风险。

CNBV SOFOM E.N.R. PLD FAQ

四、征信：贷前查询与放款后报送分开管理

SOFOM需要按适用规则与至少一家信用信息机构建立业务关系并履行信贷信息报送责任。内部应拆成：Application Bureau Query → Loan Disbursed → Bureau Report Due → Report Sent → Accepted/Rejected → Correction → User Dispute Closed。

建议指标：Bureau Hit、Report Completeness、Timeliness、Rejected Record Rate、Correction SLA、Identity Match Rate。

五、数据隐私与第三方AI/SDK

法律要求：贷款APP需要按现行墨西哥私人数据保护法核验隐私告知、处理目的、共享、跨境处理、敏感/金融数据、安全与ARCO流程。身份证/OCR、人脸/活体、设备指纹、征信、CLABE/银行卡、支付和行为数据应优先进入字段级治理。

Field → Purpose → Privacy Notice/Consent → Vendor/Subprocessor → Storage Region → Cross-border Access → Retention → AI Training Use → Delete/ARCO

潜在风险：超目的处理、授权不足、第三方共享不透明、数据泄露与AI训练用途不清，可同时形成监管、诉讼、投诉和应用商店审核风险。

六、Brand Fraud / 假APP / ATO

近7天CONDUSEF继续提示冒充金融机构、虚假贷款批准和短信/WhatsApp/邮件恶意链接。正规信贷APP应把假APP/恶意APK、Credential Theft、New Device、Password Reset、Bank Change和非本人提款连接成同一风险链。

动作：Brand Fraud Radar覆盖品牌词、域名、APK/包名、WhatsApp、SMS Sender、广告与客服投诉；确认样本必须反馈给KYC/Device/ATO/支付风控。

七、Google Play 贷款 APP Gate

Target API：自2026-08-31起，新APP和更新提交需Target Android16/API36或更高；现有手机APP至少Target Android15/API35才能继续面向更高Android版本的新用户保持可发现性；符合条件可申请延期至2026-11-01。

Financial Features Declaration：包含Personal loan direct lender、Loan facilitator、Payday loans、Banking、Line of credit、EWA、Microfinance banking等；个人贷款相关功能需要进一步材料。实际Developer、APP Brand、Actual Lender与资质/合同应一致。

风险：声明不准确、资质关系不可验证、敏感权限或贷款披露不合规，可导致更新拒绝、补件、限制分发或下架。

Google Target API要求 · Google Financial Features Declaration

八、Apple App Store 贷款 APP Gate

平台要求：App Review Guidelines 3.2.2(ix)要求个人贷款APP清晰披露全部贷款条款、最高等效APR和到期日；最高APR不得高于36%（含成本/费用），且不得要求60天或更短期限内全额偿还。

判断原则：“墨西哥法律允许经营”与“Apple允许分发”是两个独立Gate。即使法律结构可行，也不意味着产品形态满足Apple分发政策。

九、Banxico Circular 10/2026：2026-12-14合规期限

法律要求/适用范围：该Circular于2026-06-17发布，针对信用机构、与信用机构具有股权关联的受监管SOFOM等指定主体，修改Circular 3/2012并推进移动设备电子转账用户体验标准化；过渡合规期限至2026-12-14。

适用业务模式：典型SOFOM E.N.R.不因本Circular自动成为直接适用对象；但贷款APP若依赖适用银行/SOFOM E.R.合作方完成转账、收款或还款，需要跟踪合作方产品与接口迁移。

风险/分析：手机号与转账用户体验变化可能改变Beneficiary Verification、Phone Takeover与ATO攻击面，支付产品改造应与风险规则同步。
