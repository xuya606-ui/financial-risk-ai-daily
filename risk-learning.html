今日知识：额度策略 Limit Strategy

一句话：额度不是“好客户奖励”，而是把资金和风险暴露配置给不同客群。真正要优化的是每增加1 MXN额度带来的边际收入、边际资金成本与边际EL。

核心公式：

简化边际EL ≈ PD × LGD × ΔEAD（仅在PD/LGD近似不变时成立）

为什么重要：同一用户PD不变，额度从MXN1,200提升到1,800，EAD也会显著上升；若风险边缘用户更倾向把新增额度全部用满，PD与EAD可能同时上升。

墨西哥现金贷模拟案例

背景：复借策略V6把额度上限从MXN2,000提升到2,800。
数据：样本8,000；件均1,650→2,050；Take-up 58%→66%；FPD7件数9.5%→10.2%；FPD7金额10.1%→13.8%；Contribution Margin/人 MXN210→198。
现象：件数风险只小幅变化，但金额风险和利润明显恶化。
拆解：Score×Limit后，中高Score风险稳定；最低两档Score在Limit≥2,400时金额FPD达到18%。
根因：新增额度被边缘Score更充分使用，EAD放大；是否完全由提额造成仍需Champion/Challenger验证。
决策：中高Score保留提额；低Score降低提额步长或上限；提款前增加多头/账户风险轻量复核。
观察：FPD7成熟后继续看MOB1/2 Vintage、EL和Contribution Margin。

常见误区：提额当忠诚度奖励；只看件数Bad不看金额；先提额再等Vintage成熟；不同Score使用同一提额比例；忽略Take-up/Utilization选择效应。

判断链路：Score → Limit → Take-up/Utilization → Average Ticket/EAD → FPD/Vintage → EL → Contribution Margin。

小练习与参考答案

PD≈12%、LGD≈70%，每人平均新增使用额度MXN500。在PD/LGD近似不变时，边际EL约多少？

答案：0.12×0.70×500≈MXN42/人；真实业务还需考虑PD随额度和选择效应变化。

今日指标：Limit Utilization / Average Ticket / DTI / PTI

Limit Utilization：额度给了多少、实际用了多少；一次性现金贷和循环额度必须用不同口径。

Average Ticket：成功放款的平均实际本金；件均上升必须与金额FPD和EL一起看。

DTI：总月度债务偿付 ÷ 可验证月收入；低DTI也可能因收入/征信数据不完整而“假低”。

PTI：本笔周期还款 ÷ 同周期可验证收入；适合额度与期限设计。

今日实操：额度策略分层 + 边际EL

字段：score_band、approved_limit、disbursed_amount、utilization、term、verified_income、monthly_debt_payment、installment_amount、fpd7、dpd30、bad、revenue、funding_cost、collection_cost、strategy_version。

步骤：固定成熟样本 → Score×Limit矩阵 → Utilization/件均 → FPD件数+金额 → PD/LGD/EAD/EL → Contribution Margin → 找到边际利润转负的额度档 → Champion/Challenger。

SELECT score_band,limit_band,COUNT(*) n,AVG(disbursed_amount) avg_ticket,AVG(disbursed_amount/NULLIF(approved_limit,0)) utilization,AVG(fpd7_flag) fpd7_cnt FROM matured_loans GROUP BY score_band,limit_band;

复盘：第二天先看流量、Limit分布、Take-up、Utilization、支付失败和FPD1；风险标签未成熟前不全量扩大额度。

今日业务：件均提高为什么利润可能下降？

件均上涨会同时提高收入和EAD。如果新增利息收入小于新增Funding Cost + EL + 催收成本，件均越高反而越不赚钱。业务评审应改成：每新增MXN100本金，新增收入、资金成本、EL和Contribution Margin分别是多少。

今日产品：额度展示、提额与风险回退

页面建议区分“当前可借额度”“本次建议借款额”“潜在最高额度”；未最终授信的上限不要显示成确定承诺。用户选择金额后明确展示总成本和还款计划。

额度有效期内如出现新设备、手机号/银行卡变化、近期多头上升或账户风险事件，提款前执行轻量复核：轻度风险可降额，身份风险高则二次KYC，重大风险则暂停提款。

职责：产品负责额度展示与解释；风控负责Limit/提额/回退规则；数据负责Limit→Utilization→FPD/Vintage→EL看板；研发负责额度版本、有效期和实时回滚；运营只触达当前仍符合资格的人群。
