今日知识｜Affordability Decisioning & Income Stress

概念：信用模型回答“像不像坏客”，Affordability回答“当前现金流能不能承受这笔新贷款”。核心不能只看一个DTI，而是把 DTI、PTI、Residual Income 与 Income Volatility 组合起来。

Verified Income → Existing Debt Service → Proposed Payment → Residual Income → Income Stability → FPD / Vintage → EL / Margin

为什么重要：短期现金贷的风险经常来自当期现金流被额度、费用、期限和已有债务同时挤压。一个信用分数中等但高PTI、高收入波动的客户，可能比同分数、稳定工资、低PTI客户风险高很多。

墨西哥现金贷七步案例

背景：30天首贷，Strategy B 在 Channel B 放宽额度并扩量。
数据：N40,000；Approval 31%→35%；Avg Ticket MXN1,450→1,950；DTI 30%→38%；PTI 10.8%→15.2%；Median Residual Income MXN3,700→2,500；高收入波动客占比14%→24%；FPD7 13.8%→18.5%。
现象：放款量和票面额增长，但早期信用表现显著恶化。
拆解：Channel B × Low/Medium Score × 高PTI × 高Income Volatility 的 FPD7 达27%；稳定工资 + 低PTI Segment约11%。
根因：支付负担和收入不稳定与恶化高度相关，但渠道、额度和客群结构同时变化，因此不能把高PTI直接认定为唯一原因。
决策：高PTI+高波动客降额；稳定工资中等Score保留Challenger；收入数据Missing/Payroll识别异常先修数据。
结果：等两个成熟FPD7 Cohort，再看MOB1 DPD30+、EL/Loan、Approval和Contribution Margin；风险下降且利润恢复才认为策略有效。

判断方法：Income定义与周期 → Existing Debt → Proposed Payment → Residual → Income Volatility → Channel×Score×Limit → FPD/Vintage → EL/Margin。

常见误区：DTI越低越好；自报收入直接当Verified Income；短期贷款PTI与收入周期错配；必要生活支出设为0；Missing直接判高风险；只看件数Bad忽略金额风险。

小练习与答案

月净收入10,000，已有月债务3,000，新贷款到期应付1,400，必要生活支出4,000。DTI=30%、PTI=14%、Residual=1,600。能否仅凭DTI=30%判断安全？

答案：不能。必须联合PTI、Residual、收入稳定性、期限匹配和成熟信用表现。

今日指标学习

DTI：已有债务付款占收入，不能把No-hit直接当0债务。

PTI：新贷款周期付款占同期收入，额度/价格/期限会共同改变它。

Residual Income：收入扣除生活支出、已有债务和新付款后的绝对缓冲。

Income Volatility：看3-6个月工资/净流入稳定性，平均收入相同不等于偿付能力相同。

今日实操｜Affordability Stress Matrix

字段：verified_income、income_history、existing_debt_payment、essential_expense、proposed_payment、limit、term、price、score、channel、fpd7、dpd30、EL、margin、strategy_version。

步骤：统一收入周期 → DTI/PTI/Residual/Volatility → Channel×Score×Income×Limit → FPD7/Amount FPD → MOB1 DPD30+ → EL/Margin → Limit/Term Challenger。

Income / Debt / Payment → Affordability → FPD/Vintage → EL → Margin

第二天复盘：先检查收入数据缺失、Payroll识别、征信债务完整性和渠道结构；深度Bad没成熟时不因一天分布变化全量收紧。

今日业务｜不要最大化Approval，要最大化“可负担的风险调整增长”

经营链固定为 Verified Income → DTI/PTI → Residual → Approval → Limit/EAD → FPD/Vintage → EL → Contribution Margin。Approval上升但PTI、EAD、EL同步上升时，必须提前看Amount FPD和Residual。

今日产品｜额度页增加 Affordability Guardrail

用户选择金额/期限时实时计算预计到期应付与收入压力。高额度把PTI/Residual推入内部高风险区时，默认推荐更低金额或更合适期限，并清楚展示总成本；不要默认最大额度或隐藏费用。产品负责页面，风控负责Guardrail，数据负责成熟结果，研发负责实时计算/灰度/回滚，运营不得绕过高风险额度规则。
