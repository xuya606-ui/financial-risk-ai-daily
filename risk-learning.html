今日知识｜Repeat-loan Selection & Risk-adjusted LTV

概念：复借客户提供了真实还款、支付和账户行为，但“能进入复借的人”已经经过首贷筛选，因此存在幸存者选择；提额、优惠、复借间隔和重新征信又会改变风险。复借策略的目标应从“最大化Repeat Rate”升级为“最大化成熟风险调整后的累计LTV”。

Risk-adjusted LTV_N = Σ(Revenue − Funding − EL − Variable/Servicing/Collection Cost − Incremental Incentive)_cycle

为什么重要：首贷可能承担获客成本，后续Cycle才形成利润；但一次按时还款并不足以支持无限提额。件数Bad下降时，EAD和金额Bad仍可能恶化。

墨西哥现金贷七步案例

背景：30天首贷，结清后自动进入复借候选。
数据：首贷10,000人，Avg Ticket MXN1,500、FPD7 15%、风险调整贡献80/loan；5,500人Eligible，3,850人复借；Cycle2 Avg Ticket 2,100、FPD7 12%、贡献135；Cycle3 2,100人、Avg Ticket 2,700、FPD7 13%、金额FPD18%、贡献120；初始CAC约90/首贷用户。
现象：复借件数风险优于首贷，但Cycle3金额风险重新上升。
拆解：Channel C×首贷低Score×Cycle3 Limit≥3,000的Amount Bad/MOB1 DPD30+最差。
根因：行为信息、Limit/EAD、复借间隔和客群选择同时变化；不能只用“第几借”解释风险。
决策：首贷行为+最新征信/多头+收入/支付+Device/ATO共同决定Eligibility和提额。
结果：同首贷Vintage、同Cycle成熟度看Repeat Bad@MOB、EL、Cycle Margin与累计LTV，跨至少2个成熟复借Cohort确认。

判断方法：First Vintage → Eligibility → Offer Exposure → Repeat Application/Approval → Limit/EAD → FPD/Bad同Cycle成熟 → Cycle Contribution → Cumulative LTV/CAC。

常见误区：Eligible与全量首贷分母混用；复借率高=优质；一次按时还款=可以提最大额度；只看件数Bad；未成熟未来Cycle直接算LTV；CAC重复扣除。

小练习与答案

Cycle1/2/3总风险调整贡献分别为800k、519.75k、252k，首贷用户10,000。前三个Cycle每首贷用户累计价值约多少？CAC=90时LTV/CAC约多少？

答案：约MXN157.2/用户，LTV/CAC≈1.75。实际生产还要处理未来Cycle删失、折现、成熟损失和增量营销成本。

今日指标学习

Repeat Rate：成熟首贷/Eligible客群中实际再次借款的比例；必须区分Origination Cohort和Offer Take-up分母。

Repeat Approval Rate：真正进入复借重评的申请中最终批准的比例。

Repeat Bad Rate@MOB：同Cycle、同MOB成熟度下的件数/金额Bad。

Risk-adjusted LTV / LTV:CAC：多Cycle风险调整累计价值及其对获客成本的覆盖能力。

今日实操｜Cycle Cohort LTV Matrix

字段：user_id、acquisition_channel、first_vintage、cycle_no、eligibility_date、offer_exposed、repeat_apply、repeat_approved、disbursement_amount、score_at_cycle、prior_dpd、days_since_last_payoff、limit、revenue、funding、EL、CAC、incremental_marketing、collection_cost、FPD7、DPD30、Bad、maturity、strategy_version。

步骤：固定首贷Vintage与Cycle → Eligibility/Exposure → Repeat/Approval → Channel×First Score×Cycle×Limit → FPD/Bad@MOB/EL → Cycle Contribution → Cum LTV/LTV:CAC → Challenger。

CAC → First Loan → Eligibility → Repeat → Cycle EAD/Bad → Cycle Margin → Cumulative LTV

第二天复盘：先查Eligibility/Exposure口径、技术失败、策略版本和Cohort删失；深度Bad未成熟时不因一天数据全量取消复借或大幅提额。

今日业务｜最大化生命周期贡献，而不是最大化第二借

经营周报建议固定展示：CAC、首贷Margin、Repeat Rate、Repeat Approval、Cycle2/3 Avg EAD、Repeat Bad@MOB、Recovery、Cum LTV和LTV:CAC。首贷亏损不一定坏，关键是成熟生命周期价值；首贷赚钱也可能被后续高EAD坏账吃掉。

今日产品｜一次按时还款，不应自动触发最大提额

复借Offer应叠加首贷行为、最新Inquiry/多头、收入/Payroll、Device/ATO、距结清天数后再决定额度/期限。产品负责复借入口和透明展示；风控负责Eligibility/Re-underwrite/Limit Guardrail；数据负责Cycle Cohort/LTV；研发负责Strategy Version/灰度/回滚；运营不得越过高风险Guardrail。
