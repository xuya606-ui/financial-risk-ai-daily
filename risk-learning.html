今日知识｜Model Monitoring Triangulation & Drift Governance

概念：模型监控不是“每天看一个PSI”。需要同时回答三个问题：①输入/客群有没有变（PSI）；②模型排序能力有没有变（AUC/KS）；③预测PD是否仍与真实Default匹配（O/E）。

Population Drift → PSI ｜ Rank Performance → AUC / KS ｜ Calibration → O/E

为什么重要：PSI高不代表模型一定失效；AUC/KS稳定也不代表校准没有问题。流量、Feature Missing、策略选择、额度、渠道以及真实基础坏账率变化，都可能让单个指标给出误导信号。

墨西哥现金贷七步案例

背景：30天首贷 Model V6，Channel C 快速扩量，同时提高部分额度。
数据：成熟样本50,000；PSI 0.06→0.24；AUC 0.73→0.72；KS 0.38→0.36；O/E 1.02→1.28；FPD7 14.8%→17.2%；Approval 32%→35%；Avg EAD 1,500→1,800 MXN。
现象：Population和校准明显恶化，但排序能力只小幅下降。
拆解：Channel C PSI=0.37、O/E=1.55；其他渠道PSI≈0.08、O/E≈1.05；风险集中 Low Score × High Limit。
根因：可确认流量/额度变化与风险恶化相关，但AUC/KS未同步大幅坍塌，当前更像Population Shift + Calibration Deterioration；仍需排除数据管道与Feature Missing。
决策：C渠道边缘流量降量；Low Score × High Limit回滚；做Segment Recalibration/Intercept Challenger；不因一个Cohort直接全量重训。
结果：观察两个成熟Vintage的PSI/AUC/KS/O-E、FPD7、MOB1 DPD30+、EL和Margin；排序、校准、损失都持续恶化才升级重训。

判断方法：Data Quality / Missing → Channel / Strategy Mix → PSI → AUC/KS → O/E → FPD/Vintage → EL/Margin。

常见误区：PSI高就重训；AUC稳定就认为模型没问题；未成熟标签算AUC/KS/O-E；不同Score方向横比；不同Default窗口混用；忽略Selection Bias。

小练习与答案

PSI 0.07→0.28，但AUC 0.74→0.73、KS 0.40→0.39、O/E 1.03→1.04。第一动作是什么？

答案：先拆流量/渠道/Feature/Strategy变化，不应仅凭PSI全量重训；排序与校准仍基本稳定时，先做流量和数据治理。

今日指标学习

PSI：看Population/Feature/Score分布有没有漂移，是坏账成熟前的重要领先信号。

AUC：看整体排序能力，不能代替校准。

KS：看好坏累计分布最大分离度，适合与AUC联合判断排序。

O/E：看真实Default是否高于/低于模型预测，是校准核心。

第二天复盘：先看Data Freshness、Feature Missing和流量/PSI；AUC/KS/O-E等标签成熟后再判断，不因单日未成熟数据全量重训。

今日业务｜模型告警先识别“流量问题、排序问题、校准问题”

PSI高而AUC/KS/O-E稳：先治理渠道/数据；AUC/KS下降：查特征-标签关系和数据质量；AUC/KS稳但O/E高：优先Recalibration、Price/Limit；三者与EL/Margin同时恶化：回滚策略并启动重训评估。

今日产品｜模型监控结果要直接连到灰度、限额与回滚

产品/研发把 Model Version、Strategy Version、Channel、Limit Guardrail 与 Feature Flag 打通。单一Segment红灯时先局部降量/降额，不必全量关产品。产品负责灰度和Offer；风控负责告警与动作；数据负责PSI/AUC/KS/O-E和业务结果；研发负责版本、日志、回滚；运营不得绕过红灯Segment。
