今日知识：Risk-Based Pricing｜风险定价与逆向选择

一句话：风险定价不是“风险越高价格越高”，而是在合规和平台限制下，把风险成本、资金成本、CAC、用户价格敏感度、额度、期限和Take-up一起纳入报价。

Contribution Margin ≈ Interest + Fees − Funding Cost − CAC − Expected Loss − Variable Ops/Payment/Collection CostPrice Elasticity（内部分析示例） = %ΔTake-up ÷ %ΔPrice

为什么重要：提价会增加单笔收入，但也可能让低风险、价格敏感客户退出更快，使剩余放款客群平均风险变差，即Adverse Selection；降价也不一定值得，如果新增Take-up来自高风险客户或补贴超过边际利润，整体利润仍可能下降。

墨西哥现金贷模拟案例

背景：首贷30天产品在Score B/C统一提高报价，目标是覆盖资金成本上涨。
数据：20,000样本；价格指标约+8%；Take-up 51%→43%；平均收入/借款人 MXN265→301；FPD7 14.8%→17.2%；低风险Score B占放款52%→41%；Contribution Margin/借款人 MXN78→71。
现象：单借款人收入上升，但Take-up和利润下降，风险变差。
拆解：Score×Channel×Limit×Term显示优质Score B对价格更敏感，退出更快；边缘Score C仍有强提款需求。
根因：价格变化与客群结构恶化高度相关，但同期渠道素材和额度也有变化，不能直接写成唯一因果。
决策：不做统一提价；分Score/Limit/Term报价。优质客群保持更有竞争力的总成本；边缘客群优先通过额度/期限控制风险，而不是无限提价覆盖。
观察：FPD7、MOB1 DPD30+、Take-up、Average Ticket、EL、Contribution Margin、LTV。

判断链：Funding Cost → Offer Price → Take-up → Score Mix → EAD → FPD/Vintage → EL → Contribution Margin。

常见误区：APR提高=利润提高；只看收入不看流失；高风险无限加价；不同期限直接比利润；忽视Google/Apple及当地法律的价格/期限限制。

小练习与答案

提价后单笔收入+15%，Take-up -20%，低风险占比下降10个百分点，FPD7从13%升到17%。能否只因为单笔收入提高就全量上线？

答案：不能。需要计算Take-up损失、EL变化和LTV下降，并通过受控实验确认是否存在逆向选择。

今日指标：CAC / LTV / Contribution Margin / Break-even Bad Rate

CAC：固定口径下获得一个真正首贷客户的可归因成本，必须和FPD/EL/LTV一起看。

LTV：客户生命周期收入扣除Funding、风险损失、支付/运营/催收等后的净价值。

Contribution Margin：Revenue − Funding − CAC − EL − Variable Cost，是风险和经营的共同语言。

Break-even Bad Rate：在当前收入、成本、EAD和LGD下，内部可承受的盈亏平衡坏账水平；不是监管或行业统一阈值。

复盘：如果提价后Take-up下降、优质客退出、风险和EL上升且Margin下降，就不是“价格提升成功”。

今日业务：提高价格，利润为什么可能下降？

因为Price会同时改变Revenue、Take-up和Customer Mix。经营必须沿着 Price → Take-up → Score Mix → EAD → FPD/Vintage → EL → Contribution Margin → LTV 判断，而不是只看APR/CAT或单借款人收入。

今日产品：报价页的透明成本与分层报价

页面应清晰显示用户当前真实可借金额、期限、总成本和到期日；优惠券/降费要展示优惠前后总成本。风险变化导致报价更新时，外部只给稳定、合规的原因类别，内部保留Score/Rule/Strategy Version。产品负责展示，风控负责Price/Limit/Term Guardrail，数据负责Price→Take-up→Risk→Margin，研发负责报价版本和回滚。
