今日知识｜Vintage Cohort Analysis：同一批资产必须在同一年龄比较

概念：Vintage是按放款月份/周、渠道或策略版本形成的资产批次；MOB（Month on Book）是这批资产从放款后走到第几个月的“年龄”。最有价值的比较通常是同Vintage、同MOB，而不是把全部资产混在一个Current DPD里。

Vintage Cohort → MOB0 → MOB1 → MOB2 → DPD30+/Bad → Recovery/LGD → EL

为什么重要：高速扩量时，大量MOB0新资产进入分母会把Current DPD30+机械压低；业务收缩时旧资产占比提高又会让Current DPD看起来更差。Vintage/MOB可以剥离年龄结构，让渠道、Cutoff、Limit、Term和Strategy Version的真实风险差异更早暴露。

核心判断：先固定Vintage和MOB定义 → 同MOB比较DPD30+/Bad → 件数与金额双口径 → Channel×Score×Limit×Term×Strategy拆解 → Cure/Roll/Recovery → EL与Contribution Margin。

墨西哥现金贷七步案例

背景：30天首贷产品在6月升级额度V5，同时渠道C扩量。
数据：4月Vintage N=18,000、MXN26m；5月N=19,500、MXN29m；6月N=27,000、MXN47m。Current DPD30+从12.1%降至11.7%，但MOB1 DPD30+为9.8%、10.4%、14.6%；6月Avg EAD MXN1,740，前两月约1,440；低Score×Limit≥MXN2,000占比9%→21%。
现象：总体Current DPD变好，但最新Vintage同MOB明显恶化。
拆解：Channel C×低Score×Limit≥2,000的MOB1 DPD30+约21%，其他组合约10%-12%；金额口径恶化更明显。
根因：可以确认新Vintage风险恶化，但额度、渠道和客群同步变化，所以不能把单一因素写成唯一因果。
决策：低Score高额度恢复旧Limit，渠道C降量；中Score低额度保留V5 Challenger。
结果：观察后续两个Vintage的MOB1/MOB2 DPD30+、Bad、EL/Loan与Contribution Margin；风险回落且利润改善才认为策略有效。

判断方法：资产年龄/快照 → Vintage/MOB成熟度 → 件数/金额 → Channel×Score×Limit×Term×Strategy → FPD/Cure/Roll → Bad/Recovery/EL。

常见误区：用Current DPD30+判断增长期资产；不同团队MOB0/MOB1起点不一致；未成熟Vintage提前评价最终Bad；只看件数不看余额；策略版本没有绑定Vintage。

小练习与答案

总DPD30+从12%降到11%，但最新两批MOB1 DPD30+从10%→14%→16%，同时放款量增长60%。风险改善了吗？

答案：不能说改善；优先相信同Vintage同MOB的恶化，并检查新资产分母稀释。

今日指标学习

Vintage DPD30+@MOB：同一批资产在相同年龄比较30+风险，避免Current DPD被增长/收缩扭曲。

MOB：资产成熟度坐标，本身没有“越高越坏”，关键是所有团队使用统一起点和日历。

Bad Rate：最终Default结果，必须固定Bad Definition、预测窗口和成熟期，并报件数/金额。

Recovery Rate：违约后收回多少，Gross与Net要分开，同Default Vintage、同Recovery MOB比较。

Collection Rate：催收期实际收回多少，应与Cost、Complaint、Cure/Roll一起看，不能和Recovery混用。

今日业务｜Current DPD稳定，也可能最新资产已经变坏

增长期最常见错觉是大量MOB0新资产加入分母，把Current DPD30+压低。经营汇报应固定展示Vintage×MOB×件数/金额风险×EL，并把每次渠道扩量、Cutoff变化、提额与价格调整绑定Strategy Version。

今日产品｜新Vintage异常时，先做Segment Gate而不是全量冻结

低Score×高Limit×异常渠道出现MOB1恶化时，先冻结该组合提额或缩小额度恢复；稳定Score、低额度客群保留Challenger。产品负责额度/复借状态和解释，风控负责Segment Gate，数据维护Vintage/MOB，研发负责版本与回滚，运营不得绕过高风险限制。
