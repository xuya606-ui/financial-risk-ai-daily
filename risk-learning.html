今日知识｜Risk-adjusted Growth & Unit Economics：增长必须过风险调整利润这一关

概念：增长不是让Approval、Take-up或放款量越高越好，而是判断新增边际客户在收入、Funding、CAC、Expected Loss和可变成本之后，是否仍创造正的Contribution Margin和LTV。

Traffic → Approval → Offer/Limit → Take-up → Disbursement/EAD → Revenue → Funding Cost → EL → Variable Cost → Contribution Margin → Repeat/LTV → ROI

为什么重要：放宽Cutoff、提额、降价格、加优惠券通常同时改变流量选择、提款金额、资金占用和风险。单看Volume容易把“增长”误判成“价值增长”。

墨西哥现金贷七步案例

背景：30天首贷，策略B在渠道C放宽Cutoff并提高额度上限。
数据：两方案各20,000申请。A Approval30%、Take-up60%、放款3,600、Avg Ticket MXN1,400、Revenue/Loan390、Funding70、CAC90、EL120、Variable35，Margin/Loan75，总Margin约MXN270k。B Approval36%、Take-up72%、放款5,184、Avg Ticket1,900、Revenue480、Funding108、CAC78、EL205、Variable42，Margin/Loan47，总Margin约MXN243.6k。
现象：放款量增长约44%，但总贡献利润反而下降。
拆解：Channel C×Low Score×Limit≥2,000的Margin约-35；Medium Score×Limit≤1,800约+82。
根因：可以确认边际客户经济性恶化，但Approval、Take-up、Limit、EL与Funding同时变化，不能把单一因素直接写成唯一因果。
决策：低Score高Limit恢复旧策略；中Score低/中额度保留Challenger；优惠券只触达风险调整后Margin为正的Segment。
结果：等待两个FPD7 Cohort和MOB1 DPD30+成熟，继续看EL/Loan、Margin、Repeat与LTV。

判断方法：固定漏斗与成本口径 → 看Approval/Take-up → 看Ticket/EAD → 等风险成熟 → 算EL/Loan → 算Margin/Total Margin → 再看Repeat/LTV/ROI。

常见误区：Approval/Take-up越高越好；把Approved Limit当真实EAD；只看Revenue不看Funding和EL；未成熟Bad按0计；CAC分母在不同团队间不一致；短期Margin正就忽略后续Vintage。

小练习与答案

A放款3,600单、Margin/Loan=75；B放款5,184单、Margin/Loan=47。哪个总贡献利润更高？

答案：A约270,000 MXN；B约243,648 MXN。B放款更多，但风险调整后总贡献更低。

今日指标学习

Take-up Rate：有效Offer中多少真正被接受；要与Score Mix、Disbursement、EL一起看。

Average Ticket：实际成功放款的平均本金；不是Approved Limit，必须与金额FPD/EAD联动。

Funding Cost：实际资金成本应包含Reference Rate之外的Spread、Commitment/Structure/FX等可归属成本。

Risk-adjusted ROI：将Margin与实际占用资金/资本比较；公式必须内部固定，不存在唯一行业口径。

Approval → Take-up → Average Ticket/EAD → Funding + EL → Contribution Margin → LTV/ROI

今日业务｜量增长不等于价值增长

经营日报建议固定同屏展示Approval、Take-up、Avg Ticket、EL/Loan、Margin/Loan、Total Contribution和LTV。真正要最大化的是可持续的风险调整后利润，而不是单一放款量。

今日产品｜Offer页不要默认把最大额度当最佳方案

对边缘Score客群，如果高额度的新增收入不足以覆盖新增Funding与EL，默认推荐较低额度更合理。产品负责Offer与解释；风控负责Score×Limit×Term Guardrail；数据负责Take-up→EAD→EL→Margin；研发负责Offer Version和回滚；运营只能在审批范围内使用优惠。
