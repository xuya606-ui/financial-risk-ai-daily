今日知识：Debt Cycling｜债务循环与“还后即借”

一句话：按时还款并不代表债务正在下降；如果用户每次还完都迅速重新借满额度，同时多头和Utilization上升，可能是在滚动债务而不是形成健康复借。

Debt Cycling Risk ≈ 短Time-to-Redraw + 高频Drawdown + 高Utilization + 外部多头/查询上升 + 本金余额长期不下降

墨西哥现金贷模拟案例

背景：还款即恢复额度，并强化还款后召回。
数据：Redraw@30d 42%→57%；Redraw@1d 18%→34%；Median Time-to-Redraw 6.2天→2.1天；Utilization 68%→82%；FPD7 9.2%→10.0%；MOB2 DPD30+金额率11%→16%。
现象：短期FPD几乎没恶化，但中期Vintage明显变差。
拆解：高风险集中于“24小时重借 + Utilization>90% + 30天Inquiry≥3”。
根因：快速重借与风险高度相关，但营销、额度和客群结构同时变化，仍需要实验验证因果。
决策：高风险组合减少恢复额度、降低提额步长或增加轻量复核/短Cooling Period；稳定低风险客维持即时恢复。
观察：Redraw、Time-to-Redraw、Balance Rebound、MOB1/2 DPD30+、EL、投诉和Contribution Margin。

常见误区：复借率高=高LTV；按时还款=低债务压力；还后即借=纯粹产品粘性；只看件数FPD、不看余额是否净下降。

小练习与答案

用户A每月借一次、还款后10天再次提款且余额逐期下降；用户B每次还款后2小时内借满额度，近30天新增4次征信查询。谁优先进入Debt Cycling复核？

答案：B。

今日指标：Redraw / Time-to-Redraw / Drawdown Frequency / Balance Rebound

Redraw Rate：具备再次提款资格的已还款用户中，N天内再次成功提款的比例。

Time-to-Redraw：完成Full Repayment到下一次成功提款之间的时间。

Drawdown Frequency：固定周期内真实独立提款次数，需去掉系统重试和拆单。

Balance Rebound Rate：还款后债务余额恢复到还款前高位/额度高位的程度，用于判断债务是否真正下降。

今日实操：复借 Debt Cycling 风险矩阵

字段：repayment_time、next_drawdown_time、drawdown_amount、approved_limit、outstanding_balance、inquiries_30d、active_lenders、verified_income、score、fpd7、dpd30、bad。

步骤：Full Repayment口径 → Time-to-Redraw → 1d/7d/30d Redraw → Frequency → Balance Rebound → Inquiry/多头/DTI → Score×Limit → Vintage/EL。

短Time-to-Redraw + 高Frequency + 高Rebound + 多头/Inquiry上升 → Debt Cycling高优先级复核

复盘：第二天先看规则命中、提款量、用户放弃和投诉；深度风险未成熟前不全量设置硬冷静期。

今日业务：高复借不一定等于高LTV

复借可以摊薄CAC，但如果EAD、Funding Cost和MOB2坏账增长更快，最终LTV反而下降。经营链应改成：Repayment → Redraw/Time-to-Redraw → Utilization/EAD → Vintage → EL → Funding Cost → Contribution Margin → LTV。

今日产品：额度恢复分层

低风险稳定客即时恢复；中风险近期Inquiry增加、Utilization高、还后短时间借满时，降低恢复额度/提额步长或增加轻量复核；高风险多头/账户安全异常进入二验、人工或暂缓恢复。产品负责状态解释，风控负责规则，数据维护Redraw→Vintage→EL，研发支持实时额度版本与回滚，运营不得绕过限制。
