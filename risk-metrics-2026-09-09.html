风控指标学习卡｜Take-up / Average Ticket / Funding Cost / Risk-adjusted ROI

统一采用12段结构；示例数字用于训练分析方法，不代表行业统一阈值。

1. Take-up Rate｜报价接受/提款转化率

1）指标是什么：获得有效Offer且观察窗口成熟的用户里，有多少真正接受方案并进入成功提款/放款链路。大白话：批准之后，客户到底愿不愿意借。

2）为什么重要：贷前到放款阶段的同步/领先经营指标，连接Approval、Price、Limit、Term、优惠与最终EAD；解决“批准很多但资产没形成”或“边缘风险客更愿意提款”的问题。

3）精确定义与公式：Take-up Rate = 成熟有效Offer中已接受Offer的用户/订单 ÷ 成熟有效Offer用户/订单必须固定Offer有效期、接受定义、用户/订单去重。若业务把成功放款作为最终转化，应另报Approval-to-Disbursement；不要把点击“借款”直接当Take-up。对多Offer用户需规定取首个/最终Offer。

4）如何看高低：高通常意味着产品/价格更有吸引力，但不一定越高越好：高风险、资金需求最强的用户也可能更积极接受高成本或高额度Offer。低可能是价格、额度或体验问题，也可能是优质客有更多外部选择。

5）墨西哥七步案例：背景：30天首贷，策略B放宽Cutoff并提额。数据：各20k申请；A Approval30%、Take-up60%、Avg Ticket1,400、FPD7 13%、EL/Loan120、Margin/Loan75；B Approval36%、Take-up72%、Avg Ticket1,900、FPD7 16%、EL205、Margin47。现象：Take-up升12pp但利润/Loan下降；拆解：Channel C×Low Score×Limit≥2,000 Take-up 82%，Margin -35；Medium Score×Limit≤1,800 Take-up67%，Margin82。根因：高Take-up与风险集中相关，但额度/渠道/价格同步变化，不能单一归因。决策：边缘段降额并停止高补贴，中风险正利润段保留Challenger。结果：观察两个FPD7 Cohort及MOB1 DPD30+、EL和LTV。

6）诊断逻辑：Offer口径/技术 → Price/Term/Limit → Channel/Score Mix → Disbursement Failure → FPD/EL/Margin。

7）策略动作：低Take-up低风险：优化价格/Offer UX；高Take-up高风险：降额度、收Cutoff或减少激励；特定渠道异常：降量/重定向；技术失败：先修放款链路。

8）常见误区：点击按钮=Take-up；未成熟Offer进入分母；Take-up越高越好；不同Price/Term直接横比；忽略Selection Bias。

9）推荐拆分：Channel、Campaign、Score、Limit、Term、Price、Coupon、新老客、Region、Device、Strategy Version。

10）预警方式：同产品同Offer Version历史基线；设最小成熟Offer样本。示例黄灯：Take-up突然上升且低Score占比/EL同步上升；红灯：Margin/Loan转负。均为内部示例。

11）与其他指标关系：Approval → Offer → Take-up → Disbursement → EAD → FPD/EL → Contribution Margin → LTV。

12）小练习

Take-up从55%升到72%，但EL/Loan从130升到210、Margin从80降到45，是否应把72%作为增长目标？答案：不应；应优化风险调整后的Margin/LTV。

2. Average Ticket｜平均放款件均/平均提款金额

1）指标是什么：成功放款贷款的平均实际到账本金。大白话：每一笔真正放出去多少钱。

2）为什么重要：贷中同步风险与经营指标，直接影响EAD、Funding Cost、收入和金额坏账。解决“件数风险没怎么变，但金额损失暴涨”的问题。

3）精确定义与公式：Average Ticket = 成功放款本金总额 ÷ 成功放款贷款数必须使用实际Disbursed Amount而非Approved Limit；固定币种、退款/撤销、分期拆单和续借口径。建议同时报Median、P75/P90及Average EAD。

4）如何看高低：高可以提高收入和客户价值，但也放大损失与资金占用；低可能降低风险，也可能压低Take-up/LTV。不能脱离Score、Utilization、EL和Margin判断。

5）墨西哥七步案例：背景：复借V6提高额度上限。数据：样本12k；Avg Ticket1,500→1,980，Approval 48%→49%，件数FPD7 9.8%→10.4%，金额FPD10.5%→14.8%，Funding/Loan75→108，Margin/Loan96→70。现象：件数风险小幅变差但金额风险明显恶化。拆解：Low Score×Limit≥2,400平均提款2,310、金额FPD19%；高Score段保持稳定。根因：额度放大与金额风险相关，但需排除渠道和价格变化。决策：低Score恢复旧Limit，高Score保留提额。结果：观察Amount FPD、MOB1/2 DPD30+、EL和Total Margin两个Vintage。

6）诊断逻辑：Limit/Offer → Take-up/Utilization → Score/Channel → 件数vs金额FPD → Funding/EL/Margin。

7）策略动作：低Score高Ticket降额；高Score正Margin可提额；资金紧张时控高Ticket Segment；高Ticket低Take-up检查Offer与价格。

8）常见误区：Approved Limit当Ticket；均值掩盖长尾；只看件数FPD；新老客混用；忽略分笔放款/拆单。

9）推荐拆分：Score、Limit、Term、Channel、Cycle、新老客、Income、DTI/PTI、Strategy、Region。

10）预警方式：同时监控Average/Median/P90 Ticket与Amount FPD/EL。示例黄灯：Ticket上升超过自身历史波动且金额FPD同步恶化；非行业统一阈值。

11）关系：Approved Limit → Take-up/Utilization → Average Ticket/EAD → Revenue & Funding → Amount Bad/EL → Margin。

12）小练习

件数FPD从10%降到9.5%，但Average Ticket+40%、金额FPD从11%升到15%，能否判断风险改善？答案：不能，金额暴露明显恶化。

3. Funding Cost｜资金成本

1）指标是什么：为了支持贷款资产，公司为债务/资金安排实际承担的利息、费用与结构成本。大白话：每放出这笔钱，资金本身要花多少钱。

2）为什么重要：经营/利润的上游同步指标，也是定价、额度、期限和增长预算约束。资金成本上升时，风险不变也可能让原本盈利的Segment变亏。

3）精确定义与公式：Funding Cost / Loan = 分配至该贷款生命周期的利息 + Commitment Fee + 结构/对冲/流动性等可归属资金成本Annualized Funding Rate（示例）= 年化资金费用 ÷ 平均计息资金余额不同用途可有不同口径，必须声明是否包含未使用额度费、FX hedge、结构费及税费；不要把Banxico参考利率/TIIE直接等同实际Funding Cost。

4）如何看高低：通常越低越好，但低成本资金可能伴随更严格Covenant、短期限或集中度风险；高成本资金若支撑高Margin客群也可能可接受。

5）墨西哥七步案例：背景：USD资金线缩减，新增MXN仓储融资。数据：平均Funding/Loan 70→108；Avg Ticket1,400→1,900；Revenue390→480；EL120→205；Margin75→47；Facility Utilization 62%→84%。现象：收入提高但资金与风险成本吞噬新增收入。拆解：高Limit段资金占用最长、未使用承诺费也上升。根因：Funding上涨与产品提额同步发生，二者共同压缩利润。决策：高风险高Ticket段降额、调整资金分配；对正Margin高Score客群保留额度。结果：观察Funding/Disbursement、Margin、Liquidity Buffer和Covenant Headroom。

6）诊断逻辑：资金合同/口径 → Reference Rate/Spread → Utilization/Commitment → Term/FX → Segment Margin。

7）策略动作：Spread高：重谈/换资金；Commitment浪费：优化提款计划；FX暴露：对冲/币种匹配；资金紧张：优先分配给风险调整后ROI更高Segment。

8）常见误区：政策利率=资金成本；漏算Commitment Fee；年化率与单笔绝对成本混用；美元/比索成本不做FX处理。

9）推荐拆分：Funding Source、Currency、Product、Term、Score、Limit、Vintage、Strategy、Region。

10）预警方式：Reference Rate、Spread、Utilization、Covenant、Maturity Ladder联合。示例黄灯：Funding/Loan连续上升且Margin/Loan下降；红灯叠加Liquidity/Covenant压力。

11）关系：Reference Rate + Spread/Fees → Funding Cost → Price/Limit → Contribution Margin → LTV/ROI。

12）小练习

Revenue/Loan增加80，但Funding +38、EL +85，其他成本不变，Margin会改善吗？答案：不会，净影响约-43。

4. Risk-adjusted ROI｜风险调整后投资回报率

1）指标是什么：把收入扣除资金、获客、预期损失和可变成本后，再与实际占用资金/资本比较。大白话：承担这些风险、占用这些钱，最后赚得值不值。

2）为什么重要：经营/利润的综合滞后/同步指标，适用于渠道、策略、产品和资金分配；避免只看Approval、Volume或Revenue。

3）精确定义与公式：不存在唯一行业公式，必须在内部数据字典固定。例如：Risk-adjusted ROI = (Revenue − Funding Cost − CAC − Expected/Actual Credit Loss − Variable Cost) ÷ Average Funded Capital也可按Origination Principal或Allocated Capital作分母，但不能跨口径直接比较；预测期用EL，成熟期可用Actual Loss并单独标注。

4）如何看高低：通常越高越好，但短期ROI高可能来自高价格、低增长或尚未成熟的坏账；必须看Maturity、Compliance、Complaint与LTV。

5）墨西哥七步案例：背景同A/B增长实验。数据：A放款3,600单、Margin/Loan75、总Margin270k、平均资金占用约MXN3.2m，简化ROI约8.4%；B放款5,184单、Margin47、总Margin243.6k、平均资金占用约MXN6.0m，简化ROI约4.1%。现象：B量更大但资本效率更差。拆解：Low Score×High Limit为负ROI，Medium Score×Low Limit保持正。根因：EAD和EL扩张快于收入。决策：削减负ROI段，保留正ROI Challenger。结果：等待FPD7、MOB1、Repeat/LTV成熟后复核。

6）诊断逻辑：分母/资本口径 → Revenue → Funding/CAC → PD×LGD×EAD/Actual Loss → Segment/Vintage → LTV。

7）策略动作：负ROI来自PD则收准入；来自EAD则降额度；来自Funding则调资金；来自CAC则降量/换渠道；高ROI低量可谨慎扩量。

8）常见误区：Revenue/Principal当ROI；未成熟Bad用0；不同资本分母横比；忽略CAC/资金成本；高ROI就无视合规/用户保护。

9）推荐拆分：Channel、Campaign、Score、Limit、Term、Product、New/Repeat、Funding Source、Strategy、Vintage。

10）预警方式：同成熟期、同资本口径比较。示例红灯：Marginal ROI≤0且连续成熟Cohort EL恶化；黄灯：ROI下降但仍为正且量快速扩张。均为内部示例。

11）关系：Traffic/CAC → Approval/Take-up → EAD → Revenue − Funding − EL − Cost = Margin → Capital → Risk-adjusted ROI → LTV/Portfolio Allocation。

12）小练习

A总Margin270k、资金占用3.2m；B总Margin243.6k、资金占用6.0m，简化ROI谁高？答案：A约8.4%，B约4.1%。

所有案例数字为内部训练模拟，不构成行业标准或个别授信建议。
