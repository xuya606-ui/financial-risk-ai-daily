今日风控指标：额度、负债能力与件均

今天新增4个现金贷高频指标：Limit Utilization Rate、Average Ticket、Debt-to-Income (DTI)、Payment-to-Income (PTI)。案例均为墨西哥现金贷模拟数据，不代表真实公司或行业统一阈值。

1. Limit Utilization Rate｜额度使用率

授信EAD同步指标

1）指标是什么：大白话：给了用户多少额度，他实际用了多少。对于一次性现金贷，更准确的名称是“初始额度使用率/Initial Utilization”；循环额度则可按余额使用率持续监控。

2）为什么重要：它直接连接Limit与EAD。额度给得高但用户只借少量，风险暴露未必同步上升；如果边缘客群把新增额度全部用满，则提额会快速放大金额风险。

一次性现金贷 Initial Utilization = Disbursed Amount ÷ Approved Limit
循环额度 Utilization = Outstanding Balance ÷ Available Credit Limit

3）精确定义与口径：必须区分一次性贷款与循环额度；分母用审批额度还是当前有效额度要固定；退款、失败放款、额度过期和分批提款处理要一致。一次性现金贷通常以订单/用户首次放款为主，循环额度更适合账户时点口径。

4）如何看高低：高意味着用户更积极使用额度，但不一定“越高越好”。高风险用户可能有更强提款需求；低Utilization也可能意味着额度过大、产品吸引力不足或流程阻塞。

5）墨西哥现金贷案例七步法（模拟）

背景：复借客Limit从MXN2,000提升到2,800。
数据：样本6,000；Utilization 63%→78%；件均1,450→2,050；FPD7件数9.8%→10.4%；金额FPD10.5%→14.1%；Contribution Margin/人 214→199。
现象：件数风险变化不大，但金额风险和利润明显恶化。
拆解：Score×Limit后，最低两档Score在Limit≥2,400时Utilization超过90%，金额FPD达18%。
根因：新增额度主要被边缘客群使用，EAD被放大；是否完全由提额造成需用Champion/Challenger验证。
决策：中高Score保留提额；低Score降低提额步长或上限，并在提款前复核多头/账户风险。
观察结果：FPD7成熟后继续看MOB1/2 Vintage、EL和Contribution Margin。

6）诊断逻辑：Limit变化 → Take-up → Utilization → Score/多头 → 件数vs金额FPD → EL/Profit。

7）策略动作：低风险高Utilization：可考虑扩大；边缘客高Utilization：降Limit/分步提额；Utilization突然下降：查额度展示、产品成本和提款流程。

8）常见误区：把Take-up和Utilization混用；一次性贷款与循环额度公式混用；只看平均值忽略高Limit尾部。

9）推荐拆分：Score、Limit、Term、新老客、Channel、Campaign、Strategy Version、地区、设备风险。

10）预警方式：同Score、同策略版本与最近稳定8周基线比较；高Limit档Utilization和金额FPD同时跳升时优先预警。任何数值阈值均应使用内部历史校准。

11）指标关系：Approval/Limit → Take-up → Utilization → EAD → FPD/Vintage → EL → Contribution Margin。

12）小练习

两个Score相同的客群，A额度MXN1,500且Utilization 80%，B额度MXN2,500且Utilization 55%。平均实际提款分别是多少？

参考答案：A≈MXN1,200；B≈MXN1,375。B的Utilization更低，但EAD仍更高。

2. Average Ticket / Average Disbursement｜平均放款件均

经营额度同步指标

1）指标是什么：大白话：平均每笔成功放款实际借出去多少钱。

2）为什么重要：件均决定资产规模和EAD，也是收入、资金成本、金额坏账和催收成本的重要上游变量。

Average Ticket = Total Disbursed Principal ÷ Number of Successfully Disbursed Loans

3）精确定义与口径：分子是实际成功到账本金，不应混入失败、撤销或仅授信未提款金额；分母按成功放款订单。若按用户计算“人均放款”应单独命名。

4）如何看高低：件均提高可能提升利息收入和资金利用率，但也会提高EAD。件均下降也不一定坏，可能是主动降低边缘客额度后利润改善。

5）墨西哥现金贷案例七步法（模拟）

背景：渠道B为了提升放款额，提高首贷Limit。
数据：件均MXN1,300→1,750；Approval 31%→31%；Take-up 48%→54%；FPD7件数15%→16%；FPD7金额16%→21%；Risk-adjusted ROI 7.5%→4.3%。
现象：件均和放款规模上涨，但金额风险与ROI变差。
拆解：低Score×Limit≥2,000贡献了70%的新增放款额和大部分金额FPD。
根因：新增本金集中在风险边缘人群，新增收入没有覆盖EL和资金成本。
决策：保留中高Score额度，提高低风险客件均；低Score恢复较低上限。
观察：金额FPD、Vintage、EL、Contribution Margin而不是只看件均。

6）诊断逻辑：件均变化 → Limit/Utilization → Score结构 → 金额FPD → Funding Cost/EL → Profit。

7）策略动作：件均升且利润升：可继续；件均升但金额风险恶化：限制边缘Score；件均下降：区分风控主动降额还是用户提款意愿下降。

8）常见误区：把Approved Limit当件均；只看件均不看样本结构；件均上涨直接等价为收入上涨。

9）拆分：Channel、Score、Limit、Term、新老客、Strategy Version、Funding Source。

10）预警：件均与金额FPD、EL、Contribution Margin联合预警；单一件均不设“越高越好”的目标。

11）关系：Limit × Utilization → Average Ticket/EAD → Revenue & EL → Risk-adjusted Return。

12）小练习

件均上涨25%，件数FPD只涨1pp，但金额FPD涨5pp。优先排查什么？

参考答案：Score×Limit分布以及高额度坏客占比。

3. DTI｜Debt-to-Income Ratio｜债务收入比

偿付能力贷前领先指标

1）指标是什么：大白话：用户每月需要承担的全部债务偿付，相当于可验证月收入的多少。

2）为什么重要：用于判断总负债压力和多头借贷后的偿付能力，是准入、额度和定价的重要约束变量。

示例DTI = Total Monthly Debt Payments ÷ Verified Monthly Income

3）精确定义与口径：必须固定收入用Gross还是Net、债务是否包含本笔新贷款、信用卡最低还款/分期如何估算、无收入或收入不稳定如何处理。若公司另有“Outstanding Debt ÷ Annual Income”口径必须另命名，不能混用。

4）如何看高低：通常越高偿付压力越大，但低DTI不等于低风险：收入可能虚报、征信不完整或存在未上征信债务。

5）墨西哥现金贷案例七步法（模拟）

背景：首贷新增征信多头和收入验证。
数据：DTI<25%组FPD7=10%；25%-45%=15%；>45%=24%；但“DTI<25% + 无收入验证 + 近期3+查询”组FPD7=21%。
现象：DTI整体有明显风险梯度，但部分低DTI用户仍高风险。
拆解：Income Verification×Bureau Inquiry×Device Risk后发现，低DTI异常组主要来自收入不可验证和征信薄档。
根因：DTI不是错误，而是收入/债务数据不完整导致假低值。
决策：DTI高组限额或拒绝；低DTI但数据不可靠者增加收入/银行卡二验。
观察：FPD7、MOB1 DPD30+、申诉和Approval。

6）诊断逻辑：Income Quality → Bureau Coverage → DTI分布 → 多头/查询 → FPD/Vintage。

7）策略动作：高DTI：降额/缩短或拒绝；中等DTI：结合Score/PTI分层；低DTI但数据弱：补验证。

8）常见误区：Gross/Net收入混用；把未验证自报收入当真实；不同产品的债务支付频率未统一。

9）拆分：Income Source、Bureau Coverage、Score、Channel、Region、New/Repeat、Term。

10）预警：监控DTI分布漂移和高DTI放款占比；阈值必须用本产品历史损失和收入数据校准。

11）关系：Income + Existing Debt → DTI → Limit/PTI → FPD/Bad → EL。

12）小练习

用户可验证月收入MXN12,000，现有月债务偿付MXN3,600，则DTI是多少？

参考答案：30%。是否可接受取决于产品、收入质量、Score和内部风险成本，不存在通用统一阈值。

4. PTI｜Payment-to-Income Ratio｜本笔还款收入比

额度/期限偿付能力领先指标

1）指标是什么：大白话：这笔新贷款每期要还的钱，占用户同期可验证收入的多少。

2）为什么重要：DTI看总债务，PTI更直接衡量“新增这笔贷款是否把月度/周期现金流压得太紧”，适合Limit与Term设计。

PTI = Scheduled Periodic Payment for New Loan ÷ Verified Income for Same Period

3）精确定义与口径：还款周期和收入周期必须一致；7天/14天现金贷不能直接拿月还款除月收入而不做周期匹配。应明确是否包含费用、利息和一次性收费。

4）如何看高低：通常越高还款压力越大；但极低PTI也可能意味着额度过小、产品没有吸引力或优质用户流失。要和风险调整后利润一起看。

5）墨西哥现金贷案例七步法（模拟）

背景：14天期首贷把Limit上调。
数据：PTI<15%组FPD7=9%；15%-25%=14%；25%-35%=20%；>35%=29%。同时高PTI组Take-up达72%。
现象：风险越高的人反而更愿意借满额度。
拆解：高PTI×近期多头≥3组FPD7达36%，而高PTI但稳定复借客只有17%。
根因：PTI与流动性压力相关，但新老客/历史还款显著调节风险。
决策：首贷高PTI严格限额；复借稳定客允许更高PTI但按历史DPD与多头动态控制。
观察：FPD3/7、Roll、复借率、Contribution Margin。

6）诊断逻辑：Income Period → Payment Schedule → PTI → New/Repeat → 多头/Score → FPD。

7）策略动作：高PTI：降额、延长期限（需同时评估总成本和平台/法律要求）或拒绝；中等PTI：差异化定价/验证；低PTI：评估是否存在过度保守导致转化损失。

8）常见误区：周期不匹配；只算本金不含费用；PTI低就自动提额。

9）拆分：Term、Limit、New/Repeat、Income Frequency、Channel、Score、多头。

10）预警：按产品期限建立PTI分布基线，并结合FPD3/7；阈值均为内部成本函数和历史标签校准结果。

11）关系：Limit/Term/Price → PTI → Take-up/Utilization → FPD → EL → Profit。

12）小练习

用户14天可验证收入MXN5,000，本笔14天到期需还MXN1,250，则PTI是多少？

参考答案：25%。是否适合放款仍需结合总DTI、Score、多头、新老客和内部利润模型。

今日指标关系树

偿付能力：Income + Existing Debt → DTI；Limit + Term + Price → PTI。

资产生成：Approved Limit → Take-up → Utilization → Average Ticket / EAD。

风险与利润：DTI/PTI + Score → FPD/Vintage → PD/LGD/EAD → EL → Contribution Margin / Risk-adjusted Return。

本页公式和阈值仅用于指标学习。实际业务需要结合墨西哥当地监管、产品期限、收入数据质量、征信覆盖和内部损失函数校准。
