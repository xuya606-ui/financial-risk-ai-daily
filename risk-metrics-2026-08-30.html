2026-08-30复借 / Debt Cycling

今日风控指标完整学习卡

今天新增四个复借与循环额度高频指标：Redraw Rate、Time-to-Redraw、Drawdown Frequency、Balance Rebound Rate。核心学习目标是识别“高复借=高LTV”背后的潜在Debt Cycling，并把复借行为与多头、额度使用、Vintage、EL和利润连接起来。案例数字均为模拟训练数据，不代表行业统一阈值。

今日指标关系链

Repayment → Redraw Rate / Time-to-Redraw → Drawdown Frequency → Utilization / Balance Rebound → EAD → Vintage / Bad → EL → Contribution Margin → LTV

1. Redraw Rate｜还款后再提款率

复借同步指标贷中

1）指标是什么

大白话：已经还款、并且重新获得借款资格的人里，有多少在固定时间内又借了一次。

2）为什么重要

Redraw Rate反映复借活跃度和额度吸引力，也会直接影响EAD、Funding Cost和LTV。它不是单纯“越高越好”：高复借如果集中在高多头、高Utilization、短Time-to-Redraw用户中，可能是Debt Cycling领先信号。

3）精确定义与公式

Redraw Rate@N days = 完成还款后N天内再次成功提款的用户数 ÷ 具备再次提款资格且N天观察窗口成熟的还款用户数

分子：再次成功到账/提款用户，不能只算点击或提交提款。分母：资格恢复且观察窗口成熟用户。需固定Full Repayment定义、资格恢复规则、1d/7d/30d窗口和用户/订单口径。

4）如何看高低

高可能代表复借体验好和营销有效，也可能说明用户持续依赖信贷。低可能代表风险下降，也可能是额度恢复规则、产品故障或竞争流失。

5）墨西哥现金贷案例七步法（模拟）

背景：复借产品把“还款即恢复额度”作为召回卖点。
数据：成熟用户10,000；Redraw@30d 42%→57%；Redraw@1d 18%→34%；Take-up 60%→68%；MOB2 DPD30+金额率11%→16%；单客Contribution Margin MXN235→218。
现象：复借更活跃，但中期风险和利润同时变差。
拆解：风险集中于Redraw@1d + Utilization>90% + 30天Inquiry≥3；Redraw>7天且收入稳定的用户风险基本稳定。
根因：短时间再借与风险恶化高度相关，但不能单独证明还款即恢复额度是因果；营销、额度和客群结构也同期变化。
决策：高风险组合减少恢复额度/增加轻量复核；稳定低风险用户保持即时恢复。
观察结果：未来2个成熟Vintage观察Redraw、DPD30+、EL、投诉和Contribution Margin。

6）诊断逻辑

① 资格恢复/产品规则 → ② Marketing/召回 → ③ Time-to-Redraw → ④ Inquiry/Active Lenders/DTI → ⑤ Limit/Utilization → ⑥ Vintage/EL。

7）策略动作

高Redraw且风险稳定：可保留；高Redraw+高多头/高Utilization：降恢复额度或二验；Redraw突然下降：检查产品、额度有效期、支付和竞争流失。

8）常见误区

误区1：复借率高就等于LTV高。误区2：分母混入尚未恢复资格或观察窗口未成熟用户。误区3：点击提款当成功提款。

9）推荐拆分维度

1d/7d/30d、Score、Limit、Utilization、Inquiry、Active Lenders、New/Repeat Cycle、Channel、Strategy Version。

10）预警方式

使用同策略版本、同复借次数的稳定历史基线；Redraw@1d/7d跳升且MOB1/2风险同步恶化时进入黄/红灯。数值阈值应来自内部成熟样本。

11）与其他指标关系

Repayment → Redraw → Utilization/EAD → Vintage → EL → Contribution Margin → LTV。

12）小练习与参考答案

Redraw@30d从45%升到60%，但MOB2 DPD30+和EL也显著上升。是否应继续把60%当作增长目标？

答案：不应。需要看风险调整后Contribution Margin和高风险重借结构。

2. Time-to-Redraw｜还款到再次提款时间

复借行为风险领先指标

1）指标是什么

大白话：用户还清上一笔后，隔多久又借下一笔。

2）为什么重要

Time-to-Redraw能够识别资金需求强度。极短间隔如果同时出现高Utilization、外部多头和余额快速反弹，常用于发现Debt Cycling。

3）精确定义与公式

Time-to-Redraw = 下一笔成功提款时间 − 上一笔完成Full Repayment的时间

按用户计算，建议报告Median、P25/P75以及0-24h、1-3d、4-7d、8-30d分桶。必须固定“Full Repayment”与成功提款时点。

4）如何看高低

短不一定坏：发薪周期、正常周转会造成快速复借；长也不一定好：可能是竞争流失。需要和收入频率、Inquiry、Utilization和风险结果一起看。

5）案例七步法（模拟）

背景：复借营销Push在还款成功后立即触发。
数据：Median Time-to-Redraw 6.2天→2.1天；0-24h占比18%→34%；该组Utilization=92%，30天Inquiry平均3.6次，MOB2 DPD30+=20%；>7天组MOB2 DPD30+=10%。
现象：极短重借用户风险明显高。
拆解：按Income Frequency、Score、Limit和Inquiry拆分，风险主要出现在高Inquiry边缘Score用户。
根因：短间隔是强相关信号，但需排除发薪日/正常循环行为，不能直接一刀切。
决策：0-24h高风险组合增加Step-up或降低恢复额度；低风险稳定用户不增加无意义摩擦。
结果：观察Redraw、用户放弃、Vintage、EL和投诉。

6）诊断逻辑

① 还款/提款时间准确性 → ② 营销触达 → ③ Income Frequency → ④ Inquiry/DTI → ⑤ Limit/Utilization → ⑥ Vintage。

7）策略动作

短Time+高风险组合：Cooling/二验/降额度；短Time但高Score稳定收入：保持；Time突然变长：排查额度恢复和产品异常。

8）常见误区

误区1：所有24h内重借都判坏。误区2：使用提款申请时间而不是成功到账时间。误区3：忽略发薪周期。

9）推荐拆分维度

0-24h/1-3d/4-7d/8-30d、Income Frequency、Score、Limit、Inquiry、复借次数、Channel。

10）预警方式

看Median和0-24h占比的稳定基线；只有与MOB/Vintage风险同步恶化才升级信用风险预警。

11）指标关系

Repayment → Time-to-Redraw → Frequency/Utilization → Balance Rebound → Vintage/EL。

12）小练习与答案

用户还清2小时后借满额度，但收入稳定、无近期查询；是否直接拒绝？

答案：不能。需要结合历史还款、收入、多头和风险成本综合判断。

3. Drawdown Frequency｜提款频率

循环额度复借同步指标

1）指标是什么

大白话：一个用户在固定周期内实际借了多少次。

2）为什么重要

频率决定资金使用强度、交易成本、EAD周转和潜在Debt Cycling；对于循环额度比单纯“是否复借”更有信息。

3）精确定义与公式

Drawdown Frequency@N days = N天内成功独立提款次数 ÷ 活跃用户（或每用户提款次数分布）

需要排除同一订单拆分放款、系统重试和技术重复；7/30/90天窗口固定。建议同时报告P50/P90。

4）如何看高低

高可能代表活跃度，也可能代表频繁短缺现金；低可能是产品低频使用或额度不足。

5）案例七步法（模拟）

背景：循环额度支持多次小额提款。
数据：30天平均提款次数1.4→2.2；3次以上用户占比10%→22%；该组DTI 49%、Utilization 88%、MOB2 DPD30+=18%，全量为12%。
现象：高频组风险显著更高。
拆解：按单次金额、收入周期、Inquiry和Score发现高频+高DTI是主要风险段。
根因：频率与风险相关，但高频也可能是产品设计（小额多次）造成，需要同时看总EAD。
决策：高频高EAD客群限制频次/恢复额度；低总EAD的稳定高频用户保留。
结果：观察Frequency、EAD、Vintage、支付成本和利润。

6）诊断逻辑

① 独立提款去重 → ② 总EAD/件均 → ③ Income Frequency → ④ DTI/Inquiry → ⑤ Score → ⑥ Vintage/EL。

7）策略动作

高频高风险：限频/降额/二验；高频低EAD稳定客：保留；频率异常跳升：检查营销和产品改版。

8）常见误区

误区1：技术重试计成多次提款。误区2：频率高直接等于坏。误区3：不看总EAD只看次数。

9）拆分维度

7/30/90d、Total EAD、Ticket、Income Frequency、Score、DTI、Inquiry、Cycle。

10）预警方式

监控3+/5+高频用户占比与EAD占比，并联动MOB风险；阈值按产品自己的交易频率校准。

11）指标关系

Frequency × Ticket → EAD → Funding Cost / Vintage / EL → Profit。

12）小练习与答案

用户A每月4次各MXN300，用户B每月2次各MXN1,500。谁风险一定更高？

答案：不能只看频率，还要看总EAD、收入、多头和表现。

4. Balance Rebound Rate｜余额反弹率

债务循环余额风险同步/领先

1）指标是什么

大白话：用户还款后，债务余额又多快恢复到原来高位。

2）为什么重要

单看“按时还款”可能看不出债务是否真正下降。余额持续反弹说明用户可能只是滚动负债，现金流缓冲有限。

3）精确定义与公式

Balance Rebound Rate = 再提款后目标观察时点余额 ÷ 上一次还款前余额
或：Rebound-to-Limit = 再提款后余额 ÷ 当前授信额度

建议固定D+1/D+7或下一次提款完成后的观察点，并说明是相对还款前余额还是额度。

4）如何看高低

高通常表示债务去杠杆不足，但正常短期周转也可能高；低可能是现金流改善，也可能是用户流失。

5）案例七步法（模拟）

背景：复借用户连续三期表现为按时还款。
数据：高Rebound组（>90%）占比20%→35%；该组30天Inquiry=3.2、Time-to-Redraw=0.8天、MOB2 DPD30+=19%；Rebound<50%组DPD30+=9%。
现象：“按时还款”没有转化为余额净下降。
拆解：高Rebound集中在高Utilization、近期多头和额度刚提额用户。
根因：余额反弹与债务依赖相关，但必须排除工资周期和产品额度结构。
决策：高Rebound+多头用户降低提额步长或恢复额度；低风险稳定用户继续正常额度。
结果：观察净余额下降、Vintage、EL和LTV。

6）诊断逻辑

① 余额快照口径 → ② Time-to-Redraw → ③ Utilization → ④ Inquiry/DTI → ⑤ Limit Change → ⑥ Vintage。

7）策略动作

高Rebound高多头：收缩额度/复评；高Rebound但高收入稳定：Challenger；Rebound突然上升：检查营销和额度恢复规则。

8）常见误区

误区1：把余额反弹当成单纯活跃度。误区2：不同额度变化不校正。误区3：只看件数，不看金额暴露。

9）推荐拆分维度

Rebound Band、Limit Change、Score、Inquiry、DTI、Income Frequency、Cycle、Strategy Version。

10）预警方式

同Cycle/Score比较Rebound分布；高Rebound占比和MOB2风险连续同步上升时升级预警。

11）指标关系

Repayment → Rebound → EAD Persistence → Vintage/Bad → EL → LTV。

12）小练习与答案

两个用户都按时还款，A每次还款后余额持续下降，B每次还款后当天恢复到95%额度。谁更需要Debt Cycling监控？

答案：B。
