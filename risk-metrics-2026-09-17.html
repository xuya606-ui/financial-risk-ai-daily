2026-09-17｜逾期迁徙与净流量完整指标学习卡

今日4个指标：Ever 30+ Rate、Early-to-30 Roll Rate、Net Flow to 30+、Charge-off / Write-off Rate。所有阈值仅为内部示例，生产环境必须固定Bucket、Snapshot、成熟期、件数/金额和核销政策。

1. Ever 30+ Rate｜曾经进入30+逾期比例

1）指标是什么：固定放款Cohort在观察窗口内，曾经至少一次达到DPD30+的账户/金额比例。大白话：这批贷款里最终有多少真正跨过了30天逾期线。

2）为什么重要：成熟信用表现指标。比单一月底Current DPD更少被后续Cure、核销或资产年龄结构掩盖，适合渠道/策略/Vintage复盘。

3）定义与公式：Ever30+ = 窗口内任一时点达到DPD≥30的成熟账户 ÷ 同Cohort成熟账户件数和金额分别计算；必须固定MOB窗口、成熟条件、账户/订单口径。

4）如何看高低：通常越低越好，但观察窗口越长天然越高；MOB2与MOB4不可直接比较。

5）墨西哥七步案例：背景：Channel B提额；数据：N10,000、Avg EAD 1,600→2,050、Ever30+@MOB2 14%→19%、Current30+ 11%→12%、FPD7 15%→18%；现象：Current变化小但Ever明显恶化；拆解：Low Score×Limit≥2,000达到25%；根因：风险与额度/渠道高度相关但未证因果；决策：高风险组合降额/降量；结果：观察后两个Vintage同MOB Ever30+、EL与Margin。

6）诊断逻辑：窗口/成熟度 → Current vs Ever → Channel/Score/Limit → Cure/Roll → Bad/EL。

7）策略动作：局部Segment异常先降额/降量；多个Segment同向恶化再考虑收紧Cutoff；若支付故障导致假逾期先修支付。

8）常见误区：不同MOB直接比；Current=Ever；件数/金额混用；核销后忘记历史逾期。

9）推荐拆分：Vintage、MOB、Channel、Campaign、Score、Limit、Term、新老客、Strategy。

10）预警方式：同MOB历史稳定带 + 最小样本量；连续两个成熟Vintage超自身稳定区间可设内部黄灯。

11）与其他指标关系：FPD/Roll → Ever30+ → Bad → Recovery/LGD → EL。

12）小练习

成熟10,000单，1,800单曾进入30+，其中600单后来Cure。Ever30+=18%，不能用期末12%替代。

2. Early-to-30 Roll Rate｜1-29天滚入30+率

1）指标是什么：期初处于1-29DPD的账户/余额中，有多少在固定窗口滚入30+。大白话：早期逾期里有多少没拉回来，继续坏到30天以上。

2）为什么重要：贷后同步/领先指标，常在Bad成熟前发现催收、支付或信用恶化。

3）定义与公式：Roll 1-29→30+ = 期初1-29且进入30+ ÷ 期初Eligible 1-29固定Snapshot频率、件数/金额口径、展期/重组和技术挂账规则。

4）如何看高低：一般越低越好；但展期、重组或技术性延期可能人为压低Roll，不能脱离政策看。

5）墨西哥七步案例：背景：Channel B扩量且早催降人工；数据：12,000到期账户、Roll 28%→39%、30+Cure 31%→22%、MOB1 DPD30+ 12.5%→16.8%；现象：早期逾期更快滚坏；拆解：Channel B×Low Score×High Limit=52%；根因：渠道/额度/触达共变；决策：该Segment降额并恢复人工触达；结果：看2-4周Net Flow、MOB1与Collection Cost。

6）诊断逻辑：Bucket/快照 → Payment Failure → Channel/Score/Limit → RPC/PTP → Cure → DPD30+/Bad。

7）策略动作：支付技术异常先修支付；RPC下降优化触达；信用风险集中则降额/收准入；Vendor异常则切换/降量。

8）常见误区：新增放款混入分母；展期不单列；只看件数；不同观察周期横比。

9）推荐拆分：Channel、Campaign、Score、Limit、Term、Payment Method、RPC、Strategy、Region。

10）预警方式：同账龄/同产品历史带；Roll上升且Cure下降为组合黄灯，阈值用内部基线。

11）与其他指标关系：Payment/RPC → Early Roll → 30+ Balance → Bad/Charge-off。

12）小练习

期初1-29有2,000单，780单进入30+，Roll=39%。

3. Net Flow to 30+｜30+余额净流入率

1）指标是什么：期间内流入30+的余额减去从30+治愈/回收/结清流出的余额，衡量30+风险池净增长。

2）为什么重要：同步指标，把Roll和Cure合并到同一方向判断，回答“坏账池是在扩大还是收缩”。

3）示例公式：Net Flow Rate = (Inflow to 30+ − Cure/Recovery/Settlement Outflow) ÷ Opening 30+ BalanceWrite-off、资产出售、重组应独立列示。

4）如何看高低：长期正值通常意味着30+池扩张；负值通常是收缩，但若来自大额核销，不能解释为信用改善。

5）墨西哥七步案例：背景：同一复借组合；数据：Opening30+ 8.0m、Inflow 3.6m、真实Cure/Recovery流出1.7m、Net +1.9m、Net Flow Rate=23.75%；现象：风险池快速扩张；拆解：Inflow主要来自Channel B高Limit；根因：Roll/Cure共同恶化；决策：降低Inflow同时提升Cure；结果：观察连续4周Net Flow、DPD30+、Charge-off。

6）诊断逻辑：Opening Balance → Inflow来源 → Cure/Recovery → Write-off/Restructure → Segment → Bad/EL。

7）策略动作：Inflow驱动做准入/额度/早催；Cure下降做支付/RPC/Collection；Write-off异常先核查政策。

8）常见误区：Write-off当Cure；期初/期末口径不一致；件数金额混用；Net Flow下降就直接说风险变好。

9）推荐拆分：Vintage、MOB、Channel、Score、Limit、Collection Strategy、Vendor、Region。

10）预警方式：连续多期正净流入 + MOB1 DPD30+/EL恶化，可作为红灯候选；数值阈值用内部历史。

11）与其他指标关系：Roll In − Cure Out → Net Flow → DPD30+ Stock → Bad/Charge-off → Recovery/LGD。

12）小练习

3.6m−1.7m=1.9m；1.9/8.0=23.75%。

4. Charge-off / Write-off Rate｜核销率

1）指标是什么：达到内部核销政策条件并从账面冲销的账户/余额比例。

2）为什么重要：滞后损失确认指标，连接Bad、Recovery、LGD和财务损失；不等于债务免除。

3）定义与公式：常见为期间Gross Write-off ÷ 平均/期初贷款余额或Cohort累计核销/原始放款本金；必须固定gross/net、Recovery-after-write-off、MOB窗口和币种。

4）如何看高低：通常越低越好；但核销天数/政策变化会改变指标，不同政策不可直接横比。

5）墨西哥七步案例：背景：MOB4成熟Vintage；数据：原始本金20m、Gross核销1.8m=9%、上一Vintage8%、Recovery-after-write-off 1.5%→2.5%、高Limit占增量70%；现象：Gross核销恶化但回收有所改善；拆解：Score×Limit×Channel；根因：高EAD相关但需控制Mix；决策：高风险高Limit降额、后段催收分层；结果：看Net Charge-off、Recovery、LGD、Margin。

6）诊断逻辑：Write-off Policy → Gross vs Net → Vintage/MOB → Score/Limit → Recovery → LGD/EL。

7）策略动作：信用驱动收准入/降额；Recovery低改催收/法律策略；政策变化先重算可比口径。

8）常见误区：核销=债务免除；Gross=Net；不同核销天数政策直接比；错误余额分母。

9）推荐拆分：Vintage、MOB、Score、Limit、Channel、Term、Collection Vendor、Fraud/Credit。

10）预警方式：同政策、同MOB；Gross Charge-off 与 Recovery/LGD/Net Loss 联动，不设行业统一绝对阈值。

11）与其他指标关系：DPD90+/Bad → Charge-off → Recovery-after-write-off → LGD → Actual Loss/Margin。

12）小练习

原始本金20m、Gross核销1.8m，Gross=9%；后续回收0.4m，则净损失约7%。
