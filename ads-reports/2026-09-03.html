2）海外投放知识学习

Agentic Ads Operations：Agent、MCP、Skill、Tool 到底分别是什么？

AI Agent 是能够理解目标、读取上下文、调用外部工具并执行动作的 AI 系统；MCP（Model Context Protocol）可以理解成“AI Agent 连接外部平台的标准适配层”；MCP Tool 是一项具体可执行操作，例如 get performance report、update budget、pause ad group；AI Skill 则是把多个 Tool 和业务规则组合成一个更高层工作流，例如“发现素材疲劳后自动推荐替换素材”。TikTok 官方正用 Agentic Hub + MCP Server 把这些能力接入广告管理。

Goal → AI Agent → AI Skill / Workflow → MCP Tools → Ads Platform Action → Measurement → Next Decision

现金贷场景：一个 Agent 可以每天读取 Mexico Campaign 的 Spend、Apply CPA、Approve Rate、首贷 CAC、FPD7 成熟度，然后输出预算建议；但“读取并建议”和“自动写入 Budget”是两个完全不同的风险等级。

适用场景：日报、异常检测、素材疲劳诊断、Budget 建议、Campaign Health 检查、合规材料缺口提示、重复性报表。

常见误区：① 把平台 CPA 当唯一目标，让 Agent 自动把预算迁移到便宜但低质的流量；② 没有 Human Approval 就允许 Agent 改 Budget/Bid/Targeting；③ Agent 可以读取用户级信用、收入、逾期等敏感字段；④ 没有 Change Log 与 Rollback；⑤ 把平台 Tool 权限当成业务权限。

判断方法：自动化权限应按风险分级：Read → Recommend → Approve-to-Write → Auto-Write。现金贷建议先从 Read/Recommend 开始，只有成熟、可回滚、低风险动作才逐步进入 Auto-Write。

3）实操训练

今天做一个“只读 AI 投放 Agent + 扩量审批闸门”

  1. 先只读：允许 Agent 读取 Campaign、Ad Group、Creative、Spend、CPA、Budget、Bid、Learning/Status，不允许修改。
  2. 接后端：增加内部聚合数据：Approve Rate、Disburse Rate、First-loan CAC、FPD7 成熟状态、D30 Contribution；不要把用户级信用评分、收入、逾期等敏感字段发到广告平台。
  3. 定义建议条件：例如只有当 Mature First-loan CAC ≤ 目标 95%、FPD7 不劣于基线 1pct、样本量达到内部成熟门槛时，Agent 才能输出“可测试扩量”。
  4. 增加审批：Budget/Bid 修改先生成 `change_id / old_value / proposed_value / reason / expected_impact / rollback_rule`，由投放或负责人点击批准后才执行。
  5. 次日复盘：比较 Agent 建议组与人工对照组的 Spend、首贷 CAC、FPD、LTV；重点看是否出现“媒体指标改善、业务质量恶化”。

第一阶段内部阈值建议：单次自动预算变化不要超过 10%–15%；超过范围强制人工审批。该阈值是内部控制起点，不是 TikTok/Google 官方标准。

4）业务分析

Agent 把 Apply CPA 降低 25%，为什么首贷 CAC 反而变差？

假设 Agent 只优化 Apply CPA，把 100,000 MXN 预算从 Campaign A 迁移到 Campaign B。

迁移前：Apply CPA = 160 MXN；Approve=40%；Approved→Disburse=70%
理论 First-loan CAC ≈ 160 ÷ (40% × 70%) = 571 MXN

迁移后：Apply CPA = 120 MXN（-25%）；Approve=25%；Approved→Disburse=65%
理论 First-loan CAC ≈ 120 ÷ (25% × 65%) = 738 MXN

平台前端成本明显改善，但首贷 CAC 反而上升约 29%。如果 FPD7 还从 19% 升到 25%，真实风险调整价值会进一步恶化。

所以 Agent 的 Objective 不应只写“最小化 CPA”，而应该是一个多层 Guardrail：

媒体效率约束 + 首贷 CAC 约束 + FPD/Vintage 风险约束 + LTV/Payback 价值约束 + 合规约束

真正需要自动化的是重复判断，不是把经营目标简化成一个平台指标。

5）产品相关

建立 Agentic Ads Control Center

建议在内部投放后台增加一个统一的 Agentic Ads Control Center，把 AI Agent 的权限、建议、审批、执行和回滚全部可视化。

产品经理
定义 Read / Recommend / Approve-to-Write / Auto-Write 权限级别；设计审批、回滚和风险提示。
投放
定义 Budget/Bid/Creative/Targeting 哪些动作可自动化；维护 Campaign 经营目标与媒体阈值。
数据
提供成熟度、CAC、FPD、LTV 的聚合接口；计算 Agent 建议后的真实业务 uplift。
风控
定义 FPD/Vintage/Fraud 红线和成熟期；红线触发时可自动 Block 扩量。
研发
维护 Tool Permission、`change_id`、审计日志、幂等、Rate Limit、Rollback、Kill Switch。

推荐状态机：`Observed → Recommended → Approved → Executed → Monitored → Kept / Rolled Back`。所有自动修改都必须能回答：谁提出、依据什么数据、谁批准、改了什么、何时回滚。
