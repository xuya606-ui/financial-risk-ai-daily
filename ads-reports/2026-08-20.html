1）今日最新资讯

TikTok Search Ads 8 月工作流升级：支持多 Ad Group / 多 Ad，并在创建流程中列出 App Promotion

发生了什么：TikTok 在 2026 年 8 月更新的 Search Ads Campaign 设置文档中，明确写入升级后的创建流程可在一个 Campaign 下创建多个 Ad Group 和多个 Ad；关键词仍只在 Ad Group 层管理。文档同时列出 Search Ads 当前支持的目标包括 Traffic、Sales、Lead Generation 和 App Promotion。TikTok 还建议 Search Ads 的预算设置为出价的约 20 倍，以保证预算与竞价空间。

为什么重要：过去很多现金贷团队把 TikTok 当成 Feed 买量渠道；Search Ads 让用户主动搜索“贷款/信贷/借款相关需求”时进入更高意图链路。结构升级后，可以按搜索意图拆多个 Ad Group，并用不同素材、落地页和关键词进行更清晰的测试。

范围边界：TikTok 的 Search Ads 市场可用性页面明确显示，墨西哥的 Web Conversion 和 Traffic 已处于 Live 状态，Keyword Planner 也支持 Mexico；但该可用性页面当前尚未单独列出墨西哥 App Promotion 的市场状态。虽然 8 月设置文档把 App Promotion 列为支持目标，墨西哥账户是否已经开放仍应以 Ads Manager 实际界面为准，不能只凭文档推断已全量开放。

建议动作：墨西哥团队今天可以先建立 Search Web Conversion 测试；如果账户里已经出现 App Promotion，则单独建立测试 Campaign，不要把 Search Feed 与常规 Feed 混在同一判断口径。

官方原文：TikTok：How to set up a Search Ads Campaign ｜ Search Ads Campaign Availability ｜ Keyword Planner

【墨西哥重点】Search Ads 能投，不代表任何贷款关键词都能投

TikTok 当前把 Financial services 列为 Search Ads 的“Partially open”行业，关键词需要经过审核，并且不同国家可能存在差异。TikTok 的 Search Ads 关键词审核原则明确提醒：不得基于用户的困难、个人困境或敏感特征进行定向，也不能使用不负责任的广告承诺。

同时，TikTok 现行墨西哥金融服务规则仍禁止 APR ≥50% 的高 APR 贷款、Payday Loan，以及还款周期 ≤90 天的短期贷款；金融广告还需符合当地法律、许可/披露要求并限制在成人受众。过去 24 小时未检索到改变这些墨西哥现金贷核心边界的新官方政策更新。

对产品/素材的直接要求：Search 关键词、广告标题、LP/App 页面、实际贷款参数必须一致。不要用“保证放款”“人人可借”“无条件审批”等误导式表达，也不要用带有明显财务困境标签的关键词来寻找脆弱用户。

2）海外投放知识学习

Keyword ≠ Search Term：Search Ads 最重要的四个词

Keyword（关键词）是广告主主动选择、用于告诉平台希望匹配什么搜索意图的词；Search Term / Search Query（搜索词）是用户真实输入的内容。两者不是一回事。

Match Type（匹配方式）决定 Keyword 与 Search Term 要多接近才进入竞价。TikTok Search Ads 主要有 Broad、Phrase、Exact 三种匹配。需要特别注意：TikTok 的 Exact 并不必然等于逐字完全一致，官方说明中仍可能包含近义表达、同义词、语序变化或改写。

Negative Keyword（否定关键词）则是明确告诉平台哪些查询不要触发广告。对现金贷非常重要，因为可以排除与产品无关的“企业贷款、房贷、车贷”等意图，减少无效点击。

Keyword = 你希望买什么意图
Search Term = 用户实际搜了什么
Match Type = 两者允许差多远
Negative Keyword = 明确不想买什么意图

现金贷例子：你设置 Keyword “préstamo personal”，用户真实搜索 “préstamo personal en México” 后触发广告；如果你的产品不做房贷，可以把 “hipoteca” 作为 Negative Keyword，减少错误意图。

常见误区：① 把 Search Term 当成 Keyword；② 一上来全部 Exact，导致量太少；③ 全部 Broad 却不看 Search Terms Report；④ 只看点击成本，不看关键词对应的 Apply→Approve→Disburse 和 FPD。

3）实操训练

今天做第一版“墨西哥现金贷 Search Keyword 测试”

  1. 先用 Keyword Planner：目标国家选 Mexico，收集 40–80 个与个人信贷/在线贷款真实产品相关的候选词，观察搜索量和竞争度。
  2. 按意图拆 Ad Group：建议至少拆成“通用个人贷款需求”“在线/数字信贷”“品牌/产品词”三类，不要把所有词塞进一个组。
  3. 每组保证有效样本：TikTok 建议 Search Ads 新建时每个 Ad Group 不少于约 20 个关键词，并尽可能用 Broad 扩大学习空间；金融行业可以在高风险/高歧义词上更谨慎地用 Phrase/Exact。
  4. 建立 Negative Keyword：排除与你业务不相关的房贷、车贷、企业贷款等意图；不要只屏蔽一个单词版本，TikTok 官方提醒否定关键词并不会自动覆盖所有单复数、拼写错误和同义词。
  5. 预算与出价：设置文档建议预算约为 Bid 的 20 倍；Health Module 对部分 oCPM/Cost Cap 场景把“至少 5 倍 Bid”作为健康门槛。对首轮测试，优先按照 20 倍做保守规划，实在受预算约束也不要低于平台健康门槛。
  6. 第二天复盘：先看 Spend、Impression、CTR、CPC、Search Term relevance、Apply CVR；Approve/Disburse 与 FPD 需要等成熟后再下结论。

4）业务分析

为什么 Search CPC 更高，首贷 CAC 反而可能更低？

因为 Search 流量通常表达了更明确的需求，不能只和 Feed 按 CPC 比价格。假设普通 Feed 的 CPC = 8 MXN、Click→Apply = 4%、Approve = 30%、Approve→Disburse = 65%，则理论首贷 CAC 约为：

8 ÷ (4% × 30% × 65%) ≈ 1,026 MXN

另一个 Search Ad Group 的 CPC = 14 MXN，看上去贵了 75%；但如果 Click→Apply = 9%、Approve = 38%、Approve→Disburse = 72%，理论首贷 CAC 约为：

14 ÷ (9% × 38% × 72%) ≈ 569 MXN

所以真正应该比较的是 关键词/搜索词 → 申请 → 授信 → 放款 → 风险。如果 Search CAC 更低但 FPD/Vintage 更差，仍然不能直接扩量；最终要回到风险调整 LTV 与 ROI。

5）产品相关

把“Search Intent”写进产品与数据链路，而不是只留在广告后台

产品经理
为不同搜索意图设计对应 LP/App 承接；通用贷款意图先解释资格、额度范围、期限与费用，不要一律跳首页。
投放
维护 Campaign → Ad Group → Keyword → Match Type → Creative → Destination 的结构；定期用 Search Terms Report 做扩词和否词。
数据
把 keyword、search_term、match_type、campaign_id、adgroup_id 与 user_id / application_id / loan_id 关联，形成关键词级首贷 CAC 和 FPD。
风控
比较不同搜索意图的人群画像、审批率、欺诈率、FPD/Vintage，识别“高意图但高风险”关键词。
研发
LP/Deep Link 参数必须可靠透传；服务端事件回传要保留 attribution ID、keyword/adgroup 参数并做去重。

可落地页面规则：广告搜“préstamo personal”→进入个人贷款说明/资格页；已安装 App 且符合 Deep Link 条件→进入资格检查或申请入口；不应因为关键词更具体就直接展示“保证额度/保证审批”等无法兑现的结果。

产品合规：个人贷款 LP/App 应确保期限、APR/类似年化成本、代表性总成本示例等披露与真实产品一致；Google 对个人贷款的此类披露要求也可作为跨渠道页面治理的最低基线之一。
