2）海外投放知识学习

核心知识点：Impression Share ≠ Search Quality ≠ Business Value

Impression Share回答：“在你有资格参与的 Search Results 展示里，你拿到了多少？”；Top 1 Impression Share回答：“在你有资格参与的第一广告位展示里，你拿到了多少？”这两个指标主要描述可见度，不直接描述借款人质量。

对现金贷，更完整的判断链应当是：

Eligible Search Demand → Impression Share → Top 1 Share → Click/LPV → Apply → Approve → Disburse → Search First-loan CAC → FPD/Vintage → Risk-adjusted LTV

例如某关键词的 Impression Share 很低，可能代表预算/出价不足，也可能是关键词覆盖或素材相关性不足；但即使把 Share 拉高，如果新增流量的 Approve Rate 下滑或 FPD 上升，业务上仍然可能是负优化。

今天新增到基础指标体系的推荐指标：

Search Impression Share
Captured Eligible Search Impressions ÷ Eligible Search Impressions
Top 1 Impression Share
Captured Eligible Top-1 Search Impressions ÷ Eligible Top-1 Search Impressions
Search→Disburse Rate
Search-attributed First Disbursed Borrowers ÷ Matched Search Clicks/Visits
Search First-loan CAC
Search Spend ÷ First Disbursed Borrowers
Search FPD Delta
Search Cohort Mature FPD − Comparable Non-search Baseline FPD

常见误区：Impression Share 低就直接加预算；Top 1 Share 越高越好；Search CPC 高就判断搜索流量贵；把 TopSearch 当作直接转化产品。TopSearch 当前官方定位是 Reach/上中层漏斗的第一 sponsored position，最终仍需用后端 Cohort 证明经营价值。

3）实操训练

Mexico TikTok Search Intent Audit：从 Keyword Share 一路对到首贷

  1. 确认能力：先检查账户是否真正开放 Search Ads Campaign、Impression Share、TopSearch；金融服务属于受限制垂类，不要假设所有功能/关键词都可用。
  2. 导出最近 28 天：campaign_id / adgroup_id / keyword / search_query / match_type / impression_share / top1_impression_share / impressions / clicks / spend / creative_id / landing_url。
  3. 按意图分组：品牌词、品类词、需求词、竞品词、季节词；金融敏感/高风险词单独进入 Compliance Review。
  4. 接 Backend：search_query → session/user_id → application_id → loan_id，产出 Apply、Approve、Disburse、Search First-loan CAC、FPD7/Vintage、LTV。
  5. 按“缺量原因”处理：满预算且业务质量健康 → 小步加预算；未花满预算 → 查 Bid；Query 少 → 查 Keyword Coverage；Share 低且 Creative Relevance 差 → 改关键词-素材-页面匹配，不先加钱。
  6. TopSearch 只做小范围：如果账户/市场支持且金融类别允许，优先用品牌/高意图品类词测试，不把所有贷款词直接推到第一位。

内部判断逻辑（非 TikTok 官方阈值）：如果某搜索意图组 Impression Share <40%，且 Search First-loan CAC ≤ 非搜索成熟 CAC 的 90%、FPD Delta ≤ +1pct，可测试 10%–15% 的 Budget/Bid 小步提升；如果 Share 已 >70% 但首贷量仍低，优先扩 Keyword/Creative/LP Coverage，而不是继续抬价；如果 Search FPD Delta >+2pct 或 Approve Rate 明显低于基线，即使 CPA 很漂亮也暂停扩量。

次日复盘：先看 Share、Spend、Query Coverage、CTR/CPC 与 LPV；首贷 CAC、FPD/Vintage 必须等同成熟窗口再判断。

4）业务分析

Search CPC 更贵，不代表首贷更贵

假设两个 Mexico 流量组都花 100,000 MXN：

Search
2,000 Clicks，CPC=50 MXN；800 Apply；Approve 40%；Disburse 75% → 240 首贷；First-loan CAC≈417 MXN；FPD7=17%。
Feed
4,000 Clicks，CPC=25 MXN；900 Apply；Approve 30%；Disburse 67% → 181 首贷；First-loan CAC≈552 MXN；FPD7=20%。

Search 的 CPC 是 Feed 的 2 倍，但因为搜索意图更强、审批和放款转化更好，最终首贷 CAC 反而低约 24%，风险也更健康。

反过来，如果 Search Impression Share 从 35% 拉到 70% 后，新增曝光主要来自更泛的 Query，Approve 从 40% 掉到 28%、FPD7 升到 23%，那“Search Share 翻倍”并不能证明业务变好。最重要的经营问题是：

新增 Search Share 带来的边际首贷，是否仍满足 Allowable CAC + FPD/Vintage + LTV/Payback Guardrail？

因此以后 Search 扩量不要只复盘 CPC/CTR/Share，至少同时展示 Search First-loan CAC、Approve Rate、FPD Delta、Risk-adjusted LTV/CAC。

5）产品相关

Search Intent Registry + Query-to-Landing Contract

产品经理
定义 query_intent、允许承接的 product_version、额度/期限/费用、landing_version、disclosure_version、Deep Link/Fallback。
投放
维护 keyword/search_query、match_type、negative keywords、Bid/Budget、Search/TopSearch、Creative 与 Landing 映射。
数据
打通 query/keyword → session → application → loan，并按 Intent Cohort 输出 CAC、Approve、FPD/Vintage、LTV。
风控
比较 Brand/Category/Need-state 等搜索意图组的用户质量，防止泛词扩量造成边际风险恶化。
研发
保证 UTM/Click ID、Deep Link、landing_version、event_id、application_id、loan_id 稳定串联；支持 URL/文案快速回滚。

Search Intent Registry：market / platform / campaign_id / keyword / query_cluster / intent_type / match_type / compliance_status / owner

Query-to-Landing Contract：query_cluster / eligible_url / app_destination / product_version / disclosure_version / approved_copy_hash / fallback / effective_from

产品侧的目标不是“让搜索词都能落地”，而是保证每种搜索意图都进入正确、真实、可披露、可继续追踪的贷款承接路径。
