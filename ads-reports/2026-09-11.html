2）海外投放知识学习

Localization ≠ Translation：金融广告需要“不可漂移”的合规语义层

Translation解决语言转换；Localization还要解决目标市场的语言习惯、产品事实、用户理解和监管披露。金融广告真正需要的是后者。

例如英文素材写 “You may qualify for up to MXN 10,000, subject to approval.”。若机器翻译弱化 may / up to / subject to approval，用户可能理解为“保证获得 10,000 MXN”。这不仅是文案问题，也会影响投诉、审批质量和合规。

建议将素材分成：可灵活优化的 Creative Layer（Hook、场景、语气、节奏、字幕风格）与不可任意改写的 Compliance Lock（主体、金额、期限、APR/费用、资格/审批限制、必要 Disclaimer）。

Source Creative → Translation / Dubbing → Language QA → Compliance Lock → Locale Routing → LP/App Locale → Apply → Approve → Disburse → FPD/Vintage

判断方法：先看语言是否正确，再看金融语义是否保持，最后看是否提升投放效率。Device Language 只是交付信号之一，不等于国籍、居住地、贷款资格或业务 Locale。

常见误区：机器翻译正确=本地化正确；CTR 提升=理解更准确；Device Language=业务 Locale；平台审核通过=翻译永久有效；不同西语市场无需本地审核即可共用同一金融文案。

3）实操训练

Mexico Multilingual Guardrail Test

  1. Baseline：保留现有人工审核 es-MX 素材作为基准，不同时改变产品、Optimization Event、预算和 LP 版本。
  2. 确认可用性：在 Ads generation 中检查 Multilingual Tool 是否真的对账户开放，并读取实际支持的 Source/Output Language。
  3. 关键语义：抽取 Amount、Tenor、APR/Fees、Approval Condition、Disbursement Time、Eligibility、Legal Entity、Privacy/Permissions、CTA、Disclaimer 10 类字段。
  4. 逐语言 QA：对音频和字幕逐项比对 Canonical es-MX Copy，记录 translation_variant_id / creative_id / language / product_version / disclosure_version / qa_status。
  5. 经营对比：比较 Impression、CTR、CPI/CPA、KYC、Apply、Approve、Disburse、First-loan CAC；FPD/Vintage 等 Cohort 成熟后再比较。
  6. 次日复盘：先看语言路由、投诉、语义事故和浅层媒体指标；不要在 D0 直接判断风险。

内部 Guardrail：Localized Asset Compliance Pass Rate = 100% 才进入自动扩量；金额、期限、APR/费用、审批保证、到账时效出现重大 Translation Incident 时直接停用该 Variant。100% 是内部金融治理建议，不是 TikTok 官方 KPI。

4）业务分析

CPI 便宜 20%，首贷 CAC 仍可能贵约 50%

假设两组 Mexico TikTok Smart+ 都花 100,000 MXN：

A｜人工 es-MX：4,000 Install → CPI 25
KYC 50%=2,000 → Apply 60%=1,200 → Approve 35%=420 → Disburse 70%=294
First-loan CAC ≈ 340 MXN

B｜自动多语言：5,000 Install → CPI 20（便宜20%）
KYC 42%=2,100 → Apply 55%=1,155 → Approve 25%=289 → Disburse 68%=196
First-loan CAC ≈ 510 MXN

B 的 CPI 更低，但首贷 CAC 更高。问题不一定是“多语言工具不好”，而可能是翻译承诺、语言路由或 LP/App Locale 承接偏差，吸引了更多浅层安装却更少可放款用户。

Language Variant → CTR/CPI/CPA → KYC → Apply → Approve → Disburse → First-loan CAC → FPD/Vintage → Risk-adjusted LTV → Payback / ROI

今日结论

对 Mexico 现金贷，Multilingual Tool 的价值不在“少做几条翻译素材”，而在于能否在不破坏金融语义和本地合规的前提下扩大创意供给。最稳妥顺序：Canonical Copy → 自动翻译/配音 → Language QA → Compliance Lock → 小流量验证 → 首贷 CAC / FPD / LTV → 扩量。
